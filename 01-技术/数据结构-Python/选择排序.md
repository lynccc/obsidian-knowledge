# 选择排序

## 核心概念

选择排序（Selection Sort）每一轮从未排序部分**选择最小元素**，放到已排序部分的末尾。维护两个子列表：已排序（左侧）和未排序（右侧）。

## Python 实现

```python
def selection_sort(a_list):
    n = len(a_list)
    for fill_slot in range(n - 1):
        min_index = fill_slot
        for i in range(fill_slot + 1, n):
            if a_list[i] < a_list[min_index]:
                min_index = i
        a_list[fill_slot], a_list[min_index] = a_list[min_index], a_list[fill_slot]
```

## 时间复杂度

| 情况 | 复杂度 |
|------|--------|
| 最好 | O(n²) |
| 平均 | O(n²) |
| 最坏 | O(n²) |

- 空间复杂度：**O(1)**（原地排序）
- **不稳定排序**：交换可能改变相等元素的相对顺序

## 与冒泡排序的对比

| 特性 | 冒泡排序 | 选择排序 |
|------|---------|---------|
| 交换次数 | O(n²) | **O(n)** |
| 比较次数 | O(n²) | O(n²) |
| 是否稳定 | 是 | 否 |
| 核心操作 | 比较+交换 | 选择+交换 |

选择排序的**交换次数固定为 n-1**，这是它的主要优势。

## 过程示例

```
[5, 3, 8, 1, 2]
第1轮: 找到最小值1(索引3) → [1, 3, 8, 5, 2]
第2轮: 找到最小值2(索引4) → [1, 2, 8, 5, 3]
第3轮: 找到最小值3(索引4) → [1, 2, 3, 5, 8]
第4轮: 找到最小值5(索引3) → [1, 2, 3, 5, 8]
```

## 关键要点

- 每轮确定一个元素的最终位置
- 交换次数最少（O(n)），适合交换代价高的场景
- 无论输入如何，比较次数固定
- 简单直观，但效率不高
