# 链表（Linked List）

## 🗣️ 通俗讲解

> 想象一条铁链——每个环节（节点）都「钩住」下一个环节。要找第10个环节，必须从头一个一个往后摸，不能直接跳过去。好处是中间断开插入新环节很方便，不用像数组那样把后面所有元素挪开。

📖 **想看更深入的理论分析？** → [[列表List]]（邓俊辉 C++ 版）

## 核心概念

链表是一种通过**引用（指针）** 将节点串联的线性数据结构。每个节点包含数据域和指向下一个节点的引用。与 Python 列表（动态数组）不同，链表的元素不要求连续存储。

### 无序列表抽象数据类型

| 操作 | 说明 |
|------|------|
| `add(item)` | 头插法添加元素 |
| `remove(item)` | 移除指定元素 |
| `search(item)` | 查找元素是否存在 |
| `isEmpty()` | 判断是否为空 |
| `size()` | 返回元素个数 |
| `append(item)` | 尾部添加 |
| `insert(pos, item)` | 在指定位置插入 |
| `index(item)` | 返回元素索引 |
| `pop(pos)` | 移除并返回指定位置元素 |

### 有序列表抽象数据类型

与无序列表类似，但 `add` 需要保持顺序，`search` 可提前终止。

## 关键要点

- **Node 类**：链表的基本单元，包含 `data` 和 `next` 两个属性。`next` 指向下一个节点，末尾节点的 `next` 为 `None`。
- **无序列表实现**：用 `head` 指向第一个节点。`add` 使用**头插法**（O(1)），`search/remove` 需要遍历（O(n)）。需要 `previous` 引用来删除节点。
- **有序列表实现**：`add` 时需要找到正确位置插入（遍历直到找到更大的元素），`search` 可在遇到更大元素时提前停止。
- **与 Python 列表的区别**：Python `list` 是动态数组，按索引访问 O(1)；链表按索引访问 O(n)，但插入删除（已知位置时）是 O(1)。

## 与其他概念的联系

- Python 内建 `list` 底层是动态数组，见 [[Python列表]]
- 链表是实现栈和队列的另一种方式（避免 `insert(0)` 的 O(n) 代价）
- 双向链表、循环链表是链表的变体
- 可与邓俊辉版 [[列表List]] 对比
- 哈希表的冲突处理（链地址法）使用链表

## 代码示例

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

    def getData(self):
        return self.data

    def getNext(self):
        return self.next

    def setData(self, data):
        self.data = data

    def setNext(self, next_node):
        self.next = next_node


class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head is None

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

    def size(self):
        current = self.head
        count = 0
        while current is not None:
            count += 1
            current = current.getNext()
        return count

    def search(self, item):
        current = self.head
        while current is not None:
            if current.getData() == item:
                return True
            current = current.getNext()
        return False

    def remove(self, item):
        current = self.head
        previous = None
        while current is not None:
            if current.getData() == item:
                if previous is None:
                    self.head = current.getNext()
                else:
                    previous.setNext(current.getNext())
                return
            previous = current
            current = current.getNext()
```
