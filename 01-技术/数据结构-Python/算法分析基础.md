# 算法分析基础

## 核心概念

### 算法 vs 程序
- **算法**：解决问题的有限步骤序列，具有以下特性：
  - 有穷性：有限步骤内终止
  - 确定性：每步无歧义
  - 可行性：每步可执行
  - 输入：零个或多个输入
  - 输出：一个或多个输出
- **程序**：算法的编程语言实现
- **关系**：一个算法可有多种程序实现

### 基准测试的局限性
- **依赖因素**：
  - 硬件配置（CPU、内存）
  - 操作系统
  - Python解释器版本
  - 后台进程
- **问题**：同一算法在不同环境下表现不同
- **结论**：需要平台无关的分析方法

### T(n)函数
- **定义**：算法执行的基本操作数量，表示为问题规模n的函数
- **示例**：
  - 遍历n个元素的列表：T(n) = n
  - 嵌套循环遍历：T(n) = n²
- **化简**：关注增长趋势，忽略常数和低次项

## 关键要点

1. **算法是思想，程序是实现**：分析应关注算法本身
2. **基准测试不够**：需要数学化的分析方法
3. **T(n)是桥梁**：连接问题规模与执行时间
4. **化简的智慧**：大O记法进一步简化T(n)

## 代码示例

```python
# 基准测试示例（展示平台依赖性）
import time

def test_algorithm(func, n):
    start = time.time()
    func(n)
    end = time.time()
    return end - start

# 同一算法在不同n下的表现
def linear_algorithm(n):
    total = 0
    for i in range(n):
        total += i
    return total

# T(n) = n，随n线性增长
times = [test_algorithm(linear_algorithm, n) for n in [1000, 2000, 4000]]
```
