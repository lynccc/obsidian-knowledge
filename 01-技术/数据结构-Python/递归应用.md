# 递归应用

## 核心概念

递归在解决复杂问题时展现出独特优势：问题可自然分解为相同类型的子问题，且具有清晰的终止条件。

## 汉诺塔（Tower of Hanoi）

经典递归问题：将 n 个盘子从源柱移动到目标柱，借助辅助柱。

**递归思路**：
1. 将 n-1 个盘子从源移到辅助柱
2. 将最大的盘子从源移到目标柱
3. 将 n-1 个盘子从辅助移到目标柱

```python
def move_tower(height, from_pole, to_pole, with_pole):
    if height >= 1:
        move_tower(height - 1, from_pole, with_pole, to_pole)
        move_disk(from_pole, to_pole)
        move_tower(height - 1, with_pole, to_pole, from_pole)

def move_disk(from_pole, to_pole):
    print(f"Moving disk from {from_pole} to {to_pole}")
```

- 时间复杂度：**O(2ⁿ - 1)**，指数级增长
- 3 个盘子需 7 步，4 个盘子需 15 步

## 迷宫搜索

使用递归实现**回溯法（backtracking）** 搜索迷宫路径：

```python
def search_from(maze, start_row, start_column):
    maze.update_position(start_row, start_column)
    if maze[start_row][start_column] == OBSTACLE:
        return False
    if maze[start_row][start_column] == TRIED:
        return False
    if maze.is_exit(start_row, start_column):
        return True

    maze.update_position(start_row, start_column, TRIED)
    # 尝试四个方向：北、南、西、东
    found = search_from(maze, start_row - 1, start_column) or \
            search_from(maze, start_row + 1, start_column) or \
            search_from(maze, start_row, start_column - 1) or \
            search_from(maze, start_row, start_column + 1)
    if found:
        maze.update_position(start_row, start_column, PART_OF_PATH)
    else:
        maze.update_position(start_row, start_column, DEAD_END)
    return found
```

**关键**：通过标记已访问位置避免无限循环。

## 递归可视化

使用 Python 的 `turtle` 模块绘制递归图形：

- **分形树**：每次递归绘制两个分支
- **谢尔宾斯基三角形**：递归分割三角形
- **科赫雪花**：递归替换线段

递归深度控制图形复杂度，直观展示递归的自相似特性。

## 关键要点

- 汉诺塔展示了递归如何将复杂问题简化为重复的简单操作
- 迷宫搜索体现了**回溯法**：尝试 → 失败 → 回退 → 换方向
- 递归可视化帮助理解递归的展开过程
- 这些问题用迭代实现会非常复杂，递归更自然
