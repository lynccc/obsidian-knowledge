# 异序词检测

## 核心概念

**异序词（Anagram）**：由相同字符组成但顺序不同的字符串。例如："heart"与"earth"，"python"与"typhon"。

## 四种解决方案对比

### 方案1：清点法 O(n²)
- **思路**：遍历s1每个字符，在s2中查找并标记
- **复杂度**：外层n次 × 内层n次 = O(n²)
- **特点**：直观但效率低

```python
def anagram_check_v1(s1, s2):
    if len(s1) != len(s2):
        return False
    
    s2_list = list(s2)  # 转为列表以便修改
    for char in s1:
        if char in s2_list:
            s2_list.remove(char)
        else:
            return False
    return True
```

### 方案2：排序法 O(n log n)
- **思路**：排序后比较是否相同
- **复杂度**：排序O(n log n) + 比较O(n) = O(n log n)
- **特点**：简洁，利用Python内建排序

```python
def anagram_check_v2(s1, s2):
    if len(s1) != len(s2):
        return False
    return sorted(s1) == sorted(s2)
```

### 方案3：蛮力法 O(n!)
- **思路**：枚举s1的所有排列，检查是否等于s2
- **复杂度**：n个字符的全排列 = n!
- **特点**：理论可行，实际不可接受（n=20时，20! ≈ 2.4×10¹⁸）

```python
from itertools import permutations

def anagram_check_v3(s1, s2):
    if len(s1) != len(s2):
        return False
    return s2 in [''.join(p) for p in permutations(s1)]
```

### 方案4：计数法 O(n)
- **思路**：统计每个字符出现次数，比较计数是否相同
- **复杂度**：遍历s1 O(n) + 遍历s2 O(n) + 比较O(n) = O(n)
- **特点**：**空间换时间**，最优解

```python
def anagram_check_v4(s1, s2):
    if len(s1) != len(s2):
        return False
    
    count1 = {}
    count2 = {}
    
    for char in s1:
        count1[char] = count1.get(char, 0) + 1
    for char in s2:
        count2[char] = count2.get(char, 0) + 1
    
    return count1 == count2
```

## 性能对比

| 方案 | 时间复杂度 | 空间复杂度 | n=10时操作数 | n=20时操作数 |
|------|-----------|-----------|-------------|-------------|
| 清点法 | O(n²) | O(n) | 100 | 400 |
| 排序法 | O(n log n) | O(n) | 33 | 86 |
| 蛮力法 | O(n!) | O(n!) | 3,628,800 | 2.4×10¹⁸ |
| 计数法 | O(n) | O(n) | 20 | 40 |

## 关键要点

1. **算法选择至关重要**：同一问题，不同算法效率相差巨大
2. **空间换时间**：计数法用额外字典换取O(n)时间
3. **避免阶乘复杂度**：蛮力法在实际中不可接受
4. **Python优势**：sorted()和字典操作简化实现
