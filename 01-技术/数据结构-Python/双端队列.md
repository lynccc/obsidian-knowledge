# 双端队列（Deque）

## 核心概念

双端队列（Double-Ended Queue）是允许在**两端**进行插入和删除的线性数据结构，不遵循严格的 FIFO 或 LIFO，可作为栈或队列使用。

### 双端队列抽象数据类型

| 操作 | 说明 |
|------|------|
| `addFront(item)` | 在前端添加元素 |
| `addRear(item)` | 在后端添加元素 |
| `removeFront()` | 移除并返回前端元素 |
| `removeRear()` | 移除并返回后端元素 |
| `isEmpty()` | 判断是否为空 |
| `size()` | 返回元素个数 |

## 关键要点

- **Python 实现**：基于 `list`，`append` 加尾、`insert(0, item)` 加头、`pop()` 删尾、`pop(0)` 删头。注意 `pop(0)` 和 `insert(0)` 是 O(n)，若需高效实现应使用 `collections.deque`。
- **回文检测器**：将字符串逐字符从前端和后端同时添加到双端队列，然后不断从两端移除并比较。若每次移除的字符相同则为回文，不相同则不是。

## 与其他概念的联系

- 双端队列是栈和队列的**泛化**：只用一端就是栈，一端入一端出就是队列
- Python `collections.deque` 是高效的 C 实现，底层是双向链表，两端操作均为 O(1)
- 滑动窗口最大值等算法问题中常用双端队列
- 可与 [[栈]] [[队列]] 对比理解

## 代码示例

```python
class Deque:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def addFront(self, item):
        self.items.append(item)

    def addRear(self, item):
        self.items.insert(0, item)

    def removeFront(self):
        return self.items.pop()

    def removeRear(self):
        return self.items.pop(0)

    def size(self):
        return len(self.items)
```

回文检测：
```python
def palchecker(aStr):
    chardeque = Deque()
    for ch in aStr:
        chardeque.addRear(ch)
    stillEqual = True
    while chardeque.size() > 1 and stillEqual:
        front = chardeque.removeFront()
        rear = chardeque.removeRear()
        if front != rear:
            stillEqual = False
    return stillEqual
```
