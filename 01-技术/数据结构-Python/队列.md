# 队列（Queue）

## 🗣️ 通俗讲解

> 就像排队买奶茶——先来的先服务（enqueue），先走的先出队（dequeue）。这就是「先进先出」（FIFO），跟栈正好反过来。

📖 **想看更深入的理论分析？** → [[队列Queue]]（邓俊辉 C++ 版）

## 核心概念

队列是**先进先出（FIFO）** 的线性数据结构，元素从**队尾**入队，从**队首**出队。

### 队列抽象数据类型

| 操作 | 说明 |
|------|------|
| `enqueue(item)` | 将元素加入队尾 |
| `dequeue()` | 移除并返回队首元素 |
| `isEmpty()` | 判断队列是否为空 |
| `size()` | 返回队列中元素个数 |

## 关键要点

- **Python 实现**：用 `list` 实现，`insert(0, item)` 入队，`pop()` 出队，或用 `collections.deque` 提升性能。注意：列表的 `insert(0)` 是 O(n)，`deque` 的 `appendleft/popleft` 是 O(1)。
- **传土豆模拟**（Hot Potato）：围成一圈传土豆，用队列模拟：所有人入队，每次将队首出队再入队（相当于传给下一个人），第 n 次时队首的人淘汰，直到剩最后一人。
- **打印任务模拟**：用队列模拟打印机任务调度。新任务入队，打印机每秒处理一页，当前任务完成后从队首取下一任务。通过随机数模拟任务到达，统计等待时间。

## 与其他概念的联系

- BFS（广度优先搜索）本质是队列的应用
- 操作系统进程调度、消息队列等都基于此结构
- Python `collections.deque` 是高效双端队列，见 [[双端队列]]
- 可与邓俊辉版 [[队列Queue]] 对比

## 代码示例

```python
class Queue:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def enqueue(self, item):
        self.items.insert(0, item)

    def dequeue(self):
        return self.items.pop()

    def size(self):
        return len(self.items)
```

传土豆模拟：
```python
from pythonds3.basic import Queue

def hotPotato(namelist, num):
    simqueue = Queue()
    for name in namelist:
        simqueue.enqueue(name)
    while simqueue.size() > 1:
        for i in range(num):
            simqueue.enqueue(simqueue.dequeue())
        simqueue.dequeue()  # 淘汰
    return simqueue.dequeue()  # 最后剩下的人
```
