# Python数据类型概览

## 核心概念

Python数据类型分为两大类：原子类型和集合类型。

## 原子类型（不可再分）

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数，任意精度 | `42`, `-10`, `0` |
| `float` | 浮点数，双精度 | `3.14`, `-0.5` |
| `bool` | 布尔值 | `True`, `False` |

## 集合类型（可包含多个元素）

| 类型 | 特点 | 有序 | 可变 | 示例 |
|------|------|------|------|------|
| `list` | 动态数组 | ✓ | ✓ | `[1, 2, 3]` |
| `str` | 字符序列 | ✓ | ✗ | `"hello"` |
| `tuple` | 不可变列表 | ✓ | ✗ | `(1, 2, 3)` |
| `set` | 无序不重复集 | ✗ | ✓ | `{1, 2, 3}` |
| `dict` | 键值对映射 | ✓* | ✓ | `{"a": 1}` |

*Python 3.7+字典保持插入顺序

## 关键要点

### 可变性对比
- **可变**：`list`、`set`、`dict` - 创建后可修改
- **不可变**：`int`、`float`、`bool`、`str`、`tuple` - 创建后不可修改

### 序列类型
- `list`、`str`、`tuple` 都是序列类型
- 支持索引、切片、迭代等操作
- 底层实现不同，性能特性各异

### 集合类型
- `set`：基于散列表，元素唯一，支持集合运算
- `dict`：基于散列表，键值对存储，查找O(1)

## 代码示例

```python
# 原子类型
x = 42          # int
y = 3.14        # float
flag = True     # bool

# 集合类型
my_list = [1, 2, 3]        # 可变序列
my_str = "hello"           # 不可变序列
my_tuple = (1, 2, 3)       # 不可变序列
my_set = {1, 2, 3}         # 无序不重复
my_dict = {"a": 1, "b": 2} # 键值对

# 类型检查
type(42)        # <class 'int'>
isinstance(42, int)  # True
```
