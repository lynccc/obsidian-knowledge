# 八叉树量化

## 核心概念

**图像量化**是将图像中大量的颜色减少到一个较小的颜色集合，从而减小文件体积。本节从朴素方法出发，逐步引入**八叉树**来高效实现颜色量化。

### 数字图像基础

彩色图像由像素组成，每个像素用 RGB 三通道表示（每通道 0-255），共可表示 256³ ≈ 1677 万种颜色。量化就是将这些颜色映射到一个较小的调色板。

### 朴素量化

最简单的方法是将 RGB 各通道均匀分段（如每 32 为一段），将每个像素映射到最近的"桶"中。缺点是颜色分布不均匀时效果差。

### 八叉树量化

利用**八叉树**（Octree）递归划分 RGB 颜色空间：

1. 根节点代表整个颜色空间
2. 每个节点有 8 个子节点，对应 RGB 各位的 0/1 组合
3. 叶节点存储实际颜色
4. **量化时**：从最深层的叶节点开始合并（将 8 个兄弟合并为父节点），直到颜色数降到目标数量
5. **优势**：自动适应颜色分布，高频颜色保留更多细节

## 关键要点

- 八叉树深度最大 8 层（对应 RGB 各 8 位）
- 合并策略：优先合并颜色数最少的叶节点
- 时间复杂度：O(n) 建树 + O(k log k) 合并（n 为像素数，k 为节点数）

## 代码示例

```python
class OctreeNode:
    def __init__(self, level=0):
        self.children = [None] * 8
        self.level = level
        self.pixel_count = 0
        self.red_sum = 0
        self.green_sum = 0
        self.blue_sum = 0
        self.is_leaf = level == 8

    def add_color(self, r, g, b, level=0):
        if self.is_leaf:
            self.red_sum += r
            self.green_sum += g
            self.blue_sum += b
            self.pixel_count += 1
        else:
            index = ((r >> (7 - level)) & 1) << 2 | \
                    ((g >> (7 - level)) & 1) << 1 | \
                    ((b >> (7 - level)) & 1)
            if self.children[index] is None:
                self.children[index] = OctreeNode(level + 1)
            self.children[index].add_color(r, g, b, level + 1)
```
