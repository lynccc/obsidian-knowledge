# Python数据结构性能

## 核心概念

Python内建数据结构的底层实现决定了各操作的时间复杂度。理解这些特性有助于选择合适的数据结构。

## 列表（list）性能

### 底层实现
- **数据结构**：动态数组（连续内存块）
- **存储方式**：存储对象引用（指针）
- **扩容策略**：空间不足时按比例扩容

### 操作复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `lst[i]` | O(1) | 随机访问，直接索引 |
| `lst[i] = x` | O(1) | 赋值，直接修改 |
| `len(lst)` | O(1) | 维护长度属性 |
| `append(x)` | O(1)* | 尾部添加，偶尔扩容 |
| `pop()` | O(1) | 尾部弹出 |
| `pop(0)` | O(n) | 头部弹出，需移动元素 |
| `insert(0, x)` | O(n) | 头部插入，需移动元素 |
| `x in lst` | O(n) | 线性查找 |
| `lst[x:y]` | O(k) | 切片，k为切片长度 |
| `lst.sort()` | O(n log n) | Timsort算法 |
| `lst.reverse()` | O(n) | 原地反转 |

*均摊O(1)

### 性能特点
- **优势**：随机访问O(1)，尾部操作高效
- **劣势**：头部/中间插入删除O(n)，查找O(n)
- **适用**：需要频繁随机访问、尾部操作的场景

## 字典（dict）性能

### 底层实现
- **数据结构**：散列表（哈希表）
- **冲突解决**：开放寻址法
- **扩容策略**：装载因子超过2/3时扩容
- **键要求**：必须可哈希（`__hash__`和`__eq__`）

### 操作复杂度

| 操作 | 平均时间复杂度 | 最坏时间复杂度 |
|------|---------------|---------------|
| `d[key]` | O(1) | O(n) |
| `d[key] = x` | O(1) | O(n) |
| `key in d` | O(1) | O(n) |
| `del d[key]` | O(1) | O(n) |
| `d.get(key)` | O(1) | O(n) |
| `len(d)` | O(1) | O(1) |
| `d.keys()` | O(1) | O(1) |
| `d.values()` | O(1) | O(1) |
| `d.items()` | O(1) | O(1) |

### 性能特点
- **优势**：查找/插入/删除平均O(1)
- **劣势**：最坏情况O(n)（哈希冲突严重时）
- **适用**：需要频繁查找、去重、计数的场景

## 列表 vs 字典选择

| 场景 | 推荐 | 原因 |
|------|------|------|
| 频繁随机访问 | list | O(1)索引 |
| 频繁查找元素 | dict | O(1)查找 |
| 保持插入顺序 | dict (3.7+) | 内建支持 |
| 需要排序 | list | sort()原地排序 |
| 去重 | set/dict | 自动去重 |
| 计数统计 | dict | O(1)更新计数 |

## 关键要点

1. **底层决定性能**：动态数组 vs 散列表
2. **均摊分析**：append偶尔扩容，但均摊O(1)
3. **空间换时间**：字典用额外内存换O(1)查找
4. **最坏情况**：理论上O(n)，实际极少发生

## 代码示例

```python
# 列表：尾部操作高效
lst = []
lst.append(1)  # O(1)
lst.append(2)  # O(1)
lst.pop()      # O(1)

# 列表：头部操作低效
lst.insert(0, 0)  # O(n)
lst.pop(0)        # O(n)

# 字典：查找高效
d = {"a": 1, "b": 2, "c": 3}
value = d["a"]      # O(1)
d["d"] = 4          # O(1)
if "b" in d:        # O(1)
    print(d["b"])

# 性能对比实验
import time

# 列表查找 vs 字典查找
lst = list(range(10000))
d = {x: x for x in range(10000)}

start = time.time()
9999 in lst       # O(n)
lst_time = time.time() - start

start = time.time()
9999 in d          # O(1)
dict_time = time.time() - start

print(f"列表查找: {lst_time:.6f}s")
print(f"字典查找: {dict_time:.6f}s")
```
