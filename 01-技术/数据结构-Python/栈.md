# 栈（Stack）

## 🗣️ 通俗讲解

> 想象一摞盘子——你只能从最上面放（push），也只能从最上面拿（pop）。最后放进去的最先被拿出来，这就是「后进先出」（LIFO）。

📖 **想看更深入的理论分析？** → [[栈Stack]]（邓俊辉 C++ 版）

## 核心概念

栈是**后进先出（LIFO）** 的线性数据结构，只允许在**栈顶**进行插入和删除。

### 栈抽象数据类型

| 操作 | 说明 |
|------|------|
| `push(item)` | 将元素压入栈顶 |
| `pop()` | 弹出并返回栈顶元素 |
| `peek()` | 返回栈顶元素但不移除 |
| `isEmpty()` | 判断栈是否为空 |
| `size()` | 返回栈中元素个数 |

## 关键要点

- **Python 实现**：直接用 `list`，`append()` 充当 `push`，`pop()` 即为 `pop`，栈顶即列表尾部，O(1) 操作。
- **匹配括号**：遇左括号入栈，遇右括号出栈并匹配，栈空时右括号多余，遍历结束栈非空则左括号多余。
- **十进制→二进制**：不断除以2取余，余数入栈，再依次出栈拼接。栈保证了正确的位序。
- **中缀→后缀转换**：操作数直接输出；运算符入栈，入栈前弹出所有优先级 ≥ 当前的运算符；左括号入栈，右括号弹至左括号。
- **后缀表达式求值**：遇操作数入栈，遇运算符弹出两个操作数计算后结果入栈。

## 与其他概念的联系

- Python 内建列表的 `append/pop` 是栈的最佳实践，见 [[Python列表]]
- 函数调用栈是递归的基础，见第5章递归
- 深度优先搜索（DFS）本质是栈的应用
- 可与邓俊辉版 [[栈Stack]] 对比

## 代码示例

```python
class Stack:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def peek(self):
        return self.items[-1]

    def size(self):
        return len(self.items)
```

括号匹配示例：
```python
def parChecker(symbolString):
    s = Stack()
    for ch in symbolString:
        if ch == '(':
            s.push(ch)
        elif ch == ')':
            if s.isEmpty():
                return False
            s.pop()
    return s.isEmpty()
```
