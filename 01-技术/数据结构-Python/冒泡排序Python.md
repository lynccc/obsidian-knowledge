# 冒泡排序（Python）

## 🗣️ 通俗讲解

> 最简单的排序思路：从头到尾比相邻两个数，大的往后挪。一轮下来最大的「冒泡」到最后面，再来一轮排第二大的……效率不高（O(n²)），但胜在好理解。就像打扑克牌时一张张插到该去的位置。

📖 **想看更深入的理论分析？** → [[起泡排序]]（邓俊辉 C++ 版）

## 核心概念

冒泡排序（Bubble Sort）通过**重复比较相邻元素并交换**，使较大的元素逐渐"冒泡"到列表末尾。每一轮遍历将当前未排序部分的最大值移到正确位置。

## Python 实现

```python
def bubble_sort(a_list):
    n = len(a_list)
    for pass_num in range(n - 1, 0, -1):
        for i in range(pass_num):
            if a_list[i] > a_list[i + 1]:
                a_list[i], a_list[i + 1] = a_list[i + 1], a_list[i]
```

**Python 特性**：使用 `a, b = b, a` 进行交换，无需临时变量。

### 优化版本

```python
def bubble_sort_optimized(a_list):
    n = len(a_list)
    for pass_num in range(n - 1, 0, -1):
        exchanges = False
        for i in range(pass_num):
            if a_list[i] > a_list[i + 1]:
                a_list[i], a_list[i + 1] = a_list[i + 1], a_list[i]
                exchanges = True
        if not exchanges:
            break  # 本轮无交换，已有序
```

## 时间复杂度

| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 最好 | O(n) | 已有序，优化版一轮即停 |
| 平均 | O(n²) | 需要 n(n-1)/2 次比较 |
| 最坏 | O(n²) | 完全逆序 |

- 空间复杂度：**O(1)**（原地排序）
- **稳定排序**：相等元素的相对位置不变

## 过程示例

```
[5, 3, 8, 1, 2]
第1轮: [3, 5, 1, 2, 8]  ← 8 冒泡到末尾
第2轮: [3, 1, 2, 5, 8]  ← 5 冒泡
第3轮: [1, 2, 3, 5, 8]  ← 3 冒泡
第4轮: [1, 2, 3, 5, 8]  ← 无交换，提前终止
```

## 关键要点

- 实现最简单，但效率最低
- 对小数据集或近乎有序的数据尚可
- Python 交换语法 `a, b = b, a` 是惯用写法
- 优化版通过检测是否交换来提前终止
- 实际应用中很少使用，学习价值在于理解排序思想
