# 顺序搜索

## 核心概念

顺序搜索（Sequential Search / Linear Search）是最简单的搜索算法：从列表第一个元素开始，逐个比较，直到找到目标或遍历完整个列表。

## 无序列表的顺序搜索

```python
def sequential_search(a_list, item):
    pos = 0
    found = False
    while pos < len(a_list) and not found:
        if a_list[pos] == item:
            found = True
        else:
            pos += 1
    return found
```

- 时间复杂度：**O(n)**
- 最好情况：O(1)，第一个就是
- 最坏情况：O(n)，在最后或不存在

## 有序列表的优化

当列表已排序时，可以在发现当前元素大于目标时提前终止：

```python
def ordered_sequential_search(a_list, item):
    pos = 0
    found = False
    stop = False
    while pos < len(a_list) and not found and not stop:
        if a_list[pos] == item:
            found = True
        elif a_list[pos] > item:
            stop = True  # 提前终止
        else:
            pos += 1
    return found
```

- 时间复杂度仍为 **O(n)**，但平均情况更好
- 有序列表的关键优势在于可以使用[[二分搜索Python]]

## 关键要点

- 顺序搜索对列表结构无要求（有序/无序均可）
- 时间复杂度与列表长度成正比
- 对小列表（n < 100）足够高效，实现简单
- 对大列表应考虑[[二分搜索Python]]或[[散列Python]]
