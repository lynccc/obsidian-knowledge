# 递归基础

## 核心概念

递归是一个函数调用自身的过程。Python 通过**调用栈（call stack）** 管理递归，每次调用创建一个新的**栈帧（stack frame）**，存储局部变量和返回地址。

## 递归三原则

1. **必须有基本情况（base case）**：不再递归的终止条件，直接返回结果
2. **必须改变状态并朝基本情况靠近**：每次递归调用必须使问题规模缩小
3. **必须递归地调用自身**：函数调用自身来解决缩小后的问题

> 违反任何一条原则都会导致无限递归或错误结果。

## 实例：计算列表之和

```python
def list_sum(num_list):
    # 基本情况
    if len(num_list) == 1:
        return num_list[0]
    # 递归调用：状态改变（列表变短）
    else:
        return num_list[0] + list_sum(num_list[1:])
```

**调用栈展开**：
```
list_sum([1, 3, 5, 7, 9])
= 1 + list_sum([3, 5, 7, 9])
= 1 + 3 + list_sum([5, 7, 9])
= 1 + 3 + 5 + list_sum([7, 9])
= 1 + 3 + 5 + 7 + list_sum([9])
= 1 + 3 + 5 + 7 + 9  → 25
```

## 实例：进制转换

```python
def to_str(n, base):
    convert_string = "0123456789ABCDEF"
    if n < base:
        return convert_string[n]
    else:
        return to_str(n // base, base) + convert_string[n % base]
```

利用栈帧的特性：递归调用先于字符串拼接执行，结果自然反向组装。

## 栈帧：实现递归

- Python 默认递归深度限制：**1000 层**（`sys.getrecursionlimit()`）
- 每个栈帧消耗内存，深递归可能导致 `RecursionError`
- `sys.setrecursionlimit()` 可调整，但不推荐设过大

## 关键要点

- 递归本质上是用**隐式栈**替代显式循环
- 基本情况是递归的"刹车"，必须存在且可达
- Python 的切片操作（如 `num_list[1:]`）创建新列表，有额外开销
- 对于简单的线性递归，迭代版本通常更高效
