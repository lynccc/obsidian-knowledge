# Python列表

## 核心概念

Python的`list`是**动态数组**实现的序列类型，支持高效随机访问和尾部操作。

## 底层实现

- **数据结构**：动态数组（连续内存块）
- **扩容策略**：空间不足时自动扩容（通常翻倍）
- **内存布局**：存储对象引用，非对象本身

## 常用操作

### 修改操作
| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `append(x)` | 尾部添加 | O(1) |
| `insert(i, x)` | 指定位置插入 | O(n) |
| `pop()` | 尾部弹出 | O(1) |
| `pop(0)` | 头部弹出 | O(n) |
| `del lst[i]` | 删除指定位置 | O(n) |
| `remove(x)` | 删除首个匹配值 | O(n) |
| `sort()` | 原地排序 | O(n log n) |
| `reverse()` | 原地反转 | O(n) |

### 查询操作
| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `lst[i]` | 索引访问 | O(1) |
| `len(lst)` | 长度 | O(1) |
| `index(x)` | 查找值的索引 | O(n) |
| `count(x)` | 统计出现次数 | O(n) |
| `x in lst` | 成员检测 | O(n) |

## 列表解析式

```python
# 基本语法
[表达式 for 变量 in 可迭代对象]

# 示例
squares = [x**2 for x in range(10)]           # [0, 1, 4, 9, ...]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# 嵌套列表解析
matrix = [[1,2,3], [4,5,6], [7,8,9]]
flat = [x for row in matrix for x in row]  # [1,2,3,4,5,6,7,8,9]
```

## 关键要点

1. **随机访问O(1)**：底层数组支持直接索引
2. **尾部操作高效**：append/pop末尾为O(1)
3. **头部/中间操作低效**：需要移动元素，O(n)
4. **动态扩容**：用户无需关心容量管理

## 代码示例

```python
# 创建列表
my_list = [1, 2, 3, 4, 5]

# 尾部操作（高效）
my_list.append(6)      # O(1)
my_list.pop()          # O(1)

# 头部操作（低效）
my_list.insert(0, 0)   # O(n)
my_list.pop(0)         # O(n)

# 列表解析式
squares = [x**2 for x in range(10)]
even_squares = [x**2 for x in range(10) if x % 2 == 0]
```
