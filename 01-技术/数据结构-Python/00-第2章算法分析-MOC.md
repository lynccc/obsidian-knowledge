# 第2章 算法分析 - MOC

## 章节概述

本章介绍算法分析的基本方法，包括大O记法、常见复杂度层次，以及Python数据结构的性能特性。

## 核心概念

### 算法分析的意义
- **算法vs程序**：算法是思想，程序是实现
- **性能评估**：预测算法随问题规模增长的表现
- **平台无关性**：分析独立于具体硬件和软件环境

### T(n)函数
- **定义**：步骤数 = f(问题规模n)
- **作用**：量化算法的工作量
- **局限**：精确计算过于复杂，需简化

### 大O记法
- 关注决定性部分，忽略低次项和系数
- 描述最坏情况下的增长趋势
- 常见层次：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)

## 关键要点

### 分析方法
1. **基准测试**：测量实际运行时间（依赖平台）
2. **数学分析**：计算T(n)，化简为大O
3. **对比**：不同算法在同一问题上的效率比较

### Python性能特性
- **列表**：尾部操作O(1)，头部操作O(n)
- **字典**：查找/插入/删除平均O(1)
