# 第3章 基本数据结构

> 来源：《Python数据结构与算法分析》第2版（Bradley N. Miller & David L. Ranum）第3章

## 笔记索引

## 本章脉络

第3章从**抽象数据类型（ADT）** 的角度介绍四种基本线性结构：

```
ADT 定义 → Python 实现 → 经典应用
```

| 数据结构 | 核心特性 | 典型应用 |
|---------|---------|---------|
| 栈 | LIFO | 括号匹配、表达式转换与求值 |
| 队列 | FIFO | 模拟（传土豆、打印任务） |
| 双端队列 | 两端操作 | 回文检测 |
| 列表 | 有序/无序 | 链表实现 |
