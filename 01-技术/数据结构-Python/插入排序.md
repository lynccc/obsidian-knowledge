# 插入排序

## 核心概念

插入排序（Insertion Sort）模拟**整理扑克牌**的过程：每次取一张牌，插入到已排序手牌的正确位置。从第二个元素开始，逐个将元素插入到左侧已排序部分。

## Python 实现

```python
def insertion_sort(a_list):
    for i in range(1, len(a_list)):
        current_value = a_list[i]
        position = i
        while position > 0 and a_list[position - 1] > current_value:
            a_list[position] = a_list[position - 1]
            position -= 1
        a_list[position] = current_value
```

## 时间复杂度

| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 最好 | **O(n)** | 已有序，每轮只比较一次 |
| 平均 | O(n²) | |
| 最坏 | O(n²) | 完全逆序 |

- 空间复杂度：**O(1)**（原地排序）
- **稳定排序**

## 过程示例

```
[5, 3, 8, 1, 2]
i=1: 取3，插入到5前 → [3, 5, 8, 1, 2]
i=2: 取8，已在正确位置 → [3, 5, 8, 1, 2]
i=3: 取1，插入到最前 → [1, 3, 5, 8, 2]
i=4: 取2，插入到1后 → [1, 2, 3, 5, 8]
```

## 三种 O(n²) 排序对比

| 特性 | 冒泡排序 | 选择排序 | 插入排序 |
|------|---------|---------|---------|
| 最好 | O(n) | O(n²) | **O(n)** |
| 交换次数 | O(n²) | O(n) | O(n²) |
| 稳定性 | 稳定 | 不稳定 | **稳定** |
| 适用场景 | 教学 | 交换代价高 | **近乎有序** |

## 关键要点

- 对**近乎有序**的数据效率最高（接近 O(n)）
- 对小数据集（n < 50）表现优秀
- Python 的 `list.sort()` 和 `sorted()` 内部使用 TimSort（归并+插入的混合），插入排序处理小分区
- 是其他高级排序算法（如[[希尔排序Python]]、TimSort）的基础
