# 大O记法

## 🗣️ 通俗讲解

> 大O就是衡量算法「有多慢」的尺子。O(1) 是瞬间完成（不管数据多少），O(n) 是数据越多越慢（线性增长），O(n²) 是数据翻倍、时间变 4 倍——越往后越恐怖。写代码时心里要有这把尺子，不然数据量一大程序就卡死了。

📖 **想看更深入的理论分析？** → [[渐进复杂度记号]]（邓俊辉 C++ 版）

## 核心概念

大O记法是描述算法**渐进复杂度**的数学表示，关注输入规模n趋向无穷时的增长趋势。

## 定义

对于T(n)，若存在正常数c和n₀，使得当n ≥ n₀时，T(n) ≤ c·f(n)，则T(n) = O(f(n))

**直观理解**：大O表示算法的**上界**，忽略常数因子和低次项。

## 常见复杂度层次

| 大O记法 | 名称 | 示例算法 |
|---------|------|---------|
| O(1) | 常数 | 数组索引、哈希查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历列表 |
| O(n log n) | 线性对数 | 归并排序、快速排序 |
| O(n²) | 平方 | 冒泡排序、嵌套循环 |
| O(n³) | 立方 | 矩阵乘法（朴素） |
| O(2ⁿ) | 指数 | 子集枚举 |
| O(n!) | 阶乘 | 全排列枚举 |

## 复杂度分类

### 按情况分类
- **最好情况**：Ω记法，算法的下界
- **最坏情况**：O记法，算法的上界（最常用）
- **平均情况**：Θ记法，算法的紧确界

### 按资源分类
- **时间复杂度**：执行操作数量
- **空间复杂度**：额外内存使用量

## 关键要点

1. **关注趋势**：n很大时，高次项主导
2. **忽略常数**：O(2n) = O(n)，O(100) = O(1)
3. **最坏情况**：通常分析最坏情况，保证性能下限
4. **加法法则**：O(f(n)) + O(g(n)) = O(max(f(n), g(n)))
5. **乘法法则**：O(f(n)) × O(g(n)) = O(f(n) × g(n))

## 代码示例

```python
# O(1) - 常数时间
def get_first(lst):
    return lst[0]  # 无论列表多长，都是1步

# O(n) - 线性时间
def find_max(lst):
    max_val = lst[0]
    for item in lst:  # 遍历n次
        if item > max_val:
            max_val = item
    return max_val

# O(n²) - 平方时间
def bubble_sort(lst):
    n = len(lst)
    for i in range(n):        # n次
        for j in range(n-1):  # n次
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]

# O(log n) - 对数时间
def binary_search(lst, target):
    low, high = 0, len(lst)-1
    while low <= high:
        mid = (low + high) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```
