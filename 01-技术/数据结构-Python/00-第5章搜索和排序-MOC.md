# 第5章 搜索和排序

## 章节概览

本章讨论两种基本操作：在集合中查找元素（搜索）和将元素按序排列（排序）。重点分析各算法的时间复杂度和适用场景。

## 笔记索引

### 搜索算法
- [[顺序搜索]] — 最简单的搜索，O(n)
- [[二分搜索Python]] — 高效搜索有序列表，O(log n)
- [[散列Python]] — 散列表实现 O(1) 查找

### 排序算法
- [[冒泡排序Python]] — 最直观的排序，O(n²)
- [[选择排序]] — 每次选最小，O(n²)
- [[插入排序]] — 类似整理扑克牌，O(n²)
- [[希尔排序Python]] — 插入排序的改进版，O(n^(3/2))
- [[归并排序Python]] — 分治法排序，O(n log n)
- [[快速排序Python]] — 实践中最快的排序，O(n log n) 平均

## 复杂度总览

```
搜索：
  顺序搜索  O(n)
  二分搜索  O(log n)
  散列      O(1) 平均

排序：
  冒泡排序  O(n²)
  选择排序  O(n²)
  插入排序  O(n²)
  希尔排序  O(n^(3/2))
  归并排序  O(n log n)
  快速排序  O(n log n) 平均，O(n²) 最坏
```

## 学习路径

```
顺序搜索 → 二分搜索 → 散列（搜索进化）
冒泡/选择/插入 → 希尔 → 归并/快速（排序进化）
```
