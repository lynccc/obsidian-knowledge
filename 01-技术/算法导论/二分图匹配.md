# 二分图匹配（CLRS 第25章）

## 通俗讲解
> 二分图匹配是将两组实体最优配对的问题。本章介绍三种不同的"最优"定义：最大匹配（Hopcroft-Karp，配对数量最多）、稳定匹配（Gale-Shapley，没有"私奔"对）、最优分配（匈牙利算法，总价值最大）。这些算法在实际中有广泛应用：医院分配住院医、任务分配给工人、在线广告匹配等。

## 核心概念

### 二分图（Bipartite Graph）
- 顶点集 V = L ∪ R，L 和 R 不相交
- 每条边连接 L 中一个顶点和 R 中一个顶点

### 匹配（Matching）
- 匹配 M ⊆ E：每个顶点最多有一条匹配边
- **匹配的顶点**（Matched Vertex）：有匹配边的顶点
- **未匹配的顶点**（Unmatched Vertex）：无匹配边的顶点
- **完美匹配**（Perfect Matching）：所有顶点都被匹配

### M-增广路径（M-Augmenting Path）
从 L 中未匹配顶点到 R 中未匹配顶点的交替路径（边交替在 E-M 和 M 中）。

**关键性质**：M-增广路径存在 ⟺ M 不是最大匹配。

## Hopcroft-Karp 算法

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此算法。

### 核心思想
不是一次找一条增广路径，而是**同时找多条最短的顶点不相交增广路径**，批量增广。

### 算法伪代码
```
HOPCROFT-KARP(G):
  M = ∅
  repeat
    P = {P_1, P_2, ..., P_k}  // 最大顶点不相交最短 M-增广路径集
    M = M ⊕ (P_1 ∪ P_2 ∪ ... ∪ P_k)
  until P == ∅
  return M
```

### 三个阶段（每次迭代）

**第一阶段**：构建有向图 G_M
- E_M = {(l,r) : (l,r) ∈ E-M} ∪ {(r,l) : (l,r) ∈ M}
- 非匹配边从 L→R，匹配边从 R→L

**第二阶段**：BFS 构建 DAG H
- 从 L 中所有未匹配顶点开始 BFS
- 每个顶点标记 BFS 距离
- 只保留连续层之间的边
- q = R 中未匹配顶点的最小距离

**第三阶段**：DFS 找最大增广路径集
- 在 H^T 上从 R 中距离为 q 的未匹配顶点做 DFS
- 找到顶点不相交的增广路径

### 时间复杂度
**O(√V · E)**

### 分析关键
- **迭代次数**：O(√V) 次
  - 前 √V 次：每次最短增广路径长度递增（引理 25.5）
  - 之后：最短增广路径长度 ≥ √V，由引理 25.6，最多还需 √V 次
- **每次迭代**：O(E)（BFS + DFS）

### 引理 25.1
M-增广路径 P 与 M 的对称差 M ⊕ P 是匹配，且 |M ⊕ P| = |M| + 1。

### 引理 25.3
设 M 和 M* 是匹配，|M*| > |M|，则 G 中至少有 |M*|-|M| 条顶点不相交的 M-增广路径。

### 推论 25.4
匹配 M 是最大匹配 ⟺ G 中无 M-增广路径。

## 稳定婚姻问题（Stable Marriage Problem）

### 问题定义
- L 和 R 各有 n 个顶点（n 个女性，n 个男性）
- 每个顶点对另一侧所有顶点有**偏好排序**
- 目标：找一个**稳定匹配**（无阻塞对）

### 阻塞对（Blocking Pair）
若女性 w 和男性 m 未配对，但 w 偏好 m 胜过当前伴侣，且 m 也偏好 w 胜过当前伴侣，则 (w,m) 是阻塞对。

### 稳定匹配（Stable Matching）
没有阻塞对的完美匹配。

### Gale-Shapley 算法

```
GALE-SHAPLEY(men, women, rankings):
  所有人初始为"自由"
  while 存在自由女性 w
    m = w 偏好列表中她还未求过婚的最高排名男性
    if m 是自由的
      w 和 m 订婚
    elseif m 偏好 w 胜过当前伴侣 w'
      m 与 w' 解除婚约（w' 变为自由）
      w 和 m 订婚
    else m 拒绝 w
  return 所有订婚对
```

### 时间复杂度
**O(n²)**——最多 n² 次求婚。

### 正确性证明
**定理 25.9**：Gale-Shapley 总是终止并返回稳定匹配。

**证明要点**：
1. **终止性**：n 个女性各最多求婚 n 次，共 n² 次
2. **无阻塞对**：若 w 偏好 m' 胜过 m，则 w 一定先向 m' 求过婚但被拒绝；m' 当时已有更偏好的伴侣，之后只会换更好的

### 关键性质
**定理 25.11**：女性主动求婚版本中：
- 结果与求婚顺序无关（总是同一结果）
- 每个女性获得**所有稳定匹配中最好的**伴侣
- 每个男性获得**所有稳定匹配中最差的**伴侣

> **不对称性**：主动方获得最优结果，被动方获得最差结果！

### 稳定匹配的不唯一性
- 女性最优稳定匹配：Gale-Shapley（女性求婚）的结果
- 男性最优稳定匹配：Gale-Shapley（男性求婚）的结果
- 可能有多个稳定匹配介于两者之间

### 与邓俊辉版的差异
邓俊辉版通常不覆盖稳定婚姻问题。CLRS 版详细介绍了：
1. Gale-Shapley 算法及其 O(n²) 复杂度
2. 稳定匹配的存在性证明
3. 最优性定理（女性最优、男性最劣）
4. 实际应用（住院医分配 NRMP）

## 匈牙利算法（Hungarian Algorithm）

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此算法。

### 问题定义
**分配问题**（Assignment Problem）：给完全二分图的每条边赋权，找**最大权完美匹配**。

### 等式子图（Equality Subgraph）
给定可行顶点标号 h（满足 l.h + r.h ≥ w(l,r)），等式子图 G_h 包含满足 l.h + r.h = w(l,r) 的边。

### 定理 25.14
若等式子图 G_h 有完美匹配 M*，则 M* 是最大权完美匹配。

**证明**：
```
w(M*) = Σ (l.h + r.h) = Σ l.h + Σ r.h
w(M) ≤ Σ (l.h + r.h) = Σ l.h + Σ r.h（对任意匹配 M）
```
所以 w(M) ≤ w(M*) 对所有匹配 M 成立。

### 算法思路
1. 初始可行标号：l.h = max{w(l,r)}，r.h = 0
2. 在等式子图中找最大匹配
3. 若不是完美匹配，调整标号扩大等式子图
4. 重复直到找到完美匹配

### 时间复杂度
- 基本版本：**O(n⁴)**
- 优化版本（问题 25-2）：**O(n³)**

### 调整标号
当等式子图中找不到增广路径时：
1. 设 S 是从 L 中未匹配顶点可达的顶点集
2. 调整量 δ = min{ l.h + r.h - w(l,r) : l ∈ S, r ∉ S }
3. 对 l ∈ S：l.h -= δ；对 r ∈ S：r.h += δ

## 三种匹配算法对比

| 算法 | 问题 | 时间 | 输出 |
|------|------|------|------|
| Hopcroft-Karp | 最大匹配 | O(√V·E) | 最大基数匹配 |
| Gale-Shapley | 稳定匹配 | O(n²) | 稳定匹配 |
| 匈牙利算法 | 最大权匹配 | O(n³) | 最大权完美匹配 |

## 关键要点

1. **增广路径是核心**：Hopcroft-Karp 和匈牙利算法都依赖增广路径
2. **稳定 ≠ 最优**：稳定匹配关注"无阻塞对"，不追求总价值最大
3. **主动方占优**：Gale-Shapley 中主动求婚方获得最优结果
4. **等式子图**：匈牙利算法通过调整标号逐步扩大等式子图
5. **批量增广**：Hopcroft-Karp 的 O(√V·E) 来自同时增广多条路径
