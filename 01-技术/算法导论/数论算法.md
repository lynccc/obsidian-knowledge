# 数论算法

## 通俗讲解
> 数论曾经被认为是"最纯粹但也最无用"的数学分支。但RSA密码系统的发明改变了这一切——你每次网购输入密码时，都在使用数论算法！
>
> 核心思想很简单：两个大素数相乘很容易，但把结果分解回两个素数却极其困难。这种"不对称性"就是现代密码学的基础。

## 核心概念（中文，附英文术语）

### 基础数论概念
- **整除（Divisibility）**：d | a 表示d整除a，即a = kd
- **素数（Prime）**：大于1且只有1和自身两个因子的整数
- **合数（Composite）**：大于1且不是素数的整数
- **唯一素数分解定理（Unique Prime Factorization）**：任何合数a可以唯一表示为 a = p₁^e₁ · p₂^e₂ · ... · pᵣ^eᵣ
- **模运算（Modular Arithmetic）**：a mod n 是a除以n的余数
- **同余（Congruence）**：a ≡ b (mod n) 表示a和b除以n余数相同
- **互素（Relatively Prime）**：gcd(a, b) = 1

### 最大公约数（GCD）
- **欧几里得算法（Euclid's Algorithm）**：gcd(a, b) = gcd(b, a mod b)
  - 时间复杂度：O(lg(min(a,b)))次算术运算
  - 这是世界上最古老的算法之一（公元前300年）
- **扩展欧几里得算法（Extended Euclid）**：求gcd(a, b) = ax + by中的x和y
  - 这是求模逆元的关键工具

### 模运算
- **模算术群 Zₙ**：{0, 1, ..., n-1}，配备模加法和模乘法
- **模逆元（Modular Multiplicative Inverse）**：a⁻¹ mod n，满足 a·a⁻¹ ≡ 1 (mod n)
  - 存在的充要条件：gcd(a, n) = 1
- **模线性方程 ax ≡ b (mod n)**：
  - 有解当且仅当 gcd(a, n) | b
  - 若有解，则有gcd(a,n)个解
- **中国剩余定理（Chinese Remainder Theorem）**：
  - 如果n₁, n₂, ..., nₖ两两互素，则方程组 x ≡ aᵢ (mod nᵢ) 在Zₙ中有唯一解

### 模幂运算（Modular Exponentiation）
- **重复平方法（Repeated Squaring）**：计算 a^b mod n
  - 时间复杂度：O(lg b)次算术运算，O(lg²b)次位运算
  - 思想：把b写成二进制，逐位处理
  - 例：a¹³ = a⁸ · a⁴ · a¹，只需计算a¹, a², a⁴, a⁸

### RSA公钥密码系统
- **密钥生成**：
  1. 选择两个大素数p和q
  2. 计算 n = p·q
  3. 选择与φ(n) = (p-1)(q-1)互素的e
  4. 计算 d = e⁻¹ mod φ(n)
  5. 公钥 = (e, n)，私钥 = (d, n)
- **加密**：c = m^e mod n
- **解密**：m = c^d mod n
- **安全性基础**：分解n为p·q在计算上是困难的

### 素性测试（Primality Testing）
- **费马定理**：如果p是素数，则 a^(p-1) ≡ 1 (mod p) 对所有a ∈ Z*ₚ成立
- **Miller-Rabin测试**：随机化素性测试
  - 如果n是素数，总是报告"素数"
  - 如果n是合数，报告"合数"的概率 ≥ 1/2
  - 每次测试的时间复杂度：O(lg n)次算术运算
  - 重复t次，错误概率 ≤ (1/2)^t
- **Carmichael数**：合数n但对所有与n互素的a都有a^(n-1) ≡ 1 (mod n)
  - Miller-Rabin可以正确识别Carmichael数为合数

## 关键要点

1. **欧几里得算法是基础**：GCD、模逆元、解模线性方程都依赖它
2. **重复平方法是核心工具**：RSA加密/解密、素性测试都需要高效的模幂运算
3. **RSA的安全性假设**：大整数分解是困难的（至今未证明！）
4. **Miller-Rabin的实用性**：错误概率可以指数级降低，实际中极可靠
5. **输入规模的特殊性**：数论算法的"输入大小"是位数，不是整数值

## 与其他概念的联系
- 模幂运算使用[[分治法]]（重复平方法）
- Miller-Rabin是[[概率分析与随机算法]]的典型应用
