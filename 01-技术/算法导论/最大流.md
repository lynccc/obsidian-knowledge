# 最大流（CLRS 第24章）

## 通俗讲解
> 最大流问题：想象一个水管网络，水源 s 不断供水，水汇 t 不断排水，每根水管有最大流量限制。问：从 s 到 t 最大能输送多少水？这就是最大流问题。Ford-Fulkerson 方法通过不断寻找增广路径来增加流量，直到无法再增加为止。最大流最小割定理告诉我们：最大流等于最小割的容量。

## 流网络（Flow Network）

### 定义
**流网络** G = (V, E) 是有向图，满足：
- 每条边 (u,v) 有非负**容量** c(u,v) ≥ 0
- 若 (u,v) ∈ E，则 (v,u) ∉ E（无反向平行边）
- 有两个特殊顶点：**源点** s 和**汇点** t
- 每个顶点都在某条 s 到 t 的路径上

### 流的定义
**流** f: V×V → R 满足两个性质：

1. **容量约束**（Capacity Constraint）：0 ≤ f(u,v) ≤ c(u,v)
2. **流守恒**（Flow Conservation）：对于所有 u ∈ V-{s,t}，Σ f(v,u) = Σ f(u,v)

> 流守恒 = 基尔霍夫电流定律（Kirchhoff's Current Law）

### 流的值
```
|f| = Σ f(s,v) - Σ f(v,s)
```
即流出源点的净流量。

## 残存网络（Residual Network）

### 定义
给定流网络 G 和流 f，**残存网络** G_f 包含可能改变流的边。

### 残存容量
```
c_f(u,v) = { c(u,v) - f(u,v),  若 (u,v) ∈ E
            { f(v,u),           若 (v,u) ∈ E
            { 0,                否则
```

**理解**：
- **正向边**：还可以增加的流量
- **反向边**：可以"撤销"的流量（流的取消/Cancellation）

### 流的取消
反向边允许"取消"之前的流分配。例如：5 个单位从 u 到 v，2 个单位从 v 到 u，等价于 3 个单位从 u 到 v。

## 增广路径（Augmenting Path）

### 定义
**增广路径** p 是残存网络 G_f 中从 s 到 t 的简单路径。

### 残存容量
```
c_f(p) = min{ c_f(u,v) : (u,v) 在路径 p 上 }
```

### 引理 24.1
将流 f 与 G_f 中的流 f' 合并（f ↑ f'），得到 G 中的新流，值为 |f| + |f'|。

### 推论 24.3
沿增广路径 p 增广流 f，新流的值 |f ↑ f_p| = |f| + c_f(p) > |f|。

## 流网络的切割（Cut）

### 定义
流网络的**切割** (S,T) 是 V 的划分，s ∈ S，t ∈ T。

### 净流量
```
f(S,T) = Σ_{u∈S, v∈T} f(u,v) - Σ_{u∈S, v∈T} f(v,u)
```

### 切割容量
```
c(S,T) = Σ_{u∈S, v∈T} c(u,v)
```

> **注意**：净流量计算双向边，容量只计算 S→T 方向。

### 引理 24.4
对于任意切割 (S,T)，净流量 f(S,T) = |f|。

### 推论 24.5
任意流的值 ≤ 任意切割的容量：|f| ≤ c(S,T)。

## 最大流最小割定理（Max-Flow Min-Cut Theorem）

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此定理。

### 定理 24.6
以下三个条件等价：
1. f 是最大流
2. 残存网络 G_f 中不存在增广路径
3. 存在切割 (S,T) 使得 |f| = c(S,T)

### 证明思路
- **(1)→(2)**：若有增广路径，可增加流，与最大流矛盾
- **(2)→(3)**：定义 S = {v : s 到 v 在 G_f 中有路径}，则 (S,T) 是最小割
- **(3)→(1)**：由推论 24.5，|f| ≤ c(S,T) 对所有切割成立，所以 |f| = c(S,T) 意味着 f 是最大流

### 核心结论
**最大流 = 最小割**

## Ford-Fulkerson 方法

### 核心思想
反复寻找增广路径并增广，直到不存在增广路径。

### 算法伪代码
```
FORD-FULKERSON(G, s, t):
  for each edge (u,v) ∈ E
    (u,v).f = 0
  while 存在从 s 到 t 的增广路径 p
    c_f(p) = min{ c_f(u,v) : (u,v) 在 p 上 }
    for each edge (u,v) in p
      if (u,v) ∈ E
        (u,v).f = (u,v).f + c_f(p)
      else (v,u).f = (v,u).f - c_f(p)
  return f
```

### 时间复杂度
- **一般情况**：O(E · |f*|)，其中 |f*| 是最大流值
- **问题**：若容量为无理数，可能不终止
- **整数容量**：最多 |f*| 次增广，每次 O(E)

## Edmonds-Karp 算法

### 改进
用 **BFS** 寻找增广路径（最短增广路径）。

### 时间复杂度
**O(VE²)**

### 关键引理
**引理 24.7**：Edmonds-Karp 中，顶点到源点的最短路径距离 δ_f(s,v) 单调递增。

**定理 24.8**：总增广次数为 O(VE)。

**证明核心**：
- 每条边最多成为"关键边" |V|/2 次
- 关键边总数 O(VE)
- 每次增广至少有一条关键边

## 最大二分匹配（Maximum Bipartite Matching）

> 🔗 已有笔记：[[二分匹配]]

### 匹配的定义
**匹配** M ⊆ E 是边的子集，使得每个顶点最多有一条匹配边。

### 转化为最大流
给定二分图 G = (L ∪ R, E)：
1. 添加源点 s，连向 L 中所有顶点，容量 1
2. 添加汇点 t，R 中所有顶点连向 t，容量 1
3. L 到 R 的边容量设为 1

### 整性定理（Theorem 24.10）
若容量为整数，Ford-Fulkerson 方法产生的流也是整数。

### 推论 24.11
最大匹配的基数 = 对应流网络的最大流值。

### 时间复杂度
O(VE)——最大流值 O(V)，每次增广 O(E)。

## 关键要点

1. **最大流最小割定理**是流网络理论的核心
2. **增广路径方法**简单但可能很慢（依赖容量值）
3. **Edmonds-Karp** 用 BFS 保证多项式时间 O(VE²)
4. **流的取消**是残存网络反向边的关键作用
5. **二分匹配**可转化为最大流问题
