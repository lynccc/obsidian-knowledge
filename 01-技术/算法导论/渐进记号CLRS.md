# 渐进记号（CLRS）

## 通俗讲解

> 渐进记号就是给算法"算命"——当数据量 n 变得很大时，运行时间大概以什么速度增长？我们不在乎具体几秒，只在乎增长的"形状"是线性的、平方的还是指数的。
>
> **O** 是上界（"最多这么快"），**Ω** 是下界（"至少这么快"），**Θ** 是紧确界（"就这么快"）。就像说一个人身高"至少170"、"最多190"、"大约180"。

## 核心概念

### O 记号（Big-O，渐进上界）
O(g(n)) = { f(n) : 存在正常数 c 和 n₀，使得对所有 n ≥ n₀，有 0 ≤ f(n) ≤ cg(n) }

直观含义：f(n) 的增长速度**不快于** g(n)。
- 7n³ + 100n² = O(n³) ✓
- 7n³ + 100n² = O(n⁴) ✓（上界可以宽松）

### Ω 记号（Big-Omega，渐进下界）
Ω(g(n)) = { f(n) : 存在正常数 c 和 n₀，使得对所有 n ≥ n₀，有 0 ≤ cg(n) ≤ f(n) }

直观含义：f(n) 的增长速度**不低于** g(n)。
- 7n³ + 100n² = Ω(n³) ✓

### Θ 记号（Big-Theta，紧确界）
Θ(g(n)) = { f(n) : 存在正常数 c₁, c₂ 和 n₀，使得对所有 n ≥ n₀，有 c₁g(n) ≤ f(n) ≤ c₂g(n) }

**定理 3.1**：f(n) = Θ(g(n)) 当且仅当 f(n) = O(g(n)) 且 f(n) = Ω(g(n))

### o 记号与 ω 记号
- **o(g(n))**：非紧确上界，f(n) 相比 g(n) 微不足道（lim f/g = 0）
- **ω(g(n))**：非紧确下界，f(n) 相比 g(n) 任意大（lim f/g = ∞）

### 重要比较关系
lg n = o(n)，n = o(n lg n)，n lg n = o(n²)，n² = o(2ⁿ)

## 关键要点

1. 渐进记号描述的是**函数的增长率**，不是具体运行时间
2. 使用时要精确：插入排序最坏 Θ(n²)、最好 Θ(n)；不能笼统说"运行时间是 Θ(n²)"
3. O 表示上界，Θ 表示紧确——能用 Θ 就不要用 O
4. 常数因子和低阶项在渐进分析中被忽略
5. 最常用的增长率排序：O(1) < O(lg n) < O(n) < O(n lg n) < O(n²) < O(n³) < O(2ⁿ)
