# 插入排序（CLRS）

## 通俗讲解

> 想象你左手拿牌，右手从桌上一张张摸牌。每摸一张，从右往左在左手里找到合适位置插进去。左手的牌始终是排好序的——这就是插入排序。
>
> **循环不变式**就像数学归纳法：初始时成立（基础步），每次迭代保持成立（归纳步），结束时能推出结果正确（终止步）。

## 核心概念

### 插入排序算法（Insertion Sort）
从第二个元素开始，将当前元素（key）与已排序子数组中的元素从右往左比较，找到正确位置插入。

```
INSERTION-SORT(A, n)
for i = 2 to n
    key = A[i]
    j = i - 1
    while j > 0 and A[j] > key
        A[j+1] = A[j]
        j = j - 1
    A[j+1] = key
```

### 循环不变式（Loop Invariant）
在 for 循环每次迭代开始时，子数组 A[1..i-1] 包含原来在 A[1..i-1] 中的元素，但已按非降序排列。

证明循环不变式需要三步：
1. **初始化（Initialization）**：循环开始前不变式成立。i=2 时，A[1..1] 只有一个元素，天然有序。
2. **保持（Maintenance）**：若某次迭代前成立，则下次迭代前仍成立。插入操作维护了有序性。
3. **终止（Termination）**：循环结束时，不变式给出有用性质。i=n+1 时，A[1..n] 全部有序。

### 运行时间分析
- **最好情况**：数组已有序，while 循环每次只执行一次比较 → Θ(n)
- **最坏情况**：数组逆序，每次比较整个已排序子数组 → Θ(n²)
- **平均情况**：约一半元素需要移动 → Θ(n²)

## 关键要点

1. 插入排序是**稳定的**（stable）排序算法
2. 是**原地排序**（in-place），只需 O(1) 额外空间
3. 对**小规模数据**或**几乎有序的数据**效率很高
4. 循环不变式是证明算法正确性的通用方法，类似数学归纳法
