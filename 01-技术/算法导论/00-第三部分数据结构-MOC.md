# 第三部分：数据结构

## 通俗讲解
> 数据结构是组织和存储数据的方式，就像你整理房间时选择用书架、抽屉还是挂钩。好的数据结构能让数据的增删改查变得高效。这一部分从最简单的栈、队列、链表开始，逐步深入到散列表、二叉搜索树、红黑树等高级数据结构，最后介绍如何"扩张"已有数据结构来支持更多操作。

## 各章概览

### 第10章 基础数据结构（Elementary Data Structures）
- **栈（Stack）**：后进先出（LIFO），push/pop 操作
- **队列（Queue）**：先进先出（FIFO），enqueue/dequeue 操作
- **链表（Linked List）**：单链表、双链表、循环链表、哨兵节点
- **有根树（Rooted Tree）**：二叉树表示、左孩子右兄弟表示

### 第11章 散列表（Hash Tables）
- **直接寻址**：当键的范围小时，直接用数组索引
- **散列函数**：将大范围的键映射到小范围的数组下标
- **冲突解决**：链地址法（chaining）和开放寻址（open addressing）
- **期望 O(1)**：在均匀散列假设下，搜索、插入、删除都是常数时间

### 第12章 二叉搜索树（Binary Search Trees）
- **BST 性质**：左子树 ≤ 根 ≤ 右子树
- **操作**：搜索、最小值、最大值、前驱、后继、插入、删除
- **时间复杂度**：O(h)，h 为树高；最坏 O(n)，期望 O(log n)

### 第13章 红黑树（Red-Black Trees）
- **平衡 BST**：通过五条性质保证树高为 O(log n)
- **五条性质**：节点着色规则，确保没有路径比其他路径长两倍以上
- **旋转**：左旋和右旋，O(1) 时间改变树结构
- **插入/删除**：O(log n) 时间，通过重新着色和旋转恢复红黑性质

### 第14章（第17章） 数据结构的扩张（Augmenting Data Structures）
- **扩张方法**：四步法选择基础结构 → 添加信息 → 维护信息 → 开发新操作
- **动态顺序统计**：在红黑树上添加 size 属性，支持 O(log n) 的 rank/select
- **区间树**：支持高效的区间重叠查询

## 关键要点

1. **数据结构的选择取决于操作需求**：不同的操作组合需要不同的数据结构
2. **时间-空间权衡**：散列表用空间换时间，链表用时间换灵活性
3. **平衡是关键**：二叉搜索树的性能取决于树高，红黑树通过自平衡保证 O(log n)
4. **扩张是一种设计方法**：可以在已有数据结构上添加信息来支持新操作

## 数据结构操作复杂度对比

| 数据结构 | 搜索 | 插入 | 删除 | 空间 |
|---------|------|------|------|------|
| 无序数组 | O(n) | O(1) | O(n) | O(n) |
| 有序数组 | O(log n) | O(n) | O(n) | O(n) |
| 栈 | - | O(1) | O(1) | O(n) |
| 队列 | - | O(1) | O(1) | O(n) |
| 链表 | O(n) | O(1) | O(1) | O(n) |
| 散列表（期望） | O(1) | O(1) | O(1) | O(n) |
| 二叉搜索树（期望） | O(log n) | O(log n) | O(log n) | O(n) |
| 红黑树 | O(log n) | O(log n) | O(log n) | O(n) |
