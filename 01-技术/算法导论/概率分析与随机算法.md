# 概率分析与随机算法

## 通俗讲解

> 想象你每天面试一个候选人，只要比当前最好的就雇用。问题是：平均要雇几个人？如果你知道候选人以随机顺序到来，就能用概率算出来——这就是**概率分析**。
>
> 但如果你根本不知道顺序怎么办？自己打乱它！随机洗牌后再面试——这就是**随机算法**。不是靠运气，而是主动制造随机性来保证平均性能。

## 核心概念

### 雇用问题（Hiring Problem）
每天面试一个候选人，若比当前助理更好则雇用（解雇旧的）。面试费低（cᵢ），雇用费高（cₕ）。
- **最坏情况**：候选人质量递增，雇用 n 次，总费用 O(cₕn)
- **平均情况**：假设随机顺序，期望雇用约 H(n) = ln n 次（调和级数）

### 指示器随机变量（Indicator Random Variables）
对事件 A，定义指示器随机变量：

X_A = I{A} = { 1, 若 A 发生; 0, 若 A 不发生 }

**关键性质**：E[X_A] = Pr{A}

**威力**：结合**期望的线性性质**（linearity of expectation），即使事件之间有依赖关系，E[X₁ + X₂ + ... + Xₙ] = E[X₁] + E[X₂] + ... + E[Xₙ] 仍然成立。

**雇用问题分析**：
- 定义 Xᵢ = I{候选人 i 被雇用}
- 候选人 i 被雇用 ⟺ 候选人 i 是前 i 个中最好的 → Pr = 1/i
- E[Xᵢ] = 1/i
- E[总雇用次数] = Σ(1/i) = 1 + 1/2 + 1/3 + ... + 1/n = ln n + O(1)

### 随机算法（Randomized Algorithm）
算法的行为不仅取决于输入，还取决于**随机数生成器**的输出。

**两种类型**：
- **拉斯维加斯算法**（Las Vegas）：结果一定正确，运行时间随机
- **蒙特卡洛算法**（Monte Carlo）：运行时间确定，结果可能有错

**随机排列数组**（RANDOMIZE-IN-PLACE）：
```
for i = 1 to n
    交换 A[i] 与 A[RANDOM(i, n)]
```
保证每种排列等概率出现（证明用循环不变式）。

## 关键要点

1. 概率分析需要**对输入分布做假设**（如随机排列）
2. 随机算法**不依赖输入假设**，自己制造随机性
3. 指示器随机变量 + 期望线性性 = 强大的分析工具
4. "平均情况"（average-case）针对输入分布；"期望"（expected）针对算法的随机选择
5. 调和级数 Σ(1/i) ≈ ln n 在算法分析中频繁出现
