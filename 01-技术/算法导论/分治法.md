# 分治法

## 通俗讲解

> 分治法就像吃大象——一口吃不下，切成小块一块块吃。具体三步：**分**（切成小块）、**治**（每块单独处理）、**合**（拼回整体）。
>
> 归并排序就是典型分治：把数组对半分，各自排好序，再合并成一个有序数组。合并时像两堆牌面朝上，每次取较小的那张，Θ(n) 就能搞定。

## 核心概念

### 分治法三步骤
1. **分解（Divide）**：将问题划分为若干规模更小的同类子问题
2. **解决（Conquer）**：递归地求解子问题；若子问题足够小则直接求解（基本情况）
3. **合并（Combine）**：将子问题的解合并为原问题的解

### 归并排序（Merge Sort）
将数组 A[p..r] 递归排序：
- **分**：计算中点 q，分成 A[p..q] 和 A[q+1..r]
- **治**：递归排序两个子数组
- **合**：调用 MERGE 过程将两个有序子数组合并

**MERGE 过程**：将两个子数组复制到临时数组 L 和 R，然后逐个比较 L 和 R 的首元素，取较小者放回 A。时间复杂度 Θ(n)。

### 递归式（Recurrence）
分治算法的运行时间可用递归式描述：

**通用形式**：T(n) = aT(n/b) + D(n) + C(n)
- a：子问题个数
- n/b：每个子问题的规模
- D(n)：分解成本
- C(n)：合并成本

**归并排序的递归式**：T(n) = 2T(n/2) + Θ(n)

### 递归树分析（Recursion Tree）
将递归式展开为树：
- 每层的总代价为 c₂n（除叶节点层外）
- 共 lg n + 1 层
- 叶节点层总代价 c₁n
- **总代价**：c₂n lg n + c₁n = Θ(n lg n)

## 关键要点

1. 归并排序最坏情况 Θ(n lg n)，优于插入排序的 Θ(n²)
2. 归并排序是**稳定**排序，但**不是原地排序**（需要 Θ(n) 额外空间）
3. 分析递归式有三种方法：**代入法**、**递归树法**、**主方法**（见 [[递归式求解]]）
4. 插入排序的常数因子小，对小规模数据可能更快；实际中常混合使用
5. 分治法不仅用于排序，还用于矩阵乘法（Strassen）、最近点对等问题
