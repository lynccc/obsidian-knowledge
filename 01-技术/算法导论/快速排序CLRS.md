# 快速排序（Quicksort）

## 通俗讲解
> 快速排序的思路很直观：从数组里挑一个数作为"基准"（pivot），把比基准小的都放左边，比基准大的都放右边，这样基准就到了它最终该在的位置。然后对左边和右边分别递归地做同样的事情。就像你整理书架时，先选一本书作为标准，比它薄的放左边，比它厚的放右边，然后分别整理左右两边。
>
> 快速排序虽然最坏情况是 O(n²)，但在实际应用中通常是最快的排序算法，因为它的常数因子小，而且缓存命中率高。

## 核心概念（中文，附英文术语）

### 分区操作（PARTITION）
PARTITION 是快速排序的核心子程序，它选择一个**枢轴元素**（pivot），将数组重新排列，使得：
- 枢轴左边的所有元素 ≤ 枢轴
- 枢轴右边的所有元素 ≥ 枢轴
- 返回枢轴的最终位置

```
PARTITION(A, p, r):
    x = A[r]          // 选择最后一个元素作为枢轴
    i = p - 1         // i 指向低区的最后一个元素
    for j = p to r - 1:
        if A[j] ≤ x:
            i = i + 1
            exchange A[i] with A[j]
    exchange A[i + 1] with A[r]
    return i + 1
```

**循环不变量**：每次循环开始时，对于数组下标 k：
1. 若 p ≤ k ≤ i，则 A[k] ≤ x（低区）
2. 若 i+1 ≤ k ≤ j-1，则 A[k] > x（高区）
3. 若 k = r，则 A[k] = x（枢轴）

**时间复杂度**：Θ(n)，其中 n = r - p + 1

### 快速排序算法
```
QUICKSORT(A, p, r):
    if p < r:
        q = PARTITION(A, p, r)
        QUICKSORT(A, p, q - 1)
        QUICKSORT(A, q + 1, r)
```

### 快速排序的性能

| 情况 | 时间复杂度 | 条件 |
|------|-----------|------|
| 最好情况 | Θ(n log n) | 每次分区都均匀 |
| 最坏情况 | Θ(n²) | 每次分区都极不平衡（如已排序数组） |
| 平均情况 | Θ(n log n) | 随机输入 |

**最坏情况**：当每次分区都产生一个空子问题时（如数组已排序，选最后一个元素为枢轴），递归深度为 n，每层做 Θ(n) 工作。

**最好情况**：每次分区都恰好将数组分成两半，递归深度为 log n。

### 随机化版本（RANDOMIZED-QUICKSORT）
为了避免最坏情况，可以随机选择枢轴：

```
RANDOMIZED-PARTITION(A, p, r):
    i = RANDOM(p, r)          // 随机选择一个元素
    exchange A[r] with A[i]   // 将它放到最后
    return PARTITION(A, p, r) // 调用标准 PARTITION
```

**优势**：
- 没有特定输入会触发最坏情况
- 期望运行时间为 Θ(n log n)
- 实践中表现优异

### 快速排序的分析

#### 最坏情况分析
T(n) = max_{0≤q≤n-1} [T(q) + T(n-q-1)] + Θ(n)

通过代入法可证 T(n) = O(n²)，且存在输入使 T(n) = Ω(n²)，故最坏情况为 Θ(n²)。

#### 期望运行时间分析
**关键引理**：在 RANDOMIZED-QUICKSORT 中，元素 z_i 和 z_j（i < j）被比较的概率为 **2/(j-i+1)**。

**证明思路**：在 z_i, z_{i+1}, ..., z_j 中，z_i 和 z_j 被比较当且仅当 z_i 或 z_j 是其中第一个被选为枢轴的元素。

期望比较次数：
```
E[X] = Σ_{i=1}^{n-1} Σ_{j=i+1}^{n} 2/(j-i+1)
     = O(n log n)
```

## 关键要点

1. **实践中最快**：尽管最坏情况是 O(n²)，快速排序在实际应用中通常比堆排序和归并排序更快
2. **原地排序**：不需要额外的 Θ(n) 空间（归并排序需要）
3. **缓存友好**：顺序访问数组，缓存命中率高
4. **不稳定排序**：分区操作可能改变相等元素的相对顺序
5. **随机化**：随机选择枢轴可以避免最坏情况，且不需要对输入做任何假设

## 快速排序 vs 归并排序

| 特性 | 快速排序 | 归并排序 |
|------|---------|---------|
| 最坏情况 | Θ(n²) | Θ(n log n) |
| 期望情况 | Θ(n log n) | Θ(n log n) |
| 空间 | O(log n)（栈空间） | O(n) |
| 稳定性 | 不稳定 | 稳定 |
| 实践性能 | 通常更快 | 较慢 |
| 缓存友好 | 是 | 否 |
