# 最小生成树（CLRS 第21章）

## 通俗讲解
> 最小生成树问题：给定一个连通无向加权图，找到一棵包含所有顶点的树，使得树中所有边的权重之和最小。想象你要用电线连接 n 个房子，每对房子之间的电线成本不同，如何用最少的电线连接所有房子？Kruskal 算法和 Prim 算法都用贪心策略解决这个问题，时间复杂度都是 O(E log V)。

## 核心概念

### 最小生成树的定义
给定连通无向图 G = (V, E) 和权重函数 w: E → R，**最小生成树**（MST, Minimum Spanning Tree）是一个无环子集 T ⊆ E，连接所有顶点且总权重 w(T) = Σ w(u,v) 最小。

> **注意**：MST 可能不唯一，但所有 MST 的边权排序相同（练习 21.1-8）。

### 通用 MST 方法（Generic MST）
```
GENERIC-MST(G, w):
  A = ∅
  while A 不构成生成树
    找到对 A 安全的边 (u,v)
    A = A ∪ {(u,v)}
  return A
```

### 切割与安全边

#### 切割（Cut）
无向图 G = (V, E) 的**切割** (S, V-S) 是 V 的一个划分。

#### 横跨切割的边
边 (u,v) **横跨**切割 (S, V-S)，如果一个端点在 S 中，另一个在 V-S 中。

#### 尊重（Respect）
切割 (S, V-S) **尊重**边集 A，如果 A 中没有边横跨该切割。

#### 轻边（Light Edge）
横跨切割的**轻边**是权重最小的横跨边。

### 定理 21.1（安全边判定规则）
设 A 是某个 MST 的子集，(S, V-S) 是尊重 A 的切割，(u,v) 是横跨该切割的轻边，则 (u,v) 对 A 是**安全的**。

**证明核心**：切割-粘贴（Cut-and-Paste）技术——如果 MST T 不包含 (u,v)，则用 (u,v) 替换 T 中横跨同一切割的某条边 (x,y)，由于 w(u,v) ≤ w(x,y)，新树 T' 的权重不增加。

### 推论 21.2
设 C = (V_C, E_C) 是森林 G_A 中的一个连通分量（树），若 (u,v) 是连接 C 与其他分量的轻边，则 (u,v) 对 A 是安全的。

## Kruskal 算法

### 核心思想
每次选择**权重最小的边**，只要这条边连接的是两个不同的连通分量（不会形成环）。

### 算法伪代码
```
MST-KRUSKAL(G, w):
  A = ∅
  for each vertex v ∈ V
    MAKE-SET(v)
  将边按权重升序排列
  for each edge (u,v) 按权重升序
    if FIND-SET(u) ≠ FIND-SET(v)
      A = A ∪ {(u,v)}
      UNION(u, v)
  return A
```

### 关键数据结构：并查集（Disjoint-Set）
- **MAKE-SET(v)**：创建包含 v 的单元素集合
- **FIND-SET(v)**：返回 v 所在集合的代表元素
- **UNION(u, v)**：合并 u 和 v 所在的集合

> 🔗 已有笔记：[[并查集]]

### 时间复杂度分析
| 步骤 | 时间 |
|------|------|
| 初始化并查集 | O(V) |
| 排序边 | O(E log E) |
| 并查集操作 | O(E · α(V)) ≈ O(E) |
| **总计** | **O(E log E) = O(E log V)** |

> α(V) 是阿克曼函数的反函数，实际中 ≤ 4。

### 执行示例
Kruskal 算法的执行过程：
1. 将所有边按权重排序
2. 依次考虑每条边
3. 如果边的两个端点属于不同集合，则加入 MST 并合并集合
4. 否则跳过（会形成环）

## Prim 算法

### 核心思想
从某个顶点开始，逐步"生长"一棵树。每次选择连接树内和树外顶点的**最轻边**。

### 算法伪代码
```
MST-PRIM(G, w, r):
  for each vertex u ∈ V
    u.key = ∞
    u.π = NIL
  r.key = 0
  Q = V  // 最小优先队列
  while Q ≠ ∅
    u = EXTRACT-MIN(Q)
    for each vertex v ∈ Adj[u]
      if v ∈ Q and w(u,v) < v.key
        v.π = u
        v.key = w(u,v)
        DECREASE-KEY(Q, v, w(u,v))
```

### 关键属性
- **v.key**：连接 v 到树中某顶点的最小边权
- **v.π**：v 在 MST 中的父节点
- **Q**：最小优先队列，存储尚未加入树的顶点

### 时间复杂度
| 实现方式 | 时间 |
|----------|------|
| 数组 | O(V²) |
| 二叉堆 | O(E log V) |
| 斐波那契堆 | O(E + V log V) |

> **斐波那契堆**在边数远大于顶点数时（E >> V）有显著优势。

### 与 Dijkstra 算法的相似性
Prim 算法和 Dijkstra 算法结构几乎相同：
- 都使用优先队列
- 都维护"距离"（key 或 d）
- 区别：Prim 的 key 是到树的最小边权，Dijkstra 的 d 是到源点的最短路径距离

### 与邓俊辉版的差异
邓俊辉版可能更侧重于 Prim 算法的直观理解和实现细节；CLRS 版强调了：
1. 通用 MST 框架和安全边理论

## Kruskal vs Prim 对比

| 特性 | Kruskal | Prim |
|------|---------|------|
| 策略 | 全局最轻安全边 | 局部最轻安全边 |
| 数据结构 | 并查集 | 优先队列 |
| 时间复杂度 | O(E log E) | O(E log V) 或 O(E + V log V) |
| 适用图 | 稀疏图更优 | 稠密图更优 |
| 实现难度 | 较简单 | 需要优先队列 |
| 连通性 | 天然处理非连通图（生成森林） | 要求图连通 |

## 关键要点

1. **贪心策略有效**：MST 问题的特殊结构使得局部最优选择（最轻安全边）能保证全局最优
2. **切割定理**是核心：它给出了判定安全边的充分条件
3. **Kruskal 用并查集**：高效判断是否形成环
4. **Prim 用优先队列**：高效找到连接树内外的最轻边
5. **MST 不一定唯一**：但所有 MST 的边权排序相同
