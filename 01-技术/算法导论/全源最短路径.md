# 全源最短路径（CLRS 第23章）

## 通俗讲解
> 全源最短路径问题：给定加权有向图，求**每对顶点之间**的最短路径。可以运行 |V| 次单源算法，但本章的方法通常更高效。三种核心算法：矩阵乘法法 O(V³ log V)、Floyd-Warshall O(V³)、Johnson O(V² log V + VE)。特别地，Floyd-Warshall 是邓俊辉版没有深入覆盖的重要算法。

## 输入输出约定

### 输入
- n×n 权重矩阵 W = (w_ij)
- w_ij = 0（i=j）、边权（(i,j)∈E）、∞（(i,j)∉E）

### 输出
- n×n 最短路径权重矩阵 D = (d_ij)，d_ij = δ(i,j)
- n×n 前驱矩阵 Π = (π_ij)，用于重构最短路径

## 矩阵乘法法（Matrix Multiplication Method）

### 核心思想
将最短路径计算转化为类似矩阵乘法的操作，用**重复平方法**加速。

### 递推公式
设 l^(r)_ij 是从 i 到 j 最多经过 r 条边的最短路径权重：

```
l^(0)_ij = { 0, if i=j; ∞, if i≠j }
l^(r)_ij = min{ l^(r-1)_ik + w_kj : 1 ≤ k ≤ n }
```

### EXTEND-SHORTEST-PATHS
实现递推的核心操作，类似矩阵乘法：
```
EXTEND-SHORTEST-PATHS(L^(r-1), W, L^(r), n):
  for i = 1 to n
    for j = 1 to n
      for k = 1 to n
        l^(r)_ij = min(l^(r)_ij, l^(r-1)_ik + w_kj)
```

> **热带半环**（Tropical Semiring）：min 对应 +，+ 对应 ×，∞ 对应 0，0 对应 1。

### SLOW-APSP
- 运行 n-1 次 EXTEND-SHORTEST-PATHS
- 时间：**Θ(n⁴)**

### FASTER-APSP（重复平方法）
- 利用 L^(n-1) = W^(n-1)，通过重复平方计算
- 只需 ⌈lg(n-1)⌉ 次矩阵"乘法"
- 时间：**Θ(n³ log n)**

```
FASTER-APSP(W, n):
  L = W
  r = 1
  while r < n-1
    M = ∞
    EXTEND-SHORTEST-PATHS(L, L, M, n)  // M = L²
    r = 2r
    L = M
  return L
```

## Floyd-Warshall 算法

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此算法。

### 核心思想
考虑中间顶点。设 d^(k)_ij 是从 i 到 j 且中间顶点都在 {1,2,...,k} 中的最短路径权重。

### 递推公式
```
d^(0)_ij = w_ij
d^(k)_ij = min{ d^(k-1)_ij, d^(k-1)_ik + d^(k-1)_kj }
```

**理解**：对于从 i 到 j 的最短路径，考虑是否经过顶点 k：
- **不经过 k**：d^(k)_ij = d^(k-1)_ij
- **经过 k**：d^(k)_ij = d^(k-1)_ik + d^(k-1)_kj（从 i 到 k 再到 j）

### 算法伪代码
```
FLOYD-WARSHALL(W, n):
  D^(0) = W
  for k = 1 to n
    创建新矩阵 D^(k)
    for i = 1 to n
      for j = 1 to n
        d^(k)_ij = min(d^(k-1)_ij, d^(k-1)_ik + d^(k-1)_kj)
  return D^(n)
```

### 时间复杂度
**Θ(n³)**——三重循环，每层 n 次迭代。

### 空间优化
可以原地更新：只用一个矩阵 D，直接在 D 上迭代：
```
for k = 1 to n
  for i = 1 to n
    for j = 1 to n
      D[i][j] = min(D[i][j], D[i][k] + D[k][j])
```

### 与矩阵乘法法的对比
| 特性 | 矩阵乘法法 | Floyd-Warshall |
|------|-----------|----------------|
| 时间 | Θ(n³ log n) | Θ(n³) |
| 思路 | 重复平方 | 逐个加入中间顶点 |
| 负权边 | ✅ | ✅ |
| 负权环检测 | 需额外处理 | 检查对角线 |

### 构造最短路径
可以在计算 D 的同时计算前驱矩阵 Π：
```
当 d^(k)_ij 被更新为 d^(k-1)_ik + d^(k-1)_kj 时：
  π^(k)_ij = π^(k-1)_kj
```

### 传递闭包（Transitive Closure）
Floyd-Warshall 的变体，用于计算有向图的传递闭包：
```
T^(k)_ij = T^(k-1)_ij ∨ (T^(k-1)_ik ∧ T^(k-1)_kj)
```
- 将 min 替换为 ∨，+ 替换为 ∧
- 时间：Θ(n³)

## Johnson 算法

### 核心思想
通过**重新赋权**（Reweighting）消除负权边，然后对每个顶点运行 Dijkstra。

### 重新赋权的关键
给每个顶点赋一个值 h(v)，定义新权重：
```
ŵ(u,v) = w(u,v) + h(u) - h(v)
```

**性质**：
1. ŵ(u,v) ≥ 0（如果 h 选择正确）
2. 最短路径在新权重下不变（路径权重变化只是端点的 h 值差）

### 算法步骤
```
JOHNSON(G, w):
  1. 创建 G'，添加超级源点 s，w(s,v) = 0
  2. 对 G' 运行 Bellman-Ford（源点 s）
  3. 若检测到负权环，报告错误
  4. 设置 h(v) = δ(s,v)（Bellman-Ford 的结果）
  5. 重新赋权：ŵ(u,v) = w(u,v) + h(u) - h(v)
  6. 对每个顶点 u 运行 Dijkstra(G, ŵ, u)
  7. 还原真实距离：δ(u,v) = δ̂(u,v) + h(v) - h(u)
```

### 时间复杂度
- Bellman-Ford：O(VE)
- |V| 次 Dijkstra：O(V · (V log V + E)) = O(V² log V + VE)
- **总计**：**O(V² log V + VE)**

### 适用场景
- **稀疏图**：E = o(V²/log V) 时，比 Floyd-Warshall 的 O(V³) 快
- **有负权边但无负权环**

### 与邓俊辉版的差异
邓俊辉版通常不覆盖 Johnson 算法。CLRS 版详细展示了：
1. Bellman-Ford 作为子程序的使用
2. 重新赋权技术的数学证明
3. 与直接运行 |V| 次 Bellman-Ford（O(V²E)）的效率对比

## 三种算法对比

| 算法 | 时间复杂度 | 负权边 | 最佳适用 |
|------|-----------|--------|----------|
| 矩阵乘法法 | Θ(n³ log n) | ✅ | 理论分析 |
| Floyd-Warshall | Θ(n³) | ✅ | 中等规模稠密图 |
| Johnson | O(V² log V + VE) | ✅ | 大规模稀疏图 |

## 关键要点

1. **Floyd-Warshall 简洁高效**：三重循环，Θ(n³)，实现简单
2. **中间顶点的思想**：Floyd-Warshall 的核心是逐个加入中间顶点
3. **重新赋权技术**：Johnson 算法用 Bellman-Ford 消除负权边，使 Dijkstra 可用
4. **稠密 vs 稀疏**：Floyd-Warshall 适合稠密图，Johnson 适合稀疏图
5. **负权环检测**：三种算法都可以检测负权环
