# 线性时间排序

## 通俗讲解
> 你可能觉得 O(n log n) 已经是排序的极限了，但那只是"比较排序"的极限。如果我们能获取元素的其他信息（比如数字的范围、位数），就可以突破这个下界，实现线性时间排序！
>
> - **计数排序**：就像老师数有多少人考了 100 分、99 分、98 分……然后按分数从小到大排好队
> - **基数排序**：就像整理扑克牌，先按花色分组，再按数字排序
> - **桶排序**：就像把一堆小球按大小范围放进不同的桶里，每个桶内单独排序

## 核心概念（中文，附英文术语）

### 比较排序的下界（Lower Bounds for Sorting）

#### 决策树模型（Decision Tree Model）
任何基于比较的排序算法都可以用**决策树**表示：
- **内部节点**：代表一次比较 a_i : a_j
- **叶子节点**：代表一种排列结果
- **从根到叶子的路径**：代表算法的一次执行

#### 关键定理
**定理**：在最坏情况下，任何基于比较的排序算法都需要 **Ω(n log n)** 次比较。

**证明**：
1. 决策树必须有至少 n! 个叶子（因为 n 个元素有 n! 种排列）
2. 一棵高度为 h 的二叉树最多有 2^h 个叶子
3. 因此 2^h ≥ n!，即 h ≥ lg(n!) = Ω(n log n)（由 Stirling 公式）

**推论**：堆排序和归并排序是**渐近最优**的比较排序算法。

### 计数排序（Counting Sort）

**核心思想**：对每个元素 x，统计有多少个元素比 x 小，从而确定 x 的最终位置。

**前提条件**：输入元素都是 0 到 k 之间的整数。

```
COUNTING-SORT(A, n, k):
    let C[0..k] be a new array
    for i = 0 to k:
        C[i] = 0
    for j = 1 to n:
        C[A[j]] = C[A[j]] + 1       // 统计每个值出现的次数
    for i = 1 to k:
        C[i] = C[i] + C[i - 1]      // C[i] = 小于等于 i 的元素个数
    for j = n downto 1:              // 从后往前，保证稳定性
        B[C[A[j]]] = A[j]
        C[A[j]] = C[A[j]] - 1
    return B
```

**时间复杂度**：Θ(k + n)
**空间复杂度**：Θ(k + n)
**稳定性**：稳定（stable）

**关键要点**：
- 当 k = O(n) 时，计数排序是线性的
- 计数排序是**稳定排序**，这对基数排序很重要

### 基数排序（Radix Sort）

**核心思想**：按位排序，从最低有效位到最高有效位，每次使用稳定排序。

```
RADIX-SORT(A, n, d):
    for i = 1 to d:                    // 从最低位到最高位
        use a stable sort to sort A on digit i
```

**例子**：对三位数排序
```
329  457  657  839  436  720  355
// 按个位排序
720  355  436  457  657  329  839
// 按十位排序
720  329  436  839  355  457  657
// 按百位排序
329  355  436  457  657  720  839
```

**时间复杂度**：Θ(d(n + k))
- d：位数
- n：元素个数
- k：每位的取值范围（如十进制为 10）

**关键引理**：给定 n 个 d 位数，每位有 k 种可能的取值，如果使用的稳定排序耗时 Θ(n + k)，则基数排序耗时 Θ(d(n + k))。

**当 d 为常数且 k = O(n) 时，基数排序是线性的！**

### 桶排序（Bucket Sort）

**核心思想**：假设输入均匀分布在 [0, 1) 上，将元素分配到 n 个桶中，每个桶内单独排序。

```
BUCKET-SORT(A, n):
    let B[0..n-1] be a new array of empty lists
    for i = 1 to n:
        insert A[i] into list B[⌊n · A[i]⌋]
    for i = 0 to n - 1:
        sort list B[i] with insertion sort
    concatenate lists B[0], B[1], ..., B[n-1]
```

**时间复杂度**：
- **平均情况**：Θ(n)（假设输入均匀分布）
- **最坏情况**：Θ(n²)（所有元素落入同一个桶）

**期望分析**：
- 设 n_i 为第 i 个桶中的元素数
- E[n_i²] = 2 - 1/n（利用指示器随机变量）
- E[Σ n_i²] = 2n - 1
- 因此期望运行时间为 Θ(n)

## 各排序算法对比

| 算法 | 最坏情况 | 平均情况 | 稳定性 | 原地 | 适用场景 |
|------|---------|---------|--------|------|---------|
| 堆排序 | O(n log n) | O(n log n) | ❌ | ✅ | 通用 |
| 快速排序 | O(n²) | O(n log n) | ❌ | ✅ | 通用（实践中最快） |
| 归并排序 | O(n log n) | O(n log n) | ✅ | ❌ | 需要稳定性 |
| 计数排序 | O(k + n) | O(k + n) | ✅ | ❌ | k = O(n) |
| 基数排序 | O(d(n+k)) | O(d(n+k)) | ✅ | ❌ | d 小，k = O(n) |
| 桶排序 | O(n²) | O(n) | ✅ | ❌ | 均匀分布 |

## 关键要点

1. **比较排序的极限**：Ω(n log n) 是不可突破的下界
2. **非比较排序**：通过利用元素的额外信息，可以达到线性时间
3. **稳定性很重要**：计数排序和基数排序的稳定性是其正确性的关键
4. **实际选择**：选择哪种排序取决于数据特征（范围、分布、是否需要稳定性等）
