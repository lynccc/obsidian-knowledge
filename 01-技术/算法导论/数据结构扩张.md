# 数据结构的扩张（Augmenting Data Structures）

## 通俗讲解
> 现有的数据结构（如红黑树）就像一个已经很好的工具箱，但有时我们需要它做更多事情。比如：
> - **动态顺序统计**：想知道"第 k 小的元素是什么？"或者"这个元素排第几？"
> - **区间树**：想知道"哪些时间段与给定时间段有重叠？"
>
> 数据结构扩张就是"改装"现有数据结构，给它添加新功能。就像给汽车加装 GPS 导航——基本结构不变，但功能更强大了。

## 核心概念（中文，附英文术语）

### 扩张数据结构的四步法（Four-Step Method）

**第一步：选择基础数据结构**
- 根据需要支持的操作选择合适的基础结构
- 例如：需要有序操作 → 选择红黑树

**第二步：确定附加信息**
- 确定需要在每个节点存储的额外信息
- 例如：在红黑树的每个节点存储子树大小 `size`

**第三步：验证信息维护**
- 证明基础操作（如插入、删除、旋转）能高效维护附加信息
- 关键：附加信息的更新不应增加基础操作的渐近时间复杂度

**第四步：开发新操作**
- 设计利用附加信息的新操作
- 例如：SELECT 和 RANK 操作

### 扩张的关键定理

**定理 17.1**（红黑树扩张定理）：
设红黑树的每个节点 x 有附加属性 f，满足：
- f 仅依赖于 x 本身、x.left、x.right 的信息
- f 可以在 O(1) 时间从这些信息计算得出

则插入和删除操作可以在 **O(log n)** 时间内维护所有节点的 f 值。

**证明思路**：
- 改变 x 的 f 值只会影响 x 的祖先
- 红黑树高度为 O(log n)
- 因此更新 f 的总代价为 O(log n)

### 动态顺序统计（Dynamic Order Statistics）

#### 问题
在 O(log n) 时间内支持：
- **OS-SELECT(i)**：找第 i 小的元素
- **OS-RANK(x)**：找元素 x 的排名（第几小）

#### 解决方案：顺序统计树（Order-Statistic Tree）

在红黑树的每个节点 x 上添加属性 `x.size`：
```
x.size = x.left.size + x.right.size + 1
```
（NIL 的 size = 0）

#### OS-SELECT：找第 i 小的元素
```
OS-SELECT(x, i):
    r = x.left.size + 1          // x 在子树中的排名
    if i == r:
        return x                  // 找到了
    elseif i < r:
        return OS-SELECT(x.left, i)   // 在左子树找
    else:
        return OS-SELECT(x.right, i - r) // 在右子树找
```

**时间复杂度**：O(log n) —— 每次递归下降一层

**直觉**：
- x.left.size + 1 = x 在以 x 为根的子树中的排名
- 如果 i < r，第 i 小在左子树
- 如果 i > r，第 i 小在右子树，需要调整 i

#### OS-RANK：找元素 x 的排名
```
OS-RANK(T, x):
    r = x.left.size + 1          // x 在自身子树中的排名
    y = x
    while y ≠ T.root:
        if y == y.p.right:       // 如果 y 是右孩子
            r = r + y.p.left.size + 1  // 加上父节点和左子树
        y = y.p
    return r
```

**时间复杂度**：O(log n) —— 沿着路径向根移动

**直觉**：
- x 的排名 = x 左子树大小 + 1 + 所有"左祖先"的贡献
- 当 y 是右孩子时，父节点和父节点的左子树都在 y 前面

#### 维护 size 属性

**旋转时更新**：只需更新两个节点的 size
```
LEFT-ROTATE(T, x):
    // ... 标准旋转操作 ...
    y.size = x.size
    x.size = x.left.size + x.right.size + 1
```

**插入时**：沿路径向上更新 size，O(log n)
**删除时**：沿路径向上更新 size，O(log n)

### 区间树（Interval Tree）

#### 问题
存储一组区间 [low, high]，支持高效查询：
- **INTERVAL-SEARCH(i)**：找一个与区间 i 重叠的区间

#### 区间三歧性（Interval Trichotomy）
对于任意两个区间 i 和 i'，恰好满足以下之一：
1. i 和 i' **重叠**（overlap）
2. i 在 i' **左边**（i.high < i'.low）
3. i 在 i' **右边**（i'.high < i.low）

#### 区间树的结构

基于红黑树，按区间左端点 low 排序：
- 每个节点存储一个区间 `x.int`
- 附加属性 `x.max` = 以 x 为根的子树中，所有区间的最大右端点

```
x.max = max(x.int.high, x.left.max, x.right.max)
```

#### INTERVAL-SEARCH：查找重叠区间
```
INTERVAL-SEARCH(T, i):
    x = T.root
    while x ≠ T.nil and i 与 x.int 不重叠:
        if x.left ≠ T.nil and x.left.max ≥ i.low:
            x = x.left           // 左子树可能有重叠
        else:
            x = x.right          // 左子树没有重叠，去右子树
    return x
```

**时间复杂度**：O(log n)

**关键洞察**：
- 如果 x 的区间不与 i 重叠：
  - 如果 x.left.max ≥ i.low，左子树**可能**有重叠区间
  - 否则，左子树**一定没有**重叠区间，去右子树
- 只需检查一条路径！

**正确性证明**：
- 如果搜索到达 T.nil，说明树中没有与 i 重叠的区间
- 如果左子树的 max ≥ i.low，左子树中一定存在某个区间的 high ≥ i.low
- 由于 BST 按 low 排序，左子树中的所有区间 low ≤ x.low ≤ i.high（如果不重叠的话）
- 因此左子树中一定有区间与 i 重叠

#### 维护 max 属性

**旋转时更新**：只需更新两个节点的 max
```
LEFT-ROTATE(T, x):
    // ... 标准旋转操作 ...
    y.max = x.max
    x.max = max(x.int.high, x.left.max, x.right.max)
```

**插入和删除**：O(log n) 维护 max

#### 插入和删除
- **INTERVAL-INSERT**：像普通红黑树插入，然后更新路径上的 max
- **INTERVAL-DELETE**：像普通红黑树删除，然后更新路径上的 max

## 关键要点

1. **四步法是通用方法**：选择基础结构 → 添加信息 → 维护信息 → 新操作
2. **扩张不增加渐近复杂度**：如果附加信息可以在 O(1) 时间更新
3. **顺序统计树**：在红黑树上添加 size，支持 O(log n) 的 rank/select
4. **区间树**：在红黑树上添加 max，支持 O(log n) 的区间重叠查询
5. **旋转时只更新两个节点**：这是扩张高效的关键

## 扩张的其他例子

| 扩张目标 | 基础结构 | 附加信息 | 新操作 |
|---------|---------|---------|--------|
| 顺序统计 | 红黑树 | size | OS-SELECT, OS-RANK |
| 区间树 | 红黑树 | max | INTERVAL-SEARCH |
| 前缀树 | BST | 子树和 | 范围求和 |
| 最近点对 | BST | 子树边界 | 最近点查询 |
