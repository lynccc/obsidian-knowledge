# 基础数据结构（Elementary Data Structures）

## 通俗讲解
> 这一章介绍最基础的数据结构，就像学做菜前先认识锅碗瓢盆：
> - **栈**：像叠盘子，后放的先拿（后进先出）
> - **队列**：像排队买奶茶，先到的先买（先进先出）
> - **链表**：像寻宝游戏，每个线索指向下一个线索的位置
> - **有根树**：像家族族谱，每个人有自己的父母和孩子

## 核心概念（中文，附英文术语）

### 栈（Stack）

栈是一种**后进先出**（LIFO, Last-In First-Out）的数据结构。

**基本操作**：
| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| PUSH(S, x) | 将元素 x 压入栈顶 | O(1) |
| POP(S) | 弹出并返回栈顶元素 | O(1) |
| STACK-EMPTY(S) | 判断栈是否为空 | O(1) |

**数组实现**：
```
PUSH(S, x):
    S.top = S.top + 1
    S[S.top] = x

POP(S):
    if STACK-EMPTY(S):
        error "underflow"
    S.top = S.top - 1
    return S[S.top + 1]
```

**应用场景**：
- 函数调用栈
- 表达式求值（后缀表达式）
- 括号匹配
- 深度优先搜索（DFS）

---

### 队列（Queue）

队列是一种**先进先出**（FIFO, First-In First-Out）的数据结构。

**基本操作**：
| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| ENQUEUE(Q, x) | 将元素 x 加入队尾 | O(1) |
| DEQUEUE(Q) | 删除并返回队头元素 | O(1) |

**循环队列实现**：
```
ENQUEUE(Q, x):
    Q[Q.tail] = x
    if Q.tail == Q.length:
        Q.tail = 1
    else:
        Q.tail = Q.tail + 1

DEQUEUE(Q):
    x = Q[Q.head]
    if Q.head == Q.length:
        Q.head = 1
    else:
        Q.head = Q.head + 1
    return x
```

**注意**：使用循环数组实现，当 head = tail 时表示队列为空，但会浪费一个空间来区分空和满。

**应用场景**：
- 任务调度（先来先服务）
- 广度优先搜索（BFS）
- 打印任务队列
- 消息队列

### 链表（Linked List）

链表是一种**动态数据结构**，通过指针将元素串联起来。

#### 单链表（Singly Linked List）
每个节点包含：
- `key`：数据
- `next`：指向下一个节点的指针

```
SEARCH(L, k):
    x = L.head
    while x ≠ NIL and x.key ≠ k:
        x = x.next
    return x
```

**时间复杂度**：搜索 O(n)，插入/删除已知位置 O(1)

#### 双链表（Doubly Linked List）
每个节点包含：
- `key`：数据
- `prev`：指向前一个节点的指针
- `next`：指向后一个节点的指针

**优势**：删除操作更高效，只需 O(1) 时间（已知节点位置）

```
LIST-DELETE(L, x):
    x.prev.next = x.next
    x.next.prev = x.prev
```

#### 哨兵节点（Sentinel）
使用一个特殊的哨兵节点 `L.nil` 来简化边界条件：
- 哨兵位于头尾之间，形成循环
- 空链表：`L.nil.next = L.nil.prev = L.nil`
- 优点：消除空指针检查，简化代码
- 缺点：额外的空间开销，对于多个短链表可能浪费

**哨兵适用场景**：
- 链表操作频繁
- 链表数量少
- 每个链表元素较多

### 有根树（Rooted Tree）

#### 二叉树表示
每个节点包含：
- `p`：父节点指针
- `left`：左孩子指针
- `right`：右孩子指针
- `key`：数据

**空指针**：NIL 表示不存在的节点

#### 左孩子右兄弟表示（Left-Child, Right-Sibling）
用于表示一般的有根树（每个节点可以有任意多个孩子）：
- `left-child`：指向最左边的孩子
- `right-sibling`：指向右边的兄弟
- `p`：父节点指针

**优点**：统一的二叉树表示，每个节点只有两个指针

**其他表示方法**：
- 堆用数组表示（完全二叉树）
- 只存储父指针（某些图算法）
- 邻接表表示（图的树结构）

## 关键要点

1. **栈和队列是受限的线性表**：只允许在一端或两端操作
2. **链表提供动态性**：不需要预分配空间，插入删除高效
3. **哨兵简化代码**：但增加空间开销，需要权衡
4. **树的表示方式取决于应用**：不同场景选择不同的表示方法

## 数据结构选择指南

| 需求 | 推荐数据结构 |
|------|-------------|
| 后进先出 | 栈 |
| 先进先出 | 队列 |
| 频繁插入删除 | 链表 |
| 频繁随机访问 | 数组 |
| 层次关系 | 树 |
