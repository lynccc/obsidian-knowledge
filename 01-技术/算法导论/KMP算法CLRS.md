# KMP算法（CLRS版）

## 通俗讲解
> 假设你在一本书里找"abababc"这个字符串。最笨的方法是：从每个位置开始逐字符比较，发现不匹配就往后移一位。但这样效率太低——你其实已经读过的信息被浪费了！
>
> KMP算法的聪明之处在于：当匹配失败时，**利用已经匹配成功的部分**来决定下一步该跳到哪里，而不是傻傻地只移动一位。这就像你在拼图时，发现某块不对，但你已经知道这块的形状——你可以直接跳到更合适的位置。

## 核心概念（中文，附英文术语）

### 串匹配问题
- **文本串 T**：长度为n的字符串，我们要在其中搜索
- **模式串 P**：长度为m的字符串，我们要找的目标
- **有效位移（Valid Shift）**：s，使得 P 是 T[s+1..s+m] 的后缀
- **目标**：找到所有有效位移

### 朴素算法（Naive String Matching）
- 逐位比较，不匹配时移动一位
- 时间复杂度：O((n-m+1)m)，最坏 O(n²)
- 问题：完全忽略了已匹配部分的信息

### Rabin-Karp 算法
- **核心思想**：把字符串看作数字，用哈希值比较
- 使用 Horner 规则计算哈希值：O(m)预处理
- 滚动哈希：从 t_s 计算 t_{s+1} 只需 O(1)
- **匹配时间**：平均 O(n+m)，最坏 O((n-m+1)m)
- **优势**：容易推广到二维模式匹配

### 有限自动机匹配（Finite Automaton Matching）
- **有限自动机（Finite Automaton）**：一个有状态转移的机器
  - 状态集 Q = {0, 1, ..., m}
  - 初始状态 q₀ = 0
  - 接受状态 = m（表示完全匹配）
  - 转移函数 δ(q, a)：当前已匹配q个字符，读入字符a后，新匹配多少字符
- **预处理**：O(m|Σ|) 构建转移函数
- **匹配**：O(n)，每个字符只看一次
- **缺点**：|Σ|（字母表大小）可能很大

### KMP算法（Knuth-Morris-Pratt）
- **前缀函数（Prefix Function）π**：π[q] = P[1..q]的最长真前缀也是后缀的长度
  - 例：P = "abababca"，π[7] = 5，因为 "ababa" 既是前缀又是长度为5的后缀
- **关键洞察**：当匹配失败时，前缀函数告诉我们模式串可以"滑动"多远而不用回退文本指针
- **预处理**：O(m) 计算前缀函数
- **匹配**：O(n)
- **总时间**：O(m+n)

### KMP的前缀函数计算
```
COMPUTE-PREFIX-FUNCTION(P, m):
  π[1] = 0
  k = 0
  for q = 2 to m:
    while k > 0 and P[k+1] ≠ P[q]:
      k = π[k]
    if P[k+1] == P[q]:
      k = k + 1
    π[q] = k
  return π
```

### 后缀数组（Suffix Array）
- **后缀数组 SA**：将T的所有后缀按字典序排列后的索引数组
- **最长公共前缀数组 LCP**：LCP[i] = SA[i]和SA[i-1]对应后缀的最长公共前缀长度
- **构建时间**：O(n lg n)
- **匹配时间**：O(m lg n + km)，k是匹配次数
- **应用场景**：
  - 最长重复子串
  - 最长公共子串
  - 文本压缩（BWT变换）

## 关键要点

1. **KMP的核心是前缀函数**：它编码了模式串的"自相似性"
2. **时间复杂度优势**：KMP是 O(n)，朴素算法是 O(nm)
3. **KMP不回退文本指针**：文本串T只扫描一次
4. **有限自动机 vs KMP**：自动机的转移函数和KMP的前缀函数本质上等价，但KMP不需要预计算所有转移
5. **后缀数组的多功能性**：不仅能做模式匹配，还能回答多种字符串查询

### 各算法对比

| 算法 | 预处理 | 匹配 | 特点 |
|------|--------|------|------|
| 朴素 | 0 | O((n-m+1)m) | 简单但慢 |
| Rabin-Karp | O(m) | 平均O(n+m) | 可推广到2D |
| 有限自动机 | O(m\|Σ\|) | O(n) | 快但预处理贵 |
| KMP | O(m) | O(n) | 最优组合 |
| 后缀数组 | O(n lg n) | O(m lg n + km) | 多功能 |

## 与其他概念的联系
- KMP的前缀函数本质上是[[动态规划CLRS]]——用子问题的解构建更大的解
- Rabin-Karp使用[[数论算法]]中的模运算进行哈希
- 有限自动机是理论计算机科学的基础概念
- 后缀数组与数据压缩（BWT）有密切联系
