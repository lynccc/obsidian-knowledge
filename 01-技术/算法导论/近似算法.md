# 近似算法

## 通俗讲解
> 很多优化问题是NP完全的（比如旅行商问题），我们找不到精确的最优解。但现实中，一个"差不多最优"的解往往就够用了——比如送货路线只要不太离谱就行。
>
> **近似算法**就是在多项式时间内找到一个"有保证的近似解"。关键在于：我们能**证明**这个解离最优解有多远。这个"多远"就是**近似比**。
>
> 打个比方：你不知道最便宜的路线是多少，但你能证明你找到的路线最多是最便宜路线的2倍。这就比盲目尝试好得多。

## 核心概念（中文，附英文术语）

### 近似比（Approximation Ratio）
- **定义**：对于最小化问题，近似比 ρ = C/C*；对于最大化问题，ρ = C*/C
  - C = 近似算法返回的解的代价
  - C* = 最优解的代价
  - ρ ≥ 1，越接近1越好
- **ρ-近似算法**：近似比 ≤ ρ 的多项式时间算法
- **1-近似** = 最优解

### 近似方案（Approximation Scheme）
- **近似方案**：接受参数 ε > 0，对任何固定的 ε 是 (1+ε)-近似算法
- **多项式时间近似方案（PTAS）**：对任何固定 ε，运行时间是多项式的
  - 但时间可能随 ε 减小而急剧增长，如 O(n^{2/ε})
- **全多项式时间近似方案（FPTAS）**：运行时间同时关于 n 和 1/ε 是多项式的
  - 如 O((1/ε)² n³)
  - 这是最理想的近似方案

### 顶点覆盖的2-近似算法

**问题**：找最小的顶点集合，覆盖图的所有边。

**算法 APPROX-VERTEX-COVER**：
```
C = ∅
E' = E
while E' ≠ ∅:
    选任意边 (u, v) ∈ E'
    C = C ∪ {u, v}
    从E'中删除所有与u或v关联的边
return C
```

**为什么是2-近似**：
1. 设A = 算法选择的边集（极大匹配）
2. 任何顶点覆盖（包括最优）必须包含A中每条边的至少一个端点
3. A中没有两条边共享端点，所以 |C*| ≥ |A|
4. 算法返回 |C| = 2|A|
5. 因此 |C| = 2|A| ≤ 2|C*|

**运行时间**：O(V + E)

### 旅行商问题（TSP）的近似

#### 满足三角不等式的TSP
- **三角不等式**：c(u,w) ≤ c(u,v) + c(v,w)（直达不比绕路贵）
- **算法**：
  1. 找最小生成树（MST）
  2. 对MST做前序遍历
  3. 返回遍历路径
- **近似比**：2
- **改进**：Christofides算法，近似比 = 3/2

#### 不满足三角不等式的TSP
- **定理**：如果 P ≠ NP，则对任何常数 ρ ≥ 1，不存在ρ-近似算法
- **意义**：没有三角不等式，TSP连近似都几乎不可能

### 集合覆盖问题（Set Cover）
- **问题**：给定全集U和子集族S，找最少的子集覆盖U
- **贪心算法**：每次选覆盖最多未覆盖元素的集合
- **近似比**：O(ln n)，其中n是全集大小
- **证明关键**：每次选择至少覆盖剩余元素的 1/k 比例

### 加权顶点覆盖的LP近似
- **思想**：用线性规划松弛整数约束
- **算法**：
  1. 求解LP松弛得到分数解 x*
  2. 将所有 x*[v] ≥ 1/2 的顶点加入覆盖
- **近似比**：2
- **关键**：LP最优值 ≤ 最优整数解，而我们选的 ≤ 2 × LP最优值

### 子集和的FPTAS
- **问题**：给定整数集合和目标值t，找不超过t的最大子集和
- **修剪列表（Trimmed List）**：合并相近的值，控制列表大小
- **近似比**：(1+ε) 对任意 ε > 0
- **运行时间**：O(n³/ε)
- **这是FPTAS**：时间和 1/ε 是多项式关系

### 3-SAT的最大化版本
- **问题**：给定3-CNF公式，找到满足最多子句的赋值
- **随机算法**：随机赋值每个变量为0或1
- **期望满足**：7/8 的子句
- **近似比**：8/7

## 关键要点

1. **近似比是保证**：不是"通常好"，而是"最坏情况也有保证"
2. **证明方法**：通过下界（最优解≥某值）和上界（近似解≤某值）的比值得到近似比
3. **匹配（Matching）是下界来源**：顶点覆盖证明中，极大匹配的大小是覆盖大小的下界
4. **LP松弛的力量**：线性规划可以为整数规划提供自然的近似
5. **PTAS vs FPTAS**：FPTAS更强大，但只对特定问题存在
6. **近似比的障碍**：有些问题（如不满足三角不等式的TSP）连常数近似比都不可能
