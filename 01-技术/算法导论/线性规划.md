# 线性规划

## 通俗讲解
> 假设你是一个政治竞选顾问，需要分配广告预算。不同政策在不同地区的效果不同（有的政策在城市好用，有的在农村好用），你有限的预算，想让总票数最大化。这就是一个**线性规划**问题。
>
> 线性规划的本质是：**在一堆线性约束条件下，最大化或最小化一个线性目标函数**。它是最基础、最强大的优化工具之一，几乎所有优化问题都可以用它或它的变体来建模。

## 核心概念（中文，附英文术语）

### 线性规划的基本要素
- **决策变量（Decision Variables）**：x₁, x₂, ..., xₙ，代表你要做的选择
- **目标函数（Objective Function）**：c₁x₁ + c₂x₂ + ... + cₙxₙ，你要最大化或最小化的量
- **约束条件（Constraints）**：一组线性不等式或等式
- **非负约束（Nonnegativity Constraints）**：x_j ≥ 0

### 标准型（Standard Form）
- **最大化** c^T x
- **约束** Ax ≤ b, x ≥ 0
- 其中A是m×n矩阵，b是m维向量，c和x是n维向量

### 一般型转换为标准型
- 如果是最小化问题：maximize (-c^T x)
- 如果有等式约束 ax = b：拆成 ax ≤ b 和 ax ≥ b
- 如果变量可为负：用 x = x⁺ - x⁻ 替换，其中 x⁺, x⁻ ≥ 0

### 解的分类
- **可行解（Feasible Solution）**：满足所有约束的解
- **不可行解（Infeasible Solution）**：违反至少一个约束
- **最优解（Optimal Solution）**：可行解中目标函数值最大的
- **可行域（Feasible Region）**：所有可行解构成的集合（凸多面体）
- **无界（Unbounded）**：可行域无界，目标函数可以无限增大

### 单纯形法（Simplex Algorithm）
- **核心思想**：从一个顶点（基本可行解）出发，沿着可行域的边移动到相邻顶点，每次移动都让目标函数值增大
- **几何直观**：可行域是凸多面体，最优解一定在某个顶点上
- **运行时间**：最坏情况下指数级，但实际中通常非常快
- **基本可行解（Basic Feasible Solution）**：可行域的顶点

### 对偶理论（Duality）
- **原问题（Primal）**：maximize c^T x, Ax ≤ b, x ≥ 0
- **对偶问题（Dual）**：minimize b^T y, A^T y ≥ c, y ≥ 0
- **弱对偶定理**：对偶问题的任何可行解 ≥ 原问题的任何可行解
- **强对偶定理**：如果原问题有最优解，则对偶问题也有最优解，且两者相等
- **互补松弛条件（Complementary Slackness）**：最优解处，原问题和对偶问题的约束"互补"

### 重要定理
- **线性规划基本定理**：任何线性程序要么 (1) 无可行解，(2) 无界，(3) 有有限的最优解
- **线性规划对偶定理**：原问题和对偶问题的最优值相等

## 关键要点

1. **建模能力**：很多问题都可以建模为线性规划——最短路径、最大流、匹配等
2. **多项式时间算法**：椭球法（Ellipsoid）和内点法（Interior-Point）可在多项式时间内求解
3. **单纯形法的地位**：实际中最常用，虽然最坏指数级，但平均表现极好
4. **对偶的价值**：对偶问题提供了原问题最优值的上下界，是设计近似算法的重要工具
5. **整数线性规划（ILP）是NP难的**：如果要求变量取整数，问题就变得极其困难

## 与其他概念的联系
- 线性规划是[[贪心算法CLRS]]的推广——贪心可以看作是特殊的LP
- 对偶理论在[[近似算法]]的设计中起关键作用（如加权顶点覆盖的2-近似）
- 最大流问题可以建模为线性规划（参见[[图算法基础CLRS]]）
- 单纯形法的思想与[[动态规划CLRS]]中的状态转移有相似之处
