# 递归式求解

## 通俗讲解

> 递归式就是"套娃方程"——T(n) 用 T(n/2) 来表示，T(n/2) 又用 T(n/4) 来表示……直到基本情况。求解它就是要把这个"套娃"打开，得到 T(n) 关于 n 的直接表达式。
>
> **主方法**最简单：记住三种情况，对号入座就行。就像查表一样——把递归式的 a、b、f(n) 代入，看属于哪种情况，答案就出来了。

## 核心概念

### 主方法（Master Method）
适用于形如 T(n) = aT(n/b) + f(n) 的递归式，其中 a ≥ 1, b > 1。

定义**分水岭函数**（watershed function）：n^(log_b a)

将 f(n) 与 n^(log_b a) 比较：

| 情况 | 条件 | 结果 |
|------|------|------|
| **情况1** | f(n) = O(n^(log_b a - ε))，ε > 0 | T(n) = Θ(n^(log_b a)) |
| **情况2** | f(n) = Θ(n^(log_b a) · lg^k n) | T(n) = Θ(n^(log_b a) · lg^(k+1) n) |
| **情况3** | f(n) = Ω(n^(log_b a + ε))，且满足正则条件 | T(n) = Θ(f(n)) |

**常见特例**（k=0 时）：
- 情况1：叶节点主导 → 结果等于分水岭函数
- 情况2：每层代价相当 → 多乘一个 lg n
- 情况3：根节点主导 → 结果等于 f(n)

### 典型例子

| 递归式 | a | b | n^(log_b a) | f(n) | 情况 | 结果 |
|--------|---|---|-------------|------|------|------|
| T(n) = 2T(n/2) + Θ(n) | 2 | 2 | n | Θ(n) | 2 | Θ(n lg n) |
| T(n) = 9T(n/3) + n | 9 | 3 | n² | n | 1 | Θ(n²) |
| T(n) = 3T(n/4) + n lg n | 3 | 4 | n^0.793 | n lg n | 3 | Θ(n lg n) |
| T(n) = 7T(n/2) + Θ(n²) | 7 | 2 | n^2.81 | Θ(n²) | 1 | Θ(n^2.81) |

### 代入法（Substitution Method）
1. **猜测**解的形式（带待定常数）
2. 用**数学归纳法**证明

技巧：猜测不成立时，尝试**减去低阶项**（如 cn → cn - d）。
**陷阱**：归纳假设中不要使用渐进记号，必须用显式常数。

### 递归树法（Recursion Tree Method）
将递归式展开为树：
1. 每个节点代表一个子问题的代价
2. 计算每层的总代价
3. 求和所有层的代价

适合**生成猜测**，再用代入法验证。

## 关键要点

1. 主方法最易用，但有适用范围——f(n) 和 n^(log_b a) 之间必须有多项式级差距
2. 当主方法不适用时（如 T(n) = 2T(n/2) + n/lg n），用代入法或 Akra-Bazzi 方法
3. 递归式中的向下取整和向上取整通常不影响渐进解
4. Strassen 矩阵乘法的 T(n) = 7T(n/2) + Θ(n²) 得到 Θ(n^lg7) ≈ O(n^2.81)
