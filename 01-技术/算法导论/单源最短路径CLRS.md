# 单源最短路径（CLRS 第22章）

## 通俗讲解
> 单源最短路径问题：给定一个加权有向图和源点 s，找到从 s 到每个顶点的最短路径。GPS 导航就是典型的最短路径问题。本章介绍三种核心算法：Bellman-Ford（通用，O(VE)）、Dijkstra（非负权，O(E log V)）、DAG 最短路径（O(V+E)）。特别地，Bellman-Ford 和 Floyd-Warshall 是邓俊辉版《数据结构》没有深入覆盖的重要算法。

## 核心概念

### 最短路径的定义
- **路径权重**：w(p) = Σ w(v_{i-1}, v_i)
- **最短路径权重**：δ(s,v) = min{w(p) : p 是从 s 到 v 的路径}，若无路径则为 ∞

### 负权边的影响
- **无负权环**：最短路径定义良好（可能是负值）
- **有负权环**：最短路径权重为 -∞（可以无限绕环降低权重）
- **Dijkstra 不能处理负权边**，Bellman-Ford 可以

### 最短路径的最优子结构
**引理 22.1**：最短路径的子路径也是最短路径。
- 这是动态规划和贪心算法适用的关键指标

### 松弛技术（Relaxation）

> 🔗 已有笔记：[[松弛操作]]

所有最短路径算法的核心操作：

```
INITIALIZE-SINGLE-SOURCE(G, s):
  for each vertex v ∈ V
    v.d = ∞
    v.π = NIL
  s.d = 0

RELAX(u, v, w):
  if v.d > u.d + w(u,v)
    v.d = u.d + w(u,v)
    v.π = u
```

### 松弛的性质

| 性质 | 描述 |
|------|------|
| **三角不等式** | δ(s,v) ≤ δ(s,u) + w(u,v) |
| **上界性质** | v.d ≥ δ(s,v)，且一旦等于就不再改变 |
| **无路径性质** | 若 s 到 v 无路径，则 v.d = δ(s,v) = ∞ |
| **收敛性质** | 若 s ⇝ u→v 是最短路径，且 u.d = δ(s,u)，则松弛 (u,v) 后 v.d = δ(s,v) |
| **路径松弛性质** | 若最短路径的边按序松弛，则终点 d 值正确 |
| **前驱子图性质** | 终止时 G_π 是最短路径树 |

## Bellman-Ford 算法

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此算法。

### 核心思想
对所有边进行 |V|-1 轮松弛。如果一轮松弛后仍有改进，说明存在负权环。

### 算法伪代码
```
BELLMAN-FORD(G, w, s):
  INITIALIZE-SINGLE-SOURCE(G, s)
  for i = 1 to |V|-1
    for each edge (u,v) ∈ E
      RELAX(u, v, w)
  for each edge (u,v) ∈ E
    if v.d > u.d + w(u,v)
      return FALSE  // 存在负权环
  return TRUE
```

### 时间复杂度
**O(VE)**（当 E = Ω(V) 时）

### 正确性证明
**引理 22.2**：若无负权环可达，则 |V|-1 轮松弛后，所有可达顶点的 v.d = δ(s,v)。

**证明思路**：最短路径最多 |V|-1 条边。第 i 轮松弛保证距离源点 i 条边以内的最短路径被正确计算。

**定理 22.4（Bellman-Ford 正确性）**：
- 无负权环 → 返回 TRUE，v.d = δ(s,v)
- 有负权环 → 返回 FALSE

### 检测负权环的原理
如果 |V|-1 轮松弛后仍能松弛某条边，说明存在负权环：
- 假设返回 TRUE，则对环上所有边有 v_i.d ≤ v_{i-1}.d + w(v_{i-1}, v_i)
- 求和得 0 ≤ w(c)，与负权环矛盾

### 应用场景
1. 存在负权边的最短路径
2. 检测负权环
3. 差分约束系统

## DAG 最短路径（DAG Shortest Paths）

### 核心思想
对 DAG 按**拓扑排序**的顺序松弛边，只需一轮即可。

### 算法伪代码
```
DAG-SHORTEST-PATHS(G, w, s):
  对 G 进行拓扑排序
  INITIALIZE-SINGLE-SOURCE(G, s)
  for each vertex u 按拓扑排序顺序
    for each vertex v ∈ Adj[u]
      RELAX(u, v, w)
```

### 时间复杂度
**Θ(V + E)**——拓扑排序 O(V+E)，松弛 O(E)。

### 正确性
拓扑排序保证：当处理顶点 u 时，所有到达 u 的最短路径已经被计算。

### 应用
- **关键路径**（Critical Path）：PERT 图中的最长路径
  - 方法：取负权重运行 DAG-SHORTEST-PATHS，或将 ∞ 改为 -∞、> 改为 <

## Dijkstra 算法

> 🔗 已有笔记：[[最短路径Dijkstra]]

### 核心思想
类似 BFS 的"波传播"，但用**优先队列**选择最近的顶点。维护已确定最短路径的顶点集合 S。

### 算法伪代码
```
DIJKSTRA(G, w, s):
  INITIALIZE-SINGLE-SOURCE(G, s)
  S = ∅
  Q = V  // 最小优先队列，按 d 值
  while Q ≠ ∅
    u = EXTRACT-MIN(Q)
    S = S ∪ {u}
    for each vertex v ∈ Adj[u]
      RELAX(u, v, w)
      if RELAX 减小了 v.d
        DECREASE-KEY(Q, v, v.d)
```

### 贪心策略
每次选择 V-S 中 d 值最小的顶点 u（"最近"的顶点），加入 S。

### 时间复杂度
| 实现方式 | 时间 |
|----------|------|
| 数组 | O(V²) |
| 二叉堆 | O(E log V) |
| 斐波那契堆 | O(V log V + E) |

### 正确性证明
**定理 22.6**：对所有顶点 u ∈ V，终止时 u.d = δ(s,u)。

**证明关键**：当 u 被加入 S 时，u.d = δ(s,u)。
- 设 y 是从 s 到 u 的最短路径上第一个不在 S 中的顶点
- 由于 x ∈ S 已被处理，y.d = δ(s,y)
- 由于 u.d ≤ y.d（EXTRACT-MIN 选择最小值）
- 且 δ(s,y) ≤ δ(s,u)（非负权重）
- 所以 u.d = δ(s,u)

### 限制条件
- **要求所有边权重非负**：w(u,v) ≥ 0
- 反例：存在负权边时，已加入 S 的顶点的 d 值可能不是真正的最短距离

### 与 BFS 和 Prim 的关系
| 算法 | 类似点 | 区别 |
|------|--------|------|
| BFS | 都是"波传播" | BFS 用队列（边权为1），Dijkstra 用优先队列 |
| Prim | 都用优先队列选最小 | Prim 选到树的最轻边，Dijkstra 选到源的最短距离 |

## 差分约束系统（Difference Constraints）

> ⚠️ **CLRS 特有内容**：邓俊辉版没有覆盖此内容。

### 问题定义
给定 m 个形如 x_j - x_i ≤ b_k 的约束，找一组满足所有约束的 x 值。

### 转化为最短路径
- 每个约束 x_j - x_i ≤ b_k 对应边 (v_i, v_j) 权重 b_k
- 添加超级源点 v_0，到所有顶点边权为 0
- 运行 Bellman-Ford

### 定理 22.9
若约束图无负权环，则 x = (δ(v_0, v_1), ..., δ(v_0, v_n)) 是可行解。
若有负权环，则无可行解。

### 引理 22.8
若 x 是可行解，则 x + d（所有分量加常数 d）也是可行解。

## 四种算法对比

| 算法 | 时间复杂度 | 负权边 | 负权环检测 | 适用场景 |
|------|-----------|--------|-----------|----------|
| Bellman-Ford | O(VE) | ✅ | ✅ | 通用，负权边 |
| DAG 最短路径 | O(V+E) | ✅ | N/A（DAG 无环） | DAG |
| Dijkstra（二叉堆） | O(E log V) | ❌ | ❌ | 非负权，稀疏图 |
| Dijkstra（斐波那契堆） | O(V log V + E) | ❌ | ❌ | 非负权，稠密图 |

## 关键要点

1. **松弛是核心**：所有最短路径算法的本质都是不同顺序的松弛操作
2. **Bellman-Ford 是通用解法**：处理负权边，检测负权环，但较慢
3. **Dijkstra 是高效解法**：非负权时最优，但不能处理负权边
4. **DAG 特殊结构**：拓扑排序使得只需一轮松弛
5. **差分约束**：将线性不等式转化为图论问题，展示 Bellman-Ford 的广泛应用
