## 🧩 关键概念

| 概念 | 说明 |
|------|------|
| 二叉树 | 每个节点至多两棵子树的有序树 |
| BinNode | 二叉树节点类，含 data、lc、rc、parent 等 |
| BinTree | 二叉树类，管理根节点和规模 |
| 遍历 | 系统化访问每个节点，有先/中/后/层次四种 |
| 编码树 | 用二叉树路径表示字符编码 |
| Huffman编码 | 基于频率的最优前缀编码 |
