# 平衡二叉搜索树

## 核心概念

[[二叉搜索树BST|BST]] 的查找效率取决于树高。当 BST 退化为链表时，复杂度退化为 O(n)。**平衡二叉搜索树**通过维护树的平衡性，保证树高始终为 O(log n)，从而确保所有操作的对数时间复杂度。

## 关键要点

### 树高与性能

- BST 各操作复杂度均为 **O(h)**，h 为树高
- 含 n 个节点的二叉树，最小高度为 ⌊log₂n⌋
- **理想平衡**：树高恰好达到理论下界 ⌊log₂n⌋
- **适度平衡**：树高维持在 O(log n) 即可（AVL、红黑树等采用此策略）

### 理想平衡 vs 适度平衡

- 理想平衡（如完全二叉树）虽最优，但维护代价过高
- 适度平衡允许一定的"不完美"，用较低的维护成本换取足够好的性能
- 这是工程上的经典权衡

### 等价变换

**核心思想**：在不改变中序遍历序列（即不破坏 BST 有序性）的前提下，调整树的结构以降低树高。

> 中序遍历相同 → 关键码序列相同 → 逻辑等价

等价的 BST 可以有不同的形态，平衡调整就是在等价类中选择更平衡的那个。

### 旋转调整

旋转是实现等价变换的基本操作：

```
右旋（zig）           左旋（zag）
    P                    S
   / \                  / \
  S   C    ──→        A    P
 / \                      / \
A   B                    B   C
```

- **右旋**（顺时针）：将左孩子提升为父节点
- **左旋**（逆时针）：将右孩子提升为父节点
- 旋转仅改变局部结构，**保持中序遍历不变**
- 单次旋转：O(1)

### 平衡因子

定义：**bf(v) = height(v.left) - height(v.right)**

- bf > 0：左偏
- bf < 0：右偏
- bf = 0：左右等高

## 与其他概念的联系

- 是 [[二叉搜索树BST]] 的优化版本
- 旋转操作是 [[AVL树]] 的核心机制
- 更高级的平衡树：[[红黑树]]、[[B树]]
- 基于 [[二叉树]] 的结构性质
