# 左式堆

## 核心概念

左式堆（Leftist Heap）是一种支持高效**合并**操作的[[优先级队列]]实现。它是一棵满足**堆序性**的二叉树，同时额外满足**左倾性**（leftist property）。

左式堆的核心优势：合并两个堆的时间为 O(log n)，远优于[[二叉堆]]合并的 O(n)。

## 关键要点

### 堆合并问题

[[二叉堆]]的合并需要将一个堆的所有元素逐个插入另一个堆，时间 O(n log n) 或 O(n)。当应用需要频繁合并堆时（如离散事件模拟），这是瓶颈。左式堆专为解决此问题而设计。

### 空节点路径长度（NPL）

- **外部节点**（空节点）的 NPL = 0
- 内部节点的 NPL = min(左子 NPL, 右子 NPL) + 1
- NPL 实质上是以该节点为根的**满二叉树**高度

### 左倾性

左式堆要求：任意内部节点的**左子 NPL ≥ 右子 NPL**。

推论：沿最右侧通路（right spine）从根到外部节点的路径长度 = O(log n)。这是合并算法高效的关键保证。

### 合并算法 `merge(h1, h2)`

核心步骤（递归实现）：
1. 若某一堆为空，返回另一个
2. 确保 `h1` 的根关键码 ≥ `h2` 的根关键码（否则交换）
3. 递归合并 `h1->rc`（右子堆）与 `h2`
4. 将结果作为 `h1` 的新右子
5. **维护左倾性**：若左子 NPL < 右子 NPL，则交换左右子
6. 更新 `h1` 的 NPL

时间复杂度：O(log n)，因为递归沿最右侧通路进行。

### 基于合并的插入与删除

- **插入**：将新元素视为单节点左式堆，与原堆合并 → O(log n)
- **删除堆顶**：合并左右子堆 → O(log n)

所有操作均基于 `merge` 实现，算法统一简洁。
