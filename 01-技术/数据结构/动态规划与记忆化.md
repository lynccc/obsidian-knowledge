# 动态规划与记忆化

## 核心概念

递归算法可能存在大量**重复计算**。**记忆化**（制表）通过缓存已计算结果避免重复，**动态规划**则自底向上构建解，两者都是优化递归的有效策略。

## 关键要点

### 问题：朴素递归的低效

```cpp
// 朴素 Fibonacci：O(2^n) 指数时间
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // 大量重复计算
}
```

递归树中 fib(3) 被计算了 O(n) 次，fib(2) 被计算了 O(n²) 次...

### 记忆化（Memoization，自顶向下）
- 用数组/哈希表记录已计算的值
- 递归时先查表，命中直接返回
- 将 O(2^n) 降为 O(n)

```cpp
// 记忆化 Fibonacci：O(n) 时间 + O(n) 空间
int memo[MAXN];
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n]; // 查表
    return memo[n] = fib(n-1) + fib(n-2); // 存表
}
```

### 动态规划（自底向上）
- 从小问题开始迭代求解
- 填表构建完整解
- 避免递归开销，可进一步优化空间

```cpp
// 动态规划 Fibonacci：O(n) 时间 + O(1) 空间
int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int t = a + b;
        a = b;
        b = t;
    }
    return b;
}
```

## 时空权衡
- 记忆化：[[空间复杂度|O(n) 空间]]换取 O(n) 时间
- 动态规划：可优化到 O(1) 空间（仅保留必要状态）
