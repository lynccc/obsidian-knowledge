# Huffman编码

## 核心概念

**Huffman编码**是一种基于字符出现频率的**最优前缀编码**算法，通过构建最优二叉[[编码树]]实现最小编码总长度。

## 最优编码树

在所有编码树中，使**加权路径长度** (WPL) 最小的称为最优编码树：

$$WPL = \sum_{i} f_i \cdot d_i$$

其中 $f_i$ 为字符频率，$d_i$ 为对应叶子深度。

**性质**：最优编码树中，频率最低的两个字符一定是**最深**的兄弟叶子。

## Huffman 算法

采用[[贪心策略]]：

1. 为每个字符创建单节点树，权值为其频率
2. **重复**以下步骤直到只剩一棵树：
   - 选取权值最小的两棵树 $T_1, T_2$
   - 合并为新树：根权值 = $T_1 + T_2$
3. 最终得到的树即为 Huffman 编码树

```cpp
// 伪代码
forest = {单节点树集合，按频率排序}
while forest.size() > 1:
    T1 = forest.removeMin()
    T2 = forest.removeMin()
    T = merge(T1, T2)  // 新根，左右孩子为T1,T2
    forest.insert(T, T.weight)
```

## 时间复杂度

- 使用**最小堆**（优先队列）：`O(n log n)`
- `n` 为字符集大小

## 关键要点

- Huffman 编码是**贪心算法**的典型应用
- 产生的编码一定是**前缀编码**（字符都在叶子）
- **频率高的字符编码短，频率低的字符编码长**
- 编码不是唯一的（相同频率的不同合并顺序产生不同树）
