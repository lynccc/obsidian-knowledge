# 渐进复杂度记号

## 核心概念

渐进复杂度记号用于描述算法在输入规模 n 趋于无穷时的效率趋势，忽略常数因子和低阶项，关注增长趋势。

## 关键要点

### 大O记号（上界）
- **O(f(n))**：存在正常数 c 和 n₀，使得当 n ≥ n₀ 时，T(n) ≤ c·f(n)
- 表示算法复杂度的**渐进上界**
- 实际中最常用，常用来表示"最坏情况"

### 大Ω记号（下界）
- **Ω(f(n))**：存在正常数 c 和 n₀，使得当 n ≥ n₀ 时，T(n) ≥ c·f(n)
- 表示算法复杂度的**渐进下界**

### 大Θ记号（紧确界）
- **Θ(f(n))**：同时满足 O(f(n)) 和 Ω(f(n))
- 表示算法复杂度的**渐进紧确界**

## 直观理解

| 记号 | 含义 | 类比 |
|------|------|------|
| O(f(n)) | 不超过 f(n) 级别 | ≤ |
| Ω(f(n)) | 至少 f(n) 级别 | ≥ |
| Θ(f(n)) | 恰好 f(n) 级别 | = |
