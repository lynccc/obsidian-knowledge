# 向量 Vector

## 核心概念

**向量（Vector）** 是数组的抽象与封装，是线性结构最基本的实现形式。它将一组元素按线性次序存储，支持通过**秩（rank）** 直接访问任意元素。

- **数组**：C++ 内置的底层数据结构，连续内存、固定大小、通过下标直接访问
- **向量**：在数组之上封装了动态管理（扩容/缩容）和丰富操作接口的抽象数据类型

**循秩访问（Rank-based Access）**：向量中每个元素都有唯一确定的秩（即其相对于向量起始位置的偏移量），通过秩可以在 O(1) 时间内定位元素。

## 关键要点

- 向量与数组的关系：向量 = 数组 + 动态空间管理 + 操作接口
- 秩是从 0 开始的整数，元素 e 的秩等于其前驱元素的个数
- 向量支持随机访问（random access），这是其区别于链表等结构的关键特性
- 向量的 ADT 接口包括：size / get / put / insert / remove / find / search / sort / deduplicate / uniquify / traverse
