# 桶排序与基数排序

## 核心概念

桶排序和基数排序是两类**非比较排序**算法，不依赖元素间的两两比较，而是利用关键码本身的结构特征（如数值范围、位分布）进行排序，可突破 O(n log n) 的比较排序下界。

## 关键要点

### 桶排序 Bucket Sort

1. 根据关键码范围创建若干"桶"（子序列）
2. 将每个元素按散列值分配到对应桶中
3. 对各桶分别排序（可递归桶排序或其他算法）
4. 依次收集各桶得到有序序列

**适用条件**：关键码分布均匀，桶数与元素数同阶。

**时间复杂度**：
- 期望 O(n)，当桶数 ≈ n 且分布均匀时
- 最坏 O(n²)（所有元素落入同一桶）

**空间复杂度**：O(n)

### 最大间隙问题

给定 n 个数，求排序后相邻元素的最大差值。利用桶排序思想：
1. 将区间 [min, max) 等分为 n-1 个桶
2. 每个桶只记录桶内 min/max
3. 最大间隙必在相邻桶之间

可在 O(n) 时间内求解，无需显式排序。

### 基数排序 Radix Sort

按关键码的**各个位**逐趟排序，从最低位到最高位（LSD）或反之（MSD）。

**LSD 基数排序**（低位优先）：
1. 从最低位开始，对每一位做稳定排序（通常用桶排序/计数排序）
2. 逐位处理直到最高位
3. 每位的排序必须是**稳定**的，否则高位会破坏低位的有序性

**时间复杂度**：O(d × n)，d 为位数
**空间复杂度**：O(n + r)，r 为基数（每位的取值范围）

**适用条件**：关键码位数 d 较小，每位取值范围 r 适中。

### 桶排序的本质
桶排序可视为基数排序的特例——单趟、宽桶。基数排序是多趟窄桶排序的级联。

## 与其他概念的联系
- 与[[散列表]]：桶排序直接利用散列思想将元素分配到桶中
- 与[[向量排序]]中的归并排序/快速排序：非比较排序在特定条件下可突破 Ω(n log n) 下界
- 与[[跳转表Skiplist]]：跳转表维护有序性，桶排序/基数排序是批量重排
