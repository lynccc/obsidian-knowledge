# 广度优先搜索 BFS

## 核心概念

**BFS（Breadth-First Search）** 是一种图遍历算法，按照"由近及远"的顺序逐层访问顶点——先访问所有距源点为 k 的顶点，再访问距离为 k+1 的顶点。

## 算法策略

1. 选取起始顶点 s，标记为已发现（UNDISCOVERED → DISCOVERED）
2. 将 s 入队
3. 循环：取出队首顶点 v，依次检查其所有邻居 u
   - 若 u 未被发现：标记为 DISCOVERED，入队
   - 忽略已访问的边（分类为 TREE / CROSS）
4. v 处理完毕后标记为 VISITED，出队

```
BFS(G, s):
    标记 s 为 DISCOVERED, 入队 Q
    while Q 非空:
        v = Q.dequeue()
        for 每个邻居 u of v:
            if u 未发现:
                标记 u 为 DISCOVERED
                边(v,u) 标记为 TREE
                Q.enqueue(u)
            else:
                边(v,u) 标记为 CROSS
        标记 v 为 VISITED
```

## 边分类

BFS 过程中遇到的边分为两类：
- **树边（Tree Edge）**：指向未发现顶点的边，构成 BFS 树
- **跨边（Cross Edge）**：指向已发现或已访问顶点的边

## 复杂度分析

| 指标 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 时间 | O(n²) | O(n + E) |
| 空间 | O(n)（队列） | O(n) |

## 典型应用

- **最短路径**：无权图中，BFS 树给出从源点到各顶点的最短路径（边数最少）
- **层序遍历**：按层次结构处理顶点（类似[[二叉树遍历|二叉树的层序遍历]]）
- **连通分量检测**：对未访问顶点反复调用 BFS
- **二分图判定**：BFS 过程中检查是否存在奇数环

## 关键要点

- BFS 使用**队列**（FIFO）管理待访问顶点，参见 [[队列Queue]]
- 每个顶点恰好入队/出队一次，每条边恰好检查一次
- BFS 发现的顶点按**距离递增**顺序排列

## 与其他概念的联系
- 与 [[深度优先搜索DFS]] 对比：BFS 用队列（FIFO），DFS 用栈（LIFO/递归）
- 无权图最短路径是 BFS 的直接应用；带权图需用 [[最短路径Dijkstra]]
- BFS 生成的层次结构可用于[[拓扑排序]]的 Kahn 算法
