# 有序列表 Sorted List

## 核心概念

有序列表是元素按**非降序排列**的[[列表List]]。有序性带来了更高效的查找和唯一化操作。

## 查找：有序列表 vs 普通列表

### 普通列表查找 `find(e, n, p)`
- 从节点 `p` 起向前逐个比较
- 时间复杂度：O(n)
- 不利用有序性

### 有序列表查找 `search(e, n, p)`
- 从节点 `p` 起向前逐个比较
- **遇到 ≤ e 的元素即可停止**（因为有序，前面不可能有更小的）
- 时间复杂度：仍为 O(n)，但常数因子更小
- 返回值：不大于 `e` 的最后节点位置

```cpp
// 有序列表查找的核心逻辑
template <typename T>
ListNode<T>* List<T>::search(T const& e, int n, ListNode<T>* p) const {
    while (0 <= n--) {                    // 逐个向前
        if ((p = p->pred)->data <= e) break; // 遇到 ≤ e 即停
    }
    return p;  // 返回命中节点或 header（未命中）
}
```

> ⚠️ 注意：有序列表的查找**不是[[二分查找]]**。二分查找依赖循秩访问 O(1)，列表无法支持。

## 唯一化：有序列表 vs 普通列表

### 普通列表唯一化 `deduplicate()`
- 对每个元素，向前扫描查找重复 → O(n²)
- 需要 `find()` 遍历前缀

### 有序列表唯一化 `uniquify()`
- **只需比较相邻元素**
- 相邻相同则删除，不同则前进
- 时间复杂度：O(n)，仅需一趟扫描

```cpp
template <typename T>
int List<T>::uniquify() {
    if (size < 2) return 0;
    int oldSize = size;
    ListNode<T>* p = first();
    ListNode<T>* q;
    while ((q = p->succ) != trailer) {  // 直到末尾
        if (p->data != q->data) p = q;  // 不同则前进
        else remove(q);                  // 相同则删除后继
    }
    return oldSize - size;
}
```

## 关键要点

- 有序列表的唯一化效率从 O(n²) 提升到 O(n)
- 有序列表的查找仍为 O(n)（无法随机访问）
- 有序性是 [[列表排序]] 的结果
