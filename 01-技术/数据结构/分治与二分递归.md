# 分治与二分递归

## 核心概念

**分治**（Divide and Conquer）策略将问题分解为多个独立子问题，分别求解后合并结果。**二分递归**是分治的典型实现，每次将问题一分为二。

## 关键要点

### 分治三步骤
1. **分解**（Divide）：将原问题分解为若干规模更小的子问题
2. **求解**（Conquer）：递归求解各子问题（基例直接求解）
3. **合并**（Combine）：合并子问题的解得到原问题的解

### 二分递归特点
- 每次递归产生**两个**分支（区别于[[递归|线性递归]]）
- 递归树呈二叉树形状
- 栈深度 O(logn)（比线性递归更优）

### 经典实例

```cpp
// 二分递归：数组求和
int sum(int A[], int lo, int hi) {
    if (lo == hi) return A[lo];           // 递归基
    int mi = (lo + hi) / 2;
    return sum(A, lo, mi) + sum(A, mi+1, hi); // 二分递归
}
```

## 递推方程

二分递归的典型递推关系：
- T(n) = 2T(n/2) + O(1) → O(n)
- T(n) = 2T(n/2) + O(n) → O(nlogn)
