# 算法的基本概念

## 核心概念

**算法**是解决特定问题的步骤序列，具有明确的输入、输出和有限的执行时间。算法是程序的灵魂，数据结构是算法的载体。

## 关键要点

- **输入**：零个或多个外部输入
- **输出**：至少一个输出结果
- **确定性**：每一步精确定义，无歧义
- **可行性**：每一步都能在有限时间内完成
- **有穷性**：算法必须在有限步骤内终止
- **正确性**：对合法输入产生正确输出
- **退化与鲁棒性**：处理边界/非法输入的能力
- **重用性**：算法应具有通用性，可解决一类问题

## 算法效率

解决同一问题的算法可能有巨大效率差异。例如：
- 古埃及绳索测量（实际应用算法）
- 欧几里得辗转相除法（求最大公约数）
- [[起泡排序]]（排序问题的直观解法）

效率是评价算法优劣的核心指标之一，需要通过[[时间复杂度]]和[[空间复杂度]]来精确度量。

## 代码示例

```cpp
// 欧几里得算法求最大公约数
int gcd(int a, int b) {
    return (b == 0) ? a : gcd(b, a % b);
}
```
