# 第10章 优先级队列

## 章节概览

优先级队列是一种抽象数据类型，支持按优先级动态访问和删除最大（或最小）元素。本章从 ADT 定义出发，依次介绍基于完全二叉树的堆实现和支持高效合并的左式堆实现。

## 关键术语

| 术语 | 说明 |
|------|------|
| 优先级队列 (PQ) | 支持 insert 和 delMax 的 ADT |
| 堆序性 | 父节点关键码 ≥ 子节点关键码（大顶堆） |
| 上滤 (percolate up) | 插入元素后沿父链上浮 |
| 下滤 (percolate down) | 删除堆顶后沿子链下沉 |
| Floyd 建堆 | 自下而上的线性时间建堆算法 |
| 左式堆 | 满足左倾性的可合并堆 |

## 核心算法

1. **堆排序**：基于完全二叉堆的原地排序，时间 O(n log n)
2. **Floyd 建堆**：自下而上逐节点下滤，时间 O(n)
3. **左式堆合并**：沿最右侧通路递归合并，时间 O(log n)
