# 第4章 栈与队列

> 线性结构的两个重要特例，操作受限但应用场景广泛。

## 核心概念

栈和队列是两种最基本的操作受限线性表：
- **栈（Stack）**：后进先出（LIFO），仅在栈顶操作
- **队列（Queue）**：先进先出（FIFO），一端入一端出

```
线性表
├── 向量 Vector（随机访问）
├── 列表 List（双向链表）
├── 栈 Stack ← LIFO，递归/回溯的基础
└── 队列 Queue ← FIFO，调度/模拟的基础
```

## 关键要点

1. 栈和队列是**接口受限**的线性表，限制越少越通用，限制越多越专用
2. 栈是实现**递归**的底层机制（函数调用栈）
3. 栈的典型应用：嵌套匹配、表达式求值、回溯搜索
4. 队列的典型应用：任务调度、BFS、模拟系统
