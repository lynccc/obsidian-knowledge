# 列表排序 List Sorting

## 核心概念

邓俊辉在列表上实现了三种排序算法：**插入排序、选择排序、归并排序**，统一通过 `sort()` 接口调用。

## 统一入口

```cpp
template <typename T>
void List<T>::sort(ListNode<T>* p, int n) {
    switch (rand() % 3) {  // 随机选择算法
        case 0: insertionSort(p, n); break;
        case 1: selectionSort(p, n); break;
        case 2: mergeSort(p, n);     break;
    }
}
```

---

## 插入排序 Insertion Sort

**思路**：维护前缀有序子序列，依次将后续元素插入正确位置。

```
已排序区  |  待插入元素  |  未处理区
[有序前缀]    p            [剩余元素]
```

**算法步骤**：
1. 从第 2 个元素开始，记录当前元素 `p->data`
2. 在已排序区中从后向前找到插入位置
3. 将元素移动到正确位置

**复杂度**：
- 最好：O(n)（已有序）
- 最坏：O(n²)（逆序）
- 平均：O(n²)
- 空间：O(1)

**特点**：适合**基本有序**的列表，是**稳定**排序。

---

## 选择排序 Selection Sort

**思路**：从未排序区选出最大元素，移到已排序区前端。

```
未处理区       |  已排序区（从大到小）
[剩余元素]      [已选出的最大元素们]
```

**算法步骤**：
1. 在未排序区中找到最大元素
2. 将其摘除并插入已排序区前端
3. 缩小未排序区范围，重复

**复杂度**：
- 最好/最坏/平均：O(n²)
- 空间：O(1)

**特点**：比较次数固定，**不稳定**排序（交换可能改变相同元素的相对顺序）。

---

## 归并排序 Merge Sort

**思路**：分治法——递归拆分至单元素，再两两归并为有序序列。

```
[原始列表]
    ↓ 拆分
[左半] [右半]
    ↓ 递归归并
[有序左半] [有序右半]
    ↓ 归并
[完整有序列表]
```

**算法步骤**：
1. 从中间拆分为两个子列表
2. 递归对两个子列表排序
3. 将两个有序子列表**原地归并**

**复杂度**：
- 最好/最坏/平均：O(n log n)
- 空间：O(log n)（递归栈）

**特点**：
- **唯一达到 O(n log n) 的列表排序**
- 稳定排序
- 列表归并的优势：无需额外空间，仅调整指针

### 归并的核心实现

```cpp
template <typename T>
ListNode<T>* List<T>::merge(ListNode<T>* p, int n, List<T>& L, ListNode<T>* q, int m) {
    ListNode<T>* pp = p->pred;  // 归并区间前驱（用于最终连接）
    while (0 < m) {              // L[q] 的元素未耗尽
        if (0 < n && p->data <= q->data) {  // 左侧更小
            p = p->succ; n--;
        } else {                              // 右侧更小
            q = q->succ;
            insertBefore(p, L.remove(q->pred)); // 摘出插入
            m--;
        }
    }
    return pp->succ;  // 返回归并后的首节点
}
```

## 三种排序对比

| 算法 | 时间（最好） | 时间（最坏） | 时间（平均） | 空间 | 稳定性 |
|------|-------------|-------------|-------------|------|--------|
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(log n) | ✅ 稳定 |

## 关键要点

- 列表归并排序**无需额外辅助空间**（对比[[向量排序]]中的归并排序需要辅助数组）
- 插入排序对小规模或基本有序数据表现优异
- 选择排序的比较次数不受输入影响
- 归并排序是列表上唯一 O(n log n) 的排序
