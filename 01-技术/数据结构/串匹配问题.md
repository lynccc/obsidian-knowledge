# 串匹配问题

## 核心概念

**串**（String）是由零个或多个字符组成的有限序列，记作 $S = s_0 s_1 \cdots s_{n-1}$，其中 $n$ 为串的**长度**。空串长度为0。

**串匹配问题**：给定**主串** $T$（长度 $n$）和**模式串** $P$（长度 $m \leq n$），找到所有位置 $0 \leq i \leq n - m$，使得 $T[i..i+m-1] = P[0..m-1]$。

## 关键要点

### 测评标准与策略

- **正确性**：找到所有匹配且无遗漏
- **时间效率**：比较次数是核心指标，与字符比较代价直接相关
- **测评策略**：最坏情况分析（$n$ 和 $m$ 的关系）、平均情况分析

### 蛮力算法（Brute-Force）

基本思路：逐一尝试主串中每个可能的对齐位置，在每个位置逐字符比较。

```
对每个 i = 0, 1, ..., n-m:
    对每个 j = 0, 1, ..., m-1:
        若 T[i+j] ≠ P[j]，则 break
    若 j == m，则报告匹配位置 i
```

**时间复杂度**：最坏情况 $O(nm)$。当主串为 `aaa...aaab`、模式串为 `aaab` 时达到最坏情况——每次都在模式串末尾才失败。

**问题根源**：主串指针 $i$ 在失配时需要**回溯**，导致大量重复比较。

## 与其他概念的联系

- 蛮力算法的低效性驱动了 [[KMP算法]] 的设计——核心思想是利用已匹配信息消除回溯
- 与[[时间复杂度]]分析中的最坏情况构造密切相关
- [[BM算法]] 则从另一个方向优化——模式串从右向左比较
