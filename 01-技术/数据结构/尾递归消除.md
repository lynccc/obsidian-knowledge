# 尾递归消除

## 核心概念

**尾递归**是递归调用出现在函数最后一步（尾部）的特殊递归形式。尾递归可以被编译器或程序员转换为等价的**迭代**循环，消除函数调用开销。

## 关键要点

### 尾递归的特征
- 递归调用是函数的**最后一个操作**
- 递归调用的返回值直接作为当前函数的返回值
- 无需在递归返回后做额外计算

### 为什么可以消除
- 尾递归调用后无需保留当前栈帧
- 可复用当前栈帧（或直接用循环替代）
- 从 O(n) 栈空间降为 O(1)

### 转换方法

```cpp
// 尾递归版本
int factorial(int n, int acc = 1) {
    if (n <= 1) return acc;
    return factorial(n - 1, n * acc);  // 尾部调用
}

// 等价迭代版本
int factorial(int n) {
    int acc = 1;
    while (n > 1) {
        acc *= n;
        n--;
    }
    return acc;
}
```

### 通用转换模式
- 引入**累加器参数**保存中间结果
- 递归调用 → 循环更新累加器和参数
- 递归基 → 循环终止条件

## 局限性

并非所有递归都是尾递归：
- [[分治与二分递归|二分递归]]无法直接转为尾递归
- [[递归|线性递归]]如果返回后还需计算则不是尾递归
