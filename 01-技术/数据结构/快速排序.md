# 快速排序

分治策略的经典排序算法，平均时间复杂度 O(nlogn)，是实践中最常用的通用排序算法之一。

## 核心概念

**基本思想**：选取一个元素作为**轴点（pivot）**，通过**划分（partition）**将序列分为两部分——左侧元素 ≤ pivot，右侧元素 ≥ pivot——然后递归排序两个子序列。

```
[≤ pivot] pivot [≥ pivot]
   ↓                ↓
 递归排序        递归排序
```

**划分算法**是快速排序的核心。邓俊辉教材介绍了 LUG 版（Low/Unknown/Grand 三指针）及版本 A/B/C：

- **版本A**：单向扫描，L 和 G 指针从左向右扩展
- **版本B**：双向扫描，L 和 G 从两端向中间靠拢
- **版本C（LUG版）**：三个指针将序列分为 L（≤pivot）、U（未检查）、G（≥pivot）三段，最终将 pivot 归位

## 关键要点

1. **轴点选取**：可选首/末/中位数元素。随机选取或三数取中可有效避免退化
2. **原地排序**：不需要额外空间（递归栈 O(logn)）
3. **不稳定排序**：相等元素的相对顺序可能改变
4. **平均复杂度** O(nlogn)，**最坏** O(n²)（每次划分极不均匀时）
5. **应对退化**：通过随机化轴点或取首/中/尾三数中位数，将最坏情况概率降至极低

## 复杂度分析

| 指标 | 值 | 条件 |
|------|----|------|
| 最好 | O(nlogn) | 每次均匀划分 |
| 平均 | O(nlogn) | 随机输入 |
| 最坏 | O(n²) | 已排序 + 固定选首元素 |
| 空间 | O(logn) | 递归栈深度 |
