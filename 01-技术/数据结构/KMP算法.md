# KMP算法

## 核心概念

KMP（Knuth-Morris-Pratt）算法的核心思想：利用模式串自身的结构信息，在失配时**避免主串指针回溯**，实现 $O(n+m)$ 的线性时间匹配。

关键观察：当 $P[j]$ 与 $T[i]$ 失配时，前面 $j$ 个字符 $P[0..j-1]$ 已经匹配成功，这些信息可以用来决定模式串应该滑动多远。

## 关键要点

### next表的定义

`next[j]` 表示模式串 $P$ 中，子串 $P[0..j-1]$ 的**最长真前缀 = 真后缀**的长度：

$$\text{next}[j] = \max\{k : 0 \leq k < j, \; P[0..k-1] = P[j-k..j-1]\}$$

若不存在这样的 $k$，则 $\text{next}[j] = -1$。

**物理意义**：失配发生在 $P[j]$ 时，模式串应将 $\text{next}[j]$ 位置对齐到当前主串位置，跳过已经匹配的部分。

### next[0] = -1 的意义

当第一个字符就失配时，主串指针前进一位，模式串从头开始。`-1` 标记此特殊情况。

### next[j+1] 递推构造

已知 `next[0..j]`，求 `next[j+1]`：
- 设 $t = \text{next}[j]$，若 $P[t] == P[j]$，则 $\text{next}[j+1] = t + 1$
- 否则递归回溯 $t = \text{next}[t]$，直到找到匹配或 $t = -1$

递推构造时间复杂度 $O(m)$。

### 改进next表

原始next表的缺陷：当 $P[j]$ 失配且 $P[\text{next}[j]] == P[j]$ 时，滑动后仍会在同一字符失配。

**改进**：构造改进next表，递推时加入判断——若 $P[\text{next}[j]] == P[j]$，则直接使用 $\text{next}[\text{next}[j]]$。

### 性能分析

| 指标 | 复杂度 |
|------|--------|
| 预处理（构造next表） | $O(m)$ |
| 匹配过程 | $O(n)$ |
| 总计 | $O(n + m)$ |
| 空间 | $O(m)$ |

核心在于主串指针 $i$ **永不回溯**，只增不减，故总比较次数不超过 $2n$。

## 与其他概念的联系

- next表的本质是模式串的**自匹配**信息，与[[串匹配问题]]中蛮力算法的"回溯浪费"形成对比
- [[BM算法]] 从另一个角度优化——不利用前缀信息，而是从右向左比较并跳跃
- 改进next表的思想与[[Karp-Rabin算法]]中的散列去重异曲同工——避免不必要的重复工作
