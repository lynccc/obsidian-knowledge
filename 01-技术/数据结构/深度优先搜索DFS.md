# 深度优先搜索 DFS

## 核心概念

**DFS（Depth-First Search）** 是一种图遍历算法，沿着一条路径尽可能深地探索，直到无路可走时回溯——类似走迷宫时"贴右墙"的策略。

## 算法策略

1. 选取起始顶点 s，标记为 DISCOVERED
2. 从 s 出发，选择一条未探索的边 (s, u)
   - 若 u 未访问：递归访问 u（深入）
   - 若 u 已访问：标记该边为非树边
3. s 的所有边探索完毕后，标记为 VISITED（回溯）

```
DFS(G, v):
    标记 v 为 DISCOVERED
    for 每个邻居 u of v:
        if u 未发现:
            边(v,u) 标记为 TREE
            DFS(G, u)
        else if u 为 DISCOVERED:
            边(v,u) 标记为 BACKWARD（回边）
        else:  // u 为 VISITED
            边(v,u) 标记为 FORWARD / CROSS
    标记 v 为 VISITED
```

## 边分类（有向图）

| 边类型 | 含义 |
|--------|------|
| **树边（Tree）** | 指向未发现顶点，构成 DFS 树 |
| **回边（Backward）** | 指向祖先（DISCOVERED 状态），说明存在环 |
| **前向边（Forward）** | 指向已访问的后代 |
| **跨边（Cross）** | 指向已访问的非后代 |

> 无向图中只有**树边**和**回边**两种。

## 复杂度分析

| 指标 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 时间 | O(n²) | O(n + E) |
| 空间 | O(n)（递归栈） | O(n) |

## 典型应用

- **环检测**：存在回边 ⟺ 图中有环
- **拓扑排序**：DFS 完成时间的逆序 = [[拓扑排序]]（有向无环图）
- **连通分量**：无向图中每次 DFS 访问一个连通分量
- **关节点与双连通域**：基于 DFS 的发现时间和最早可达祖先

## 关键要点

- DFS 本质上使用**栈**（LIFO），递归版本由系统调用栈隐式实现，参见 [[栈Stack]]
- 每个顶点恰好被 DISCOVERED 和 VISITED 各一次
- DFS 的**括号定理**：顶点 u 是 v 的祖先 ⟺ [d[u], f[u]] ⊇ [d[v], f[v]]
  - d[u] = 发现时间，f[u] = 完成时间

## 与其他概念的联系
- 与 [[广度优先搜索BFS]] 对比：DFS 探索深度优先（栈），BFS 探索广度优先（队列）
- DFS 是 [[拓扑排序]] 的基础（完成时间逆序）
- DFS 树的结构揭示了图的连通性质，参见 [[图的基本概念]]
