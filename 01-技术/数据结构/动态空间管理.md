# 动态空间管理

## 核心概念

向量底层使用数组存储，容量固定。当元素数量超过容量时需要**扩容**；当元素远少于容量时可**缩容**以回收空间。动态空间管理解决的核心问题是：如何在扩容/缩容时保持高效？

## 关键要点

### 静态空间管理的局限
- 固定容量 `_capacity`：若预设过小则溢出，过大则浪费
- 无法适应数据规模的动态变化

### 扩容策略：倍增（Doubling）
- 当 `size == capacity` 时，申请 `2 × capacity` 的新空间
- 将原有元素复制到新空间，释放旧空间
- 每次扩容代价 O(n)，但扩容频率极低

### 分摊分析（Amortized Analysis）
- **核心结论**：倍增策略下，单次插入的分摊时间复杂度为 **O(1)**
- 分析方法：将 n 次插入操作的总代价均摊到每次操作
- 总复制量：1 + 2 + 4 + ... + n ≈ 2n，均摊每次约 2 次操作
- 关键在于扩容间隔呈**几何级数**增长，而非算术级数

### 缩容策略
- 当 `size < capacity / 4` 时，缩容至 `capacity / 2`
- 阈值设为 1/4（而非 1/2）是为了避免**抖动**（oscillation）：在边界处反复扩容/缩容
