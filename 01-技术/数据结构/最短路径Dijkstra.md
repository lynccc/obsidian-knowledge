# 最短路径 Dijkstra

## 核心概念

**最短路径问题**：在带权有向图中，找到从源点 s 到其他各顶点的最短路径。

### 最短路径树（SPT）
- 以源点 s 为根的有向树
- 树中从 s 到任意顶点 v 的路径即为图中 s→v 的最短路径
- 边数 = |V| - 1

### Dijkstra 箠法
- 解决**非负权**图的单源最短路径问题
- 贪心策略：每步选择距源点最近的未确定顶点，确定其最短距离

## 算法步骤

1. 初始化：dist[s] = 0，其余 dist[v] = ∞
2. 循环 n 次：
   - 选取 dist 值最小的未确定顶点 u（贪心选择）
   - 将 u 标记为"已确定"（最短距离已确定）
   - **松弛（Relaxation）**：对 u 的每个出边邻居 v
     - 若 dist[u] + w(u, v) < dist[v]：
       - dist[v] = dist[u] + w(u, v)
       - parent[v] = u

```
Dijkstra(G, s):
    dist[s] = 0, 其余 dist[v] = ∞
    for i = 1 to n:
        u = dist 最小的未确定顶点
        标记 u 为确定
        for 每个邻居 v of u:
            if dist[u] + w(u,v) < dist[v]:
                dist[v] = dist[u] + w(u,v)
                parent[v] = u
```

## 复杂度分析

| 实现方式 | 时间复杂度 |
|---------|-----------|
| 朴素（数组） | O(n²) |
| 优先队列（二叉堆） | O((n+E) log n) |

## 与 Prim 的对比

| 维度 | Dijkstra | [[最小支撑树\|Prim]] |
|------|----------|-----|
| 目标 | 最短路径树 | 最小支撑树 |
| dist 含义 | 到源点的最短距离 | 到已选集的最小边权 |
| 松弛条件 | dist[u]+w < dist[v] | w(u,v) < dist[v] |
| 适用 | 非负权有向图 | 无向连通图 |

两者代码结构几乎一致，仅松弛判断不同。

## 关键要点

- Dijkstra 要求**边权非负**（负权边会导致贪心选择失效）
- 负权图需用 **Bellman-Ford** 算法
- Dijkstra 不能处理含负权环的图（此时最短路径无定义）
- 每次"确定"一个顶点后其最短距离不再改变（贪心正确性）

## 与其他概念的联系
- 算法框架与 [[最小支撑树|Prim]] 几乎相同
- 朴素实现中"选最小 dist"可优化为优先队列（§6.10 优先级搜索）
- 无权图的最短路径退化为 [[广度优先搜索BFS]]
- DAG 上的最短路径可通过 [[拓扑排序]] 后线性 DP 求解
