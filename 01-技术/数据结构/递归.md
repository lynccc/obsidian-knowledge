# 递归

## 核心概念

**递归**是函数直接或间接调用自身的编程技巧。递归算法将问题分解为相同但更小的子问题，直到达到**递归基**（基本情况）。

## 关键要点

### 递归三要素
1. **递归基**（base case）：最简单的情况，直接返回结果，不再递归
2. **递归步骤**：将问题分解为更小的子问题
3. **趋向递归基**：每次递归必须向递归基靠近，否则无限递归

### 线性递归
- 每次递归只调用自身一次
- 递归调用链呈线性展开
- 栈空间复杂度 O(n)

```cpp
// 线性递归：数组求和
int sum(int A[], int n) {
    if (n == 0) return 0;        // 递归基
    return A[n-1] + sum(A, n-1); // 递归步骤
}
```

### 多递归基
- 可以有多个递归基处理不同边界情况
- 增强算法的[[算法的基本概念|鲁棒性]]

## 递归的代价
- 函数调用开销（压栈/出栈）
- 栈空间占用（递归深度 × 每帧大小）
- 可能导致栈溢出
