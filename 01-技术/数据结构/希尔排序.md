# 希尔排序

插入排序的推广，通过**递减增量（diminishing increment）**策略大幅提升效率，时间复杂度可达 O(n^(3/2))。

## 核心概念

**基本思想**：先以较大增量对序列做间隔插入排序，逐步缩小增量，最终增量为 1 时退化为普通插入排序。但经过前面各趟的"预排序"，序列已接近有序，最后一趟插入排序效率极高。

```
增量序列 h₁ > h₂ > ... > 1

for each h in {h₁, h₂, ..., 1}:
    对序列做 h-间隔插入排序（相隔 h 的元素视为同一子序列）
```

**h-间隔插入排序**：将序列按间隔 h 分成 h 个子序列，每个子序列内部做插入排序。

## 关键要点

1. **增量序列的选择**是希尔排序性能的关键
   - **Shell 序列**：n/2, n/4, ..., 1（最朴素，效果一般）
   - **Knuth 序列**：1, 4, 13, 40, ...（h = 3h + 1），复杂度 O(n^(3/2))
   - **Sedgewick 序列**：1, 5, 19, 41, 109, ...（经验最优）
2. 希尔排序是**原地排序**，空间 O(1)
3. 希尔排序是**不稳定排序**（间隔交换可能打乱相等元素顺序）
4. 复杂度分析依赖增量序列，无精确通用公式
5. 实际表现优于插入排序和起泡排序，常数因子小，适合中等规模数据

## 复杂度

| 增量序列 | 时间复杂度 |
|----------|-----------|
| Shell (n/2) | O(n²) |
| Knuth (3h+1) | O(n^(3/2)) |
| Sedgewick | O(n^(4/3)) 经验值 |

## 与其他概念的联系

- 本质是 [[向量排序]] 中插入排序的多趟推广
- 与 [[快速排序]] 相比，希尔排序实现更简单，对几乎有序数据效果好
- 增量序列的设计体现了递减增量的渐进策略思想
