# 队列 Queue

## 核心概念

**队列**是只允许在一端（队尾）插入、另一端（队头）删除的线性表，遵循**先进先出（FIFO, First In First Out）**原则。

类比：排队买票，先来的先服务。

## ADT 接口

| 操作 | 功能 | 复杂度 |
|------|------|--------|
| `enqueue(e)` | 将元素 e 插入队尾 | O(1) 均摊 |
| `dequeue()` | 删除并返回队头元素 | O(1) |
| `front()` | 读取队头元素（不删除） | O(1) |
| `empty()` | 判断队列是否为空 | O(1) |
| `size()` | 返回队列中元素个数 | O(1) |

## 关键要点

1. **FIFO 语义**：先入先出，保证了公平性（先到先服务）
2. **实现方式**：
   - **数组实现**：需考虑假溢出问题，用**循环队列**解决（取模运算）
   - **链表实现**：队头出队、队尾入队，天然支持
   - 邓俊辉书中基于 `List` 实现
3. **循环队列**：数组实现时，队头/队尾指针通过 `(ptr + 1) % capacity` 循环移动，空间可复用
4. **队列 vs 栈**：都是线性表的受限版本，区别在于访问顺序（FIFO vs LIFO）

## 代码示例

```cpp
template <typename T> class Queue : public List<T> {
public:
    void enqueue(T const& e) { insertAsLast(e); }  // 队尾入
    T dequeue() { return remove(first()); }          // 队头出
    T& front() { return first()->data; }             // 队头读
};
```

> 队头 = 链表首节点，队尾 = 链表末尾。

## 典型应用

- **BFS（广度优先搜索）**：用队列管理待访问节点
- **任务调度**：操作系统进程调度、打印队列
- **缓冲区**：生产者-消费者模型、消息队列
- **银行服务模拟**：见 §4.6，模拟多窗口排队，统计等待时间

## 与其他概念的联系

- **队列 vs 栈**：操作方向相反的线性表受限版本
- **BFS** 依赖队列（图论章节）
- **优先队列**（堆）是队列的泛化，按优先级而非到达顺序出队
