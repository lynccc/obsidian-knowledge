## 选择指南

```
需要稳定排序？
├── 是 → 数据范围小 → 桶排序/基数排序 O(n)
│        数据范围大 → 归并排序 O(nlogn)
│
└── 否 → 数据量小 → 插入排序（常数因子小）
         数据量大 → 快速排序（平均最优）
         需要最坏保证 → 堆排序 O(nlogn)
         内存受限 → 堆排序 / 快排（原地）
```

## 关键结论

1. **比较排序下界**：基于比较的排序算法最坏时间复杂度下界为 **Ω(nlogn)**（参见 [[比较树与排序下界]]）
2. **非比较排序突破下界**：桶排序和基数排序利用数据特征，可达 O(n)，但适用场景受限
3. **快排最实用**：平均性能最优，常数因子小，缓存友好，C++ STL `std::sort` 的基础
4. **归并适合链表**：归并排序在链表上可 O(1) 额外空间
5. **堆排序保底**：保证 O(nlogn) 最坏性能，适合实时系统
