# Karp-Rabin算法

## 核心概念

Karp-Rabin算法的核心思想：将串匹配问题转化为**散列值比较**。通过为模式串和主串的每个长度为 $m$ 的子串计算散列值，只需比较散列值即可快速筛选候选位置，再逐字符验证。

关键创新在于**滚动散列**（Rolling Hash）：相邻子串的散列值可以在 $O(1)$ 时间内从上一个散列值推导，无需重新计算。

## 关键要点

### 散列函数设计

将串 $S = s_0 s_1 \cdots s_{m-1}$ 映射为 $R$ 进制数：
$$h(S) = \sum_{k=0}^{m-1} s_k \cdot R^{m-1-k} \mod M$$

其中 $R$ 为进制基数（通常取字符集大小+1），$M$ 为散列表大小（取大素数）。

### 滚动散列计算

已知子串 $T[i..i+m-1]$ 的散列值 $h_i$，求 $T[i+1..i+m]$ 的散列值：

$$h_{i+1} = (h_i - T[i] \cdot R^{m-1}) \cdot R + T[i+m] \mod M$$

- **减去**最高位贡献：$T[i] \cdot R^{m-1}$
- **乘以 $R$**：左移一位
- **加上**新字符：$T[i+m]$
- 预计算 $R^{m-1} \mod M$，每次更新仅需常数时间

### 算法流程

```
计算 P 的散列值 hp
计算 T[0..m-1] 的散列值 h0
for i = 0, 1, ..., n-m:
    if hi == hp:
        逐字符验证 T[i..i+m-1] == P  // 散列碰撞处理
    if i < n-m:
        hi+1 = rolling_hash(hi, T[i], T[i+m])
```

### 时间复杂度

| 阶段 | 复杂度 |
|------|--------|
| 预处理 | $O(m)$ |
| 滚动散列计算 | $O(n)$ |
| 验证（期望） | $O(n \cdot (1/M))$，合理选 $M$ 时趋近 $O(1)$ |
| **总计（期望）** | $O(n + m)$ |

空间复杂度 $O(1)$（不计输入）。

### 散列碰撞

两个不同串可能有相同散列值。通过**二次验证**（逐字符比较）保证正确性。选择足够大的素数 $M$ 可将碰撞概率降至极低。

## 与其他概念的联系

- 散列函数设计直接借鉴[[散列表]]中的除余法和 $M$ 取素数的思想
- 滚动散列是一种**增量计算**思想——利用相邻子串的关系避免重复计算
- 与[[KMP算法]]和[[BM算法]]不同，KR算法不依赖模式串的结构信息，适合**多模式匹配**场景
- 在子串搜索、DNA序列比对等领域有广泛应用
