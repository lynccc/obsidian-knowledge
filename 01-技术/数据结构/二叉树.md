# 二叉树

## 核心概念

**二叉树**是每个节点至多有两棵子树（左/右）且子树有**有序**之分的树结构。它是树结构中最重要的特例，也是 [[Huffman编码]] 等算法的基础。

### 基本术语

| 术语 | 定义 |
|------|------|
| 度 (degree) | 节点的子树数目，二叉树中 ≤ 2 |
| 深度 (depth) | 从根到该节点的边数 |
| 高度 (height) | 从该节点到最深叶节点的边数 |
| 满二叉树 | 每个内部节点度数恰好为 2 |
| 完全二叉树 | 除最后一层外，其余层均满，且最后一层靠左 |

### BinNode 节点结构

```cpp
template <typename T> struct BinNode {
    T data;
    BinNodePosi(T) lc, rc, parent;  // 左/右孩子、父亲
    int height;                      // 高度
    // ... 其他辅助信息
};
```

### BinTree 类

```cpp
template <typename T> class BinTree {
protected:
    int _size;            // 规模
    BinNodePosi(T) _root; // 根节点
public:
    int size() const { return _size; }
    bool empty() const { return !_root; }
    BinNodePosi(T) root() const { return _root; }
};
```

## 关键要点

- 二叉树是**有序树**，左右子树不可交换
- 完全二叉树可用**向量**紧凑存储：节点 `i` 的左孩子为 `2i+1`，右孩子为 `2i+2`
- `n` 个节点的二叉树有 `n+1` 个空链域（外部节点/叶子）
