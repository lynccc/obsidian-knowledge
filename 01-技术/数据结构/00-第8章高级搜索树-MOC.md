# 第8章 高级搜索树 MOC

本章介绍几种高级搜索树结构，它们在不同场景下对基础 [[二叉搜索树BST]] 进行了优化与扩展。

## 笔记列表

| 笔记 | 核心思想 | 复杂度 |
|------|---------|--------|
| [[伸展树Splay]] | 利用局部性，通过旋转将访问节点提升至根 | 分摊 O(logn) |
| [[B树]] | 多路平衡查找树，磁盘友好的外部搜索结构 | O(logₘn) |
| [[红黑树]] | 近似平衡的 BST，用红黑标记替代严格平衡条件 | O(logn) |
| [[kd树]] | 多维空间划分树，支持范围查询与最近邻 | O(√n + k) 范围查询 |

## 章节脉络

```
基础 BST → [[平衡二叉搜索树]] / [[AVL树]] (严格平衡)
         → [[伸展树Splay]]        (无需显式平衡信息，分摊保证)
         → [[红黑树]]              (弱平衡，旋转次数少)
         → [[B树]]                 (多路分支，降低树高，适配磁盘 I/O)
         → [[kd树]]               (多维空间，范围/近邻查询)
```

## 要点速览

- **伸展树**：无需存储平衡因子，借助 splay 操作自底向上旋转，保证分摊 O(logn)；具有良好的**局部性**。
- **B-树**：每个节点可有 m 个孩子，树高极低；插入时**上溢分裂**、删除时**下溢合并**，是数据库索引的基石。
- **红黑树**：节点染红/黑，最长路径不超过最短路径 2 倍；插入用**双红修正**、删除用**双黑修正**，最多 3 次旋转。
- **kd-树**：将 k 维空间交替按各维度二分，支持高效范围查询。
