# 起泡排序

## 核心概念

**起泡排序**（Bubble Sort）是最直观的排序算法之一，通过反复比较相邻元素并交换，使最大元素像气泡一样"浮"到数组末尾。是学习[[算法的基本概念|算法分析]]的经典实例。

## 关键要点

### 算法过程
1. 从头到尾比较相邻元素，若逆序则交换
2. 一轮扫描后，最大元素到达末尾
3. 对剩余元素重复，直到全部有序

### 代码实现

```cpp
void bubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool sorted = true;
        for (int j = 0; j < n - 1 - i; j++) {
            if (A[j] > A[j + 1]) {
                swap(A[j], A[j + 1]);
                sorted = false;
            }
        }
        if (sorted) break;  // 优化：无交换说明已有序
    }
}
```

### 复杂度分析

| 指标 | 值 |
|------|-----|
| 最好时间 | O(n)（已有序，优化版本） |
| 最坏时间 | O(n²)（逆序） |
| 平均时间 | O(n²) |
| [[空间复杂度]] | O(1)（原地排序） |
| 稳定性 | 稳定 |

### 关键优化
- **提前终止**：一轮无交换则已有序（`sorted` 标志）
- 记录最后交换位置，缩小扫描范围
