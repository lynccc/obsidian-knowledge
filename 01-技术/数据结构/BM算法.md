# BM算法

## 核心概念

BM（Boyer-Moore）算法的核心思想：模式串**从右向左**比较，并在失配时利用两条启发式规则计算跳跃距离，取较大值。实践中是最快的串匹配算法。

## 关键要点

### 坏字符规则（Bad Character, BC）

当 $P[j]$ 与 $T[i]$ 失配时：
- $T[i]$ 称为**坏字符**
- 在 $P[0..j-1]$ 中查找与坏字符相同的最右位置 $k$
- 若找到，模式串右移 $j - k$ 位对齐；若未找到，模式串整体跳过坏字符

**BC表构造**：对字符集中每个字符 $c$，记录其在 $P$ 中最右出现位置：
$$\text{BC}[c] = \max\{k : 0 \leq k < m, \; P[k] = c\}$$
构造时间 $O(m + \sigma)$，其中 $\sigma$ 为字符集大小。

### 好后缀规则（Good Suffix, GS）

当 $P[j]$ 与 $T[i]$ 失配时，$P[j+1..m-1]$ 已匹配成功的部分称为**好后缀**：
- 在 $P[0..j]$ 中查找与好后缀匹配的最右子串（不能与好后缀重叠）
- 若找到，模式串右移使该子串对齐
- 若未找到，查找好后缀的某个后缀是否为 $P$ 的前缀

**GS表构造**：$P$ 与自身的后缀匹配。通过从右向左扫描并利用已计算的 GS 值，在 $O(m)$ 时间内完成。

### BM算法流程

```
i = 0  (主串对齐位置)
while i <= n - m:
    j = m - 1  (从模式串末尾开始)
    while j >= 0 且 P[j] == T[i+j]:
        j--  (继续向左比较)
    if j < 0:
        报告匹配，i += shift_by_GS[0]
    else:
        i += max(BC_shift, GS_shift)
```

### 性能特点

- **最坏情况**：$O(nm)$（如 `aaa...` 匹配 `baaa...`）
- **最好情况**：$O(n/m)$，每次跳跃 $m$ 位
- **实际表现**：对于字母表较大的场景（如英文文本），跳跃幅度大，接近 $O(n/m)$
- 两条规则互补：BC规则利用坏字符信息，GS规则利用已匹配信息

## 与其他概念的联系

- [[KMP算法]] 从左向右比较，利用前缀信息；BM从右向左，利用后缀和字符位置信息
- BC表的散列思想与[[散列表]]类似——用 $O(\sigma)$ 空间实现 $O(1)$ 查询
- [[Karp-Rabin算法]] 则完全不同的思路——用散列值代替逐字符比较
- BM算法在实际工程中的应用：`grep`、文本编辑器等
