# 二叉搜索树（BST）

## 核心概念

二叉搜索树（Binary Search Tree）是一种满足**顺序性**的[[二叉树]]：对于任意节点，其左子树中所有节点的关键码均**不大于**该节点，右子树中所有节点的关键码均**不小于**该节点。

## 关键要点

### 基本性质

- **顺序性**：`左子树 ≤ 根 ≤ 右子树`（递归成立）
- **中序遍历有序**：对 BST 做[[二叉树遍历|中序遍历]]，得到严格递增序列，这是 BST 最核心的性质
- BST 是[[二分查找]]的树形实现

### 查找算法

从根节点开始，逐层比较：
- 目标 = 当前节点 → 找到
- 目标 < 当前节点 → 进入左子树
- 目标 > 当前节点 → 进入右子树
- 到达空节点 → 不存在

时间复杂度：**O(h)**，h 为树高。

### 插入算法

1. 执行查找操作，找到应插入的空位
2. 在该位置创建新节点
3. 无需调整其他节点，天然保持 BST 性质

### 删除算法

情况较复杂，需分三类处理：
- **叶子节点**：直接删除
- **仅有左/右子树**：用子树替换该节点
- **左右子树均存在**：找到**中序遍历的直接后继**（右子树最左节点），替换并删除后继

### 性能分析

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

> 最坏情况：BST 退化为单链表（如按有序序列依次插入），此时需要[[平衡二叉搜索树]]来优化。

## 与其他概念的联系

- 基于 [[二叉树]] 和 [[二叉树遍历]]
- 是 [[二分查找]] 的树形表达
- 平衡版本见 [[平衡二叉搜索树]]、[[AVL树]]
- 退化问题催生了 [[红黑树]]、[[B树]] 等结构
