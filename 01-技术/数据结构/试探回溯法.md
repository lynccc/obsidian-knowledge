# 试探回溯法

## 核心概念

**试探回溯法**是一种系统性搜索策略：沿着一条路径向前探索（试探），遇到死路则退回到上一步（回溯），尝试其他分支。其实现依赖**递归**（即隐式栈）。

## 基本框架

```cpp
void backtrack(状态 s) {
    if (s 是目标) { 记录/输出解; return; }
    for (每个候选决策 d) {
        if (d 可行) {
            执行 d，更新状态;
            backtrack(新状态);   // 递归试探
            撤销 d，恢复状态;    // 回溯
        }
    }
}
```

> 核心思想：**试错—回退—换路**，穷举所有可能但通过剪枝避免无效搜索。

## 经典问题

### 八皇后问题

**问题**：在 8×8 棋盘上放置 8 个皇后，使其互不攻击（同行、同列、同对角线不能共存）。

**解法**：
- 逐行放置皇后，每行只放一个
- 用栈记录每行皇后的列位置
- 放置前检查是否与已有皇后冲突（列冲突、对角线冲突）
- 冲突则尝试下一列；所有列都冲突则回溯到上一行

**关键**：`O(n)` 空间即可表示棋盘状态（数组 `queen[i]` = 第 i 行皇后所在列）。

### 迷宫寻径

**问题**：在迷宫中找到从起点到终点的一条路径。

**解法**：
- 从起点出发，沿可行方向前进（试探）
- 遇到死路则退回上一个路口，换一个方向（回溯）
- 用栈记录路径，回溯时弹出

> 等价于**深度优先搜索（DFS）**，栈中保存的就是当前路径。

## 关键要点

1. 回溯法本质是**DFS + 剪枝**，用递归栈隐式维护搜索路径
2. 时间复杂度通常是指数级（穷举），但剪枝可大幅减少实际搜索空间
3. **显式栈版本**：将递归改写为循环 + 显式栈，避免栈溢出
4. 回溯法是很多算法的基础：数独求解、正则匹配、博弈树搜索等
