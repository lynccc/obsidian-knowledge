# 哨兵节点 Sentinel Node

## 核心概念

哨兵节点（Sentinel Node）是不存储实际数据的**辅助节点**，用于简化链表的边界条件处理。邓俊辉的列表实现中引入**头哨兵 `header`** 和**尾哨兵 `trailer`** 两个节点。

## 头尾哨兵的作用

```
header ⇄ A ⇄ B ⇄ C ⇄ trailer
(空)                         (空)
```

### 1. 统一空表与非空表

- 无哨兵时：空表 `head == nullptr`，非空表 `head != nullptr`，需分别处理
- 有哨兵时：空表 `header->succ == trailer`，始终有节点可操作

### 2. 消除边界特判

| 操作 | 无哨兵 | 有哨兵 |
|------|--------|--------|
| 头部插入 | 特判 `head` 为空 | 统一为 `insertAfter(header, e)` |
| 尾部插入 | 特判 `tail` 为空 | 统一为 `insertBefore(trailer, e)` |
| 删除首节点 | 需更新 `head` | 统一为 `remove(header->succ)` |
| 遍历终止 | `p != nullptr` | `p != trailer` |

### 3. 实现细节

```cpp
// 初始化哨兵节点
header = new ListNode<T>;   // 头哨兵
trailer = new ListNode<T>;  // 尾哨兵
header->succ = trailer;
trailer->pred = header;
header->pred = nullptr;
trailer->succ = nullptr;
size = 0;                   // 有效元素数（不含哨兵）
```

## 关键要点

- 哨兵节点**不计入**列表规模 `size`
- 遍历时应跳过哨兵：范围为 `(header, trailer)` 的开区间
- 空间代价：仅 O(1) 额外存储，但显著降低代码复杂度
- 这是**空间换时间/简洁性**的经典技巧
