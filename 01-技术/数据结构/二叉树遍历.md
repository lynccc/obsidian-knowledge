# 二叉树遍历

## 核心概念

**遍历**是按照某种规则系统化地访问二叉树中每个节点恰好一次。不同遍历方式产生不同的节点访问序列，是许多算法的基础。

## 四种遍历方式

| 方式 | 顺序 | 递归定义 | 典型应用 |
|------|------|----------|----------|
| **先序** (preorder) | V → L → R | 先访问根，再左子树，最后右子树 | 复制树、前缀表达式 |
| **中序** (inorder) | L → V → R | 先左子树，再访问根，最后右子树 | BST 有序输出 |
| **后序** (postorder) | L → R → V | 先左子树，再右子树，最后访问根 | 释放树、后缀表达式 |
| **层次** (level-order) | 逐层从左到右 | 借助 [[队列Queue]] 实现 | 层序相关问题 |

## 递归实现

```cpp
template <typename T, typename VST>
void travPre_R(BinNodePosi(T) x, VST& visit) {
    if (!x) return;
    visit(x->data);
    travPre_R(x->lc, visit);
    travPre_R(x->rc, visit);
}
```

中序和后序仅改变 `visit` 与递归调用的顺序。

## 迭代实现

递归遍历可改写为迭代版，利用 [[栈Stack]] 模拟递归调用栈：

- **迭代先序**：沿左分支下行时立即访问并压栈右孩子
- **迭代中序**：沿左分支一路压栈，弹出时访问，转向右子树
- **迭代后序**：需要额外标记是否从右子树返回（或用"反转法"）

## 关键要点

- 四种遍历的**时间复杂度**均为 `O(n)`，`n` 为节点数
- 递归实现简洁但有栈溢出风险，迭代版更稳健
- 中序遍历 BST 可得有序序列
- 层次遍历必须用队列，不能用栈
