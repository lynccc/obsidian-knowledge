# 编码树

## 核心概念

**编码树**是用二叉树的路径来表示字符编码的结构。从根到每个叶节点的路径（左=0，右=1）唯一确定一个字符的编码。

## 二进制编码

将字符集映射为 0/1 序列：
- **定长编码**：所有字符用等长的二进制串表示（如 ASCII）
- **变长编码**：高频字符用短编码，低频字符用长编码，更节省空间

## 前缀编码

**关键性质**：任何字符的编码都不是另一个字符编码的**前缀**。

这保证了编码的**唯一可解码性**，无需分隔符即可无歧义解码。

二叉编码树自然满足前缀编码：每个字符都是叶子节点，从根到叶子的路径不可能互为前缀。

## 编码树结构

```
        [根]
       /    \
     0       1
    / \     / \
   a   b   c  [内部节点]
              / \
             d   e
```

- **叶节点**：代表待编码的字符
- **内部节点**：不存储字符，仅作路径分支
- 路径长度 = 该字符编码的长度

## 关键要点

- 前缀编码 = 二叉树中所有编码字符都是**叶子**
- 编码长度 = 叶子深度 → 越深编码越长
- 编码树的结构直接影响**编码效率**（平均编码长度）
- [[Huffman编码]] 通过贪心策略构建最优编码树
