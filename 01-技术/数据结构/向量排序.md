# 向量排序

## 核心概念

排序是将无序向量转化为有序向量的过程。本章介绍两种经典排序算法在向量上的实现：**起泡排序**和**归并排序**。

## 关键要点

### 统一入口
- 向量提供 `sort()` 接口，内部可选择不同排序算法
- 排序器（Sorter）是可替换的策略对象

### 起泡排序（Bubble Sort）
- 思想：反复遍历向量，比较相邻元素并交换逆序对
- 每趟扫描将最大元素"冒泡"到末尾
- **提前终止优化**：若某趟无交换，说明已有序，提前退出
- 时间复杂度：最坏 O(n²)，最好 O(n)（已有序时）
- 空间复杂度：O(1)，原地排序
- **稳定排序**

### 归并排序（Merge Sort）
- 思想：**分治法**——将向量递归地分成两半，分别排序后归并
- 归并操作：两个有序子序列合并为一个有序序列，O(n) 时间
- 时间复杂度：**O(nlogn)**，最好/最坏/平均均一致
- 空间复杂度：O(n)，需要辅助数组
- **稳定排序**

### 对比

| 排序算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|---------|-----------|-----------|--------|
| 起泡排序 | O(n²) | O(1) | 稳定 |
| 归并排序 | O(nlogn) | O(n) | 稳定 |

## 代码示例

```cpp
// 归并排序核心：归并两个有序子序列
void merge(int* A, int lo, int mi, int hi) {
    int* A_lo = A + lo;
    int lb = mi - lo;
    int* B = new int[lb]; // 复制前半段
    for (int i = 0; i < lb; B[i] = A_lo[i++]);
    int lc = hi - mi;
    int* C = A + mi;
    for (int i = 0, j = 0, k = 0; j < lb || k < lc; ) {
        if (j < lb && (k >= lc || B[j] <= C[k])) A_lo[i++] = B[j++];
        if (k < lc && (j >= lb || C[k] <  B[j])) A_lo[i++] = C[k++];
    }
    delete[] B;
}
```
