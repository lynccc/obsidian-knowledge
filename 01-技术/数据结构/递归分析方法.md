# 递归分析方法

## 核心概念

分析递归算法的[[时间复杂度]]需要专门的方法，主要有**递归跟踪法**和**递推方程法**两种。

## 关键要点

### 递归跟踪法（直观）
- 画出递归调用的展开图（调用树）
- 统计每层的工作量，然后累加
- 直观但对复杂递归难以精确分析

```
sum(A, 4)
  └─ A[3] + sum(A, 3)
                  └─ A[2] + sum(A, 2)
                                  └─ A[1] + sum(A, 1)
                                                  └─ 0
每层 O(1)，共 n 层 → 总复杂度 O(n)
```

### 递推方程法（系统）
- 建立递推关系式：T(n) = T(n-1) + O(1)
- 求解递推方程得到闭合形式
- 适用于各种递归模式

**求解步骤：**
1. 根据递归结构写出递推方程
2. 展开递推式或使用主定理
3. 求解得到 T(n)

## 常见递推方程

| 递推方程 | 解 | 对应模式 |
|----------|-----|----------|
| T(n) = T(n-1) + O(1) | O(n) | [[递归\|线性递归]] |
| T(n) = T(n/2) + O(1) | O(logn) | [[分治与二分递归\|二分递归]] |
| T(n) = 2T(n/2) + O(n) | O(nlogn) | 归并排序 |
