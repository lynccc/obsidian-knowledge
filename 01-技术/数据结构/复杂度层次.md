# 复杂度层次

## 核心概念

不同算法的时间复杂度呈现不同的增长速率，形成明确的效率层次。理解这些层次有助于选择合适的算法。

## 关键要点

### 常见复杂度层次（从优到劣）

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 数组随机访问 |
| O(logn) | 对数 | [[分治与二分递归\|二分查找]] |
| O(n) | 线性 | 遍历数组 |
| O(nlogn) | 线性对数 | 归并排序 |
| O(n²) | 平方 | [[起泡排序\|起泡排序]]、选择排序 |
| O(2^n) | 指数 | 暴力求解子集 |

### 关键规律

- O(logn) 增长极慢，即使 n 很大也高效
- O(nlogn) 是比较排序的理论下界
- O(n²) 对大规模数据已不可接受
- O(2^n) 仅适用于极小规模问题

## 输入规模与可接受复杂度

| 输入规模 | 可接受的复杂度 |
|----------|----------------|
| n ≤ 10 | O(n!) 或 O(2^n) |
| n ≤ 100 | O(n³) |
| n ≤ 10⁴ | O(n²) |
| n ≤ 10⁶ | O(nlogn) |
| n ≤ 10⁸ | O(n) |
