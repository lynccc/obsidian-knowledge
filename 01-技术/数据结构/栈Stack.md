# 栈 Stack

## 核心概念

**栈**是仅允许在一端（栈顶）进行插入和删除操作的线性表，遵循**后进先出（LIFO, Last In First Out）**原则。

类比：一摞盘子，只能从顶部取放。

## ADT 接口

| 操作 | 功能 | 复杂度 |
|------|------|--------|
| `push(e)` | 将元素 e 压入栈顶 | O(1) 均摊 |
| `pop()` | 弹出并返回栈顶元素 | O(1) |
| `top()` | 读取栈顶元素（不弹出） | O(1) |
| `empty()` | 判断栈是否为空 | O(1) |
| `size()` | 返回栈中元素个数 | O(1) |

## 关键要点

1. **LIFO 语义**：最后压入的元素最先被弹出，这是栈最本质的特性
2. **实现方式**：底层可用数组（顺序栈）或链表（链式栈），邓俊辉书中采用 `Vector` 作为底层容器
3. **均摊复杂度**：基于向量实现时，`push` 均摊 O(1)（扩容时 O(n) 但均摊下来常数级）
4. **空栈异常**：对空栈执行 `pop()` 或 `top()` 是未定义行为，需先检查 `empty()`

## 代码示例

```cpp
template <typename T> class Stack : public Vector<T> {
public:
    void push(T const& e) { insert(size(), e); }  // 栈顶 = 向量末尾
    T pop() { return remove(size() - 1); }
    T& top() { return (*this)[size() - 1]; }
};
```

> 栈顶对应向量末尾，利用 `Vector` 已有的 `insert`/`remove` 实现。
