# kd-树

## 核心概念

kd-树（k-dimensional tree）是一种用于 **k 维空间**中组织点的数据结构，是 [[二叉搜索树BST]] 在多维空间的推广。它通过**交替选择不同维度**进行空间二分划分，使得范围查询和最近邻查询在大多数情况下高效执行。

### 基本结构

- 每个内部节点代表一次**空间划分**：选择第 d 维，用该维坐标值作为切割超平面
- 左子树：第 d 维坐标 < 切割值
- 右子树：第 d 维坐标 ≥ 切割值
- 维度 d 在各层**循环交替**：第 0 层用 x 维，第 1 层用 y 维，第 2 层又用 x 维……
- 叶节点存储实际数据点

以 2 维为例（2d-树）：

```
        x=5
       /    \
   x<5      x>=5
   y=3      y=7
   / \      / \
 ... ...  ... ...
```

## 关键要点

### 构建

递归构建过程：
1. 选择当前维度 d（层号 mod k）
2. 按第 d 维坐标**取中位数**作为划分点（保证左右子树大小均衡）
3. 分别递归构建左右子树，维度切换为 (d+1) mod k

最优构建：O(n logn)（若使用线性时间中位数选择算法）

### 范围查询

给定一个多维矩形范围 R，找出所有落在 R 内的点：

1. 从根开始，检查当前节点是否在范围内
2. 根据 R 与切割超平面的关系，决定搜索哪些子树：
   - R 完全在左/右侧 → 只搜一侧
   - R 跨越切割面 → 搜两侧
   - R 与当前子树区域不相交 → **剪枝**

> [!tip] 范围查询复杂度
> 对于 n 个点的 2d-树，范围查询报告 k 个结果的复杂度为 **O(√n + k)**。这远优于遍历全部点的 O(n)。

### 最近邻查询

从根开始，递归搜索可能包含更近点的子树，同时用当前最近距离作为**上界**剪枝另一侧。

## 与其他概念的联系

- kd-树是 [[二叉搜索树BST]] 在 k 维空间的自然扩展
- 当 k=1 时退化为普通 BST
- 高维空间（k 较大）时性能下降（"维度灾难"），此时可考虑 R 树、Ball 树等
- 与 [[B树]] 的区别：B-树解决一维有序数据的磁盘索引；kd-树解决多维空间划分
- 应用场景：地理信息系统（GIS）、计算机图形学（光线追踪）、机器学习（kNN 分类）
