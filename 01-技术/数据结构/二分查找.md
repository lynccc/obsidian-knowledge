# 二分查找

## 核心概念

**二分查找（Binary Search）** 是在有序向量中高效查找的核心算法。其思想是：每次将搜索区间缩小一半，通过比较中间元素与目标值来决定继续在左半部分还是右半部分查找。

## 关键要点

### 三个版本

**版本 A（基本版）**
- 每次迭代做**两次比较**（与左端点、与右端点各比较一次）
- 有三个分支：命中、左半、右半
- 代码最直观，但比较次数多

**版本 B（改进版）**
- 每次迭代只做**一次比较**（与中间元素比较）
- 用 `lo` 和 `hi` 维护候选区间，最终收敛到一个元素
- 比较次数更少，但需注意区间收缩的细节

**版本 C（最终版）**
- 进一步优化：保持 `[lo, hi)` 半开区间不变式
- 每次迭代一次比较，最终 `lo` 即为命中位置或插入位置
- 返回值可区分"命中"和"应插入位置"，兼顾查找与插入需求

### Fibonacci 查找
- 利用 **Fibonacci 数列**来划分区间（而非简单取中点）
- 将除法替换为加减法，在某些硬件上更高效
- 查找效率与二分查找同阶：O(logn)
- 实际中优势不明显，更多是理论意义

### 复杂度
- 时间复杂度：**O(logn)**，其中 n 为向量规模
- 每次迭代区间减半，最多迭代 ⌈log₂n⌉ 次

## 与其他概念的联系

## 代码示例

```cpp
// 版本 C：半开区间 [lo, hi)
int binSearch(int* A, int e, int lo, int hi) {
    while (lo < hi) {
        int mi = (lo + hi) >> 1;
        (e < A[mi]) ? hi = mi : lo = mi + 1;
    }
    return --lo; // 最后一个不大于 e 的元素位置
}
```
