# 🎯 枚举

## 核心概念

- 枚举（Enum）用于定义命名常量集合
- `enum class`（C++11）是类型安全的枚举，推荐使用
- 传统 `enum` 存在命名污染问题

## 传统 enum

```cpp
enum Color {
    RED,      // 0
    GREEN,    // 1
    BLUE      // 2
};

enum Color c = RED;
int value = GREEN;  // 可以隐式转为 int（不安全）

// 自定义值
enum ErrorCode {
    OK = 0,
    NOT_FOUND = 404,
    SERVER_ERROR = 500
};
```

## enum class（推荐，C++11）

```cpp
enum class Color {
    RED,
    GREEN,
    BLUE
};

Color c = Color::RED;    // 必须带作用域
// int v = Color::RED;   // ❌ 不能隐式转为 int
int v = static_cast<int>(Color::RED);  // ✅ 显式转换

// 可以指定底层类型
enum class Direction : uint8_t {
    UP = 0,
    DOWN,
    LEFT,
    RIGHT
};
```

## 配合 switch

```cpp
enum class Season { SPRING, SUMMER, AUTUMN, WINTER };

std::string get_season(Season s) {
    switch (s) {
        case Season::SPRING: return "春";
        case Season::SUMMER: return "夏";
        case Season::AUTUMN: return "秋";
        case Season::WINTER: return "冬";
    }
    return "未知";
}
```

## 传统 enum vs enum class

| 特性 | enum | enum class |
|------|------|-----------|
| 作用域 | 全局（会污染） | 有作用域 |
| 隐式转 int | ✅ 可以 | ❌ 不行 |
| 类型安全 | ❌ | ✅ |
| 推荐度 | 旧代码兼容 | **强烈推荐** |
