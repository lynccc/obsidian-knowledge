# 🧠 智能指针

## 核心概念

- 智能指针（Smart Pointer）自动管理堆内存，防止内存泄漏
- `unique_ptr`：独占所有权，不能复制
- `shared_ptr`：共享所有权，引用计数
- `weak_ptr`：弱引用，不增加引用计数

## unique_ptr（最常用）

```cpp
#include <memory>

// 创建
auto p1 = std::make_unique<int>(42);
std::cout << *p1;  // 42

// 独占所有权，不能复制
auto p2 = p1;              // ❌ 编译错误
auto p2 = std::move(p1);   // ✅ 转移所有权（p1 变为 nullptr）

// 管理数组
auto arr = std::make_unique<int[]>(10);
arr[0] = 1;
```

## shared_ptr（共享所有权）

```cpp
auto p1 = std::make_shared<int>(42);
std::cout << p1.use_count();  // 1

{
    auto p2 = p1;              // 共享所有权
    std::cout << p1.use_count();  // 2
}  // p2 销毁，引用计数减 1

std::cout << p1.use_count();  // 1
// 最后一个 shared_ptr 销毁时释放内存
```

## weak_ptr（打破循环引用）

```cpp
std::weak_ptr<int> weak;

{
    auto shared = std::make_shared<int>(100);
    weak = shared;  // weak 不增加引用计数

    if (auto locked = weak.lock()) {
        std::cout << *locked;  // 安全访问
    }
}  // shared 销毁

// weak.expired() == true
```

## 选择建议

| 场景 | 使用 |
|------|------|
| 默认首选 | `unique_ptr` |
| 多处共享同一资源 | `shared_ptr` |
| 避免循环引用 | `weak_ptr` |
| 简单局部变量 | 直接用栈变量 |
