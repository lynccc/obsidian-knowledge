# 🔄 类型转换

## 核心概念

- 隐式转换：编译器自动完成，可能丢失精度
- 显式转换：程序员手动指定，更安全
- C++ 推荐使用 `static_cast` 而非 C 风格强制转换

## 隐式转换（Implicit Conversion）

```cpp
int a = 3.14;         // double → int，截断小数部分，a = 3
double b = 10;        // int → double，b = 10.0
bool c = 42;          // int → bool，非零为 true
char d = 65;          // int → char，d = 'A'

// 算术运算中的隐式转换
int x = 3;
double y = 4.5;
auto result = x + y;  // int 提升为 double，result = 7.5
```

## 显式转换（C++ 风格）

```cpp
// static_cast — 最常用，编译期检查
int a = static_cast<int>(3.14);      // a = 3
double b = static_cast<double>(10);  // b = 10.0

// const_cast — 去除/添加 const
const int c = 10;
int* p = const_cast<int*>(&c);

// dynamic_cast — 运行时多态转换（用于类继承）
// reinterpret_cast — 底层位模式重新解释（慎用）
```

## C 风格转换（不推荐）

```cpp
int a = (int)3.14;    // C 风格，不如 static_cast 安全
```

## 常见陷阱

```cpp
int a = 5;
int b = 2;
double c = a / b;     // c = 2.0（整数除法！）

double d = static_cast<double>(a) / b;  // d = 2.5（正确）
```
