# 🔢 基本数据类型

## 核心概念

- C++ 提供多种内置数据类型
- 不同类型占用不同内存大小
- `sizeof` 运算符可查看类型大小

## 整型

```cpp
short a = 10;          // 至少 16 位
int b = 100;           // 至少 16 位，通常 32 位
long c = 1000L;        // 至少 32 位
long long d = 10000LL; // 至少 64 位

unsigned int e = 42;   // 无符号，不能为负
```

## 浮点型

```cpp
float a = 3.14f;       // 单精度，约 6-7 位有效数字
double b = 3.14159;    // 双精度，约 15-16 位有效数字（推荐）
long double c = 3.14L; // 扩展精度
```

## 字符与布尔

```cpp
char c = 'A';          // 单个字符，ASCII 码存储
bool flag = true;      // true(1) 或 false(0)
```

## sizeof 查看大小

```cpp
#include <iostream>
int main() {
    std::cout << "int: " << sizeof(int) << " 字节" << std::endl;      // 4
    std::cout << "double: " << sizeof(double) << " 字节" << std::endl; // 8
    std::cout << "char: " << sizeof(char) << " 字节" << std::endl;    // 1
    std::cout << "bool: " << sizeof(bool) << " 字节" << std::endl;    // 1
    return 0;
}
```

## 类型速查表

| 类型 | 大小(典型) | 范围 |
|------|-----------|------|
| `char` | 1 字节 | -128 ~ 127 |
| `int` | 4 字节 | -2³¹ ~ 2³¹-1 |
| `float` | 4 字节 | ±3.4e38 |
| `double` | 8 字节 | ±1.7e308 |
| `bool` | 1 字节 | true/false |
