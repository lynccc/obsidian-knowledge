# 🧱 结构体

## 核心概念

- 结构体（Struct）将多个不同类型的数据组合在一起
- 成员默认**公开**（public）
- 适合简单的数据聚合，复杂行为用 `class`

## 基本用法

```cpp
struct Student {
    std::string name;
    int age;
    double score;
};

Student s1 = {"Alice", 20, 95.5};
Student s2;
s2.name = "Bob";
s2.age = 21;
s2.score = 88.0;
```

## 成员访问

```cpp
Student s = {"Alice", 20, 95.5};

s.name = "Bob";           // 点运算符
Student* p = &s;
p->name = "Charlie";      // 指针用箭头运算符
```

## 结构体初始化

```cpp
// C++11 聚合初始化
struct Point {
    int x;
    int y;
};

Point p1 = {10, 20};      // 拷贝列表初始化
Point p2{30, 40};         // 直接列表初始化
Point p3 = {10};          // y 默认为 0
```

## 结构体与函数

```cpp
struct Rect {
    int width;
    int height;

    // 可以有成员函数
    int area() {
        return width * height;
    }
};

// 也可以用独立函数
void print_rect(const Rect& r) {
    std::cout << r.width << "x" << r.height;
}
```

## struct vs class

| 特性 | struct | class |
|------|--------|-------|
| 默认访问权限 | public | private |
| 继承默认权限 | public | private |
| 使用场景 | 数据聚合 | 封装行为 |

> 💡 实际开发中，纯数据用 `struct`，有行为用 `class`。
