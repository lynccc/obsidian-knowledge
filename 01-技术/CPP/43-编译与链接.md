# ⚙️ 编译与链接

## 核心概念

- C++ 是编译型语言，源码需经过编译才能运行
- 编译过程分为 4 个阶段：预处理→编译→汇编→链接
- 理解编译过程有助于排查错误

## 四个阶段

### 1. 预处理（Preprocessing）

处理 `#` 开头的指令：`#include`、`#define`、`#ifdef` 等。

```bash
g++ -E hello.cpp -o hello.i  # 只做预处理
```

### 2. 编译（Compilation）

将预处理后的代码编译为汇编代码。

```bash
g++ -S hello.cpp -o hello.s  # 只做编译
```

### 3. 汇编（Assembly）

将汇编代码转为机器码（目标文件 `.o`）。

```bash
g++ -c hello.cpp -o hello.o  # 只做汇编
```

### 4. 链接（Linking）

将多个目标文件和库文件链接为可执行文件。

```bash
g++ hello.o -o hello  # 链接
```

## 头文件与源文件

```cpp
// math_utils.h — 头文件（声明）
#ifndef MATH_UTILS_H
#define MATH_UTILS_H
int add(int a, int b);
#endif

// math_utils.cpp — 源文件（定义）
#include "math_utils.h"
int add(int a, int b) {
    return a + b;
}
```

- **头文件（.h/.hpp）**：放声明，用 `#include` 引入
- **源文件（.cpp）**：放定义（实现）
- `#ifndef` / `#define` 防止头文件重复包含

## 常见编译命令

```bash
g++ main.cpp utils.cpp -o app       # 编译多个文件
g++ -std=c++17 main.cpp -o app      # 指定 C++ 标准
g++ -Wall -Wextra main.cpp -o app   # 开启警告
g++ -g main.cpp -o app              # 包含调试信息
```
