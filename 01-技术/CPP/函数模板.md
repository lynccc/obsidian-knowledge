# 📐 函数模板

## 核心概念

- 函数模板（Function Template）让函数适用于多种类型
- 编译器根据调用参数自动推导类型
- 避免为每种类型写重复代码

## 基本用法

```cpp
template <typename T>
T max_value(T a, T b) {
    return (a > b) ? a : b;
}

// 调用时自动推导类型
int m1 = max_value(3, 5);           // T = int
double m2 = max_value(3.14, 2.71);  // T = double
```

## 多个模板参数

```cpp
template <typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

auto result = add(3, 4.5);  // T=int, U=double, 返回 double
```

## 显式指定类型

```cpp
template <typename T>
T square(T x) { return x * x; }

auto r1 = square(5);        // T = int
auto r2 = square<double>(5); // 显式指定 T = double
```

## 模板特化

```cpp
// 通用版本
template <typename T>
T max_value(T a, T b) {
    return (a > b) ? a : b;
}

// 针对 const char* 的特化
template <>
const char* max_value<const char*>(const char* a, const char* b) {
    return (std::strcmp(a, b) > 0) ? a : b;
}
```

## 注意事项

- 模板的声明和定义通常放在头文件中
- 编译错误信息可能很难读（C++20 concepts 改善了这点）
- 模板在使用时才实例化
