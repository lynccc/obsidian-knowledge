# 🔮 自动类型推导

## 核心概念

- `auto` 让编译器自动推导变量类型（C++11）
- `decltype` 获取表达式的类型（C++11）
- 减少冗余代码，提高可读性

## auto

```cpp
auto x = 42;              // int
auto y = 3.14;            // double
auto s = std::string("hello");  // std::string
auto v = std::vector<int>{1, 2, 3};  // std::vector<int>

// 迭代器类型很长时特别有用
std::map<std::string, int> m;
auto it = m.begin();      // 比 std::map<std::string,int>::iterator 简洁

// 范围 for
for (const auto& item : m) { }
```

## auto 的注意事项

```cpp
auto a = 5;        // int
auto& b = a;       // int&（引用）
const auto c = 5;  // const int
auto* p = &a;      // int*（显式指针）

// ❌ 不能用 auto 的情况
// auto x;           // 必须有初始化
// auto arr[] = {1}; // 不能推导数组类型
```

## decltype

```cpp
int x = 5;
decltype(x) y = 10;        // y 的类型是 int

const int& ref = x;
decltype(ref) z = x;       // z 的类型是 const int&

// 常用于模板返回类型
template <typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

## auto vs decltype

| 特性 | auto | decltype |
|------|------|----------|
| 用途 | 变量类型推导 | 获取表达式类型 |
| 会忽略引用 | ✅ | ❌ 保留 |
| 会忽略顶层 const | ✅ | ❌ 保留 |

```cpp
const int x = 5;
auto a = x;           // int（忽略 const）
decltype(x) b = 10;   // const int（保留）
```
