# 🎭 多态

## 核心概念

- 多态（Polymorphism）：同一接口，不同实现
- 通过**虚函数**（virtual）实现运行时多态
- 纯虚函数定义**抽象类**，不能实例化

## 虚函数

```cpp
class Shape {
public:
    virtual double area() const { return 0; }
    virtual void draw() const {
        std::cout << "Drawing shape" << std::endl;
    }
};

class Circle : public Shape {
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override {       // override 明确表示重写
        return 3.14159 * radius * radius;
    }
    void draw() const override {
        std::cout << "Drawing circle" << std::endl;
    }
};
```

## 多态使用

```cpp
Circle c(5.0);
Shape& s = c;       // 基类引用指向派生类
s.area();            // 调用 Circle::area()（多态）
s.draw();            // 调用 Circle::draw()

// 指针也一样
Shape* p = &c;
p->area();           // 调用 Circle::area()
```

## 纯虚函数与抽象类

```cpp
class Shape {
public:
    virtual double area() const = 0;    // 纯虚函数
    virtual void draw() const = 0;
};

// Shape s;  // ❌ 抽象类不能实例化

class Circle : public Shape {
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override { return 3.14159 * radius * radius; }
    void draw() const override { std::cout << "circle"; }
};

Circle c(5.0);  // ✅ 具体类可以实例化
```

## 虚析构函数

```cpp
class Base {
public:
    virtual ~Base() { }  // 虚析构：确保正确释放派生类资源
};

Base* p = new Derived();
delete p;  // 如果没有虚析构，可能不会调用 Derived 的析构函数
```

## override 和 final（C++11）

```cpp
class Base {
public:
    virtual void foo() const;
};

class Derived : public Base {
    void foo() const override;     // 明确重写
    void bar() const final;        // 不能被子类重写
};

class Final final : public Base { };  // 不能被继承
```
