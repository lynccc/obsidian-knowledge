# 🔀 函数重载

## 核心概念

- 函数重载（Overload）：同名函数，参数列表不同
- 编译器根据参数类型和数量自动选择正确版本
- 仅返回类型不同**不构成**重载

## 基本用法

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

// 调用时编译器自动匹配
add(1, 2);        // 调用 int 版本
add(1.5, 2.5);    // 调用 double 版本
add(1, 2, 3);     // 调用三参数版本
```

## 重载决议规则

```cpp
void print(int x) { std::cout << "int: " << x; }
void print(double x) { std::cout << "double: " << x; }
void print(const std::string& s) { std::cout << "string: " << s; }

print(42);        // int
print(3.14);      // double
print("hello");   // string（const char* 转换为 string）
```

## 不构成重载的情况

```cpp
// ❌ 仅返回类型不同
int func(int x);
double func(int x);  // 编译错误

// ❌ 仅 const 修饰不构成重载（对于值参数）
void foo(int x);
void foo(const int x);  // 编译错误：重复定义
```

## const 引用参数可以构成重载

```cpp
void process(int& x) { }           // 可修改版本
void process(const int& x) { }     // 只读版本

int a = 10;
process(a);           // 调用非 const 版本
process(42);          // 调用 const 版本（字面量只能绑定 const 引用）
```
