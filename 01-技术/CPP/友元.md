# 🤝 友元

## 核心概念

- 友元（Friend）允许外部函数或类访问私有成员
- 破坏了封装性，谨慎使用
- 常用于运算符重载和紧密耦合的类

## 友元函数

```cpp
class Box {
    int width;
public:
    Box(int w) : width(w) {}

    // 声明友元函数
    friend void print_width(const Box& b);
};

// 友元函数可以访问私有成员
void print_width(const Box& b) {
    std::cout << "Width: " << b.width << std::endl;
}
```

## 友元类

```cpp
class Engine {
    int horsepower;
public:
    Engine(int hp) : horsepower(hp) {}

    // 声明友元类
    friend class Car;
};

class Car {
public:
    void show_engine(const Engine& e) {
        // 可以访问 Engine 的私有成员
        std::cout << e.horsepower << " HP";
    }
};
```

## 运算符重载中的友元

```cpp
class Point {
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {}

    // << 运算符必须用友元（左操作数是 ostream）
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        return os << "(" << p.x << ", " << p.y << ")";
    }
};
```

## 注意事项

- 友元关系**不能传递**（A 是 B 的友元，B 是 C 的友元，不代表 A 是 C 的友元）
- 友元关系**不能继承**
- 能用公开接口就不用友元
- 过度使用友元说明设计有问题
