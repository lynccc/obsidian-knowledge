# 🚀 移动语义

## 核心概念

- 移动语义（Move Semantics）避免不必要的深拷贝（C++11）
- `std::move` 将左值转为右值引用
- 移动构造函数"偷走"资源而非复制

## 为什么需要移动语义

```cpp
std::vector<int> create_vec() {
    std::vector<int> v = {1, 2, 3, 4, 5};
    return v;  // 返回时可能触发拷贝（虽然有 RVO）
}

// 移动：直接转移内部指针，O(1)
// 拷贝：分配新内存并复制数据，O(n)
```

## 移动构造函数

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    // 拷贝构造（深拷贝）
    Buffer(const Buffer& other) : size(other.size), data(new int[size]) {
        std::copy(other.data, other.data + size, data);
    }

    // 移动构造（转移所有权）
    Buffer(Buffer&& other) noexcept
        : data(other.data), size(other.size) {
        other.data = nullptr;  // 置空源对象
        other.size = 0;
    }
};
```

## std::move

```cpp
std::string s1 = "Hello";
std::string s2 = std::move(s1);  // 移动，s1 变为空

// s1 现在处于有效但未指定状态
// 不要再使用 s1 的值
```

## 移动赋值运算符

```cpp
class Buffer {
    // ...
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data;        // 释放原有资源
            data = other.data;    // 接管资源
            size = other.size;
            other.data = nullptr;
            other.size = 0;
        }
        return *this;
    }
};
```

## 移动与容器

```cpp
std::vector<std::string> v;
std::string s = "Hello World";

v.push_back(s);               // 拷贝（s 仍有效）
v.push_back(std::move(s));    // 移动（s 变为空）

// 移动整个容器
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = std::move(v1);  // v1 变为空
```

## 完美转发

```cpp
template <typename T>
void wrapper(T&& arg) {
    // std::forward 保持参数的左/右值属性
    target(std::forward<T>(arg));
}
```
