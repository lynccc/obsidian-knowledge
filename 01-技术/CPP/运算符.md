# ➕ 运算符

## 核心概念

- C++ 提供丰富的运算符类型
- 运算符有优先级，不确定时加括号
- 自增自减有前置和后置两种形式

## 算术运算符

```cpp
int a = 10, b = 3;
a + b;   // 13  加
a - b;   // 7   减
a * b;   // 30  乘
a / b;   // 3   整数除法（截断）
a % b;   // 1   取模（仅整数）
```

## 关系运算符

```cpp
a == b;  // 等于
a != b;  // 不等于
a > b;   // 大于
a < b;   // 小于
a >= b;  // 大于等于
a <= b;  // 小于等于
```

## 逻辑运算符

```cpp
true && false;  // 逻辑与（都为真才真）
true || false;  // 逻辑或（一个为真就真）
!true;          // 逻辑非（取反）
```

## 赋值运算符

```cpp
int x = 10;
x += 5;   // x = x + 5
x -= 3;   // x = x - 3
x *= 2;   // x = x * 2
x /= 4;   // x = x / 4
x %= 3;   // x = x % 3
```

## 自增自减

```cpp
int a = 5;
int b = a++;  // b = 5, a = 6（后置：先用后加）
int c = ++a;  // c = 7, a = 7（前置：先加后用）
```

## 位运算符

```cpp
int a = 0b1010, b = 0b1100;
a & b;   // 0b1000  按位与
a | b;   // 0b1110  按位或
a ^ b;   // 0b0110  按位异或
~a;      // 按位取反
a << 1;  // 左移
a >> 1;  // 右移
```

## 三目运算符

```cpp
int x = 10;
string result = (x > 5) ? "大于5" : "小于等于5";
```
