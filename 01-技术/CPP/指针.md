# 🎯 指针

## 核心概念

- 指针（Pointer）存储的是变量的**内存地址**
- `*` 用于声明指针或解引用，`&` 用于取地址
- 指针是 C++ 最强大也最危险的特性

## 基本用法

```cpp
int x = 42;
int* p = &x;        // p 指向 x 的地址

std::cout << p;      // 输出地址（如 0x7ffd5e8a3b4c）
std::cout << *p;     // 解引用，输出 42

*p = 100;            // 通过指针修改 x
// x 现在是 100
```

## 空指针

```cpp
int* p1 = nullptr;   // C++11 推荐
int* p2 = NULL;      // C 风格（不推荐）
int* p3 = 0;         // 不推荐

// 使用前检查
if (p1 != nullptr) {
    std::cout << *p1;
}
```

## 指针与数组

```cpp
int arr[] = {10, 20, 30};
int* p = arr;         // 数组名就是首元素地址

std::cout << *p;      // 10
std::cout << *(p+1);  // 20
std::cout << p[2];    // 30（等价于 *(p+2)）
```

## 野指针与悬空指针

```cpp
// 野指针 — 未初始化的指针（危险！）
int* p;               // 未初始化，指向随机地址
*p = 10;              // ❌ 未定义行为

// 悬空指针 — 指向已释放的内存
int* p = new int(42);
delete p;             // 释放内存
*p = 10;              // ❌ 悬空指针，未定义行为
p = nullptr;          // ✅ 置空防止误用
```

## 指针运算

```cpp
int arr[] = {10, 20, 30, 40, 50};
int* p = arr;

p++;                  // 指向下一个元素（20）
p += 2;               // 跳两个元素（40）
int diff = p - arr;   // 指针相减，得到偏移量
```
