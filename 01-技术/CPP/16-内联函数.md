# ⚡ 内联函数

## 核心概念

- `inline` 建议编译器将函数调用替换为函数体
- 目的：减少函数调用开销，提升性能
- 现代编译器会自动内联简单函数，`inline` 更多是建议

## 基本用法

```cpp
inline int square(int x) {
    return x * x;
}

inline int max(int a, int b) {
    return (a > b) ? a : b;
}

int main() {
    int result = square(5);  // 编译器可能替换为 5 * 5
}
```

## 适用场景

```cpp
// ✅ 适合内联：函数体小、调用频繁
inline int abs_val(int x) { return x < 0 ? -x : x; }
inline bool is_even(int x) { return x % 2 == 0; }

// ❌ 不适合内联：函数体大、有循环/递归
inline void complex_function() {
    // 大量代码...编译器会忽略 inline 建议
}
```

## inline 与头文件

```cpp
// utils.h — 在头文件中定义函数
inline int add(int a, int b) {
    return a + b;
}

// 内联函数通常定义在头文件中
// 因为编译器需要在每个调用点看到函数体
```

## 注意事项

- `inline` 只是建议，编译器可以忽略
- 过度内联会导致代码膨胀（增大可执行文件）
- 现代编译器优化能力强，通常自动决定是否内联
- 在头文件中定义的函数默认具有内联特性
