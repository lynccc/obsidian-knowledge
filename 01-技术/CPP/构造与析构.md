# 🔨 构造与析构

## 核心概念

- 构造函数：对象创建时自动调用，用于初始化
- 析构函数：对象销毁时自动调用，用于清理资源
- 拷贝构造函数：用已有对象创建新对象

## 构造函数

```cpp
class Student {
    std::string name;
    int age;
public:
    // 默认构造函数
    Student() : name("unknown"), age(0) {}

    // 参数化构造函数
    Student(const std::string& n, int a) : name(n), age(a) {}

    // 委托构造函数（C++11）
    Student(const std::string& n) : Student(n, 0) {}
};
```

## 初始化列表

```cpp
class Point {
    int x, y;
public:
    // ✅ 推荐：初始化列表
    Point(int x, int y) : x(x), y(y) {}

    // ❌ 不推荐：赋值方式
    Point(int x, int y) {
        this->x = x;  // 先默认构造再赋值，效率低
        this->y = y;
    }
};
```

## 析构函数

```cpp
class Buffer {
    int* data;
public:
    Buffer(int size) : data(new int[size]) {}

    ~Buffer() {           // 析构函数：释放资源
        delete[] data;
    }
};
```

## 拷贝构造函数

```cpp
class Student {
    std::string name;
    int* scores;
public:
    // 拷贝构造（深拷贝）
    Student(const Student& other)
        : name(other.name),
          scores(new int[10]) {
        for (int i = 0; i < 10; i++)
            scores[i] = other.scores[i];
    }
};

Student s1;
Student s2 = s1;   // 调用拷贝构造
Student s3(s1);    // 也是拷贝构造
```

## Rule of Three/Five

如果类需要自定义以下之一，通常需要全部自定义：

- **三法则**（C++98）：析构函数、拷贝构造、拷贝赋值
- **五法则**（C++11）：加上移动构造、移动赋值
