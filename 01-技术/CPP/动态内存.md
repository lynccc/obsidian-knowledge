# 💾 动态内存

## 核心概念

- 动态内存在**堆（Heap）**上分配，程序手动管理
- `new` 分配内存，`delete` 释放内存
- 忘记释放会导致**内存泄漏**（Memory Leak）

## new 和 delete

```cpp
// 分配单个变量
int* p = new int(42);      // 在堆上分配一个 int
std::cout << *p;           // 42
delete p;                  // 释放内存
p = nullptr;               // 置空防误用

// 分配数组
int* arr = new int[5];     // 分配 5 个 int
arr[0] = 10;
delete[] arr;              // 释放数组（注意 []）
arr = nullptr;
```

## 内存泄漏

```cpp
void leak_example() {
    int* p = new int(100);
    // 忘记 delete p → 内存泄漏
    // 函数结束后 p 消失，但内存未释放
}

// ✅ 正确做法
void no_leak() {
    int* p = new int(100);
    // ... 使用 p
    delete p;
    p = nullptr;
}
```

## 栈 vs 堆

| 特性 | 栈（Stack） | 堆（Heap） |
|------|-----------|-----------|
| 分配速度 | 快 | 慢 |
| 大小限制 | 较小（通常 1-8MB） | 大（受系统内存限制） |
| 管理方式 | 自动（作用域结束释放） | 手动（new/delete） |
| 用途 | 局部变量 | 动态大小数据 |

## 现代 C++ 的建议

```cpp
// ❌ 尽量避免裸 new/delete
int* p = new int(42);
delete p;

// ✅ 使用智能指针（推荐）
auto p = std::make_unique<int>(42);  // 自动释放

// ✅ 使用容器（推荐）
std::vector<int> vec = {1, 2, 3};    // 自动管理内存
```
