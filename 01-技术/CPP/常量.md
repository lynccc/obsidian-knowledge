# 🔒 常量

## 核心概念

- 常量是值不能被修改的变量
- `const`：运行时常量
- `constexpr`：编译时常量（C++11）
- `#define`：预处理宏替换（不推荐）

## const

```cpp
const int MAX_SIZE = 100;
MAX_SIZE = 200;  // ❌ 编译错误：不能修改 const

const double PI = 3.14159;
const std::string NAME = "Alice";
```

## constexpr（C++11）

```cpp
constexpr int SQUARE(int x) { return x * x; }

constexpr int AREA = SQUARE(5);  // 编译期计算，AREA = 25
constexpr double PI = 3.14159;

// constexpr 函数在编译期求值（参数为常量时）
int val = 10;
int result = SQUARE(val);  // 也可以运行时调用
```

## #define（不推荐）

```cpp
#define MAX_SIZE 100    // 预处理宏，无类型检查
#define SQUARE(x) ((x) * (x))

// 问题：没有作用域、没有类型安全
#undef MAX_SIZE         // 取消定义
```

## const vs constexpr

| 特性 | const | constexpr |
|------|-------|-----------|
| 求值时机 | 运行时 | 编译时 |
| 函数 | 不能修饰函数 | 可以修饰函数 |
| 推荐场景 | 不需要编译时常量 | 编译期常量表达式 |

## const 指针

```cpp
int x = 10;
const int* p1 = &x;    // 指向常量的指针，不能通过 p1 修改 *p1
int* const p2 = &x;    // 常量指针，p2 不能指向别处
const int* const p3 = &x;  // 两者都不能改
```
