# 🔒 封装

## 核心概念

- 封装（Encapsulation）将数据和操作绑定在一起
- 通过访问控制隐藏内部实现细节
- 对外提供统一接口，保护数据安全

## 访问控制

```cpp
class BankAccount {
private:          // 外部不能直接访问
    double balance;
    std::string owner;

protected:        // 子类可以访问
    int account_type;

public:           // 任何地方都能访问
    BankAccount(const std::string& owner, double initial)
        : owner(owner), balance(initial) {}

    // 公开接口
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    bool withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false;
    }

    double get_balance() const { return balance; }
};
```

## getter / setter

```cpp
class Student {
private:
    std::string name;
    int age;

public:
    // getter（只读）
    std::string get_name() const { return name; }
    int get_age() const { return age; }

    // setter（带验证）
    void set_age(int a) {
        if (a >= 0 && a <= 150) age = a;
    }
};
```

## 封装的好处

- **数据保护**：防止非法修改
- **接口稳定**：内部实现可以改变，不影响外部代码
- **易于维护**：修改逻辑只需改一处

## 何时用 public / private

| 成员类型 | 建议 |
|---------|------|
| 内部数据 | private |
| 对外接口 | public |
| 辅助函数 | private |
| 子类需要的 | protected |
