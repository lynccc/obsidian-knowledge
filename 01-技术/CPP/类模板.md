# 📦 类模板

## 核心概念

- 类模板（Class Template）让类适用于多种类型
- STL 容器（如 `vector<T>`、`map<K,V>`）都是类模板
- 实例化时必须显式指定模板参数

## 基本用法

```cpp
template <typename T>
class Box {
    T content;
public:
    Box(T c) : content(c) {}
    T get() const { return content; }
    void set(T c) { content = c; }
};

Box<int> int_box(42);
Box<std::string> str_box("hello");

std::cout << int_box.get();  // 42
std::cout << str_box.get();  // hello
```

## 多个模板参数

```cpp
template <typename K, typename V>
class Pair {
    K key;
    V value;
public:
    Pair(K k, V v) : key(k), value(v) {}
    K get_key() const { return key; }
    V get_value() const { return value; }
};

Pair<std::string, int> p("age", 25);
```

## 类模板的成员函数在类外定义

```cpp
template <typename T>
class Stack {
    std::vector<T> data;
public:
    void push(const T& item);
    T pop();
};

// 类外定义需要重复模板参数
template <typename T>
void Stack<T>::push(const T& item) {
    data.push_back(item);
}

template <typename T>
T Stack<T>::pop() {
    T item = data.back();
    data.pop_back();
    return item;
}
```

## 默认模板参数

```cpp
template <typename T, int Size = 10>
class FixedArray {
    T data[Size];
public:
    int size() const { return Size; }
};

FixedArray<int> a1;         // Size = 10
FixedArray<int, 100> a2;    // Size = 100
```
