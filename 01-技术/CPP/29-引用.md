# 🔗 引用

## 核心概念

- 引用（Reference）是变量的**别名**
- 引用必须初始化，且不能重新绑定
- 比指针更安全，是 C++ 推荐的参数传递方式

## 左值引用

```cpp
int x = 42;
int& ref = x;       // ref 是 x 的别名

ref = 100;          // 通过引用修改 x
// x 现在是 100

std::cout << &x << std::endl;    // 相同地址
std::cout << &ref << std::endl;  // 相同地址
```

## 引用作为函数参数

```cpp
// 值传递 — 不修改原变量
void swap_wrong(int a, int b) {
    int temp = a; a = b; b = temp;  // 无效
}

// 引用传递 — 修改原变量
void swap_right(int& a, int& b) {
    int temp = a; a = b; b = temp;  // 有效
}

// const 引用 — 只读，避免拷贝
void print(const std::string& s) {
    std::cout << s;
}
```

## 引用 vs 指针

| 特性 | 引用 | 指针 |
|------|------|------|
| 必须初始化 | ✅ | ❌ |
| 可以为空 | ❌ | ✅（nullptr） |
| 可重新绑定 | ❌ | ✅ |
| 语法 | 直接用 | 需要 `*` 解引用 |
| 安全性 | 更高 | 更灵活 |

## 右值引用（C++11）

```cpp
// 右值引用 — 绑定到临时值
int&& rref = 42;           // 绑定到字面量
int&& rref2 = 1 + 2;      // 绑定到临时值

// 主要用于移动语义
void process(std::string&& s) {
    // 可以"偷走" s 的资源
}
```

## 常见用法

```cpp
// 返回引用（避免拷贝）
std::vector<int> vec = {1, 2, 3};
int& first = vec[0];
first = 100;  // 修改 vec[0]

// 范围 for 中使用引用
for (const auto& item : vec) { }  // 只读
for (auto& item : vec) { }        // 可修改
```
