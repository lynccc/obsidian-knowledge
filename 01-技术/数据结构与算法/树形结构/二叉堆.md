# 二叉堆

## 🗣️ 通俗讲解

> 想象一棵树种在数组里：第 i 个位置的「孩子」在 2i 和 2i+1 位置，「爸爸」在 i/2 位置。最大堆就是爸爸永远比孩子大，所以堆顶就是最大值。插入时新元素「上浮」到该去的位置，删除时把最后一个元素放到堆顶再「下沉」——就像水里的气泡一样。

## 📖 核心概念

二叉堆（Binary Heap）是**优先级队列**最常用的实现，底层采用**完全二叉树**，同时满足两个条件：

1. **结构性**：完全二叉树，可用数组紧凑存储，无空洞
2. **堆序性**：任意节点的关键码 ≥ 其子节点的关键码（大顶堆）或 ≤ 其子节点（小顶堆）

### 数组存储映射

对于索引 `i` 的节点：
- **父节点**：`PARENT(i) = ⌊(i-1)/2⌋`（Python 中为 `i // 2`）
- **左孩子**：`LEFT(i) = 2i + 1`（Python 中为 `2 * i`）
- **右孩子**：`RIGHT(i) = 2i + 2`（Python 中为 `2 * i + 1`）

```python
class BinHeap:
    def __init__(self):
        self.heap_list = [0]  # 索引 0 不使用
        self.current_size = 0
```

### 插入操作 — 上滤（Percolate Up）

新元素追加到数组末尾（保持完全二叉树结构），然后与父节点比较：
- 若新元素关键码更大（大顶堆），则与父节点交换
- 重复直到堆序性恢复或到达根

```python
def perc_up(self, i):
    while i // 2 > 0:
        if self.heap_list[i] < self.heap_list[i // 2]:
            self.heap_list[i // 2], self.heap_list[i] = \
                self.heap_list[i], self.heap_list[i // 2]
        i = i // 2
```

时间复杂度：O(log n)

### 删除操作 — 下滤（Percolate Down）

删除堆顶后，将末尾元素移至堆顶，然后与较大的子节点比较：
- 若当前节点关键码更小，则与较大子节点交换
- 重复直到堆序性恢复或成为叶节点

```python
def perc_down(self, i):
    while (i * 2) <= self.current_size:
        mc = self.min_child(i)
        if self.heap_list[i] > self.heap_list[mc]:
            self.heap_list[i], self.heap_list[mc] = \
                self.heap_list[mc], self.heap_list[i]
        i = mc
```

时间复杂度：O(log n)

### 建堆（Floyd 建堆算法）

**自下而上**逐节点下滤，从最后一个非叶子节点开始，依次对每个节点执行下滤操作。

```python
def build_heap(self, a_list):
    i = len(a_list) // 2
    self.current_size = len(a_list)
    self.heap_list = [0] + a_list[:]
    while i > 0:
        self.perc_down(i)
        i -= 1
```

**时间复杂度 O(n)** — 优于逐个插入的 O(n log n)。原理：大部分节点在树的底部，下滤路径短；只有少量高层节点路径长。

### 堆排序

利用 Floyd 算法先建堆，然后反复：
1. 将堆顶（最大值）与末尾元素交换
2. 堆规模减一，对新堆顶下滤

结果：数组原地升序排列。时间 O(n log n)，空间 O(1)。

## 优先队列

堆的一个重要应用是实现**优先队列**：

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| INSERT(S, x, k) | 插入元素 x，键值为 k | O(log n) |
| MAXIMUM(S) | 返回键值最大的元素 | O(1) |
| EXTRACT-MAX(S) | 删除并返回键值最大的元素 | O(log n) |
| INCREASE-KEY(S, x, k) | 将元素 x 的键值增加到 k | O(log n) |
