# 哈夫曼编码

## 🗣️ 通俗讲解

> 哈夫曼编码就像给字母编"暗号"——常用的字母用短暗号，不常用的用长暗号。比如英文中 'e' 最常见，就给它最短的编码；'z' 很少见，就用长一点的编码。这样整体传输的数据量就最小了。
>
> 核心思想是贪心：每次把频率最低的两个"合并"，直到只剩一棵树。

## 📖 核心概念

**Huffman编码**是一种基于字符出现频率的**最优前缀编码**算法，通过构建最优二叉编码树实现最小编码总长度。

### 最优编码树

在所有编码树中，使**加权路径长度** (WPL) 最小的称为最优编码树：

$$WPL = \sum_{i} f_i \cdot d_i$$

其中 $f_i$ 为字符频率，$d_i$ 为对应叶子深度。

**性质**：最优编码树中，频率最低的两个字符一定是**最深**的兄弟叶子。

### Huffman 算法

采用贪心策略：

1. 为每个字符创建单节点树，权值为其频率
2. **重复**以下步骤直到只剩一棵树：
   - 选取权值最小的两棵树 $T_1, T_2$
   - 合并为新树：根权值 = $T_1 + T_2$
3. 最终得到的树即为 Huffman 编码树

```python
def huffman(C):
    n = len(C)
    Q = MinHeap(C)  # 最小堆，按频率排序
    for i in range(n - 1):
        z = TreeNode()
        z.left = x = Q.extract_min()
        z.right = y = Q.extract_min()
        z.freq = x.freq + y.freq
        Q.insert(z)
    return Q.extract_min()  # 根节点
```

### 时间复杂度

- 使用**最小堆**（优先队列）：**O(n log n)**
- n 为字符集大小

## 关键要点

1. Huffman 编码是**贪心算法**的典型应用
2. 产生的编码一定是**前缀编码**（字符都在叶子，不会有歧义）
3. **频率高的字符编码短，频率低的字符编码长**
4. 编码不是唯一的（相同频率的不同合并顺序产生不同树）
5. 遍历 Huffman 树即可生成编码表
