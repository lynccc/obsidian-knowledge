# 快速排序

## 🗣️ 通俗讲解
> 选一个数当「标杆」（pivot），比它小的扔左边，比它大的扔右边，然后左右两边各自再选标杆、再分……这就是分治。平均情况下是最快的通用排序（O(n log n)），但如果运气差选到最大或最小的数当标杆，就会退化成 O(n²)。所以实战中常用「三数取中」来选标杆。

## 📖 核心概念

快速排序选取一个**轴点（pivot）**，通过**划分（partition）**将序列分为两部分——左侧 ≤ pivot，右侧 ≥ pivot——然后递归排序两个子序列。

### 复杂度

| 情况 | 复杂度 | 条件 |
|------|--------|------|
| 最好 | O(nlogn) | 每次均匀划分 |
| 平均 | O(nlogn) | 随机输入 |
| 最坏 | O(n²) | 已排序 + 固定选首元素 |

- 空间复杂度：**O(logn)**（递归栈）
- **不稳定排序**

### 枢轴选择策略

1. **首元素**：简单但对有序数据退化
2. **随机选择**：避免最坏情况
3. **三数取中（Median of Three）**：取首、中、末三数的中位数，实践中最常用

### 关键优势
- **实践中最快**：常数因子小，缓存友好
- **原地排序**：不需要额外数组空间
- C++ STL `std::sort` 的基础

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：LUG 版划分算法（Low/Unknown/Grand 三指针），版本 A/B/C 的演进
- 特色：强调轴点选取策略对性能的影响

### Miller版（Python）
- 侧重：双向扫描分区实现，三数取中的 Python 实现
- 特色：代码清晰，适合理解分区过程

### CLRS版（算法导论）
- 侧重：Lomuto 分区方案、随机化版本、期望运行时间分析
- 特色：严格证明——元素 z_i 和 z_j 被比较的概率为 2/(j-i+1)
