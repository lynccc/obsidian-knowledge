# 冒泡排序

## 🗣️ 通俗讲解
> 最简单的排序思路：从头到尾比相邻两个数，大的往后挪。一轮下来最大的「冒泡」到最后面，再来一轮排第二大的……效率不高（O(n²)），但胜在好理解。就像打扑克牌时一张张插到该去的位置。

## 📖 核心概念

冒泡排序通过**重复比较相邻元素并交换**，使较大的元素逐渐"冒泡"到列表末尾。每一轮遍历将当前未排序部分的最大值移到正确位置。

**关键优化**：一轮无交换则说明已有序，可提前终止（`sorted` 标志）。

### 复杂度

| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 最好 | O(n) | 已有序，优化版一轮即停 |
| 平均 | O(n²) | 需要 n(n-1)/2 次比较 |
| 最坏 | O(n²) | 完全逆序 |

- 空间复杂度：**O(1)**（原地排序）
- **稳定排序**：相等元素的相对位置不变

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：有序性检测优化（`sorted` 标志），记录最后交换位置缩小扫描范围
- 特色：强调起泡排序作为算法分析入门实例的地位

### Miller版（Python）
- 侧重：Python 交换语法 `a, b = b, a` 的惯用写法
- 特色：过程示例清晰，适合初学者理解每轮变化

### CLRS版（算法导论）
- 侧重：起泡排序未单独讲解，但插入排序的循环不变式证明方法可类比应用
- 特色：强调正确性证明的方法论
