# 选择排序

## 🗣️ 通俗讲解
> 每一轮从未排序部分找最小的，放到已排序部分的末尾。就像从一堆人里每次挑最矮的排到队伍前面。交换次数最少（固定 n-1 次），适合交换代价高的场景。

## 📖 核心概念

选择排序维护两个子列表：已排序（左侧）和未排序（右侧）。每一轮从未排序部分**选择最小元素**，与未排序部分的第一个元素交换。

### 复杂度

| 情况 | 复杂度 |
|------|--------|
| 最好 | O(n²) |
| 平均 | O(n²) |
| 最坏 | O(n²) |

- 空间复杂度：**O(1)**（原地排序）
- **不稳定排序**：交换可能改变相等元素的相对顺序

### 与冒泡排序对比

| 特性 | 冒泡排序 | 选择排序 |
|------|---------|---------|
| 交换次数 | O(n²) | **O(n)** |
| 比较次数 | O(n²) | O(n²) |
| 是否稳定 | 是 | 否 |

选择排序的**交换次数固定为 n-1**，这是它的主要优势。

## 📝 各书特色

### Miller版（Python）
- 侧重：Python 实现的简洁性，与冒泡排序的对比
- 特色：过程示例清晰展示每轮选择过程

### 邓俊辉版（C++）
- 侧重：选择排序在向量排序中的定位
- 特色：从算法策略角度分析

### CLRS版（算法导论）
- 侧重：选择排序作为 O(n²) 排序的代表之一
- 特色：与其他排序的复杂度对比
