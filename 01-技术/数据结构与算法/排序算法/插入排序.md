# 插入排序

## 🗣️ 通俗讲解
> 想象你左手拿牌，右手从桌上一张张摸牌。每摸一张，从右往左在左手里找到合适位置插进去。左手的牌始终是排好序的——这就是插入排序。对近乎有序的数据特别快，接近 O(n)。

## 📖 核心概念

插入排序从第二个元素开始，将当前元素（key）与已排序子数组中的元素从右往左比较，找到正确位置插入。

### 复杂度

| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 最好 | **O(n)** | 已有序，每轮只比较一次 |
| 平均 | O(n²) | |
| 最坏 | O(n²) | 完全逆序 |

- 空间复杂度：**O(1)**（原地排序）
- **稳定排序**

### 三种 O(n²) 排序对比

| 特性 | 冒泡排序 | 选择排序 | 插入排序 |
|------|---------|---------|---------|
| 最好 | O(n) | O(n²) | **O(n)** |
| 交换次数 | O(n²) | O(n) | O(n²) |
| 稳定性 | 稳定 | 不稳定 | **稳定** |
| 适用场景 | 教学 | 交换代价高 | **近乎有序** |

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：作为向量基本操作，强调与有序向量的联系
- 特色：从数据结构视角理解排序

### Miller版（Python）
- 侧重：三种 O(n²) 排序的横向对比，Python `list.sort()` 内部使用 TimSort（归并+插入混合）
- 特色：实用导向，代码简洁

### CLRS版（算法导论）
- 侧重：**循环不变式**（Loop Invariant）证明算法正确性——初始化、保持、终止三步
- 特色：严格证明方法论，伪代码约定（1 起始索引、缩进表示块结构）
