# 队列

## 🗣️ 通俗讲解

> 就像排队买奶茶——先来的先服务（enqueue），先走的先出队（dequeue）。这就是「先进先出」（FIFO），跟栈正好反过来。

## 📖 核心概念

**队列**是只允许在一端（队尾）插入、另一端（队头）删除的线性表，遵循**先进先出（FIFO, First In First Out）**原则。

### ADT 接口

| 操作 | 功能 | 复杂度 |
|------|------|--------|
| `enqueue(e)` | 将元素 e 插入队尾 | O(1) 均摊 |
| `dequeue()` | 删除并返回队头元素 | O(1) |
| `front()` | 读取队头元素（不删除） | O(1) |
| `isEmpty()` | 判断队列是否为空 | O(1) |
| `size()` | 返回队列中元素个数 | O(1) |

### 实现方式

**数组实现（循环队列）**：
- 数组实现时，队头/队尾指针通过 `(ptr + 1) % capacity` 循环移动
- 空间可复用，解决假溢出问题
- 注意：当 head = tail 时表示队列为空，但会浪费一个空间来区分空和满

**链表实现**：
- 队头出队、队尾入队，天然支持

**Python 实现**：
- 用 `list` 实现，`insert(0, item)` 入队，`pop()` 出队
- 注意：列表的 `insert(0)` 是 O(n)，`deque` 的 `appendleft/popleft` 是 O(1)
- 推荐使用 `collections.deque` 提升性能

```python
class Queue:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def enqueue(self, item):
        self.items.insert(0, item)

    def dequeue(self):
        return self.items.pop()

    def size(self):
        return len(self.items)
```

## 关键要点

1. **FIFO 语义**：先入先出，保证了公平性（先到先服务）
2. **队列 vs 栈**：都是线性表的受限版本，区别在于访问顺序（FIFO vs LIFO）
3. **循环队列**：数组实现时，用取模运算实现循环，空间可复用
4. Python `collections.deque` 是高效双端队列，底层是双向链表，两端操作均为 O(1)

## 典型应用

- **BFS（广度优先搜索）**：用队列管理待访问节点
- **任务调度**：操作系统进程调度、打印队列
- **缓冲区**：生产者-消费者模型、消息队列
- **银行服务模拟**：模拟多窗口排队，统计等待时间
- **传土豆模拟**（Hot Potato）：围成一圈传土豆，用队列模拟淘汰过程
