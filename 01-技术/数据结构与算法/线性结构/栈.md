# 栈

## 🗣️ 通俗讲解

> 想象一摞盘子——你只能从最上面放（push），也只能从最上面拿（pop）。最后放进去的最先被拿出来，这就是「后进先出」（LIFO）。
>
> 递归函数的执行本质上就是栈操作——每次函数调用会在调用栈上创建一个新的栈帧，函数返回时弹出栈帧。

## 📖 核心概念

**栈**是仅允许在一端（栈顶）进行插入和删除操作的线性表，遵循**后进先出（LIFO, Last In First Out）**原则。

### ADT 接口

| 操作 | 功能 | 复杂度 |
|------|------|--------|
| `push(e)` | 将元素 e 压入栈顶 | O(1) 均摊 |
| `pop()` | 弹出并返回栈顶元素 | O(1) |
| `top()/peek()` | 读取栈顶元素（不弹出） | O(1) |
| `isEmpty()` | 判断栈是否为空 | O(1) |
| `size()` | 返回栈中元素个数 | O(1) |

### 实现方式

**数组实现（顺序栈）**：
- 底层用数组（向量），栈顶对应数组末尾
- `push` 均摊 O(1)（扩容时 O(n) 但均摊下来常数级）

```cpp
template <typename T> class Stack : public Vector<T> {
public:
    void push(T const& e) { insert(size(), e); }
    T pop() { return remove(size() - 1); }
    T& top() { return (*this)[size() - 1]; }
};
```

**Python 实现**：
- 直接用 `list`，`append()` 充当 `push`，`pop()` 即为 `pop`

```python
class Stack:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def peek(self):
        return self.items[-1]

    def size(self):
        return len(self.items)
```

### 栈与递归

**递归函数的执行本质上就是栈操作**。每次函数调用会在调用栈上创建一个新的栈帧（stack frame），保存局部变量、参数和返回地址；函数返回时弹出栈帧。

1. **调用**：将新栈帧压入调用栈（类比 `push`）
2. **返回**：弹出当前栈帧，恢复调用者的上下文（类比 `pop`）
3. **栈溢出**：递归过深导致调用栈空间耗尽

**关键**：任何递归算法都可以改写为显式使用栈的迭代版本。

## 栈的三大应用模式

### 1. 逆序输出（LIFO → 逆序）

栈的后进先出特性直接实现逆序：
- 进制转换（十进制→二进制，逐位入栈再依次弹出）
- 行编辑器的撤销（Undo）操作

### 2. 递归嵌套 —— 括号匹配

判断括号序列是否合法，如 `{[()]}` ✓，`{[(])}` ✗：
1. 遇到左括号 → 压栈
2. 遇到右括号 → 检查栈顶是否为对应左括号，是则弹出，否则非法
3. 最终栈为空 → 合法

### 3. 延迟缓冲 —— 表达式求值

计算算术表达式，如 `3 + 4 * 2 - (1 + 5)`：
- **双栈算法**：操作数栈 + 运算符栈
- **逆波兰表达式（RPN）**：将中缀转后缀，消除括号和优先级问题
- 如 `3 + 4 * 2` → `3 4 2 * +`

## 关键要点

1. **LIFO 语义**：最后压入的元素最先被弹出，这是栈最本质的特性
2. **空栈异常**：对空栈执行 `pop()` 或 `top()` 是未定义行为，需先检查
3. **括号匹配**延伸到 HTML/XML 标签匹配
4. **逆波兰表达式**是编译器内部常用的形式
5. 深度优先搜索（DFS）本质是栈的应用
