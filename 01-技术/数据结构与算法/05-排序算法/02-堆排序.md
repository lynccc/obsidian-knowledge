# 堆排序

## 🗣️ 通俗讲解
> 想象你有一堆数字，想把它们从小到大排好。先把这堆数字整理成一个"大顶堆"——最大的数在最顶上，然后把最大的数和最后一个数交换，这样最大的数就到了最后面。接着缩小堆的范围，重新整理堆……如此反复，直到所有数都排好。就像从一堆东西里不断挑出最大的那个放到最后。

## 📖 核心概念

堆是一个**近似完全二叉树**，用数组高效表示：
- 父节点：`PARENT(i) = ⌊i/2⌋`
- 左孩子：`LEFT(i) = 2i`
- 右孩子：`RIGHT(i) = 2i + 1`

### 算法流程

1. **建堆（BUILD-MAX-HEAP）**：将无序数组转为大顶堆，O(n) 时间
2. **排序**：将堆顶（最大值）与末尾交换，缩小堆范围，对堆顶调用 MAX-HEAPIFY，重复 n-1 次

### 复杂度

| 操作 | 时间 |
|------|------|
| 建堆 | O(n) |
| 排序 | O(nlogn) |
| 总计 | O(nlogn) |

- 空间复杂度：**O(1)**（原地排序）
- **不稳定排序**

### 优先队列

堆的经典应用是实现**优先队列**：

| 操作 | 时间 |
|------|------|
| INSERT | O(logn) |
| MAXIMUM | O(1) |
| EXTRACT-MAX | O(logn) |
| INCREASE-KEY | O(logn) |

应用场景：操作系统任务调度、Dijkstra 最短路径、Huffman 编码。
