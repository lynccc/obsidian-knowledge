# 归并排序

## 🗣️ 通俗讲解
> 核心思路是「先拆后合」：把列表一分为二，各自排好序，然后像拉拉链一样把两个有序列表合在一起。时间稳定在 O(n log n)，不像快排那样有退化风险，但代价是需要额外空间。Python 内置的 `sorted()` 就是基于归并排序的改进版（TimSort）。

## 📖 核心概念

归并排序是**分治法**的经典应用：将列表分成两半，递归排序每一半，然后将两个有序子列表**合并（merge）** 成一个有序列表。

### 复杂度

| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 所有情况 | O(nlogn) | 分割 logn 层，每层合并 O(n) |

- 空间复杂度：**O(n)**（需要辅助数组）
- **稳定排序**

### 归并排序 vs 快速排序

| 特性 | 归并排序 | 快速排序 |
|------|---------|---------|
| 最坏 | O(nlogn) | O(n²) |
| 空间 | O(n) | O(logn) |
| 稳定性 | **稳定** | 不稳定 |
| 适用 | 需要稳定排序 | 通用场景 |

### 关键特点
- 时间复杂度**恒定** O(nlogn)，不受输入数据影响
- 适合**链表排序**（无需随机访问，合并操作天然适合链表）
- Python 的 `sorted()` 使用 **TimSort**（归并+插入的混合）

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：向量上的归并实现，归并操作的 C++ 代码细节
- 特色：强调分治策略在向量排序中的应用

### Miller版（Python）
- 侧重：Python 实现的清晰递归结构，TimSort 的实际应用
- 特色：代码简洁易读，适合快速上手

### CLRS版（算法导论）
- 侧重：分治法的递推式 T(n) = 2T(n/2) + Θ(n)，由主定理得 Θ(nlogn)
- 特色：严格的复杂度证明
