# 线性时间排序

## 🗣️ 通俗讲解
> 你可能觉得 O(n log n) 已经是排序的极限了，但那只是"比较排序"的极限。如果我们能获取元素的其他信息（比如数字的范围、位数），就可以突破这个下界，实现线性时间排序！计数排序就像老师数有多少人考了100分、99分……然后按分数排好队。

## 📖 核心概念

### 比较排序下界

任何基于比较的排序算法最坏情况都需要 **Ω(nlogn)** 次比较（由决策树模型证明）。非比较排序通过利用元素的额外信息突破此下界。

### 计数排序（Counting Sort）

对每个元素 x，统计有多少个元素比 x 小，从而确定 x 的最终位置。
- 前提：输入元素都是 0 到 k 之间的整数
- 时间：**Θ(k+n)**，当 k=O(n) 时为线性
- **稳定排序**

### 基数排序（Radix Sort）

按关键码的**各个位**逐趟排序，从最低位到最高位（LSD）。每位的排序必须是**稳定**的。
- 时间：**Θ(d(n+k))**，d 为位数，k 为每位取值范围
- 当 d 为常数且 k=O(n) 时为线性

### 桶排序（Bucket Sort）

将元素分配到若干"桶"中，各桶分别排序，依次收集。
- 期望 **O(n)**（均匀分布时）
- 最坏 O(n²)（所有元素落入同一桶）

### 最大间隙问题

给定 n 个数，求排序后相邻元素的最大差值。利用桶排序思想，O(n) 时间求解，无需显式排序。

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：桶排序与基数排序的关系——桶排序是基数排序的特例（单趟宽桶），基数排序是多趟窄桶的级联
- 特色：最大间隙问题的巧妙解法

### CLRS版（算法导论）
- 侧重：比较排序下界的严格证明（决策树模型、Stirling 公式），计数排序的稳定性证明
- 特色：理论深度，各排序算法的完整对比表
