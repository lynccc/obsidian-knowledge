# 排序算法总结

## 🗣️ 通俗讲解
> 排序就像整理扑克牌——不同方法效率天差地别。有的像冒泡排序一张张慢慢挪，有的像归并排序先拆后合，有的像快速排序选个标杆左右分。选对算法，百万数据秒排；选错算法，可能等到天荒地老。

### 比较排序下界

基于比较的排序算法最坏时间复杂度下界为 **Ω(nlogn)**（由决策树模型证明）。堆排序和归并排序是渐近最优的比较排序。

非比较排序（桶排序、基数排序、计数排序）利用数据特征可达 O(n)，但适用场景受限。

### 选择指南

```
需要稳定排序？
├── 是 → 数据范围小 → 桶排序/基数排序 O(n)
│        数据范围大 → 归并排序 O(nlogn)
└── 否 → 数据量小 → 插入排序（常数因子小）
         数据量大 → 快速排序（平均最优）
         需要最坏保证 → 堆排序 O(nlogn)
         内存受限 → 堆排序 / 快排（原地）
```

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：向量排序的统一接口设计，起泡排序与归并排序的对比
- 特色：强调排序器（Sorter）作为策略对象的可替换性

### Miller版（Python）
- 侧重：Python 内置 `sorted()` 和 `list.sort()` 使用 TimSort（归并+插入混合）
- 特色：代码简洁，适合快速上手

### CLRS版（算法导论）
- 侧重：决策树模型证明比较排序下界，非比较排序的数学分析
- 特色：严格证明，归约到 Ω(nlogn) 的理论深度
