# 串匹配

## 🗣️ 通俗讲解

> 串匹配就是在一篇长文章（主串）里找一个关键词（模式串）。最笨的方法是从头一个个字符比较，发现不对就往后挪一位重新比较——这就是蛮力算法。KMP 算法更聪明：利用已经匹配过的信息，避免重复比较，主串指针永远不回退。

## 📖 核心概念

**串匹配问题**：给定**主串** T（长度 n）和**模式串** P（长度 m ≤ n），找到所有位置 i，使得 T[i..i+m-1] = P[0..m-1]。

### 蛮力算法（Brute-Force）

逐一尝试主串中每个可能的对齐位置，在每个位置逐字符比较。

```python
def brute_force_search(text, pattern):
    n, m = len(text), len(pattern)
    results = []
    for i in range(n - m + 1):
        j = 0
        while j < m and text[i + j] == pattern[j]:
            j += 1
        if j == m:
            results.append(i)
    return results
```

时间复杂度：最坏情况 O(nm)

**问题根源**：主串指针 i 在失配时需要**回溯**，导致大量重复比较。

### KMP 算法

KMP（Knuth-Morris-Pratt）算法利用模式串自身的结构信息，在失配时**避免主串指针回溯**，实现 O(n+m) 的线性时间匹配。

#### next 表

`next[j]` 表示模式串 P 中，子串 P[0..j-1] 的**最长真前缀 = 真后缀**的长度。

**物理意义**：失配发生在 P[j] 时，模式串应将 next[j] 位置对齐到当前主串位置，跳过已经匹配的部分。

#### next 表的递推构造

已知 next[0..j]，求 next[j+1]：
- 设 t = next[j]，若 P[t] == P[j]，则 next[j+1] = t + 1
- 否则递归回溯 t = next[t]，直到找到匹配或 t = -1

递推构造时间复杂度 O(m)。

#### KMP 匹配过程

```python
def kmp_search(text, pattern):
    n, m = len(text), len(pattern)
    next_table = build_next(pattern)
    results = []
    i = j = 0
    while i < n:
        if text[i] == pattern[j]:
            i += 1
            j += 1
            if j == m:
                results.append(i - j)
                j = next_table[j - 1]
        else:
            if j > 0:
                j = next_table[j - 1]
            else:
                i += 1
    return results
```

### 复杂度分析

| 算法 | 预处理 | 匹配 | 总计 | 空间 |
|------|--------|------|------|------|
| 蛮力 | 无 | O(nm) | O(nm) | O(1) |
| KMP | O(m) | O(n) | O(n+m) | O(m) |

核心在于主串指针 i **永不回溯**，只增不减，故总比较次数不超过 2n。

## 关键要点

1. KMP 的核心思想是利用已匹配信息消除回溯
2. next 表的本质是模式串的**自匹配**信息
3. 改进 next 表可避免同一字符的重复失配
4. BM 算法从另一个方向优化——模式串从右向左比较并跳跃
