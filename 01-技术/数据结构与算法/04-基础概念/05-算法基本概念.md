# 算法基本概念

## 🗣️ 通俗讲解

> 算法就是解决问题的"菜谱"——给定输入，按照明确的步骤执行，在有限时间内得到输出。就像你按菜谱做菜：食材是输入，步骤是算法，成品是输出。
>
> 为什么算法重要？因为**好算法 + 慢机器 胜过 坏算法 + 快机器**。CLRS 给了一个经典例子：快机器（每秒100亿条指令）跑插入排序排1000万个数要5.5小时，而慢机器（每秒1000万条指令）跑归并排序只要20分钟——差了17倍！

## 📖 核心概念

### 算法的定义

**算法**是解决特定问题的步骤序列，具有明确的输入、输出和有限的执行时间。算法是程序的灵魂，数据结构是算法的载体。

### 算法的五要素

1. **输入**：零个或多个外部输入
2. **输出**：至少一个输出结果
3. **确定性**：每一步精确定义，无歧义
4. **可行性**：每一步都能在有限时间内完成
5. **有穷性**：算法必须在有限步骤内终止

### 算法的其他特性

- **正确性**：对合法输入产生正确输出
- **退化与鲁棒性**：处理边界/非法输入的能力
- **重用性**：算法应具有通用性，可解决一类问题

### 算法 vs 程序

- **算法**：解决问题的有限步骤序列，是思想
- **程序**：算法的编程语言实现
- **关系**：一个算法可有多种程序实现；分析应关注算法本身

### 算法作为技术

- **效率差异巨大**：同一问题的不同算法，其效率差异远大于硬件或软件带来的差异
- **插入排序** Θ(n²) vs **归并排序** Θ(n lg n)：当 n 足够大时，增长率的差异压倒一切
- 算法与硬件、GUI、网络等一样，是核心技术之一

### 基准测试的局限性

- **依赖因素**：硬件配置、操作系统、语言版本、后台进程
- **问题**：同一算法在不同环境下表现不同
- **结论**：需要平台无关的数学分析方法（T(n) 函数和大O记法）

### T(n) 函数

- **定义**：算法执行的基本操作数量，表示为问题规模 n 的函数
- **示例**：遍历 n 个元素的列表：T(n) = n；嵌套循环遍历：T(n) = n²
- **化简**：关注增长趋势，忽略常数和低次项，进一步用大O记法简化

## 关键要点

1. **算法无处不在**：基因组测序、互联网路由、电子商务加密、资源分配、搜索引擎等
2. **数据结构**与算法相辅相成——存储和组织数据的方式直接影响算法效率
3. **NP 完全问题**：至今未找到高效算法，但也没证明不存在
4. **算法是思想，程序是实现**：分析应关注算法本身
5. **T(n)是桥梁**：连接问题规模与执行时间

## 📝 各书讲解特点

### 邓俊辉版（C++）
- **侧重点**：从实际问题出发引入算法概念
- **特色**：用欧几里得算法（辗转相除法）作为经典示例，强调算法的正确性证明和退化处理
- **适合**：建立算法思维的入门

### Miller版（Python）
- **侧重点**：从基准测试的局限性出发引入数学分析方法
- **特色**：用 Python 代码演示基准测试的不确定性，强调 T(n) 函数作为分析桥梁
- **适合**：从实践角度理解为什么需要算法分析

### CLRS版（算法导论）
- **侧重点**：最全面的算法概述，涵盖算法在各领域的应用
- **特色**：用插入排序 vs 归并排序的效率对比震撼读者，提出"算法作为技术"的观点
- **适合**：宏观理解算法的重要性和应用范围

## 代码示例

```cpp
// 欧几里得算法求最大公约数（邓俊辉版示例）
int gcd(int a, int b) {
    return (b == 0) ? a : gcd(b, a % b);
}
```

```python
# 基准测试示例（展示平台依赖性）
import time

def test_algorithm(func, n):
    start = time.time()
    func(n)
    end = time.time()
    return end - start

def linear_algorithm(n):
    total = 0
    for i in range(n):
        total += i
    return total

# T(n) = n，随n线性增长
times = [test_algorithm(linear_algorithm, n) for n in [1000, 2000, 4000]]
```
