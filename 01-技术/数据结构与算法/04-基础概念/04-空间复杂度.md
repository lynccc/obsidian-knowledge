# 空间复杂度

## 🗣️ 通俗讲解

> 空间复杂度就是算法需要多少"额外的内存"。就像你做菜，食材本身不算，但你需要锅碗瓢盆这些工具——空间复杂度算的就是这些"工具"需要多少。有的算法很省空间（原地排序），有的算法很费空间（需要很多临时数组）。

## 📖 核心概念

**空间复杂度**是算法执行所需额外存储空间的度量，同样使用渐进记号表示。与[[02-时间复杂度]]类似，关注的是随输入规模 n 增长的空间开销趋势。

### 基本概念

- **空间复杂度 S(n)**：额外辅助空间与输入规模 n 的关系
- 输入数据本身占用的空间不计入（那是问题本身的需求）
- 关注的是**辅助空间**（算法运行时额外分配的空间）

### 常见空间复杂度

| 复杂度 | 含义 | 示例 |
|--------|------|------|
| O(1) | 原地操作，常数辅助空间 | 原地交换、[[01-冒泡排序]] |
| O(log n) | 递归栈深度 | 二分递归 |
| O(n) | 线性辅助空间 | 归并排序、哈希表 |
| O(n²) | 平方辅助空间 | 邻接矩阵 |

### 时空权衡

算法设计中常面临**时间-空间权衡**：
- 用更多空间换取更快时间（如[[03-动态规划]]的制表）
- 用更多时间节省空间（如多次遍历代替哈希）

## 关键要点

1. 空间复杂度与时间复杂度一样，使用渐进记号简化
2. 递归算法的空间复杂度要考虑调用栈的深度
3. 原地算法（in-place）的空间复杂度为 O(1)
4. 很多时候可以用空间换时间，或用时间换空间

## 📝 各书讲解特点

### 邓俊辉版（C++）
- **侧重点**：详细讲解空间复杂度的分析方法
- **特色**：强调递归栈深度对空间复杂度的影响，分析了不同排序算法的空间开销
- **适合**：深入理解空间分析

### Miller版（Python）
- **侧重点**：在算法分析中一并提及空间复杂度
- **特色**：用 Python 的内存管理特点来解释空间开销
- **适合**：了解 Python 环境下的空间考量

### CLRS版（算法导论）
- **侧重点**：在具体算法分析中讨论空间复杂度
- **特色**：强调原地算法的概念，分析了不同数据结构的空间需求
- **适合**：学术研究
