# NP完全性

## 🗣️ 通俗讲解

> 在算法世界里，有些问题很容易（比如排序），有些问题看起来很难（比如旅行商问题）。但"难"到底有多难？
>
> - **P** = 能快速求解的问题（多项式时间）
> - **NP** = 能快速验证答案的问题
> - **NP完全** = NP 中最难的一类问题
>
> 关键问题是：**P = NP 吗？** 即，所有能快速验证答案的问题，是否都能快速求解？大多数科学家认为 P ≠ NP，但这至今未被证明。
>
> 打个比方：考试时，做一道数学题可能很难，但验证一个答案是否正确通常很容易。P = NP 意味着"做题和验题一样容易"——这看起来不太可能，但我们无法证明。

## 📖 核心概念

### 三个复杂性类

#### P 类（Polynomial Time）
- **定义**：能在多项式时间内**求解**的判定问题集合
- **例子**：排序、最短路径、最大流、二分图匹配
- **直觉**：这些问题是"易解的"

#### NP 类（Nondeterministic Polynomial Time）
- **定义**：能在多项式时间内**验证**一个解是否正确的判定问题集合
- **关键概念**——**证书（Certificate）**：对于 NP 问题，如果给你一个"候选答案"，你能在多项式时间内验证它是否正确
- **P ⊆ NP**：如果一个问题能快速求解，当然也能快速验证

#### NP 完全类（NPC, NP-Complete）
- **定义**：一个问题 L 是 NP 完全的，如果：
  1. L ∈ NP
  2. NP 中的每个问题都可以**多项式时间归约**到 L
- **关键性质**：如果任何一个 NPC 问题有多项式时间算法，则所有 NP 问题都有（即 P = NP）

### 多项式时间归约

问题 A 可以多项式时间归约到问题 B（写作 A ≤_P B），如果存在一个多项式时间函数 f，把 A 的任何实例转换为 B 的一个实例，且答案一致。

### 经典 NP 完全问题

```
电路可满足性 → 3-SAT → 团问题 → 顶点覆盖 → 哈密顿回路 → TSP
                                                          ↓
                              3-SAT → 子集和 ──────────────┘
```

| 问题 | 描述 |
|------|------|
| 电路可满足性 | 给定布尔电路，是否存在输入使输出为 1？ |
| 3-SAT | 给定 3-CNF 布尔公式，是否存在满足赋值？ |
| 团问题 | 给定图 G 和整数 k，是否存在 k 个顶点两两相连？ |
| 顶点覆盖 | 给定图 G 和整数 k，是否存在 k 个顶点覆盖所有边？ |
| 哈密顿回路 | 给定图 G，是否存在经过每个顶点恰好一次的回路？ |
| 旅行商问题 | 给定完全图和边权，是否存在总权重 ≤ k 的哈密顿回路？ |
| 子集和 | 给定整数集合 S 和目标值 t，是否存在子集的和恰好为 t？ |

### NP 完全问题的应对策略

1. **近似算法**：接受不精确但快速的解
2. **启发式算法**：实际中表现好的非精确算法
3. **参数化算法**：对问题的某个参数是指数级，但对输入大小是多项式
4. **特殊情况**：限制输入结构，使问题变得易解
5. **随机化算法**：用随机性换取效率

## 关键要点

1. **P vs NP 的核心含义**：求解和验证的难度是否对等？
2. **NP 完全的意义**：如果找到任何一个 NPC 问题的多项式算法，P = NP
3. **归约是证明的核心**：通过归约链，一个 NPC 问题的硬度"传递"给所有后续问题
4. **实际影响**：证明一个问题是 NP 完全的，就不要浪费时间找精确的多项式算法了
5. **2-SAT vs 3-SAT**：从 2 到 3，问题从 P 跳到 NPC，这是复杂性的"相变"
