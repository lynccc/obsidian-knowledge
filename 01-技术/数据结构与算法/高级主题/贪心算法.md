# 贪心算法

## 🗣️ 通俗讲解

> 贪心算法就像"走一步看一步"——每一步都选当前看起来最好的选择，不回头，不后悔。如果问题满足贪心选择性质和最优子结构，就能得到全局最优解。
>
> 大白话：贪心是"一条路走到黑"，DP 是"把所有路都试一遍"。贪心快但不一定对，DP 慢但保证对。

## 📖 核心概念

**贪心算法**在每一步都选"眼前最好"的，不回头，不后悔。如果问题满足贪心选择性质和最优子结构，就能得到全局最优解。

### 贪心策略的两大要素

#### 1. 贪心选择性质

可以通过**局部最优选择**（不考虑子问题的解）构造出**全局最优解**。

- DP：先解子问题，再做选择（自底向上）
- 贪心：先做选择，再解剩下的子问题（自顶向下）

#### 2. 最优子结构

问题的最优解包含其子问题的最优解。这个性质 DP 和贪心都要求。

### 贪心算法设计步骤

1. 将问题转化为：做一个选择，剩下一个子问题
2. 证明存在一个最优解包含贪心选择（贪心选择性质）
3. 证明贪心选择 + 子问题最优解 = 原问题最优解（最优子结构）

### 经典贪心问题

#### 活动选择问题

有 n 个活动，每个有开始时间和结束时间，同一时间只能进行一个活动。求最多能选多少个兼容活动。

**贪心策略**：总是选最早结束的活动，然后排除与之冲突的，重复此过程。

时间复杂度：O(n log n)（排序）或 O(n)（已排序）

#### 赫夫曼编码

用变长编码：高频字符用短编码，低频字符用长编码。用**二叉树**表示编码。

**贪心策略**：每次合并频率最小的两棵树。

时间复杂度：O(n log n)

#### 分数背包问题

背包容量 W，n 个物品各有重量和价值，可以拿物品的一部分。求最大价值。

**贪心策略**：按价值密度（价值/重量）排序，优先拿密度高的。

### 贪心不适用的情况

**0-1 背包问题**：贪心（按价值密度排序）不能得到最优解！需要 DP。

| 特性 | 贪心 | 动态规划 |
|------|------|----------|
| 选择 | 只看一个（贪心选择） | 考虑所有可能 |
| 子问题数 | 1 个 | 多个重叠子问题 |
| 求解顺序 | 自顶向下 | 自底向上 / 备忘录 |
| 效率 | 通常更快 | 可能较慢 |
| 正确性 | 需要证明 | 通常更可靠 |

## 关键要点

1. 贪心算法的核心是**证明贪心选择性质**——为什么局部最优能导致全局最优
2. **剪切-粘贴**（exchange argument）是证明贪心正确性的常用技巧
3. 贪心是 DP 的特例——只考虑一个选择而不是所有选择
4. 贪心不保证总是正确，需要严格证明
