# 动态规划

## 🗣️ 通俗讲解

> 核心思想就是「记住已经算过的答案」。就像做数学题时把中间步骤写在草稿纸上，下次遇到同样的子问题直接抄答案，不用重新算。斐波那契数列是最经典的例子：朴素递归慢得要死（指数级），加个缓存就变线性了。

## 📖 核心概念

**动态规划**（Dynamic Programming, DP）是优化递归问题的技术，核心思想是**避免重复计算**。当递归函数多次计算相同的子问题时，使用缓存（记忆化）存储已计算的结果。

### DP 的两大条件

1. **最优子结构**：问题的最优解包含其子问题的最优解
2. **重叠子问题**：递归过程中多次计算相同的子问题

### 两种实现方式

#### 记忆化（Memoization，自顶向下）

用数组/哈希表记录已计算的值，递归时先查表，命中直接返回。

```python
def fib_memo(n, memo=None):
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    if n == 0: return 0
    if n == 1: return 1
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]
```

#### 迭代 DP（自底向上）

从小问题开始迭代求解，填表构建完整解。

```python
def fib_dp(n):
    if n == 0: return 0
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

### 备忘录 vs 自底向上

| 特性 | 自顶向下 + 备忘录 | 自底向上 |
|------|-------------------|----------|
| 思路 | 递归 + 缓存 | 迭代，从小到大 |
| 子问题 | 只算需要的子问题 | 算所有子问题 |
| 常数因子 | 递归调用开销大 | 循环开销小 |
| 适用场景 | 子问题空间稀疏时更优 | 子问题空间密集时更优 |

### 经典 DP 问题

#### 钢条切割

给定一根长度为 n 的钢条和价格表，求切割方案使总收入最大。

$$r_n = \max_{1 \le i \le n}(p_i + r_{n-i})$$

#### 矩阵链乘法

给定 n 个矩阵，求加括号方式使标量乘法次数最少。

$$m[i,j] = \min_{i \le k < j} \{m[i,k] + m[k+1,j] + p_{i-1} p_k p_j\}$$

时间复杂度：O(n³)

#### 最长公共子序列（LCS）

给定序列 X 和 Y，求它们的最长公共子序列。

$$c[i,j] = \begin{cases} c[i-1,j-1] + 1 & \text{if } x_i = y_j \\ \max(c[i-1,j], c[i,j-1]) & \text{if } x_i \ne y_j \end{cases}$$

时间复杂度：O(mn)

#### 0/1 背包问题

给定背包容量 W 和 n 个物品，求最大价值。

```python
def knapsack(weights, values, W):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(W + 1):
            dp[i][w] = dp[i - 1][w]
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i][w],
                    dp[i - 1][w - weights[i - 1]] + values[i - 1])
    return dp[n][W]
```

时间复杂度：O(nW)

### DP 的四步法

| 步骤 | 说明 |
|------|------|
| 1. 刻画最优解的结构 | 找出最优解包含哪些子问题的最优解 |
| 2. 递归定义最优解的值 | 写出递推公式（状态转移方程） |
| 3. 自底向上计算最优解的值 | 按子问题规模从小到大求解 |
| 4. 构造最优解（可选） | 利用保存的中间结果回溯 |

## 关键要点

1. **时空权衡**：记忆化用 O(n) 空间换取 O(n) 时间，可进一步优化到 O(1) 空间
2. **子问题图**：自底向上 = 按逆拓扑序遍历，备忘录 = DFS
3. **DP vs 贪心 vs 分治**：DP 考虑所有选择，贪心只考虑一个选择，分治子问题不重叠
