# 最短路径

## 🗣️ 通俗讲解

> 最短路径问题就是"导航"——从 A 地到 B 地，哪条路最近？Dijkstra 就像手机地图导航，从你的位置出发，每次选「目前最近的」未探索路口，更新它邻居的距离。但如果有「负数距离」的路（不现实），Dijkstra 就不灵了，得用 Bellman-Ford。

## 📖 核心概念

**最短路径问题**：在带权有向图中，找到从源点 s 到其他各顶点的最短路径。

### 松弛技术（Relaxation）

所有最短路径算法的核心操作：

```
INITIALIZE-SINGLE-SOURCE(G, s):
    for each vertex v ∈ V
        v.d = ∞
        v.π = NIL
    s.d = 0

RELAX(u, v, w):
    if v.d > u.d + w(u,v)
        v.d = u.d + w(u,v)
        v.π = u
```

### Dijkstra 算法

解决**非负权**图的单源最短路径问题。贪心策略：每步选择距源点最近的未确定顶点，确定其最短距离。

```python
import heapq

def dijkstra(graph, start):
    distances = {v: float('inf') for v in graph}
    distances[start] = 0
    predecessors = {v: None for v in graph}
    pq = [(0, start)]
    visited = set()

    while pq:
        curr_dist, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)

        for v, weight in graph[u].get_connections_with_weights():
            if v not in visited:
                new_dist = curr_dist + weight
                if new_dist < distances[v]:
                    distances[v] = new_dist
                    predecessors[v] = u
                    heapq.heappush(pq, (new_dist, v))

    return distances, predecessors
```

| 实现方式 | 时间复杂度 |
|---------|-----------|
| 朴素（数组） | O(n²) |
| 优先队列（二叉堆） | O((n+E) log n) |
| 斐波那契堆 | O(V log V + E) |

### Bellman-Ford 算法

解决**含负权边**的单源最短路径问题，还能检测负权环。

对所有边进行 |V|-1 轮松弛。如果一轮松弛后仍有改进，说明存在负权环。

```
BELLMAN-FORD(G, w, s):
    INITIALIZE-SINGLE-SOURCE(G, s)
    for i = 1 to |V|-1
        for each edge (u,v) ∈ E
            RELAX(u, v, w)
    for each edge (u,v) ∈ E
        if v.d > u.d + w(u,v)
            return FALSE  // 存在负权环
    return TRUE
```

时间复杂度：**O(VE)**

### DAG 最短路径

对 DAG 按**拓扑排序**的顺序松弛边，只需一轮即可。

时间复杂度：**Θ(V + E)**

### Floyd-Warshall 算法

解决**全源最短路径**问题：任意两点间的最短路径。

```
FLOYD-WARSHALL(W, n):
    D = W
    for k = 1 to n
        for i = 1 to n
            for j = 1 to n
                D[i][j] = min(D[i][j], D[i][k] + D[k][j])
    return D
```

时间复杂度：**O(V³)**

## 四种算法对比

| 算法 | 时间复杂度 | 负权边 | 负权环检测 | 适用场景 |
|------|-----------|--------|-----------|----------|
| Bellman-Ford | O(VE) | ✅ | ✅ | 通用，负权边 |
| DAG 最短路径 | O(V+E) | ✅ | N/A | DAG |
| Dijkstra（二叉堆） | O(E log V) | ❌ | ❌ | 非负权，稀疏图 |
| Floyd-Warshall | O(V³) | ✅ | ✅ | 全源最短路径 |

## 与 Prim 的对比

| 维度 | Dijkstra | Prim |
|------|----------|------|
| 目标 | 最短路径树 | 最小生成树 |
| dist 含义 | 到源点的最短距离 | 到已选集的最小边权 |
| 松弛条件 | dist[u]+w < dist[v] | w(u,v) < dist[v] |
| 适用 | 非负权有向图 | 无向连通图 |

两者代码结构几乎一致，仅松弛判断不同。
