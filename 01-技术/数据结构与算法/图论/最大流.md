# 最大流

## 🗣️ 通俗讲解

> 最大流问题：想象一个水管网络，水源 s 不断供水，水汇 t 不断排水，每根水管有最大流量限制。问：从 s 到 t 最大能输送多少水？Ford-Fulkerson 方法通过不断寻找增广路径来增加流量，直到无法再增加为止。最大流最小割定理告诉我们：最大流等于最小割的容量。

## 📖 核心概念

### 流网络（Flow Network）

**流网络** G = (V, E) 是有向图，满足：
- 每条边 (u,v) 有非负**容量** c(u,v) ≥ 0
- 有两个特殊顶点：**源点** s 和**汇点** t

### 流的定义

**流** f: V×V → R 满足：
1. **容量约束**：0 ≤ f(u,v) ≤ c(u,v)
2. **流守恒**：对于所有 u ∈ V-{s,t}，Σ f(v,u) = Σ f(u,v)

### 残存网络（Residual Network）

给定流网络 G 和流 f，**残存网络** G_f 包含可能改变流的边：
- **正向边**：还可以增加的流量
- **反向边**：可以"撤销"的流量（流的取消/Cancellation）

### 增广路径（Augmenting Path）

**增广路径** p 是残存网络 G_f 中从 s 到 t 的简单路径。沿增广路径增广流，新流的值增加 c_f(p)。

### 最大流最小割定理

以下三个条件等价：
1. f 是最大流
2. 残存网络 G_f 中不存在增广路径
3. 存在切割 (S,T) 使得 |f| = c(S,T)

**核心结论**：**最大流 = 最小割**

## Ford-Fulkerson 方法

反复寻找增广路径并增广，直到不存在增广路径。

```
FORD-FULKERSON(G, s, t):
    for each edge (u,v) ∈ E
        (u,v).f = 0
    while 存在从 s 到 t 的增广路径 p
        c_f(p) = min{ c_f(u,v) : (u,v) 在路径 p 上 }
        for each edge (u,v) in p
            if (u,v) ∈ E
                (u,v).f = (u,v).f + c_f(p)
            else (v,u).f = (v,u).f - c_f(p)
    return f
```

时间复杂度：O(E · |f*|)，其中 |f*| 是最大流值。

## Edmonds-Karp 算法

用 **BFS** 寻找增广路径（最短增广路径）。

时间复杂度：**O(VE²)**

## 最大二分匹配

**匹配** M ⊆ E 是边的子集，使得每个顶点最多有一条匹配边。

**转化为最大流**：给定二分图 G = (L ∪ R, E)：
1. 添加源点 s，连向 L 中所有顶点，容量 1
2. 添加汇点 t，R 中所有顶点连向 t，容量 1
3. L 到 R 的边容量设为 1

最大匹配的基数 = 对应流网络的最大流值。

## 关键要点

1. **最大流最小割定理**是流网络理论的核心
2. **增广路径方法**简单但可能很慢（依赖容量值）
3. **Edmonds-Karp** 用 BFS 保证多项式时间 O(VE²)
4. **流的取消**是残存网络反向边的关键作用
5. **二分匹配**可转化为最大流问题
