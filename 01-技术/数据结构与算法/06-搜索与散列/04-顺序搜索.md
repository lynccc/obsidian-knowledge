# 顺序搜索

## 🗣️ 通俗讲解
> 最简单的搜索方法：从头到尾一个个找，找到就停。就像在书架上一本本翻书名。效率不高（O(n)），但对小列表够用，而且对列表结构无要求——有序无序都行。

## 📖 核心概念

顺序搜索从列表第一个元素开始，逐个比较，直到找到目标或遍历完整个列表。

### 无序列表

```python
def sequential_search(a_list, item):
    pos = 0
    found = False
    while pos < len(a_list) and not found:
        if a_list[pos] == item:
            found = True
        else:
            pos += 1
    return found
```

### 有序列表优化

当列表已排序时，发现当前元素大于目标可提前终止。时间仍为 O(n)，但平均情况更好。

### 复杂度

| 情况 | 复杂度 |
|------|--------|
| 最好 | O(1) |
| 平均 | O(n) |
| 最坏 | O(n) |
