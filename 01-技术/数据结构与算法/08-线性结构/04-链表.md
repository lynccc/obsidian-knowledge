# 链表

## 🗣️ 通俗讲解

> 想象一条铁链——每个环节（节点）都「钩住」下一个环节。要找第10个环节，必须从头一个一个往后摸，不能直接跳过去。好处是中间断开插入新环节很方便，不用像数组那样把后面所有元素挪开。
>
> 双向链表就像两边都能钩的环节，既能往前摸也能往后摸。

## 📖 核心概念

### 单链表（Singly Linked List）

每个节点包含数据域和指向下一个节点的指针：

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None
```

### 双向链表（Doubly Linked List）

每个节点同时持有前驱 `pred` 和后继 `succ` 指针，支持双向遍历：

```cpp
template <typename T> struct ListNode {
    T data;                // 数据域
    ListNode<T>* pred;     // 前驱指针
    ListNode<T>* succ;     // 后继指针
};
```

### 向量 vs 链表

| 维度 | 向量 | 链表 |
|------|------|------|
| 存储方式 | 连续空间 | 离散节点 + 指针链接 |
| 访问方式 | 循秩访问（O(1)） | 循位置访问（O(n)） |
| 插入/删除 | O(n)（需移位） | O(1)（修改指针） |
| 空间 | 紧凑，可能浪费 | 每节点额外指针开销 |

### 哨兵节点（Sentinel Node）

哨兵节点是不存储实际数据的**辅助节点**，用于简化链表的边界条件处理：

```
header ⇄ A ⇄ B ⇄ C ⇄ trailer
(空)                         (空)
```

**作用**：
- 统一空表与非空表的处理
- 消除边界特判（头部插入、尾部插入、删除首节点）
- 空间代价：仅 O(1) 额外存储，但显著降低代码复杂度

### 链表操作

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `add(item)` | 头插法添加元素 | O(1) |
| `remove(item)` | 移除指定元素 | O(n) |
| `search(item)` | 查找元素是否存在 | O(n) |
| `insert(pos, item)` | 在指定位置插入 | O(n) |
| `pop(pos)` | 移除并返回指定位置元素 | O(n) |

## 关键要点

1. 链表提供**动态性**：不需要预分配空间，插入删除高效
2. 哨兵节点简化代码，但增加空间开销，需要权衡
3. 哨兵适用场景：链表操作频繁、链表数量少、每个链表元素较多
4. 链表是实现栈和队列的另一种方式（避免 `insert(0)` 的 O(n) 代价）
5. 哈希表的冲突处理（链地址法）使用链表

## 代码示例

```python
class UnorderedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head is None

    def add(self, item):
        temp = Node(item)
        temp.setNext(self.head)
        self.head = temp

    def size(self):
        current = self.head
        count = 0
        while current is not None:
            count += 1
            current = current.getNext()
        return count

    def search(self, item):
        current = self.head
        while current is not None:
            if current.getData() == item:
                return True
            current = current.getNext()
        return False

    def remove(self, item):
        current = self.head
        previous = None
        while current is not None:
            if current.getData() == item:
                if previous is None:
                    self.head = current.getNext()
                else:
                    previous.setNext(current.getNext())
                return
            previous = current
            current = current.getNext()
```
