# 向量与数组

## 🗣️ 通俗讲解

> 数组就像一排连续的储物柜——每个柜子有编号（下标），你可以直接走到第10个柜子拿东西（O(1) 随机访问）。但如果要在中间插入一个新柜子，后面所有柜子都得往后挪一位（O(n)）。向量就是"会自动长大的数组"——空间不够时自动扩容。

## 📖 核心概念

### 数组（Array）

数组是 C++ 内置的底层数据结构，具有以下特性：
- **连续内存**：元素在内存中紧密排列
- **固定大小**：编译时确定，运行时不可改变
- **下标访问**：通过下标直接定位元素，O(1) 时间

### 向量（Vector）

**向量**是数组的抽象与封装，是线性结构最基本的实现形式。它将一组元素按线性次序存储，支持通过**秩（rank）** 直接访问任意元素。

向量 = 数组 + 动态空间管理 + 操作接口

### 循秩访问（Rank-based Access）

向量中每个元素都有唯一确定的秩（即其相对于向量起始位置的偏移量），通过秩可以在 O(1) 时间内定位元素。秩是从 0 开始的整数，元素 e 的秩等于其前驱元素的个数。

### 向量的 ADT 接口

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `size()` | 返回元素个数 | O(1) |
| `get(r)` | 获取秩为 r 的元素 | O(1) |
| `put(r, e)` | 将秩为 r 的元素替换为 e | O(1) |
| `insert(r, e)` | 在秩 r 处插入元素 e | O(n) |
| `remove(r)` | 删除秩为 r 的元素 | O(n) |
| `find(e)` | 查找元素 e | O(n) |
| `sort()` | 排序 | O(n log n) |

### 动态空间管理

当向量空间不足时，需要扩容：
- 分配更大的新数组
- 将旧数据复制到新数组
- 释放旧数组
- 通常按倍数扩容（如 2 倍），均摊 O(1)

### Python 列表（动态数组）

Python 的 `list` 底层也是动态数组：
- 支持随机访问 O(1)
- 尾部 append 均摊 O(1)
- 中间插入/删除 O(n)

```python
# Python 列表操作
lst = [1, 2, 3]
lst.append(4)      # O(1) 均摊
lst.insert(0, 0)   # O(n)
lst[2]             # O(1) 随机访问
```

## 关键要点

1. 向量支持**随机访问**（区别于链表的关键特性）
2. 插入/删除操作需要移动元素，时间复杂度 O(n)
3. 动态扩容的均摊复杂度为 O(1)
4. Python 的 `list` 就是向量的实现
5. C++ 的 `std::vector` 是向量的标准实现
