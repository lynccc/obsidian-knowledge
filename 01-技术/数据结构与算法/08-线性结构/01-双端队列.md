# 双端队列

## 🗣️ 通俗讲解

> 双端队列就像一个两头都能进出的排队通道——你可以从前面加人，也可以从后面加人；可以从前面走，也可以从后面走。它是栈和队列的"综合体"。

## 📖 核心概念

**双端队列**（Double-Ended Queue, Deque）是允许在**两端**进行插入和删除的线性数据结构，不遵循严格的 FIFO 或 LIFO，可作为栈或队列使用。

### ADT 接口

| 操作 | 说明 |
|------|------|
| `addFront(item)` | 在前端添加元素 |
| `addRear(item)` | 在后端添加元素 |
| `removeFront()` | 移除并返回前端元素 |
| `removeRear()` | 移除并返回后端元素 |
| `isEmpty()` | 判断是否为空 |
| `size()` | 返回元素个数 |

### 实现方式

**Python list 实现**：
- `append` 加尾、`insert(0, item)` 加头
- `pop()` 删尾、`pop(0)` 删头
- 注意：`pop(0)` 和 `insert(0)` 是 O(n)

**collections.deque 实现**：
- 底层是双向链表
- 两端操作均为 O(1)
- 推荐用于需要高效双端操作的场景

```python
from collections import deque

dq = deque()
dq.append(1)        # 右端添加
dq.appendleft(0)    # 左端添加
dq.pop()             # 右端删除
dq.popleft()         # 左端删除
```

## 关键要点

1. 双端队列是栈和队列的**泛化**：只用一端就是栈，一端入一端出就是队列
2. Python `collections.deque` 是高效的 C 实现，底层是双向链表，两端操作均为 O(1)
3. 滑动窗口最大值等算法问题中常用双端队列

## 典型应用

- **回文检测器**：将字符串逐字符从前端和后端同时添加到双端队列，然后不断从两端移除并比较
- **滑动窗口最大值**：用双端队列维护窗口内的最大值
- **工作窃取算法**：多线程调度中的任务分配

## 代码示例

```python
class Deque:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def addFront(self, item):
        self.items.append(item)

    def addRear(self, item):
        self.items.insert(0, item)

    def removeFront(self):
        return self.items.pop()

    def removeRear(self):
        return self.items.pop(0)

    def size(self):
        return len(self.items)

# 回文检测
def palchecker(aStr):
    chardeque = Deque()
    for ch in aStr:
        chardeque.addRear(ch)
    stillEqual = True
    while chardeque.size() > 1 and stillEqual:
        front = chardeque.removeFront()
        rear = chardeque.removeRear()
        if front != rear:
            stillEqual = False
    return stillEqual
```
