# 二叉搜索树

## 🗣️ 通俗讲解

> 想象一个猜数字游戏：根节点是「标准答案」，比它小的放左边，比它大的放右边。这样找数字就像二分查找一样快。但如果数据本身是排好序的，树就会退化成一条链，查找变慢——所以后来有了 AVL 树来「扶正」。

## 📖 核心概念

**二叉搜索树**（Binary Search Tree, BST）是一种满足**顺序性**的[[05-二叉树]]：对于任意节点，其左子树中所有节点的关键码均**不大于**该节点，右子树中所有节点的关键码均**不小于**该节点。

### BST 性质

- **顺序性**：`左子树 ≤ 根 ≤ 右子树`（递归成立）
- **中序遍历有序**：对 BST 做中序遍历，得到严格递增序列，这是 BST 最核心的性质
- BST 是[[01-二分搜索]]的树形实现

### 核心操作

#### 查找算法

从根节点开始，逐层比较：
- 目标 = 当前节点 → 找到
- 目标 < 当前节点 → 进入左子树
- 目标 > 当前节点 → 进入右子树
- 到达空节点 → 不存在

时间复杂度：**O(h)**，h 为树高。

```python
def _get(self, key, current_node):
    if current_node is None:
        return None
    if current_node.key == key:
        return current_node
    elif key < current_node.key:
        return self._get(key, current_node.left_child)
    else:
        return self._get(key, current_node.right_child)
```

#### 插入算法

1. 执行查找操作，找到应插入的空位
2. 在该位置创建新节点
3. 无需调整其他节点，天然保持 BST 性质

#### 删除算法

情况较复杂，需分三类处理：
1. **叶子节点**：直接删除
2. **仅有左/右子树**：用子树替换该节点
3. **左右子树均存在**：找到**中序遍历的直接后继**（右子树最左节点），替换并删除后继

### 性能分析

| 操作 | 平均（随机插入） | 最坏（退化成链） |
|------|----------------|-----------------|
| 搜索 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |
| 最小/最大 | O(log n) | O(n) |
| 前驱/后继 | O(log n) | O(n) |

**关键问题**：最坏情况下 BST 退化为链表，性能变差。

**解决方案**：
- **随机 BST**：随机插入时，期望树高为 O(log n)
- **平衡 BST**：[[07-红黑树]]、[[01-AVL树]] 等保证树高为 O(log n)

## 关键要点

1. **BST 性质**：左 ≤ 根 ≤ 右，中序遍历产生有序序列
2. **所有操作都是 O(h)**：性能取决于树高
3. **插入在叶子，删除分三种情况**：有两个孩子的删除最复杂
4. **随机 BST 期望平衡**：但无法保证最坏情况
5. **需要平衡机制**：红黑树通过旋转和着色保证 O(log n)

## BST vs 其他数据结构

| 特性 | BST | 散列表 | 有序数组 |
|------|-----|--------|---------|
| 搜索 | O(h) | O(1) 期望 | O(log n) |
| 插入 | O(h) | O(1) 期望 | O(n) |
| 删除 | O(h) | O(1) 期望 | O(n) |
| 有序遍历 | O(n) | 不支持 | O(n) |
| 范围查询 | O(h + k) | 不支持 | O(log n + k) |
