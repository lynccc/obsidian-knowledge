# 二叉树

## 🗣️ 通俗讲解

> 二叉树就像一棵倒过来的树——树根在上面，树枝向下分叉。每个节点最多有两个孩子（左孩子和右孩子），就像每个父母最多有两个孩子。
>
> 遍历二叉树就像在树上"逛街"——先序遍历是"先看店再左转右转"，中序遍历是"先左转再看店再右转"，后序遍历是"先左转右转再看店"，层次遍历是"一层一层逛"。

## 📖 核心概念

**二叉树**是每个节点至多有两棵子树（左/右）且子树有**有序**之分的树结构。

### 基本术语

| 术语 | 定义 |
|------|------|
| 度 (degree) | 节点的子树数目，二叉树中 ≤ 2 |
| 深度 (depth) | 从根到该节点的边数 |
| 高度 (height) | 从该节点到最深叶节点的边数 |
| 满二叉树 | 每个内部节点度数恰好为 2 |
| 完全二叉树 | 除最后一层外，其余层均满，且最后一层靠左 |

### 二叉树的性质

- 二叉树是**有序树**，左右子树不可交换
- 完全二叉树可用**向量**紧凑存储：节点 `i` 的左孩子为 `2i+1`，右孩子为 `2i+2`
- `n` 个节点的二叉树有 `n+1` 个空链域（外部节点/叶子）

### Python 实现

**列表之列表**：用嵌套列表表示树，`[root, left, right]`

```python
def BinaryTree(r):
    return [r, [], []]
```

**节点与引用**：用类和对象引用表示树

```python
class BinaryTree:
    def __init__(self, root_obj):
        self.key = root_obj
        self.left_child = None
        self.right_child = None
```

## 二叉树遍历

**遍历**是按照某种规则系统化地访问二叉树中每个节点恰好一次。

| 方式 | 顺序 | 递归定义 | 典型应用 |
|------|------|----------|----------|
| **先序** (preorder) | V → L → R | 先访问根，再左子树，最后右子树 | 复制树、前缀表达式 |
| **中序** (inorder) | L → V → R | 先左子树，再访问根，最后右子树 | BST 有序输出 |
| **后序** (postorder) | L → R → V | 先左子树，再右子树，最后访问根 | 释放树、后缀表达式 |
| **层次** (level-order) | 逐层从左到右 | 借助队列实现 | 层序相关问题 |

### 递归实现

```python
def preorder(tree):
    if tree:
        print(tree.key)
        preorder(tree.left_child)
        preorder(tree.right_child)

def inorder(tree):
    if tree:
        inorder(tree.left_child)
        print(tree.key)
        inorder(tree.right_child)

def postorder(tree):
    if tree:
        postorder(tree.left_child)
        postorder(tree.right_child)
        print(tree.key)
```

### 迭代实现

递归遍历可改写为迭代版，利用栈模拟递归调用栈：
- **迭代先序**：沿左分支下行时立即访问并压栈右孩子
- **迭代中序**：沿左分支一路压栈，弹出时访问，转向右子树
- **迭代后序**：需要额外标记是否从右子树返回

## 关键要点

1. 四种遍历的**时间复杂度**均为 O(n)，n 为节点数
2. 递归实现简洁但有栈溢出风险，迭代版更稳健
3. 中序遍历 BST 可得有序序列
4. 层次遍历必须用队列，不能用栈
