# AVL树

## 🗣️ 通俗讲解

> 普通 BST 可能退化成一条「歪脖子树」，查找变慢。AVL 树的秘诀是：每次插入/删除后，检查每个节点的左右子树高度差，如果差超过 1，就通过「旋转」把树扶正。就像玩积木一样，把偏重的一边转一下，保持整体平衡。

## 📖 核心概念

AVL树是最早被发明的**平衡二叉搜索树**，由 Adelson-Velsky 和 Landis 于 1962 年提出。其核心约束：**任意节点的平衡因子绝对值不超过 1**，即 `|bf(v)| ≤ 1`。这一简单约束保证了树高为 O(log n)。

### 定义与性质

- **AVL 条件**：对每个节点 v，`bf(v) ∈ {-1, 0, 1}`
- 含 n 个节点的 AVL 树高度 h ≤ 1.44 log₂(n+2) ≈ **O(log n)**
- 比理想平衡略差，但维护成本更低

### 平衡因子

```python
def update_balance(self, node):
    if node.balance_factor > 1 or node.balance_factor < -1:
        self.rebalance(node)
        return
    if node.parent is not None:
        if node.is_left_child():
            node.parent.balance_factor += 1
        elif node.is_right_child():
            node.parent.balance_factor -= 1
        if node.parent.balance_factor != 0:
            self.update_balance(node.parent)
```

### 旋转操作

插入新节点后，可能破坏祖先节点的 AVL 条件，需要通过旋转恢复平衡：

| 情况 | 形态 | 旋转方式 |
|------|------|----------|
| LL | 在 g 的左孩子的左子树插入 | 对 g 做**右旋** |
| RR | 在 g 的右孩子的右子树插入 | 对 g 做**左旋** |
| LR | 在 g 的左孩子的右子树插入 | 先对左孩子**左旋**，再对 g **右旋** |
| RL | 在 g 的右孩子的左子树插入 | 先对右孩子**右旋**，再对 g **左旋** |

**左旋示例**：
```
    A             B
     \           / \
      B    →    A   C
       \
        C
```

### 节点插入

1. **失衡检测**：从插入点向上回溯，找到第一个失衡节点 g
2. **失衡原因**：g 的某个孩子的子树因插入而"长高"
3. **重平衡**：通过旋转恢复平衡

> 插入后至多需要 **1 次**单旋或双旋即可恢复全局平衡。

### 节点删除

删除比插入更复杂：
1. 执行标准 BST 删除
2. 从删除点向上回溯，检查每个祖先的平衡因子
3. 失衡时进行旋转修复
4. 旋转后**可能引发上层继续失衡**，需继续向上检查

> 删除后可能需要 **O(log n) 次**旋转（而非插入时的 O(1) 次）。

### 复杂度

| 操作 | 时间复杂度 | 旋转次数 |
|------|-----------|---------|
| 查找 | O(log n) | 0 |
| 插入 | O(log n) | 最多 1 次 |
| 删除 | O(log n) | 最多 O(log n) 次 |
