# 图基础

## 🗣️ 通俗讲解

> 图就像一张"关系网"——点（顶点）代表事物，线（边）代表事物之间的关系。比如社交网络中，每个人是一个点，朋友关系是一条线；地图上，城市是点，道路是线。
>
> 有向图就像单行道（只能从A到B），无向图就像双行道（A和B互通）。

## 📖 核心概念

**图（Graph）** G = (V, E)，由顶点集 V 和边集 E 组成。

### 基本术语

- **顶点（Vertex）**：图中的基本元素，也称节点（node）
- **边（Edge）**：顶点间的连接关系
  - **有向边**：⟨u, v⟩，u 为起点，v 为终点
  - **无向边**：(u, v)，等价于 ⟨u, v⟩ + ⟨v, u⟩
- **权值（Weight）**：边或顶点的附加数值，用于表示代价、距离等

### 有向图与无向图

- **有向图（Digraph）**：所有边均为有向边
- **无向图**：所有边均为无向边，无向边可视为两条方向相反的有向边

### 度

- **度（Degree）**：与顶点关联的边数
- **出度（out-degree）**：以该顶点为起点的有向边数
- **入度（in-degree）**：以该顶点为终点的有向边数
- 定理：有向图中，所有顶点的出度之和 = 入度之和 = 边数 |E|

### 连通性

- **路径（Path）**：顶点序列 v₀, v₁, ..., vₖ，相邻顶点间有边
- **简单路径**：路径中顶点不重复
- **环（Cycle）**：起点和终点相同的路径
- **连通图**：任意两顶点间存在路径
- **连通分量**：无向图中的极大连通子图
- **强连通**：有向图中，任意两顶点 u→v 和 v→u 均有路径

### 图的存储

#### 邻接矩阵（Adjacency Matrix）

用 n×n 的二维数组 M 存储边信息：
- M[i][j] = 1（或权值 w）：顶点 i 到 j 有边
- M[i][j] = 0（或 ∞）：无边

| 特性 | 说明 |
|------|------|
| 空间 | O(n²) |
| 判边存在 | O(1) |
| 枚举出边 | O(n) |
| 适用 | 稠密图 |

#### 邻接表（Adjacency List）

每个顶点维护一个链表/向量，存储其所有出边的终点。

```python
class Vertex:
    def __init__(self, key):
        self.id = key
        self.connected_to = {}  # {neighbor_id: weight}

class Graph:
    def __init__(self):
        self.vert_list = {}
        self.num_vertices = 0
```

| 特性 | 说明 |
|------|------|
| 空间 | O(n + E) |
| 判边存在 | O(deg) |
| 枚举出边 | O(deg) |
| 适用 | 稀疏图 |

### 复杂度对比

| 操作 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(n²) | O(n+E) |
| 判边存在 | O(1) | O(deg) |
| 枚举出边 | O(n) | O(deg) |
| 添加边 | O(1) | O(1) |
| 删除边 | O(1) | O(deg) |

## 关键要点

1. 稠密图用邻接矩阵，稀疏图用邻接表
2. Python 中用 dict of dict 实现邻接表，天然支持任意可哈希的顶点标识符
3. 有向图只 `add_edge` 一次；无向图需调用两次（双向）
4. 图是比树更一般的非线性结构
