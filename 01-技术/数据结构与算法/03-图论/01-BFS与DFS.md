# BFS与DFS

## 🗣️ 通俗讲解

> **BFS** 就像往水里扔一颗石子——波纹从落点一圈一圈向外扩散。先访问所有「距离为 1」的邻居，再访问「距离为 2」的……用队列管理待访问的顶点。
>
> **DFS** 就像走迷宫时"贴右墙"——沿着一条路尽可能深地走，走到死胡同就回退，换一条路继续走。用栈（或递归）管理待访问的顶点。

## 📖 核心概念

### 广度优先搜索（BFS）

BFS 按照"由近及远"的顺序逐层访问顶点——先访问所有距源点为 k 的顶点，再访问距离为 k+1 的顶点。

**算法策略**：
1. 选取起始顶点 s，标记为已发现
2. 将 s 入队
3. 循环：取出队首顶点 v，依次检查其所有邻居 u
   - 若 u 未被发现：标记为已发现，入队
   - 忽略已访问的边
4. v 处理完毕后标记为已访问

**边分类**：
- **树边（Tree Edge）**：指向未发现顶点的边，构成 BFS 树
- **跨边（Cross Edge）**：指向已发现或已访问顶点的边

**典型应用**：
- 无权图中，BFS 树给出从源点到各顶点的**最短路径**（边数最少）
- 层序遍历
- 连通分量检测
- 二分图判定

```python
def bfs(g, start):
    start.set_distance(0)
    start.set_pred(None)
    vert_queue = Queue()
    vert_queue.enqueue(start)
    while not vert_queue.is_empty():
        current_vert = vert_queue.dequeue()
        for nbr in current_vert.get_connections():
            if nbr.getColor() == 'white':
                nbr.setColor('gray')
                nbr.set_distance(current_vert.get_distance() + 1)
                nbr.set_pred(current_vert)
                vert_queue.enqueue(nbr)
        current_vert.setColor('black')
```

### 深度优先搜索（DFS）

DFS 沿着一条路径尽可能深地探索，直到无路可走时回溯。

**算法策略**：
1. 选取起始顶点 s，标记为已发现
2. 从 s 出发，选择一条未探索的边 (s, u)
   - 若 u 未访问：递归访问 u（深入）
   - 若 u 已访问：标记该边为非树边
3. s 的所有边探索完毕后，标记为已访问（回溯）

**边分类（有向图）**：
| 边类型 | 含义 |
|--------|------|
| **树边（Tree）** | 指向未发现顶点，构成 DFS 树 |
| **回边（Backward）** | 指向祖先，说明存在环 |
| **前向边（Forward）** | 指向已访问的后代 |
| **跨边（Cross）** | 指向已访问的非后代 |

**典型应用**：
- **环检测**：存在回边 ⟺ 图中有环
- **拓扑排序**：DFS 完成时间的逆序
- **连通分量**
- **关节点与双连通域**

### BFS vs DFS

| 特性 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列（FIFO） | 栈（LIFO）/递归 |
| 探索顺序 | 广度优先（逐层） | 深度优先（沿路径） |
| 最短路径 | 无权图保证 | 不保证 |
| 空间 | O(V) | O(V) |
| 时间 | O(V + E) | O(V + E) |
