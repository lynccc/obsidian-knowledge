# 拓扑排序

## 🗣️ 通俗讲解

> 想象你有好多任务，有些任务必须先完成其他任务才能开始（比如得先买菜才能做饭）。拓扑排序就是帮你排出一个合法的执行顺序——保证每个任务都在它依赖的任务之后执行。如果有循环依赖（A 等 B，B 等 A），那就无解了。

## 📖 核心概念

**拓扑排序（Topological Sort）** 是对**有向无环图（DAG, Directed Acyclic Graph）** 的所有顶点进行线性排序，使得对于每条边 ⟨u, v⟩，u 在序列中排在 v 之前。

### DAG（有向无环图）

- 没有环的有向图
- 拓扑排序存在的**充要条件**：图是 DAG
- 现实意义：任务间的依赖关系（先修课程、编译顺序、工程调度等）

### 算法一：基于 DFS

利用深度优先搜索的完成时间（f 值）：

1. 对 DAG 执行 DFS
2. 每个顶点完成访问时（标记 VISITED）加入序列头部
3. 最终序列即为一个拓扑序

**原理**：DFS 完成时间逆序保证了对于边 ⟨u, v⟩，v 先于 u 完成 → v 排在 u 之前。

### 算法二：基于入度（Kahn 算法）

基于广度优先搜索的思想：

1. 计算所有顶点的入度
2. 将入度为 0 的顶点入队
3. 循环：取出队首顶点 v，加入拓扑序列；对 v 的每个出边邻居 u，入度减 1
4. 若 u 入度变为 0，入队
5. 若序列长度 < |V|，说明图中有环

```python
from collections import deque

def kahn_topo_sort(g):
    in_degree = {v: 0 for v in g}
    for u in g:
        for v in g[u]:
            in_degree[v] += 1

    queue = deque([v for v in g if in_degree[v] == 0])
    result = []
    while queue:
        u = queue.popleft()
        result.append(u)
        for v in g[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    if len(result) != len(g):
        raise ValueError("Graph has a cycle")
    return result
```

## 复杂度分析

| 算法 | 时间 | 空间 |
|------|------|------|
| DFS 法 | O(n + E) | O(n) |
| Kahn 法 | O(n + E) | O(n) |

两种算法均为线性时间。

## 关键要点

1. 拓扑排序的结果**不唯一**（当 DAG 中存在多个入度为 0 的顶点时）
2. **环检测**：若 Kahn 算法无法将所有顶点加入序列，或 DFS 发现回边，则图中存在环
3. 拓扑排序是 DAG 最短路径的前置步骤
