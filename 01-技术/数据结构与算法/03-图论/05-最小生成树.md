# 最小生成树

## 🗣️ 通俗讲解

> 想象你要在几个城市之间修铁路，目标是所有城市都能互通，但总花费最少。Prim 算法的思路是：从任意一个城市开始，每次选一条连接「已修好」和「没修好」城市的最便宜铁路，逐步扩展，直到所有城市连通。
>
> Kruskal 算法的思路不同：把所有铁路按价格排序，从最便宜的开始修，只要不形成环就修，直到所有城市连通。

## 📖 核心概念

### 支撑树（Spanning Tree）

连通图 G 的**支撑树** T：包含 G 所有顶点的极小连通子图。边数 = |V| - 1，无环且连通。

### 最小支撑树（MST）

**最小支撑树**：边权之和最小的支撑树。仅对带权连通无向图定义。MST 可能不唯一（当有权值相同的边时）。

### 切割定理

对于任意切割 (S, V-S)，横跨切割的最小权边必属于某棵 MST。这是 Prim 和 Kruskal 算法正确性的理论基础。

## Prim 算法

**贪心策略**：从任一顶点出发，每步选择连接"已选顶点集"与"未选顶点集"的**最小权边**，将其加入树中。

```python
import heapq

def prim(graph, start):
    mst = []
    visited = set()
    edges = [(0, start, None)]
    total_cost = 0

    while edges and len(visited) < len(graph):
        weight, u, from_v = heapq.heappop(edges)
        if u in visited:
            continue
        visited.add(u)
        if from_v is not None:
            mst.append((from_v, u, weight))
            total_cost += weight

        for v, w in graph[u].get_connections_with_weights():
            if v not in visited:
                heapq.heappush(edges, (w, v, u))

    return mst, total_cost
```

| 实现方式 | 时间复杂度 |
|---------|-----------|
| 朴素（数组） | O(n²) |
| 优先队列（二叉堆） | O((n+E) log n) |
| 斐波那契堆 | O(E + V log V) |

## Kruskal 算法

**贪心策略**：每次选择**权重最小的边**，只要这条边连接的是两个不同的连通分量（不会形成环）。

```
MST-KRUSKAL(G, w):
    A = ∅
    for each vertex v ∈ V
        MAKE-SET(v)
    将边按权重升序排列
    for each edge (u,v) 按权重升序
        if FIND-SET(u) ≠ FIND-SET(v)
            A = A ∪ {(u,v)}
            UNION(u, v)
    return A
```

时间复杂度：**O(E log E) = O(E log V)**

关键数据结构：**并查集**（Disjoint-Set），用于高效判断是否形成环。

## Kruskal vs Prim 对比

| 特性 | Kruskal | Prim |
|------|---------|------|
| 策略 | 全局最轻安全边 | 局部最轻安全边 |
| 数据结构 | 并查集 | 优先队列 |
| 时间复杂度 | O(E log E) | O(E log V) |
| 适用图 | 稀疏图更优 | 稠密图更优 |
| 实现难度 | 较简单 | 需要优先队列 |
