# 递归

## 🗣️ 通俗讲解

> 递归就是函数自己调用自己。就像你问"什么是递归？"，答案是"去查递归的定义"——当然这会无限循环，所以递归必须有个"刹车"（基本情况）。
>
> 分治法就像吃大象——一口吃不下，切成小块一块块吃。具体三步：**分**（切成小块）、**治**（每块单独处理）、**合**（拼回整体）。

## 📖 核心概念

**递归**是函数直接或间接调用自身的编程技巧。递归算法将问题分解为相同但更小的子问题，直到达到**递归基**（基本情况）。

### 递归三要素

1. **递归基**（base case）：最简单的情况，直接返回结果，不再递归
2. **递归步骤**：将问题分解为更小的子问题
3. **趋向递归基**：每次递归必须向递归基靠近，否则无限递归

> 违反任何一条原则都会导致无限递归或错误结果。

### 递归的类型

#### 线性递归
- 每次递归只调用自身一次
- 递归调用链呈线性展开
- 栈空间复杂度 O(n)

```python
# 线性递归：数组求和
def list_sum(num_list):
    if len(num_list) == 1:
        return num_list[0]
    else:
        return num_list[0] + list_sum(num_list[1:])
```

#### 二分递归（分治）
- 每次递归产生**两个**分支
- 递归树呈二叉树形状
- 栈深度 O(log n)（比线性递归更优）

```python
# 二分递归：数组求和
def sum(A, lo, hi):
    if lo == hi:
        return A[lo]
    mi = (lo + hi) // 2
    return sum(A, lo, mi) + sum(A, mi+1, hi)
```

### 分治法三步骤

1. **分解**（Divide）：将原问题分解为若干规模更小的子问题
2. **求解**（Conquer）：递归求解各子问题（基例直接求解）
3. **合并**（Combine）：合并子问题的解得到原问题的解

### 递归的代价

- 函数调用开销（压栈/出栈）
- 栈空间占用（递归深度 × 每帧大小）
- 可能导致栈溢出（Python 默认递归深度限制：1000 层）

### 递归的实现机制

Python 通过**调用栈（call stack）** 管理递归，每次调用创建一个新的**栈帧（stack frame）**，存储局部变量和返回地址。

```
list_sum([1, 3, 5, 7, 9])
= 1 + list_sum([3, 5, 7, 9])
= 1 + 3 + list_sum([5, 7, 9])
= 1 + 3 + 5 + list_sum([7, 9])
= 1 + 3 + 5 + 7 + list_sum([9])
= 1 + 3 + 5 + 7 + 9  → 25
```

## 递归分析方法

分析递归算法的时间复杂度需要专门的方法：

### 递归跟踪法（直观）
- 画出递归调用的展开图（调用树）
- 统计每层的工作量，然后累加
- 直观但对复杂递归难以精确分析

### 递推方程法（系统）
- 建立递推关系式：T(n) = T(n-1) + O(1)
- 求解递推方程得到闭合形式
- 适用于各种递归模式

### 常见递推方程

| 递推方程 | 解 | 对应模式 |
|----------|-----|----------|
| T(n) = T(n-1) + O(1) | O(n) | 线性递归 |
| T(n) = T(n/2) + O(1) | O(log n) | 二分递归 |
| T(n) = 2T(n/2) + O(n) | O(n log n) | 归并排序 |

### 递归树分析
将递归式展开为树：
- 每层的总代价为 cn（除叶节点层外）
- 共 lg n + 1 层
- 叶节点层总代价 cn
- **总代价**：cn lg n + cn = Θ(n lg n)

## 经典递归问题

### 汉诺塔（Tower of Hanoi）
将 n 个盘子从源柱移动到目标柱，借助辅助柱：
1. 将 n-1 个盘子从源移到辅助柱
2. 将最大的盘子从源移到目标柱
3. 将 n-1 个盘子从辅助移到目标柱

时间复杂度：**O(2ⁿ - 1)**，指数级增长

### 迷宫搜索
使用递归实现**回溯法（backtracking）** 搜索迷宫路径：
- 尝试 → 失败 → 回退 → 换方向
- 通过标记已访问位置避免无限循环

## 关键要点

1. 递归本质上是用**隐式栈**替代显式循环
2. 基本情况是递归的"刹车"，必须存在且可达
3. Python 的切片操作（如 `num_list[1:]`）创建新列表，有额外开销
4. 对于简单的线性递归，迭代版本通常更高效
5. 分治法不仅用于排序，还用于矩阵乘法、最近点对等问题
6. 插入排序的常数因子小，对小规模数据可能更快；实际中常混合使用
