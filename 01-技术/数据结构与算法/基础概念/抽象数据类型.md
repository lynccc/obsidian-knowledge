# 抽象数据类型

## 🗣️ 通俗讲解

> ADT 就像一份「使用说明书」——它只告诉你这个东西能做什么（比如栈能 push 和 pop），但不告诉你里面是怎么实现的。就像你开车只需要知道油门和刹车，不需要知道发动机原理。同一个 ADT 可以有不同的底层实现（数组或链表），但用法一样。

## 📖 核心概念

**抽象数据类型**（Abstract Data Type, ADT）是数据类型的数学模型，将**数据对象**和**操作**封装在一起，只通过接口访问，隐藏内部实现细节。

### ADT 的组成

- **数据对象**：数据元素的集合（如整数集合、字符串集合）
- **数据关系**：元素之间的逻辑关系
- **操作集合**：可对数据执行的操作（如插入、删除、查找）

### ADT 的特点

- **抽象性**：只关心"做什么"，不关心"怎么做"
- **封装性**：内部表示对外部不可见
- **独立性**：接口与实现分离

### 信息隐藏

- 将实现细节封装在内部，对外只暴露接口
- 用户无需了解数据如何存储、操作如何实现
- 优势：可修改实现而不影响用户代码

### ADT vs 数据结构

| 概念 | 层次 | 关注点 |
|------|------|--------|
| ADT | 逻辑层 | 定义操作语义 |
| 数据结构 | 实现层 | 如何存储和实现 |
| 算法 | 操作层 | 如何高效执行操作 |

### 示例：栈 ADT

```
ADT Stack:
    数据对象：有限元素序列
    操作：
        push(x)    - 入栈
        pop()      - 出栈
        top()      - 取栈顶
        isEmpty()  - 判断空
        size()     - 元素个数
```

栈可以用数组或链表实现，但 ADT 层面不关心具体实现。

## 设计原则

- 操作应**正交**（功能不重叠）
- 接口应**最小完备**（必要的操作都在）
- 操作应有明确的**前置/后置条件**

## 📝 各书讲解特点

### 邓俊辉版（C++）
- **侧重点**：从理论角度定义 ADT，强调数学模型
- **特色**：用 C++ 模板和类来实现 ADT，展示接口与实现的分离
- **适合**：理解 ADT 的理论基础

### Miller版（Python）
- **侧重点**：从 Python 面向对象的角度引入 ADT
- **特色**：用 Python 类来实现 ADT，强调信息隐藏和接口设计
- **适合**：通过 Python 实践理解 ADT

### CLRS版（算法导论）
- **侧重点**：在数据结构章节中讨论 ADT 的实现
- **特色**：用伪代码描述操作，关注算法效率
- **适合**：从算法角度理解 ADT

## 代码示例

```python
# ADT视角：定义操作接口
class MyList:
    def append(self, item):
        """添加元素到末尾"""
        pass
    
    def pop(self):
        """移除并返回末尾元素"""
        pass

# 用户只需知道接口，无需了解实现细节
my_list = MyList()
my_list.append(1)
my_list.pop()
```

```cpp
// C++ 模板实现
template <typename T>
class Stack {
public:
    virtual void push(const T& x) = 0;
    virtual T pop() = 0;
    virtual T top() const = 0;
    virtual bool isEmpty() const = 0;
    virtual int size() const = 0;
};
```
