# 渐进记号

## 🗣️ 通俗讲解

> 大O就是衡量算法「有多慢」的尺子。O(1) 是瞬间完成（不管数据多少），O(n) 是数据越多越慢（线性增长），O(n²) 是数据翻倍、时间变 4 倍——越往后越恐怖。写代码时心里要有这把尺子，不然数据量一大程序就卡死了。
>
> 更精确地说，渐进记号就是给算法"算命"——当数据量 n 变得很大时，运行时间大概以什么速度增长？我们不在乎具体几秒，只在乎增长的"形状"是线性的、平方的还是指数的。
>
> **O** 是上界（"最多这么快"），**Ω** 是下界（"至少这么快"），**Θ** 是紧确界（"就这么快"）。就像说一个人身高"至少170"、"最多190"、"大约180"。

## 📖 核心概念

渐进复杂度记号用于描述算法在输入规模 n 趋于无穷时的效率趋势，忽略常数因子和低阶项，关注增长趋势。

### O 记号（Big-O，渐进上界）

- **O(f(n))**：存在正常数 c 和 n₀，使得当 n ≥ n₀ 时，T(n) ≤ c·f(n)
- 表示算法复杂度的**渐进上界**，f(n) 的增长速度**不快于** g(n)
- 实际中最常用，常用来表示"最坏情况"
- 7n³ + 100n² = O(n³) ✓；7n³ + 100n² = O(n⁴) ✓（上界可以宽松）

### Ω 记号（Big-Omega，渐进下界）

- **Ω(f(n))**：存在正常数 c 和 n₀，使得当 n ≥ n₀ 时，T(n) ≥ c·f(n)
- 表示算法复杂度的**渐进下界**，f(n) 的增长速度**不低于** g(n)

### Θ 记号（Big-Theta，紧确界）

- **Θ(f(n))**：同时满足 O(f(n)) 和 Ω(f(n))
- 存在正常数 c₁, c₂ 和 n₀，使得对所有 n ≥ n₀，有 c₁g(n) ≤ f(n) ≤ c₂g(n)
- **定理**：f(n) = Θ(g(n)) 当且仅当 f(n) = O(g(n)) 且 f(n) = Ω(g(n))

### o 记号与 ω 记号（非紧确界）

- **o(g(n))**：非紧确上界，f(n) 相比 g(n) 微不足道（lim f/g = 0）
- **ω(g(n))**：非紧确下界，f(n) 相比 g(n) 任意大（lim f/g = ∞）
- 重要关系：lg n = o(n)，n = o(n lg n)，n lg n = o(n²)，n² = o(2ⁿ)

### 直观理解

| 记号 | 含义 | 类比 |
|------|------|------|
| O(f(n)) | 不超过 f(n) 级别 | ≤ |
| Ω(f(n)) | 至少 f(n) 级别 | ≥ |
| Θ(f(n)) | 恰好 f(n) 级别 | = |
| o(f(n)) | 远小于 f(n) 级别 | << |
| ω(f(n)) | 远大于 f(n) 级别 | >> |

### 常见复杂度层次

| 大O记法 | 名称 | 示例算法 |
|---------|------|---------|
| O(1) | 常数 | 数组索引、哈希查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历列表 |
| O(n log n) | 线性对数 | 归并排序、快速排序 |
| O(n²) | 平方 | 冒泡排序、嵌套循环 |
| O(n³) | 立方 | 矩阵乘法（朴素） |
| O(2ⁿ) | 指数 | 子集枚举 |
| O(n!) | 阶乘 | 全排列枚举 |

## 关键要点

1. 渐进记号描述的是**函数的增长率**，不是具体运行时间
2. 使用时要精确：插入排序最坏 Θ(n²)、最好 Θ(n)；不能笼统说"运行时间是 Θ(n²)"
3. O 表示上界，Θ 表示紧确——能用 Θ 就不要用 O
4. **关注趋势**：n很大时，高次项主导，忽略常数因子和低阶项
5. **加法法则**：O(f(n)) + O(g(n)) = O(max(f(n), g(n)))
6. **乘法法则**：O(f(n)) × O(g(n)) = O(f(n) × g(n))

- **适合**：学术研究、深入理解算法分析的数学基础

## 代码示例

```python
# O(1) - 常数时间
def get_first(lst):
    return lst[0]  # 无论列表多长，都是1步

# O(n) - 线性时间
def find_max(lst):
    max_val = lst[0]
    for item in lst:  # 遍历n次
        if item > max_val:
            max_val = item
    return max_val

# O(n²) - 平方时间
def bubble_sort(lst):
    n = len(lst)
    for i in range(n):        # n次
        for j in range(n-1):  # n次
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]

# O(log n) - 对数时间
def binary_search(lst, target):
    low, high = 0, len(lst)-1
    while low <= high:
        mid = (low + high) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```
