# 时间复杂度

## 🗣️ 通俗讲解

> 时间复杂度就是衡量算法"有多慢"的指标。不是说具体几秒（那取决于电脑快慢），而是说数据量翻倍时，运行时间大概会怎么变——是翻一倍（线性），还是变四倍（平方），还是几乎不变（常数）？

## 📖 核心概念

**时间复杂度**是算法执行所需时间的度量。实际运行时间受硬件、编译器等因素影响，因此用**基本操作次数**来衡量算法效率。

### 基本概念

- **基本操作**：算法中最核心、执行次数最多的操作（如比较、赋值）
- **输入规模**：通常用 n 表示，如数组长度、问题规模
- **时间复杂度 T(n)**：基本操作次数与输入规模 n 的函数关系
- 直接统计精确操作次数过于繁琐，通常使用[[渐进记号]]简化表示

### 度量方法

1. 确定算法中的基本操作
2. 分析基本操作的执行次数与输入规模的关系
3. 建立 T(n) 的表达式
4. 使用[[渐进记号]]（大O等）简化

### 按情况分类

- **最好情况**：Ω记法，算法的下界
- **最坏情况**：O记法，算法的上界（最常用）
- **平均情况**：Θ记法，算法的紧确界

## 关键要点

1. **关注趋势**：n很大时，高次项主导
2. **忽略常数**：O(2n) = O(n)，O(100) = O(1)
3. **最坏情况**：通常分析最坏情况，保证性能下限
4. **加法法则**：O(f(n)) + O(g(n)) = O(max(f(n), g(n)))
5. **乘法法则**：O(f(n)) × O(g(n)) = O(f(n) × g(n))

## 📝 各书讲解特点

### 邓俊辉版（C++）
- **侧重点**：从基本操作的概念出发，系统讲解度量方法
- **特色**：用起泡排序作为完整示例，推导 T(n) = n(n-1)/2，再用渐进记号简化为 O(n²)
- **适合**：理解时间复杂度分析的完整过程

### Miller版（Python）
- **侧重点**：从基准测试的局限性出发引入 T(n) 函数
- **特色**：强调"算法是思想，程序是实现"，用 Python 代码演示不同复杂度的实际差异
- **适合**：从实践角度理解时间复杂度的意义

### CLRS版（算法导论）
- **侧重点**：最严谨的数学处理，区分最好/最坏/平均情况
- **特色**：用插入排序作为例子，展示如何从算法伪代码推导出运行时间
- **适合**：学术研究和深入理解

## 代码示例

```cpp
// 起泡排序：基本操作是比较
void bubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (A[j] > A[j+1])  // 基本操作：比较
                swap(A[j], A[j+1]);
}
// 比较次数: T(n) = (n-1) + (n-2) + ... + 1 = n(n-1)/2
// 时间复杂度: O(n²)
```

```python
# Python 版本
def bubble_sort(lst):
    n = len(lst)
    for i in range(n):
        for j in range(n - 1 - i):
            if lst[j] > lst[j+1]:  # 基本操作：比较
                lst[j], lst[j+1] = lst[j+1], lst[j]
    return lst
```
