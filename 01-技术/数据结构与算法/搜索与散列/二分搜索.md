# 二分搜索

## 🗣️ 通俗讲解
> 就像猜数字游戏：「大了」「小了」——每次把范围砍掉一半，所以叫「二分」。100 万个数最多猜 20 次就能找到目标。前提是要先排好序，不然没法二分。

## 📖 核心概念

二分搜索利用列表**有序**的特性，每次比较中间元素，将搜索范围减半，直到找到目标或范围为空。

### 复杂度

- 时间复杂度：**O(logn)**，每次迭代区间减半
- 100 万个元素只需约 20 次比较

### 三个版本（邓俊辉）

| 版本 | 特点 |
|------|------|
| 版本A | 每次两次比较，三个分支，最直观 |
| 版本B | 每次一次比较，收敛到单一元素 |
| 版本C | 半开区间 [lo, hi)，返回值兼顾查找与插入 |

### Fibonacci 查找

利用 Fibonacci 数列划分区间，将除法替换为加减法。效率与二分同阶 O(logn)，更多是理论意义。

### 关键限制
- **前提**：列表必须有序
- 只适用于支持**随机访问**的数据结构（如数组，不适用于链表）
- Python 的 `bisect` 模块提供了高效实现

## 📝 各书特色

### 邓俊辉版（C++）
- 侧重：三个版本的演进优化，Fibonacci 查找，版本 C 的半开区间设计
- 特色：从接口设计角度分析查找算法

### Miller版（Python）
- 侧重：迭代与递归两种实现，递归版本因切片操作有额外开销
- 特色：数据对比直观展示 O(logn) vs O(n) 的差距
