# 散列表

## 🗣️ 通俗讲解
> 就像图书馆的索引卡片——通过书名能直接算出书架位置，不用一本本翻找。散列表就是这个原理：用一个函数把 key 转换成数组下标，直接定位。但偶尔两个 key 会算出同一个位置（冲突），需要额外处理。Python 的 `dict` 和 `set` 底层就是散列表。

## 📖 核心概念

散列表通过**散列函数**将关键码直接映射到数组下标，实现期望 O(1) 的查找/插入/删除。

### 散列函数

| 方法 | 公式 | 特点 |
|------|------|------|
| 除余法 | h(key) = key % M | M 取素数效果更好 |
| MAD法 | (a*key + b) % M | 消除周期性 |
| 多项式散列码 | 用于字符串 | 引入位置权重 |

### 冲突解决

**开散列（拉链法）**：每个桶维护一个链表，冲突元素挂入同一桶。

**闭散列（开地址法）**：冲突元素存放在表内其他空桶。

| 探测策略 | 特点 |
|----------|------|
| 线性试探 | 缓存友好，但有主聚集问题 |
| 平方试探 | 减少主聚集，可能有二级聚集 |
| 双向平方试探 | 表长为 4k+3 素数时探测全表 |
| 双重散列 | 最好的开放寻址方法 |

### 装填因子 λ = n/N

- λ 越大，冲突越多，性能下降
- 链地址法：λ 可以 > 1
- 开放寻址：λ 必须 < 1
- λ = 0.5 时，成功搜索约 1.39 次

### 复杂度

| 操作 | 期望时间 | 最坏时间 |
|------|---------|---------|
| 查找 | O(1) | O(n) |
| 插入 | O(1) | O(n) |
| 删除 | O(1) | O(n) |
