# 参考书目

## 📚 三本核心参考书

### 1. 《数据结构（C++语言版）》第3版

- **作者**：邓俊辉
- **出版社**：清华大学出版社
- **特点**：
  - 理论严谨，从数学定义出发
  - 注重底层实现和复杂度分析
  - 适合考研、面试深入理解
  - C++ 模板实现，强调泛型编程
- **涵盖内容**：向量、列表、栈与队列、二叉树、图、搜索树、散列表、排序

### 2. 《Python数据结构与算法分析》第2版

- **作者**：Bradley N. Miller, David L. Ranum
- **出版社**：人民邮电出版社
- **特点**：
  - 实践导向，代码简洁易读
  - 用 Python 实现，适合快速上手
  - 强调 ADT 和面向对象设计
  - 包含大量实际应用案例
- **涵盖内容**：基本数据结构、递归、搜索与排序、树与图

### 3. 《算法导论》第4版（CLRS）

- **作者**：Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein
- **出版社**：机械工业出版社
- **特点**：
  - 最全面、最权威的算法教材
  - 数学证明严谨，覆盖广泛
  - 包含大量高级主题（NP完全性、近似算法等）
  - 适合学术研究和深入理解
- **涵盖内容**：排序、数据结构、图算法、动态规划、贪心、NP完全性

## 📖 阅读建议

- **入门**：先读 Miller 的 Python 版，建立直觉
- **深入**：再读邓俊辉的 C++ 版，理解底层机制
- **全面**：最后读 CLRS，覆盖高级主题和严格证明
- **实践**：每读一个知识点，用代码实现一遍
