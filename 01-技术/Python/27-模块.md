# 📦 Python 模块

## 核心概念

模块 = **包含函数的 `.py` 文件**，可以把函数"打包"到单独的文件里

类比：**模块就像工具箱** —— 你把常用的工具（函数）放进一个箱子（.py 文件）里，需要的时候打开箱子拿出来用。不用每次都重新造工具。

---

## 一、导入整个模块

### 📌 先认识：import — 导入模块

假设有一个文件 `pizza.py`，里面有一个函数：

```python
# pizza.py（这是一个单独的文件）
def make_pizza(size, *toppings):
    """显示要制作的披萨"""
    print("\nMaking a " + str(size) + "-inch pizza with the following toppings:")
    for topping in toppings:
        print("- " + topping)
```

在另一个文件 `making_pizzas.py` 中导入并使用：

```python
# making_pizzas.py
import pizza    # 导入 pizza 模块

# 使用模块名.函数名 的方式调用
pizza.make_pizza(16, 'pepperoni')
pizza.make_pizza(12, 'mushrooms', 'green peppers', 'extra cheese')

# 输出：
# Making a 16-inch pizza with the following toppings:
# - pepperoni
#
# Making a 12-inch pizza with the following toppings:
# - mushrooms
# - green peppers
# - extra cheese
```

**`import pizza` = "打开 pizza 这个工具箱"。** 之后用 `pizza.函数名()` 来使用里面的工具。

---

## 二、导入特定函数

### 📌 先认识：from...import — 从模块中导入特定函数

```python
# 只导入 make_pizza 这一个函数
from pizza import make_pizza

# 直接用函数名调用，不需要 pizza. 前缀
make_pizza(16, 'pepperoni')

# 输出：
# Making a 16-inch pizza with the following toppings:
# - pepperoni
```

**`from pizza import make_pizza` = "从 pizza 工具箱里只拿出 make_pizza 这一个工具"。** 拿出来后直接用，不需要再写工具箱的名字。

---

## 三、使用别名

### 函数别名

```python
# 给函数起别名：make_pizza → mp
from pizza import make_pizza as mp

mp(16, 'pepperoni')    # 用别名调用

# 输出：
# Making a 16-inch pizza with the following toppings:
# - pepperoni
```

### 模块别名

```python
# 给模块起别名：pizza → p
import pizza as p

p.make_pizza(16, 'pepperoni')    # 用别名调用

# 输出：
# Making a 16-inch pizza with the following toppings:
# - pepperoni
```

**类比：** 就像你有个朋友叫"张三丰"，你叫他"三丰"（别名），意思一样，只是更简短。

### 导入所有函数（不推荐）

```python
# 导入 pizza 模块中的所有函数
from pizza import *

make_pizza(16, 'pepperoni')
```

**⚠️ 不推荐使用 `import *`！** 因为它会导入模块中的所有函数，可能导致命名冲突（两个模块有同名函数时会出问题）。

---

## 四、什么时候用哪种导入方式？

| 方式 | 语法 | 适用场景 |
|------|------|----------|
| `import 模块` | `pizza.make_pizza()` | 需要用模块中的多个函数 |
| `from 模块 import 函数` | `make_pizza()` | 只需要用一两个函数 |
| `import 模块 as 别名` | `p.make_pizza()` | 模块名太长，想简写 |
| `from 模块 import *` | `make_pizza()` | **不推荐**，可能导致冲突 |

---

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 模块 `.py` | 包含函数的文件 | 工具箱 |
| `import` | 导入整个模块 | 打开工具箱 |
| `from...import` | 导入特定函数 | 只拿出一个工具 |
| `as` | 起别名 | 给朋友起昵称 |
| `模块.函数()` | 用模块名调用 | 说"工具箱里的锤子" |
