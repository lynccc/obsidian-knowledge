# ⚠️ Python 异常处理

## 核心概念

异常 = **程序运行时发生的错误**，异常处理 = **提前准备好"出错时怎么办"**

类比：**异常处理就像安全气囊** —— 你开车时希望一切正常，但万一出了事故（异常），安全气囊会弹出来保护你（处理异常），而不是让车直接撞毁（程序崩溃）。

```python
try:
    # 尝试做这件事
    可能出错的代码
except 异常类型:
    # 如果出错，执行这里
    出错时的处理
```

---

## 一、处理 ZeroDivisionError

除以零是不允许的，会报错：

```python
# ❌ 没有异常处理：程序直接崩溃
print(5 / 0)

# 输出：
# ZeroDivisionError: division by zero
# 翻译：不能除以零
```

```python
# ✅ 有异常处理：程序不会崩溃
try:
    print(5 / 0)              # 尝试除以零
except ZeroDivisionError:     # 如果出现除以零的错误
    print("You can't divide by zero!")   # 就执行这行

# 输出：
# You can't divide by zero!
```

**逐行解释：**
1. `try:` — "试试看能不能执行下面的代码"
2. `print(5 / 0)` — 尝试除以零 → 出错了！
3. `except ZeroDivisionError:` — "如果出现 ZeroDivisionError 这种错误"
4. `print("You can't divide by zero!")` — "就执行这行代码"

**类比：** 就像你试着打开一扇门（try），如果门锁了（异常），就走另一扇门（except）。

## 二、使用 try-except-else

`else` = **try 成功时执行的代码**

```python
print("Give me two numbers, and I'll divide them.")
print("Enter 'q' to quit.")

while True:
    first_number = input("\nFirst number: ")
    if first_number == 'q':
        break

    second_number = input("Second number: ")
    if second_number == 'q':
        break

    try:
        answer = int(first_number) / int(second_number)   # 尝试计算
    except ZeroDivisionError:
        print("You can't divide by 0!")                    # 除以零 → 报错
    else:
        print(answer)                                      # 计算成功 → 打印结果

# 运行效果：
# Give me two numbers, and I'll divide them.
# First number: 5
# Second number: 2
# 2.5
# First number: 5
# Second number: 0
# You can't divide by 0!
```

**`else` 的作用：** 只有 `try` 里的代码**没有出错**时，才会执行 `else` 里的代码。

## 三、处理 FileNotFoundError

文件不存在时会报错：

```python
filename = 'alice.txt'

try:
    with open(filename) as f_obj:       # 尝试打开文件
        contents = f_obj.read()         # 读取内容
except FileNotFoundError:
    msg = "Sorry, the file " + filename + " does not exist."  # 文件不存在
    print(msg)

# 输出（假设文件不存在）：
# Sorry, the file alice.txt does not exist.
```

## 四、静默处理

有时候出错了也不想让程序崩溃，也不想显示任何信息：

### 📌 先认识：pass — 什么都不做

```python
filename = 'alice.txt'

try:
    with open(filename) as f_obj:
        contents = f_obj.read()
except FileNotFoundError:
    pass    # 什么都不做，静默跳过
else:
    # 统计单词数
    words = contents.split()    # split() 把文本按空格分割成单词列表
    num_words = len(words)      # len() 计算单词数量
    print("The file " + filename + " has about " + str(num_words) + " words.")
```

**`pass` = "什么都不做"。** 就像听到一个无关紧要的消息，你选择忽略它。

## 五、决定报告哪些错误

**原则：** 不要向用户暴露代码细节，只告诉用户他们需要知道的信息。

```python
# ✅ 好的做法：用户友好的提示
filename = 'alice.txt'
try:
    with open(filename) as f_obj:
        contents = f_obj.read()
except FileNotFoundError:
    print("Sorry, the file '" + filename + "' was not found.")
    # 用户不需要知道 FileNotFoundError 这种技术细节

# ❌ 差的做法：暴露技术细节
# except FileNotFoundError as e:
#     print(e)   # 显示：[Errno 2] No such file or directory: 'alice.txt'
```

## 六、常见异常类型

| 异常类型 | 原因 | 示例 |
|----------|------|------|
| `ZeroDivisionError` | 除以零 | `5 / 0` |
| `FileNotFoundError` | 文件不存在 | `open('不存在的文件')` |
| `TypeError` | 类型错误 | `'5' + 3` |
| `ValueError` | 值错误 | `int('abc')` |
| `NameError` | 变量未定义 | `print(不存在的变量)` |
| `IndexError` | 索引超出范围 | `[1,2][5]` |

---

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| `try` | 尝试执行 | 试着开门 |
| `except` | 出错时执行 | 门锁了走另一扇 |
| `else` | 成功时执行 | 门开了继续走 |
| `pass` | 什么都不做 | 忽略消息 |
| 异常 | 程序运行时的错误 | 事故 |
| 异常处理 | 出错时的应对方案 | 安全气囊 |
