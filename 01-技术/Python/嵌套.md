# 🧱 Python 嵌套

## 核心概念

嵌套 = **把数据结构"套"在一起**

类比：**嵌套就像收纳箱里套小箱子** —— 大箱子（列表）里可以放小箱子（字典），小箱子里还可以放更小的箱子（列表）。

三种常见嵌套：
1. 列表中存储字典
2. 字典中存储列表
3. 字典中存储字典

---

## 一、字典列表（列表里放字典）

```python
# 创建 3 个外星人字典
alien_0 = {'color': 'green', 'points': 5}
alien_1 = {'color': 'yellow', 'points': 10}
alien_2 = {'color': 'red', 'points': 15}

# 把它们放进一个列表里
aliens = [alien_0, alien_1, alien_2]

# 遍历列表，打印每个外星人
for alien in aliens:
    print(alien)

# 输出：
# {'color': 'green', 'points': 5}
# {'color': 'yellow', 'points': 10}
# {'color': 'red', 'points': 15}
```

**类比：** 就像一个班级（列表）里有很多学生（字典），每个学生都有自己的信息（姓名、成绩等）。

**实际场景：** 一个游戏里有 30 个外星人，每个外星人都有自己的颜色和分数，用字典列表来管理它们非常方便。

---

## 二、字典中存储列表（字典里放列表）

```python
# 披萨订单：饼皮类型 + 配料列表
pizza = {
    'crust': 'thick',              # 饼皮类型
    'toppings': ['mushrooms', 'extra cheese'],   # 配料列表
}

print("You ordered a " + pizza['crust'] + "-crust pizza with the following toppings:")

# 遍历配料列表
for topping in pizza['toppings']:
    print("\t" + topping)

# 输出：
# You ordered a thick-crust pizza with the following toppings:
# 	mushrooms
# 	extra cheese
```

**类比：** 就像一个订单（字典）里记录了饼皮类型（值）和配料清单（列表）。

**为什么用嵌套？** 因为配料可能有多个，用列表存储更方便。如果只有一种配料，可以直接用字符串。

---

## 三、字典中存储字典（字典里套字典）

```python
# 两个用户，每个用户都有详细信息
users = {
    'aeinstein': {                    # 键是用户名
        'first': 'albert',           # 值是一个字典
        'last': 'einstein',
        'location': 'princeton',
    },
    'mcurie': {
        'first': 'marie',
        'last': 'curie',
        'location': 'paris',
    },
}

# 遍历外层字典
for username, user_info in users.items():
    print("\nUsername: " + username)

    # 从内层字典中获取信息
    full_name = user_info['first'] + " " + user_info['last']
    location = user_info['location']

    print("\tFull name: " + full_name.title())
    print("\tLocation: " + location.title())

# 输出：
# Username: aeinstein
# 	Full name: Albert Einstein
# 	Location: Princeton
#
# Username: mcurie
# 	Full name: Marie Curie
# 	Location: Paris
```

**逐行解释：**
1. `users` 是一个外层字典，键是用户名
2. 每个键对应的值又是一个字典（包含 first、last、location）
3. `for username, user_info in users.items():` — 遍历外层字典
4. `user_info['first']` — 从内层字典中获取值

**类比：** 就像一个通讯录（外层字典）里，每个人（键）都有一张名片（内层字典），名片上有姓名、地址等信息。

---

## 总结

| 嵌套类型 | 语法 | 类比 |
|----------|------|------|
| 列表里放字典 | `[{...}, {...}]` | 班级里的学生名单 |
| 字典里放列表 | `{'key': [...]}` | 订单里的配料清单 |
| 字典里套字典 | `{'key': {...}}` | 通讯录里的名片 |
