# 🔒 Python 元组

## 核心概念

- 元组是不可变的列表
- 用圆括号 `()` 表示
- 不能修改元组的元素
- 但可以重新赋值整个元组变量

## 创建元组

```python
dimensions = (200, 50)
print(dimensions[0])  # 200
print(dimensions[1])  # 50
```

## 遍历元组

```python
dimensions = (200, 50)
for dimension in dimensions:
    print(dimension)
# 输出:
# 200
# 50
```

## 不能修改元素

```python
dimensions = (200, 50)
dimensions[0] = 250  # ❌ TypeError: 'tuple' object does not support item assignment
```

## 可以重新赋值变量

```python
dimensions = (200, 50)
print("Original dimensions:")
for dimension in dimensions:
    print(dimension)

dimensions = (400, 100)  # ✅ 重新赋值整个变量
print("\nModified dimensions:")
for dimension in dimensions:
    print(dimension)
```

## 什么时候用元组

- 数据不应该被修改时（如配置、常量）
- 需要确保数据安全时
- 作为字典的键（列表不行）
