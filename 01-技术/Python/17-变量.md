# 📦 Python 变量

## 核心概念

变量 = **给值起个名字，方便以后使用**

类比：**变量就像贴了标签的收纳盒** —— 盒子里放东西，标签上写名字。你看到标签就知道盒子里是什么。

```python
message = "Hello Python world!"
```
这句话的意思是：**把 "Hello Python world!" 这段文字放进名叫 message 的盒子里**

---

## 一、变量命名规则

| 规则 | 示例 | 说明 |
|------|------|------|
| 只能包含字母、数字、下划线 | `student_name` ✅ | 用下划线分隔多个单词 |
| 不能以数字开头 | `1_message` ❌ | Python 会以为是数字 |
| 不能有空格 | `greeting message` ❌ | 用下划线代替空格 |
| 不能是 Python 关键字 | `print = 5` ❌ | print 是 Python 自带的 |
| 区分大小写 | `Name` ≠ `name` | 大写 N 和小写 n 是两个不同的变量 |

```python
# ✅ 正确的变量名
message = "hello"           # 小写字母
student_name = "Alice"      # 用下划线分隔单词
name_length = 10            # 包含数字（但不是以数字开头）

# ❌ 错误的变量名
1_message = "hello"         # 不能以数字开头 → 会报错
greeting message = "hi"     # 不能有空格 → 会报错
```

**💡 命名建议：**
- 用小写字母和下划线：`student_name` 比 `StudentName` 更好
- 变量名要有意义：`name` 比 `n` 好，一眼就知道存的是什么
- 慎用小写 `l` 和大写 `O`，容易和数字 1、0 混淆

## 二、使用变量

```python
# 第一步：把 "Hello Python world!" 存进 message 变量
message = "Hello Python world!"

# 第二步：打印 message 的内容
print(message)

# 输出：
# Hello Python world!
```

**变量的值可以随时修改：**

```python
# 先存一段话
message = "Hello Python world!"
print(message)

# 改成另一段话
message = "Hello Python Crash Course world!"
print(message)

# 输出：
# Hello Python world!
# Hello Python Crash Course world!
```

**类比：** 就像你可以把收纳盒里的东西拿出来，换一个新的东西进去。标签没变，但里面的东西变了。

## 三、常见错误

### 错误 1：变量名拼写错误

```python
message = "Hello"
print(mesage)      # ❌ 少打了一个 s

# 输出：
# NameError: name 'mesage' is not defined
# 翻译：Python 找不到叫 "mesage" 的变量
```

**原因：** Python 是严格区分拼写的，`message` 和 `mesage` 对它来说是两个完全不同的名字。

### 错误 2：使用前没有先赋值

```python
print(name)        # ❌ name 还没有定义

# 输出：
# NameError: name 'name' is not defined
```

**原因：** 就像你去找一个"还没有贴标签的收纳盒"，当然找不到。必须先给变量赋值，才能使用它。

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 变量 | 给值起个名字 | 贴了标签的收纳盒 |
| 赋值 `=` | 把值放进变量 | 把东西放进盒子 |
| 修改变量 | 重新赋值 | 换盒子里的东西 |
| `print()` | 打印变量的值 | 打开盒子看看里面 |
