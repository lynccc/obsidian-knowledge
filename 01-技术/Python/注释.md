# 💬 Python 注释

## 核心概念

- 注释用 `#` 开头
- Python 解释器会忽略注释内容
- 注释用于说明代码的用途和逻辑

## 如何编写

```python
# 向大家问好
print("Hello Python people!")
```

输出只有：`Hello Python people!`

## 什么时候写注释

- 解释代码**为什么**这样做（而不是做什么）
- 记录解决方案的思路
- 标注待完成的任务
- 复杂逻辑的说明

## 命名建议

```python
# ✅ 好的注释：解释为什么
# 使用小写存储，因为用户输入大小写不一致
favorite_language = 'python'.lower()

# ❌ 差的注释：重复代码本身
# 把 favorite_language 转成小写
favorite_language = 'python'.lower()
```
