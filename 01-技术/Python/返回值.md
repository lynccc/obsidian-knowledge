# 📥 Python 返回值

## 核心概念

返回值 = **函数处理完数据后，把结果"交还"给调用者**

类比：**返回值就像自动售货机** —— 你投币（输入），机器给你饮料（返回值）。你拿到饮料后可以喝、可以带走、可以给别人。

```python
def add(a, b):
    return a + b    # 把结果交还给调用者

result = add(3, 5)  # result 接收到返回值 8
print(result)

# 输出：
# 8
```

---

## 一、返回简单值

```python
def get_formatted_name(first_name, last_name):
    """返回整洁的姓名"""
    full_name = first_name + ' ' + last_name   # 拼接姓名
    return full_name.title()                    # 返回首字母大写的姓名

# 调用函数，把返回值存进变量
musician = get_formatted_name('jimi', 'hendrix')
print(musician)

# 输出：
# Jimi Hendrix
```

**逐行解释：**
1. `'jimi'` 和 `'hendrix'` 传入函数
2. 函数把它们拼成 `'jimi hendrix'`
3. `.title()` 变成 `'Jimi Hendrix'`
4. `return` 把 `'Jimi Hendrix'` 交还给调用者
5. `musician` 接收到这个值

## 二、让参数变成可选的

给参数设置默认值（空字符串），就可以选择传或不传：

```python
def get_formatted_name(first_name, last_name, middle_name=''):
    """返回整洁的姓名，中间名可选"""
    if middle_name:                              # 如果有中间名
        full_name = first_name + ' ' + middle_name + ' ' + last_name
    else:                                        # 如果没有中间名
        full_name = first_name + ' ' + last_name
    return full_name.title()

# 不传中间名
musician = get_formatted_name('jimi', 'hendrix')
print(musician)

# 输出：
# Jimi Hendrix

# 传中间名
musician = get_formatted_name('john', 'hooker', 'lee')
print(musician)

# 输出：
# John Lee Hooker
```

**类比：** 就像填表格 —— 姓名是必填项，中间名是选填项。你可以填，也可以不填。

## 三、返回字典

函数可以返回任何类型的数据，包括字典：

```python
def build_person(first_name, last_name, age=''):
    """返回一个表示人的字典"""
    person = {'first': first_name, 'last': last_name}   # 创建字典
    if age:                                              # 如果传了年龄
        person['age'] = age                              # 加到字典里
    return person                                        # 返回字典

musician = build_person('jimi', 'hendrix', age=27)
print(musician)

# 输出：
# {'first': 'jimi', 'last': 'hendrix', 'age': 27}
```

## 四、结合 while 循环

```python
def get_formatted_name(first_name, last_name):
    full_name = first_name + ' ' + last_name
    return full_name.title()

while True:
    print("\nPlease tell me your name:")
    print("(enter 'q' at any time to quit)")

    f_name = input("First name: ")
    if f_name == 'q':         # 用户输入 q 就退出
        break

    l_name = input("Last name: ")
    if l_name == 'q':         # 用户输入 q 就退出
        break

    # 调用函数，获取格式化的姓名
    formatted_name = get_formatted_name(f_name, l_name)
    print("Hello, " + formatted_name + "!")

# 运行效果：
# Please tell me your name:
# (enter 'q' at any time to quit)
# First name: jimi
# Last name: hendrix
# Hello, Jimi Hendrix!
```

**类比：** 就像自动售货机一直运行，你不断投币（输入姓名），机器不断给你饮料（格式化的姓名），直到你说"不买了"（输入 q）。

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| `return` | 把结果交还给调用者 | 售货机给你饮料 |
| 返回值 | 函数的"产出" | 你拿到的饮料 |
| 可选参数 | 用默认值让参数可选 | 表格的选填项 |
| 返回字典 | 函数可以返回任何类型 | 售货机可以卖任何东西 |
