# ⚙️ Python 函数基础

## 核心概念

- 函数用 `def` 定义
- 函数名后跟括号和冒号
- 缩进定义函数体
- 调用函数时使用函数名加括号

## 定义函数

```python
def greet_user():
    """显示简单的问候语"""
    print("Hello!")

greet_user()  # Hello!
```

## 传递信息

```python
def greet_user(username):
    """显示个性化的问候语"""
    print("Hello, " + username.title() + "!")

greet_user('jesse')  # Hello, Jesse!
```

## 实参和形参

```python
def greet_user(username):  # username 是形参
    print("Hello, " + username.title() + "!")

greet_user('jesse')  # 'jesse' 是实参
```
