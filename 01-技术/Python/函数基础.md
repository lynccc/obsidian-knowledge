# ⚙️ Python 函数基础

## 核心概念

函数 = **把一段代码"打包"起来，起个名字，以后随时调用**

类比：**函数就像微波炉** —— 你把食物放进去（输入），按一下按钮（调用），食物就热好了（输出）。你不需要每次热食物都重新造一个微波炉。

```python
# 定义函数（制造微波炉）
def greet_user():
    print("Hello!")

# 调用函数（使用微波炉）
greet_user()

# 输出：
# Hello!
```

---

## 一、定义函数

```python
# def = "定义"（define 的缩写）
# greet_user = 函数名（自己起的）
# () = 参数列表（这里没有参数）
# : = 代码块开始

def greet_user():
    """显示简单的问候语"""     # 这是文档字符串，描述函数做什么
    print("Hello!")

# 调用函数
greet_user()

# 输出：
# Hello!
```

**逐行解释：**
1. `def greet_user():` — 定义一个叫 `greet_user` 的函数
2. `"""显示简单的问候语"""` — 文档字符串（可选），描述函数的用途
3. `print("Hello!")` — 函数体，调用函数时会执行这段代码
4. `greet_user()` — 调用函数，执行函数体里的代码

---

## 二、传递信息

函数可以接收**参数**（就像微波炉可以放不同的食物）：

```python
# username 是参数（接收传入的值）
def greet_user(username):
    """显示个性化的问候语"""
    print("Hello, " + username.title() + "!")

# 调用函数，传入 'jesse'
greet_user('jesse')

# 输出：
# Hello, Jesse!

# 传入不同的值，得到不同的结果
greet_user('sarah')

# 输出：
# Hello, Sarah!
```

**类比：** 就像微波炉可以热不同的食物 —— 你放面包进去，出来的是热面包；你放牛奶进去，出来的是热牛奶。

---

## 三、实参和形参

- **形参**（parameter）：定义函数时的参数名，就像"占位符"
- **实参**（argument）：调用函数时传入的实际值

```python
# 定义函数时，username 是形参（占位符）
def greet_user(username):
    print("Hello, " + username.title() + "!")

# 调用函数时，'jesse' 是实参（实际的值）
greet_user('jesse')

# 输出：
# Hello, Jesse!
```

**类比：** 形参就像微波炉上的"食物"标签（告诉你这里放食物），实参就像你实际放进去的"面包"（具体的东西）。

---

## 四、函数的好处

### 1. 避免重复代码

```python
# ❌ 没有函数：同样的代码写了 3 遍
print("Hello, Jesse!")
print("Hello, Sarah!")
print("Hello, Edward!")

# ✅ 用函数：写一次，调用 3 次
def greet_user(username):
    print("Hello, " + username.title() + "!")

greet_user('jesse')
greet_user('sarah')
greet_user('edward')
```

### 2. 代码更清晰

```python
# 函数名就能说明代码在做什么
def calculate_area(length, width):
    return length * width

area = calculate_area(5, 3)
print(area)

# 输出：
# 15
```

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| `def` | 定义函数 | 制造微波炉 |
| 函数名 | 给函数起名字 | 给微波炉贴标签 |
| 形参 | 定义时的占位符 | "食物"标签 |
| 实参 | 调用时传入的值 | 实际放进去的面包 |
| 调用函数 | 执行函数里的代码 | 按下启动按钮 |
