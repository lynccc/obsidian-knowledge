# 🔄 Python 列表排序

## 核心概念

排序 = **把列表中的元素按一定顺序排列**

类比：**排序就像整理书架** —— 你可以按书名排序（字母顺序）、按大小排序，排完之后书架上的书就整齐了。

---

## 一、永久排序

### 📌 先认识：sort() — 永久修改原列表的顺序

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

# 按字母顺序排序（永久修改原列表）
cars.sort()
print(cars)

# 输出：
# ['audi', 'bmw', 'subaru', 'toyota']
```

**⚠️ `sort()` 会直接修改原列表！** 就像你把书架上的书重新排列了，原来的顺序就没了。

### 反向排序

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

# reverse=True 表示反向排序（从 Z 到 A）
cars.sort(reverse=True)
print(cars)

# 输出：
# ['toyota', 'subaru', 'bmw', 'audi']
```

---

## 二、临时排序

### 📌 先认识：sorted() — 返回排序后的新列表，不修改原列表

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

# sorted() 返回排序后的结果，但原列表不变
print(sorted(cars))

# 输出：
# ['audi', 'bmw', 'subaru', 'toyota']

# 原列表还是原来的顺序
print(cars)

# 输出：
# ['bmw', 'audi', 'toyota', 'subaru']
```

**类比：** `sorted()` 就像你复印了一份书架的目录，按顺序排好，但书架上的书没动。

---

## 三、反转列表

### 📌 先认识：reverse() — 反转列表顺序（不是排序！）

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

# reverse() 反转顺序（把最后一个变第一个，第一个变最后一个）
cars.reverse()
print(cars)

# 输出：
# ['subaru', 'toyota', 'audi', 'bmw']
```

**⚠️ 注意：** `reverse()` 不是排序，只是把顺序颠倒。就像你把排队的人从后往前重新排，不管他们原来是什么顺序。

---

## 四、获取列表长度

### 📌 先认识：len() — 获取列表中有多少个元素

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']

# len() 返回列表的长度（元素个数）
print(len(cars))

# 输出：
# 4
```

**类比：** `len()` 就像数"书架上有几本书"。

---

## 五、常见错误

### 错误：索引超出范围

```python
cars = ['bmw', 'audi', 'toyota']   # 只有 3 个元素

# 最大索引是 2（从 0 数到 2）
print(cars[3])   # ❌ 索引 3 超出了范围

# 输出：
# IndexError: list index out of range
# 翻译：列表索引超出范围
```

**原因：** 列表有 3 个元素，索引分别是 0、1、2。索引 3 不存在。

---

## 总结

| 方法 | 作用 | 是否修改原列表 | 类比 |
|------|------|---------------|------|
| `sort()` | 排序 | ✅ 永久修改 | 把书架上的书重新排列 |
| `sorted()` | 临时排序 | ❌ 不修改 | 复印一份目录排好 |
| `reverse()` | 反转顺序 | ✅ 永久修改 | 把排队的人从后往前排 |
| `len()` | 获取长度 | ❌ 不修改 | 数书架上有几本书 |
