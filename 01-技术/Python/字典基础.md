# 📖 Python 字典基础

## 核心概念

字典 = **键值对的集合**，每个"键"对应一个"值"

类比：**字典就像通讯录** —— 你用名字（键）查找电话号码（值）。`{'张三': '13800138000'}` 就是说"张三的电话是 13800138000"。

```python
alien_0 = {'color': 'green', 'points': 5}
```

这句话的意思是：**创建一个字典，color 对应 green，points 对应 5**

---

## 一、创建字典

```python
# 创建一个外星人字典
alien_0 = {'color': 'green', 'points': 5}

# 打印整个字典
print(alien_0)

# 输出：
# {'color': 'green', 'points': 5}
```

**字典的格式：** `{键1: 值1, 键2: 值2, ...}`，键和值用冒号 `:` 分隔，每对之间用逗号 `,` 分隔。

---

## 二、访问值

用**键**来访问对应的**值**：

```python
alien_0 = {'color': 'green', 'points': 5}

# 用键访问值
print(alien_0['color'])

# 输出：
# green

print(alien_0['points'])

# 输出：
# 5
```

**类比：** 就像你在通讯录里查"张三"的电话 → `alien_0['color']` → 得到 `'green'`。

---

## 三、添加键值对

```python
alien_0 = {'color': 'green', 'points': 5}

# 添加新的键值对
alien_0['x_position'] = 0       # x 坐标 = 0
alien_0['y_position'] = 25      # y 坐标 = 25

print(alien_0)

# 输出：
# {'color': 'green', 'points': 5, 'x_position': 0, 'y_position': 25}
```

**类比：** 就像你在通讯录里新增一个联系人 —— 写上名字（键）和电话（值）。

---

## 四、创建空字典

```python
# 先创建一个空字典
alien_0 = {}

# 再逐步添加键值对
alien_0['color'] = 'green'
alien_0['points'] = 5

print(alien_0)

# 输出：
# {'color': 'green', 'points': 5}
```

---

## 五、修改值

```python
alien_0 = {'color': 'green'}
print("The alien is " + alien_0['color'] + ".")

# 输出：
# The alien is green.

# 修改 color 对应的值
alien_0['color'] = 'yellow'
print("The alien is now " + alien_0['color'] + ".")

# 输出：
# The alien is now yellow.
```

**类比：** 就像更新通讯录 —— 张三换了电话号码，你把旧号码改成新号码。

---

## 六、删除键值对

### 📌 先认识：del — 删除指定的键值对

```python
alien_0 = {'color': 'green', 'points': 5}

# 删除 'points' 这个键值对
del alien_0['points']
print(alien_0)

# 输出：
# {'color': 'green'}
```

**`del` = 永久删除。** 就像从通讯录里删掉一个联系人，删了就没了。

---

## 总结

| 操作 | 语法 | 类比 |
|------|------|------|
| 创建字典 | `{键: 值, ...}` | 建立通讯录 |
| 访问值 | `字典[键]` | 查通讯录 |
| 添加 | `字典[新键] = 新值` | 新增联系人 |
| 修改 | `字典[键] = 新值` | 更新电话号码 |
| 删除 | `del 字典[键]` | 删掉联系人 |
