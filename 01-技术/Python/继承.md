# 🧬 Python 继承

## 核心概念

继承 = **子类自动拥有父类的所有属性和方法**，还可以添加自己独有的

类比：**继承就像遗传** —— 孩子（子类）继承了父母（父类）的外貌和性格（属性和方法），但孩子也有自己独特的个性（新增的属性和方法）。

```python
# 父类：Car（汽车）
class Car():
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

# 子类：ElectricCar（电动汽车）继承了 Car
class ElectricCar(Car):
    def __init__(self, make, model, year):
        super().__init__(make, model, year)   # 调用父类的初始化
        self.battery_size = 70                # 新增自己的属性
```

## 一、创建子类

```python
# 父类：Car
class Car():
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer_reading = 0

    def get_descriptive_name(self):
        long_name = str(self.year) + ' ' + self.make + ' ' + self.model
        return long_name.title()

    def read_odometer(self):
        print("This car has " + str(self.odometer_reading) + " miles on it.")

# 子类：ElectricCar 继承 Car
class ElectricCar(Car):
    """电动汽车的独特之处"""

    def __init__(self, make, model, year):
        """初始化父类的属性"""
        super().__init__(make, model, year)   # 调用父类的 __init__
        self.battery_size = 70                # 新增属性：电池容量

    def describe_battery(self):
        """打印电池容量"""
        print("This car has a " + str(self.battery_size) + "-kWh battery.")

# 创建电动汽车实例
my_tesla = ElectricCar('tesla', 'model s', 2016)
print(my_tesla.get_descriptive_name())   # 继承自父类的方法
my_tesla.describe_battery()              # 子类自己的方法

# 输出：
# 2016 Tesla Model S
# This car has a 70-kWh battery.
```

**逐行解释：**
1. `class ElectricCar(Car):` — 定义 ElectricCar 类，括号里的 `Car` 表示"继承 Car"
2. `super().__init__(make, model, year)` — `super()` 调用父类的方法，把参数传给父类的 `__init__`
3. `self.battery_size = 70` — 子类新增的属性，父类没有
4. `my_tesla.get_descriptive_name()` — 子类可以使用父类的方法

**类比：** 就像孩子遗传了父母的身高和眼睛颜色（继承属性），但孩子有自己的爱好（新增属性）。

## 二、重写方法

子类可以**重写**父类的方法，用自己版本的实现：

```python
class ElectricCar(Car):
    def __init__(self, make, model, year):
        super().__init__(make, model, year)
        self.battery_size = 70

    def fill_gas_tank(self):
        """重写父类的方法：电动车不需要加油"""
        print("This car doesn't need a gas tank!")
```

**类比：** 就像父母说"要学钢琴"，但孩子说"我想学吉他" —— 孩子用自己的方式覆盖了父母的期望。

## 三、将实例用作属性

可以把一个类的实例作为另一个类的属性：

```python
# 电池类（单独定义）
class Battery():
    def __init__(self, battery_size=70):
        self.battery_size = battery_size

    def describe_battery(self):
        print("This car has a " + str(self.battery_size) + "-kWh battery.")

# 电动汽车类，把 Battery 实例作为属性
class ElectricCar(Car):
    def __init__(self, make, model, year):
        super().__init__(make, model, year)
        self.battery = Battery()   # 把 Battery 实例作为属性

my_tesla = ElectricCar('tesla', 'model s', 2016)
my_tesla.battery.describe_battery()   # 通过 battery 属性调用方法

# 输出：
# This car has a 70-kWh battery.
```

**类比：** 就像汽车里有一个独立的电池系统 —— 电池有自己的规格和功能，但它是汽车的一部分。

## 四、导入类

### 从模块导入单个类

```python
from car import Car, ElectricCar
```

### 从模块导入多个类

```python
from car import Car
from electric_car import ElectricCar
```

### 导入整个模块

```python
import car
my_car = car.Car('audi', 'a4', 2016)
```

### 导入模块中所有类（不推荐）

```python
from car import *   # 可能导致命名冲突
```

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 父类 | 被继承的类 | 父母 |
| 子类 | 继承父类的类 | 孩子 |
| `class 子类(父类):` | 定义继承关系 | "孩子遗传父母" |
| `super()` | 调用父类的方法 | "用父母的基因" |
| 重写方法 | 子类用自己的版本覆盖父类 | "孩子有自己的想法" |
| 实例作为属性 | 把一个类的实例放进另一个类 | "汽车里的电池系统" |
