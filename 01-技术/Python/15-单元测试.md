# 🧪 Python 单元测试

## 核心概念

单元测试 = **自动检查代码是否正确**，就像考试一样

类比：**单元测试就像自动阅卷机** —— 你把答案（代码的输出）和标准答案（预期结果）对比，机器自动告诉你对不对。如果不对，它会告诉你哪里错了。

```python
# 被测试的函数
def get_formatted_name(first, last):
    full_name = first + ' ' + last
    return full_name.title()

# 测试：检查函数的输出是否正确
result = get_formatted_name('janis', 'joplin')
assert result == 'Janis Joplin'    # 如果不相等，测试失败
```

---

## 一、测试函数

### 第一步：写一个要测试的函数

```python
# name_function.py（被测试的文件）
def get_formatted_name(first, last):
    """返回整洁的姓名"""
    full_name = first + ' ' + last
    return full_name.title()
```

### 第二步：写测试代码

```python
# test_name_function.py（测试文件）
import unittest                        # 导入 unittest 模块
from name_function import get_formatted_name  # 导入要测试的函数

class NamesTestCase(unittest.TestCase):
    """测试 name_function.py"""

    def test_first_last_name(self):
        """能否正确处理 Janis Joplin 这样的姓名？"""
        formatted_name = get_formatted_name('janis', 'joplin')  # 调用函数
        self.assertEqual(formatted_name, 'Janis Joplin')        # 检查结果

# 运行测试
unittest.main()
```

**逐行解释：**
1. `import unittest` — 导入 Python 自带的测试模块
2. `from name_function import get_formatted_name` — 导入要测试的函数
3. `class NamesTestCase(unittest.TestCase):` — 定义测试类，继承 `unittest.TestCase`
4. `def test_first_last_name(self):` — 定义测试方法（方法名必须以 `test_` 开头）
5. `self.assertEqual(formatted_name, 'Janis Joplin')` — 断言：实际值 == 预期值
6. `unittest.main()` — 运行所有测试

**运行结果：**
```
.
----------------------------------------------------------------------
Ran 1 test in 0.001s

OK
```

`.` 表示一个测试通过。如果有失败，会显示 `F` 和错误信息。

## 二、常用断言方法

断言 = **"我断言这个条件是对的"**，如果不对，测试就失败。

| 方法 | 用途 | 示例 |
|------|------|------|
| `assertEqual(a, b)` | a == b | 结果等于预期 |
| `assertNotEqual(a, b)` | a != b | 结果不等于某个值 |
| `assertTrue(x)` | x 为 True | 条件为真 |
| `assertFalse(x)` | x 为 False | 条件为假 |
| `assertIn(item, list)` | item 在 list 中 | 元素在列表里 |
| `assertNotIn(item, list)` | item 不在 list 中 | 元素不在列表里 |

```python
# 示例：各种断言
self.assertEqual(2 + 2, 4)              # 2+2 等于 4？
self.assertTrue(5 > 3)                   # 5 大于 3？
self.assertIn('apple', ['apple', 'banana'])  # apple 在列表里？
```

**类比：** 断言就像考试时说"我确定答案是 A"。如果答案确实是 A，你就对了；如果不是，你就错了。

## 三、测试类

### 第一步：写一个要测试的类

```python
# survey.py（被测试的文件）
class AnonymousSurvey():
    """收集匿名调查问卷的答案"""

    def __init__(self, question):
        self.question = question
        self.responses = []          # 存储所有答案的列表

    def show_question(self):
        """显示调查问题"""
        print(self.question)

    def store_response(self, new_response):
        """存储一个答案"""
        self.responses.append(new_response)   # append() 在末尾添加

    def show_results(self):
        """显示所有答案"""
        print("Survey results:")
        for response in self.responses:
            print('- ' + response)
```

### 第二步：写测试代码

```python
# test_survey.py（测试文件）
import unittest
from survey import AnonymousSurvey

class TestAnonymousSurvey(unittest.TestCase):

    def setUp(self):
        """在每个测试方法运行前，先执行这个方法"""
        question = "What language did you first learn to speak?"
        self.my_survey = AnonymousSurvey(question)   # 创建调查对象
        self.responses = ['English', 'Spanish', 'Mandarin']  # 准备答案

    def test_store_single_response(self):
        """测试存储单个答案"""
        self.my_survey.store_response(self.responses[0])  # 存储一个答案
        self.assertIn(self.responses[0], self.my_survey.responses)  # 检查是否存进去了

    def test_store_three_responses(self):
        """测试存储三个答案"""
        for response in self.responses:        # 存储三个答案
            self.my_survey.store_response(response)
        for response in self.responses:        # 检查每个答案都在里面
            self.assertIn(response, self.my_survey.responses)

# 运行测试
unittest.main()
```

## 四、setUp() 方法

`setUp()` = **在每个测试方法运行前，先执行的"准备工作"**

```python
def setUp(self):
    """在每个测试方法运行前，先执行这个方法"""
    question = "What language did you first learn to speak?"
    self.my_survey = AnonymousSurvey(question)
    self.responses = ['English', 'Spanish', 'Mandarin']
```

**为什么要用 `setUp()`？** 因为每个测试方法都需要一个调查对象和一组答案。如果不用 `setUp()`，每个测试方法都要重复写这些代码。

**类比：** `setUp()` 就像考试前老师发试卷 —— 每次考试（测试方法）前都要先发试卷（准备工作），但你不需要每次考试都重新准备教室。

## 五、测试的好处

| 好处 | 说明 |
|------|------|
| 自动化 | 不需要手动检查每个功能 |
| 可重复 | 随时运行，确保代码没被改坏 |
| 信心 | 修改代码后，运行测试就知道有没有破坏什么 |
| 文档 | 测试代码本身就是"这个函数应该做什么"的说明 |

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 单元测试 | 自动检查代码是否正确 | 自动阅卷机 |
| `unittest` | Python 测试模块 | 阅卷机的操作系统 |
| `TestCase` | 测试类 | 一份试卷 |
| `test_` 开头 | 测试方法 | 试卷上的题目 |
| `assertEqual` | 断言相等 | "我确定答案是 A" |
| `setUp()` | 测试前的准备工作 | 考前发试卷 |
