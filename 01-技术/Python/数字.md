# 🔢 Python 数字

## 核心概念

- **整数** — 没有小数点的数字
- **浮点数** — 带小数点的数字
- 数字可以直接参与运算

## 整数运算

```python
# 基本运算
2 + 3    # 5（加法）
3 - 2    # 1（减法）
2 * 3    # 6（乘法）
3 / 2    # 1.5（除法）

# 乘方
3 ** 2   # 9（3的平方）
3 ** 3   # 27（3的立方）
10 ** 6  # 1000000

# 运算次序
2 + 3 * 4    # 14（先乘后加）
(2 + 3) * 4  # 20（括号优先）
```

## 浮点数

```python
0.1 + 0.1   # 0.2
0.2 + 0.2   # 0.4

# 注意：浮点数可能有精度问题
0.2 + 0.1   # 0.30000000000000004
```

> 💡 这是所有编程语言的通病，不用担心

## 类型转换

```python
# 数字转字符串（避免 TypeError）
age = 23
message = "Happy " + str(age) + "rd Birthday!"
print(message)  # Happy 23rd Birthday!
```

> ⚠️ 字符串和数字不能直接拼接，需要用 `str()` 转换

## Python 2 vs Python 3

```python
# Python 2：整数除法只保留整数部分
3 / 2      # 1（Python 2）
3 / 2      # 1.5（Python 3）

# Python 2 中要用浮点数
3.0 / 2    # 1.5
```
