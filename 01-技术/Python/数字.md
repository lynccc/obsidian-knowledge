# 🔢 Python 数字

## 核心概念

Python 中有两种数字：
- **整数** — 没有小数点的数字（如 1、42、-7）
- **浮点数** — 带小数点的数字（如 3.14、0.5、-2.0）

类比：**整数就像数硬币**（1个、2个、3个），**浮点数就像称重量**（1.5公斤、0.75升）。

---

## 一、整数运算

```python
# 加法
2 + 3       # 5
print(2 + 3)

# 减法
3 - 2       # 1
print(3 - 2)

# 乘法
2 * 3       # 6
print(2 * 3)

# 除法（结果是浮点数）
3 / 2       # 1.5
print(3 / 2)

# 输出：
# 5
# 1
# 6
# 1.5
```

### 乘方运算

**`**` 是乘方符号**，`3 ** 2` 就是 3 的 2 次方（3²）。

```python
3 ** 2      # 9（3×3）
print(3 ** 2)

3 ** 3      # 27（3×3×3）
print(3 ** 3)

10 ** 6     # 1000000（10的6次方）
print(10 ** 6)

# 输出：
# 9
# 27
# 1000000
```

### 运算次序

Python 遵守数学的运算规则：**先乘除，后加减；括号最优先**。

```python
# 先算 3×4=12，再算 2+12=14
2 + 3 * 4       # 14
print(2 + 3 * 4)

# 括号优先：先算 2+3=5，再算 5×4=20
(2 + 3) * 4     # 20
print((2 + 3) * 4)

# 输出：
# 14
# 20
```

## 二、浮点数

浮点数 = **带小数点的数字**。

```python
0.1 + 0.1   # 0.2
print(0.1 + 0.1)

0.2 + 0.2   # 0.4
print(0.2 + 0.2)

# 输出：
# 0.2
# 0.4
```

### ⚠️ 浮点数的精度问题

```python
0.2 + 0.1   # 0.30000000000000004（不是精确的 0.3！）
print(0.2 + 0.1)

# 输出：
# 0.30000000000000004
```

**为什么会这样？** 计算机用二进制存储数字，有些小数（如 0.1）在二进制中无法精确表示，就像 1/3 = 0.33333... 一样，永远写不完。这是所有编程语言都有的问题，不用担心。

## 三、类型转换

**字符串和数字不能直接拼接**，需要用 `str()` 把数字转成字符串。

### 📌 先认识：str() — 把数字变成字符串

```python
age = 23
print("Happy " + str(age) + "rd Birthday!")

# 输出：
# Happy 23rd Birthday!
```

**为什么需要 `str()`？** Python 不知道你想把数字 23 当作文字 "23" 来拼接。就像你不能把苹果和橙子直接相加，需要先告诉 Python "把数字当成文字来用"。

```python
# ❌ 错误：直接拼接字符串和数字
age = 23
print("Happy " + age + "rd Birthday!")
# 输出：
# TypeError: can only concatenate str (not "int") to str
# 翻译：字符串只能和字符串拼接，不能和整数拼接

# ✅ 正确：用 str() 转换
age = 23
print("Happy " + str(age) + "rd Birthday!")
# 输出：
# Happy 23rd Birthday!
```

## 四、Python 2 vs Python 3

Python 2 和 Python 3 在除法上有一个重要区别：

```python
# Python 2：整数除法只保留整数部分（小数部分被丢弃）
3 / 2      # 1（Python 2）
# 因为 Python 2 认为：两个整数相除，结果也应该是整数

# Python 3：整数除法得到浮点数（保留小数部分）
3 / 2      # 1.5（Python 3）
# Python 3 更"诚实"，给出真实的计算结果
```

**如果你用的是 Python 3（推荐），不需要担心这个问题。**

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 整数 | 没有小数点的数字 | 数硬币（1个、2个） |
| 浮点数 | 带小数点的数字 | 称重量（1.5公斤） |
| `+` `-` `*` `/` | 加减乘除 | 和数学一样 |
