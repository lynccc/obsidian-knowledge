# 📋 Python 列表基础

## 核心概念

列表 = **按顺序排列的一组数据**，用方括号 `[]` 表示

类比：**列表就像排队** —— 每个人（元素）都有自己的位置（索引），而且顺序是固定的。你可以叫"第1个人"、"第2个人"来找到他们。

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']
```

这句话的意思是：**创建一个列表，里面有4个元素，按顺序排列**

---

## 一、创建列表

```python
# 创建一个包含4个自行车品牌的列表
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 打印整个列表
print(bicycles)

# 输出：
# ['trek', 'cannondale', 'redline', 'specialized']
```

**列表里可以放任何类型的数据：**
```python
# 字符串列表
fruits = ['苹果', '香蕉', '橘子']

# 数字列表
scores = [95, 87, 92, 78]

# 混合列表（可以放不同类型，但不推荐）
mixed = ['hello', 42, True, 3.14]

# 空列表
empty = []
```

---

## 二、访问元素（索引）

索引 = **元素在列表中的"位置编号"**，从 **0** 开始！

类比：**就像楼房的楼层** —— 地面是 0 楼，1 楼是上面一层，2 楼再上面……Python 的索引也是从 0 开始数的。

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 正向索引（从 0 开始）
print(bicycles[0])   # 第 1 个元素（索引 0）

# 输出：
# trek

print(bicycles[1])   # 第 2 个元素（索引 1）

# 输出：
# cannondale
```

### 反向索引（从末尾开始）

用**负数**索引，`-1` 表示最后一个，`-2` 表示倒数第二个。

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# -1 = 最后一个
print(bicycles[-1])

# 输出：
# specialized

# -2 = 倒数第二个
print(bicycles[-2])

# 输出：
# redline
```

**类比：** 就像排队时，你可以说"第1个人"（正向），也可以说"最后一个人"（反向）。

---

## 三、使用列表中的元素

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 从列表中取出第一个品牌，拼成一句话
message = "My first bicycle was a " + bicycles[0].title() + "."
print(message)

# 输出：
# My first bicycle was a Trek.
```

**逐行解释：**
- `bicycles[0]` 取出第一个元素 `'trek'`
- `.title()` 把 `'trek'` 变成 `'Trek'`（首字母大写）
- 用 `+` 拼接字符串

---

## 四、常见错误

### 错误：索引超出范围

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 只有 4 个元素，最大索引是 3（从 0 数到 3）
print(bicycles[4])   # ❌ 索引 4 超出了范围

# 输出：
# IndexError: list index out of range
# 翻译：列表索引超出范围
```

**原因：** 列表有 4 个元素，索引分别是 0、1、2、3。索引 4 不存在，就像排队只有 4 个人，你叫"第5个人"当然没人答应。

---

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| 列表 `[]` | 按顺序排列的一组数据 | 排队的一群人 |
| 索引 `[0]` | 元素的位置编号 | 第几个人 |
| 正向索引 | 从 0 开始往后数 | 从前向后数 |
| 反向索引 `[-1]` | 从末尾开始往前数 | "最后一个人" |
