# 📋 Python 列表基础

## 核心概念

列表 = **按顺序排列的一组数据**，用方括号 `[]` 表示

类比：**列表就像排队** —— 每个人（元素）都有自己的位置（索引），而且顺序是固定的。你可以叫"第1个人"、"第2个人"来找到他们。

（如果你还不熟悉 Python 的基础语法，建议先看 [[Python学习路线]]）

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']
```

这句话的意思是：**创建一个列表，里面有4个元素，按顺序排列**

---

## 一、创建列表

```python
# 创建一个包含4个自行车品牌的列表
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 打印整个列表
print(bicycles)

# 输出：
# ['trek', 'cannondale', 'redline', 'specialized']
```

**列表里可以放任何类型的数据：**
```python
# 字符串列表
fruits = ['苹果', '香蕉', '橘子']

# 数字列表
scores = [95, 87, 92, 78]

# 混合列表（可以放不同类型，但不推荐）
mixed = ['hello', 42, True, 3.14]

# 空列表
empty = []
```

---

## 二、访问列表元素

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 访问第1个元素（索引从0开始！）
print(bicycles[0])   # 输出：trek

# 访问第2个元素
print(bicycles[1])   # 输出：cannondale

# 访问最后一个元素（用 -1）
print(bicycles[-1])  # 输出：specialized

# 访问倒数第2个元素（用 -2）
print(bicycles[-2])  # 输出：redline
```

**关键：** 列表的索引从 `0` 开始，不是从 `1` 开始！

类比：**就像楼层编号** —— 欧美国家的楼层从 `0` 开始（Ground Floor = 0层），而不是 `1` 开始。

---

## 三、修改列表元素

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 修改第1个元素
bicycles[0] = 'giant'
print(bicycles)

# 输出：
# ['giant', 'cannondale', 'redline', 'specialized']
```

---

## 四、添加列表元素

### 方法1：append() — 在末尾添加

```python
bicycles = ['trek', 'cannondale', 'redline']

# 在末尾添加 'specialized'
bicycles.append('specialized')
print(bicycles)

# 输出：
# ['trek', 'cannondale', 'redline', 'specialized']
```

### 方法2：insert() — 在指定位置插入

```python
bicycles = ['trek', 'cannondale', 'redline']

# 在索引 1 的位置插入 'giant'（原来的元素后移）
bicycles.insert(1, 'giant')
print(bicycles)

# 输出：
# ['trek', 'giant', 'cannondale', 'redline']
```

---

## 五、删除列表元素

### 方法1：del 语句 — 按索引删除

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 删除第2个元素
del bicycles[1]
print(bicycles)

# 输出：
# ['trek', 'redline', 'specialized']
```

### 方法2：pop() — 删除并返回

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 删除最后一个元素，并返回它
popped = bicycles.pop()
print(popped)       # 输出：specialized
print(bicycles)      # 输出：['trek', 'cannondale', 'redline']

# 删除指定位置的元素
popped = bicycles.pop(1)
print(popped)       # 输出：cannondale
print(bicycles)      # 输出：['trek', 'redline']
```

### 方法3：remove() — 按值删除

```python
bicycles = ['trek', 'cannondale', 'redline', 'specialized']

# 删除值为 'redline' 的元素
bicycles.remove('redline')
print(bicycles)

# 输出：
# ['trek', 'cannondale', 'specialized']
```

## 六、列表操作

（更多列表操作，详见 [[列表操作]] 和 [[列表排序]]）

```python
# 列表长度
bicycles = ['trek', 'cannondale', 'redline']
print(len(bicycles))   # 输出：3

# 列表排序
bicycles.sort()
print(bicycles)        # 输出：['cannondale', 'redline', 'trek']

# 列表反转
bicycles.reverse()
print(bicycles)        # 输出：['trek', 'redline', 'cannondale']
```
