# ❓ Python 条件测试

## 核心概念

条件测试 = **判断一个条件是否成立**，结果是 `True`（真）或 `False`（假）

类比：**条件测试就像法官判案** —— 法官会问"被告有没有做这件事？"，答案只有两种：有（True）或没有（False）。

```python
age = 18
age >= 18     # True（18 大于等于 18 → 成立）
age > 21      # False（18 不大于 21 → 不成立）
```

---

## 一、相等判断

用 `==` 判断两个值是否相等（注意是**两个等号**，一个等号是赋值）。

```python
car = 'bmw'

# == 判断是否相等
car == 'bmw'      # True（相等）
print(car == 'bmw')

car == 'audi'     # False（不相等）
print(car == 'audi')

# 输出：
# True
# False
```

**⚠️ 区分 `=` 和 `==`：**
- `=` 是赋值：`car = 'bmw'` → 把 'bmw' 存进 car
- `==` 是判断：`car == 'bmw'` → 问"car 是不是 'bmw'？"

### 不区分大小写的比较

```python
car = 'Audi'

# 直接比较：大小写不同 → False
car == 'audi'         # False
print(car == 'audi')

# 先转小写再比较 → True
car.lower() == 'audi'  # True
print(car.lower() == 'audi')

# 输出：
# False
# True
```

---

## 二、不等判断

用 `!=` 判断两个值是否**不相等**。

```python
requested_topping = 'mushrooms'

# != 判断是否不等
requested_topping != 'anchovies'   # True（不相等）
print(requested_topping != 'anchovies')

# 输出：
# True
```

---

## 三、数字比较

```python
age = 18

age == 18   # True（等于）
age != 20   # True（不等于）
age < 20    # True（小于）
age <= 18   # True（小于等于）
age > 21    # False（大于）
age >= 18   # True（大于等于）

print(age == 18)   # True
print(age > 21)    # False

# 输出：
# True
# False
```

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `18 == 18` | True |
| `!=` | 不等于 | `18 != 20` | True |
| `<` | 小于 | `18 < 20` | True |
| `<=` | 小于等于 | `18 <= 18` | True |
| `>` | 大于 | `18 > 21` | False |
| `>=` | 大于等于 | `18 >= 18` | True |

## 四、多个条件组合

### and — 两个条件都满足才为 True

```python
age_0 = 22
age_1 = 18

# 两个条件都满足？→ False（age_1 不大于等于 21）
age_0 >= 21 and age_1 >= 21
print(age_0 >= 21 and age_1 >= 21)

# 输出：
# False
```

**类比：** `and` 就像"并且" —— "你既要有身份证，**并且**要满18岁"，两个条件都要满足。

### or — 至少一个条件满足就为 True

```python
age_0 = 22
age_1 = 18

# 至少一个条件满足？→ True（age_0 大于等于 21）
age_0 >= 21 or age_1 >= 21
print(age_0 >= 21 or age_1 >= 21)

# 输出：
# True
```

**类比：** `or` 就像"或者" —— "你有身份证，**或者**你满18岁"，满足一个就行。

## 五、检查元素是否在列表中

### 📌 先认识：in — 检查是否在列表中

```python
requested_toppings = ['mushrooms', 'onions', 'pineapple']

# in 检查是否在列表中
'mushrooms' in requested_toppings    # True（在列表中）
print('mushrooms' in requested_toppings)

'pepperoni' in requested_toppings    # False（不在列表中）
print('pepperoni' in requested_toppings)

# 输出：
# True
# False
```

**类比：** `in` 就像问"这个人在不在这个名单上？"

### 📌 先认识：not in — 检查是否不在列表中

```python
banned_users = ['andrew', 'carolina', 'david']
user = 'marie'

# not in 检查是否不在列表中
user not in banned_users   # True（marie 不在黑名单中）
print(user not in banned_users)

# 输出：
# True
```

**类比：** `not in` 就像问"这个人有没有被禁止？" → 没有 → 可以进。

## 六、布尔值

布尔值只有两个：`True`（真）和 `False`（假）。

```python
game_active = True      # 游戏正在进行
can_edit = False        # 不能编辑

print(game_active)      # True
print(can_edit)         # False

# 输出：
# True
# False
```

**类比：** 布尔值就像开关 —— 只有"开"（True）和"关"（False）两种状态。

## 总结

| 运算符 | 含义 | 类比 |
|--------|------|------|
| `==` | 等于 | "是不是？" |
| `!=` | 不等于 | "是不是不一样？" |
| `<` `<=` `>` `>=` | 大小比较 | 比大小 |
| `and` | 两个都满足 | "并且" |
| `or` | 至少一个满足 | "或者" |
| `in` | 在列表中 | "在不在名单上？" |
| `not in` | 不在列表中 | "有没有被禁止？" |
| `True` / `False` | 布尔值 | 开关（开/关） |
