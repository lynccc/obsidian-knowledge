# ❓ Python 条件测试

## 核心概念

- 条件测试返回 `True` 或 `False`
- 用 `==` 判断相等，`!=` 判断不等
- 可以用 `and`、`or` 组合条件
- `in` 检查是否在列表中

## 相等判断

```python
car = 'bmw'
car == 'bmw'    # True
car == 'audi'   # False

# 不区分大小写
car = 'Audi'
car.lower() == 'audi'  # True
```

## 不等判断

```python
requested_topping = 'mushrooms'
requested_topping != 'anchovies'  # True
```

## 数字比较

```python
age = 18
age == 18   # True
age != 20   # True
age < 20    # True
age <= 18   # True
age > 21    # False
age >= 18   # True
```

## 多个条件

```python
# and — 两个都满足
age_0 = 22
age_1 = 18
age_0 >= 21 and age_1 >= 21  # False

# or — 至少一个满足
age_0 = 22
age_1 = 18
age_0 >= 21 or age_1 >= 21   # True
```

## 检查列表

```python
# in — 是否在列表中
requested_toppings = ['mushrooms', 'onions', 'pineapple']
'mushrooms' in requested_toppings   # True
'pepperoni' in requested_toppings   # False

# not in — 是否不在列表中
banned_users = ['andrew', 'carolina', 'david']
user = 'marie'
user not in banned_users  # True
```

## 布尔值

```python
game_active = True
can_edit = False
```
