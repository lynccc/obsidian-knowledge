# 🏷️ Python 类基础

## 核心概念

类 = **创建对象的"模板"**，用来描述一类事物的特征和行为

类比：**类就像饼干模具** —— 模具定义了饼干的形状（属性）和花纹（方法），你可以用同一个模具做出很多块饼干（实例），每块饼干都长得一样，但可以有不同的口味（属性值）。

```python
# 定义一个 Dog 类（制造饼干模具）
class Dog():
    def __init__(self, name, age):
        self.name = name      # 属性：名字
        self.age = age        # 属性：年龄

    def sit(self):            # 方法：蹲下
        print(self.name.title() + " is now sitting.")

    def roll_over(self):      # 方法：打滚
        print(self.name.title() + " rolled over!")
```

## 一、创建类

```python
class Dog():
    """一次模拟小狗的简单尝试"""

    def __init__(self, name, age):
        """初始化属性 name 和 age"""
        self.name = name      # 把传入的 name 存进 self.name
        self.age = age        # 把传入的 age 存进 self.age

    def sit(self):
        """模拟小狗蹲下"""
        print(self.name.title() + " is now sitting.")

    def roll_over(self):
        """模拟小狗打滚"""
        print(self.name.title() + " rolled over!")
```

**逐行解释：**
1. `class Dog():` — 定义一个叫 Dog 的类
2. `__init__` — 特殊方法，创建实例时**自动调用**（构造方法）
3. `self` — 代表"实例本身"，Python 自动传入
4. `self.name = name` — 把传入的值存进实例的属性
5. `def sit(self):` — 定义一个方法（行为）

**类比：**
- `__init__` 就像工厂的"初始化生产线" —— 每次做饼干时，先把面团放进去
- `self` 就像"这块饼干自己" —— 每块饼干都知道自己的口味
- `self.name` 就像饼干上的标签 —— 写着"巧克力味"或"草莓味"

## 二、创建实例

```python
# 用 Dog 类创建一个实例（用模具做一块饼干）
my_dog = Dog('willie', 6)

# 访问属性（看饼干上的标签）
print("My dog's name is " + my_dog.name.title() + ".")
print("My dog is " + str(my_dog.age) + " years old.")

# 调用方法（让饼干做动作）
my_dog.sit()
my_dog.roll_over()

# 输出：
# My dog's name is Willie.
# My dog is 6 years old.
# Willie is now sitting.
# Willie rolled over!
```

**逐行解释：**
1. `my_dog = Dog('willie', 6)` — 用 Dog 类创建一个实例，传入 'willie' 和 6
2. `my_dog.name` — 访问实例的 name 属性
3. `my_dog.sit()` — 调用实例的 sit 方法

## 三、创建多个实例

```python
# 用同一个模具做两块不同的饼干
my_dog = Dog('willie', 6)
your_dog = Dog('lucy', 3)

print("My dog's name is " + my_dog.name.title() + ".")
print("Your dog's name is " + your_dog.name.title() + ".")

my_dog.sit()
your_dog.sit()

# 输出：
# My dog's name is Willie.
# Your dog's name is Lucy.
# Willie is now sitting.
# Lucy is now sitting.
```

**类比：** 同一个饼干模具可以做很多块饼干，每块饼干有自己的口味（属性值），但形状（类的结构）是一样的。

## 四、给属性指定默认值

```python
class Car():
    def __init__(self, make, model, year):
        self.make = make          # 品牌
        self.model = model        # 型号
        self.year = year          # 年份
        self.odometer_reading = 0 # 里程表，默认值是 0

    def read_odometer(self):
        """显示里程表读数"""
        print("This car has " + str(self.odometer_reading) + " miles on it.")

my_new_car = Car('audi', 'a4', 2016)
my_new_car.read_odometer()

# 输出：
# This car has 0 miles on it.
```

**`odometer_reading = 0` = 设置默认值。** 就像新出厂的车，里程表默认是 0。

## 五、修改属性值

### 方法 1：直接修改

```python
my_new_car = Car('audi', 'a4', 2016)

# 直接修改属性值
my_new_car.odometer_reading = 23
my_new_car.read_odometer()

# 输出：
# This car has 23 miles on it.
```

### 方法 2：通过方法修改

```python
class Car():
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer_reading = 0

    def update_odometer(self, mileage):
        """通过方法修改里程表"""
        self.odometer_reading = mileage

my_new_car = Car('audi', 'a4', 2016)
my_new_car.update_odometer(23)    # 通过方法修改
my_new_car.read_odometer()

# 输出：
# This car has 23 miles on it.
```

### 方法 3：通过方法递增

```python
class Car():
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer_reading = 0

    def increment_odometer(self, miles):
        """增加里程"""
        self.odometer_reading += miles

my_new_car = Car('audi', 'a4', 2016)
my_new_car.increment_odometer(100)    # 增加 100 英里
my_new_car.read_odometer()

# 输出：
# This car has 100 miles on it.
```
