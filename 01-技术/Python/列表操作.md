# ✏️ Python 列表操作

## 核心概念

列表是**动态的**，可以随时增删改

类比：**列表就像一排挂钩** —— 你可以在末尾挂新东西（append）、在中间插入（insert）、拿走某个（remove）、或者直接换掉某个（修改）。

---

## 一、修改元素

直接用索引指定位置，赋新值：

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# 把第 1 个元素（索引 0）改成 'ducati'
motorcycles[0] = 'ducati'
print(motorcycles)

# 输出：
# ['ducati', 'yamaha', 'suzuki']
```

**类比：** 就像把挂钩上原来的东西取下来，换一个新的挂上去。

---

## 二、添加元素

### 📌 先认识：append() — 在末尾添加

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# 在列表末尾添加 'ducati'
motorcycles.append('ducati')
print(motorcycles)

# 输出：
# ['honda', 'yamaha', 'suzuki', 'ducati']
```

**`append()` = 在列表的最后面加一个新元素。** 就像排队时，新来的人站到最后面。

### 📌 先认识：insert() — 在指定位置插入

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# 在索引 0 的位置插入 'ducati'（挤到最前面）
motorcycles.insert(0, 'ducati')
print(motorcycles)

# 输出：
# ['ducati', 'honda', 'yamaha', 'suzuki']
```

**`insert(位置, 元素)` = 在指定位置插入一个新元素，原来在那个位置及后面的人都往后挪一位。** 就像有人插队到第1个位置，原来第1个人变成第2个。

---

## 三、删除元素

### 方法 1：del — 删除指定位置（知道位置）

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# 删除索引 0 的元素（第 1 个）
del motorcycles[0]
print(motorcycles)

# 输出：
# ['yamaha', 'suzuki']
```

**`del` = 直接删除，不需要保留被删除的值。** 就像直接把挂钩上的东西扔掉。

### 📌 先认识：pop() — 弹出末尾元素

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# pop() 取出最后一个元素，列表里就没有它了
popped = motorcycles.pop()
print(motorcycles)

# 输出：
# ['honda', 'yamaha']

print(popped)

# 输出：
# suzuki
```

**`pop()` = 取走最后一个元素，同时返回它的值。** 就像从书架末尾拿走一本书，你可以知道拿走的是哪本。

### 📌 先认识：pop(位置) — 弹出指定位置的元素

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# pop(0) 取出索引 0 的元素（第 1 个）
first_owned = motorcycles.pop(0)
print("The first motorcycle I owned was a " + first_owned.title() + ".")

# 输出：
# The first motorcycle I owned was a Honda.
```

### 📌 先认识：remove() — 按值删除

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

# 删除值为 'yamaha' 的元素（不需要知道位置）
motorcycles.remove('yamaha')
print(motorcycles)

# 输出：
# ['honda', 'suzuki']
```

**`remove(值)` = 找到第一个匹配的值并删除。** 就像你说"把那本《Python入门》拿走"，不需要知道它在书架的第几个位置。

**⚠️ 注意：** `remove()` 只删除**第一个**匹配的元素。如果列表里有多个相同的值，只删第一个。

---

## 四、什么时候用哪种删除方式？

| 场景 | 用什么 | 例子 |
|------|--------|------|
| 知道要删第几个 | `del` | `del motorcycles[0]` |
| 需要用被删的值 | `pop()` | `popped = motorcycles.pop()` |
| 知道要删的值 | `remove()` | `motorcycles.remove('yamaha')` |

---

## 总结

| 方法 | 作用 | 类比 |
|------|------|------|
| `列表[i] = 新值` | 修改指定位置的元素 | 换挂钩上的东西 |
| `append()` | 在末尾添加 | 新人站到队尾 |
| `insert(i, 值)` | 在指定位置插入 | 插队到第 i 个位置 |
| `del 列表[i]` | 删除指定位置 | 直接扔掉 |
| `pop()` | 取出末尾元素 | 从书架末尾拿走一本书 |
| `pop(i)` | 取出指定位置元素 | 从书架第 i 个位置拿走 |
| `remove(值)` | 按值删除 | "把那本书拿走" |
