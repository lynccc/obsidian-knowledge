# 🔄 Python 列表排序

## 核心概念

- `sort()` — 永久排序（修改原列表）
- `sorted()` — 临时排序（不修改原列表）
- `reverse()` — 反转列表顺序
- `len()` — 获取列表长度

## 永久排序

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
cars.sort()
print(cars)  # ['audi', 'bmw', 'subaru', 'toyota']（字母顺序）

# 反向排序
cars.sort(reverse=True)
print(cars)  # ['toyota', 'subaru', 'bmw', 'audi']
```

## 临时排序

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
print(sorted(cars))       # ['audi', 'bmw', 'subaru', 'toyota']
print(cars)               # ['bmw', 'audi', 'toyota', 'subaru']（原列表不变）
```

## 反转列表

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
cars.reverse()
print(cars)  # ['subaru', 'toyota', 'audi', 'bmw']（永久反转）
```

## 列表长度

```python
cars = ['bmw', 'audi', 'toyota', 'subaru']
print(len(cars))  # 4
```

## 常见错误

```python
# IndexError: 索引超出范围
cars = ['bmw', 'audi', 'toyota']
print(cars[3])  # ❌ 只有 3 个元素，最大索引是 2
```
