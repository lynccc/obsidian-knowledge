# 📤 Python 参数传递

## 核心概念

参数传递 = **告诉函数"用什么数据来工作"**

类比：**参数就像你去餐厅点菜** —— 你告诉服务员"要一份宫保鸡丁"（参数），厨师就按你的要求做菜（函数执行）。

---

## 一、位置参数

位置参数 = **按顺序匹配**，第 1 个实参给第 1 个形参，第 2 个给第 2 个……

```python
def describe_pet(animal_type, pet_name):
    """显示宠物的信息"""
    print("I have a " + animal_type + ".")
    print("My " + animal_type + "'s name is " + pet_name.title() + ".")

# 按顺序：'hamster' 给 animal_type，'harry' 给 pet_name
describe_pet('hamster', 'harry')

# 输出：
# I have a hamster.
# My hamster's name is Harry.
```

**⚠️ 顺序很重要！** 如果顺序反了：

```python
# 顺序反了：'harry' 给了 animal_type，'hamster' 给了 pet_name
describe_pet('harry', 'hamster')

# 输出：
# I have a harry.
# My harry's name is Hamster.   ← 明显不对！
```

**类比：** 就像点菜时说"宫保鸡丁，微辣"和"微辣，宫保鸡丁" —— 服务员可能会搞混。

---

## 二、关键字参数

关键字参数 = **用名称指定**，顺序无所谓。

```python
def describe_pet(animal_type, pet_name):
    print("I have a " + animal_type + ".")
    print("My " + animal_type + "'s name is " + pet_name.title() + ".")

# 用关键字指定：animal_type='hamster'，pet_name='harry'
describe_pet(animal_type='hamster', pet_name='harry')

# 输出：
# I have a hamster.
# My hamster's name is Harry.

# 顺序反了也没关系，因为用关键字指定了
describe_pet(pet_name='harry', animal_type='hamster')

# 输出：
# I have a hamster.
# My hamster's name is Harry.
```

**类比：** 就像点菜时说"宫保鸡丁要微辣的" —— 明确说了哪个是菜名，哪个是口味，不会搞混。

---

## 三、默认值

默认值 = **参数的"备选项"**，如果调用时没有传入，就用默认值。

```python
# animal_type 的默认值是 'dog'
def describe_pet(pet_name, animal_type='dog'):
    print("I have a " + animal_type + ".")
    print("My " + animal_type + "'s name is " + pet_name.title() + ".")

# 只传 pet_name，animal_type 用默认值 'dog'
describe_pet('willie')

# 输出：
# I have a dog.
# My dog's name is Willie.

# 传入两个参数，覆盖默认值
describe_pet('harry', 'hamster')

# 输出：
# I have a hamster.
# My hamster's name is Harry.
```

**类比：** 就像去咖啡店点咖啡 —— 你说"一杯拿铁"，店员默认给你中杯。如果你说"一杯大杯拿铁"，就覆盖了默认的中杯。

**⚠️ 注意：** 有默认值的参数要放在没有默认值的参数后面。

```python
# ✅ 正确：pet_name 在前（无默认值），animal_type 在后（有默认值）
def describe_pet(pet_name, animal_type='dog'):

# ❌ 错误：有默认值的参数在前面
def describe_pet(animal_type='dog', pet_name):
# SyntaxError: non-default argument follows default argument
```

## 四、等效调用

以下几种调用方式效果完全一样：

```python
def describe_pet(pet_name, animal_type='dog'):
    print("I have a " + animal_type + ".")
    print("My " + animal_type + "'s name is " + pet_name.title() + ".")

# 方式 1：只传必填参数
describe_pet('willie')

# 方式 2：用关键字参数
describe_pet(pet_name='willie')

# 方式 3：用关键字参数指定所有参数
describe_pet(pet_name='willie', animal_type='dog')

# 以上三种方式输出完全一样：
# I have a dog.
# My dog's name is Willie.
```

## 五、任意数量参数

有时候你不知道函数会收到多少个参数，可以用 `*args` 和 `**kwargs`。

### *args — 任意数量的位置参数

```python
# *toppings 会接收所有传入的参数，存成一个元组
def make_pizza(*toppings):
    print(toppings)

make_pizza('pepperoni')

# 输出：
# ('pepperoni',)

make_pizza('mushrooms', 'green peppers', 'extra cheese')

# 输出：
# ('mushrooms', 'green peppers', 'extra cheese')
```

**`*args` = "不管传多少个参数，我都收着"。** 就像餐厅说"不管你点几个菜，我都能做"。

### **kwargs — 任意数量的关键字参数

```python
# **user_info 会接收所有关键字参数，存成一个字典
def build_profile(first, last, **user_info):
    profile = {}
    profile['first_name'] = first
    profile['last_name'] = last
    for key, value in user_info.items():
        profile[key] = value
    return profile

user_profile = build_profile('albert', 'einstein', location='princeton', field='physics')
print(user_profile)

# 输出：
# {'first_name': 'albert', 'last_name': 'einstein', 'location': 'princeton', 'field': 'physics'}
```

**`**kwargs` = "不管传多少个关键字参数，我都收着"。** 就像填表格时，除了必填项，你还可以填任意多的选填项。

---

## 总结

| 参数类型 | 语法 | 特点 | 类比 |
|----------|------|------|------|
| 位置参数 | `f(a, b)` | 按顺序匹配 | "宫保鸡丁，微辣" |
| 关键字参数 | `f(a=x, b=y)` | 按名称匹配 | "宫保鸡丁要微辣的" |
| 默认值 | `f(a, b=10)` | 不传就用默认值 | 咖啡默认中杯 |
| `*args` | `f(*args)` | 接收任意数量参数 | 不管点几个菜都能做 |
| `**kwargs` | `f(**kwargs)` | 接收任意关键字参数 | 表格的选填项 |
