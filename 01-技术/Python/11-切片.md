# ✂️ Python 切片

## 核心概念

切片 = **从列表中"切"出一部分**

类比：**切片就像切蛋糕** —— 蛋糕有8块，你说"给我第2到第4块"，就切出3块给你。切片就是指定"从哪块开始，到哪块结束"。

语法：`列表[起始:结束]`

**⚠️ 重要规则：包含起始索引，不包含结束索引（"左闭右开"）**

---

## 一、基本切片

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

# 从索引 0 到索引 3（不包含 3）→ 取前 3 个
print(players[0:3])

# 输出：
# ['charles', 'martina', 'michael']

# 从索引 1 到索引 3（不包含 3）→ 取第 2 和第 3 个
print(players[1:3])

# 输出：
# ['martina', 'michael']
```

**为什么 `players[0:3]` 只取到第 3 个，不包含第 4 个？**

这是 Python 的规则：`[起始:结束]` 包含起始，不包含结束。就像你说"从第1页读到第3页"，通常意思是读第1、2页，不读第3页（第3页是"边界"）。

---

## 二、省略起始或结束

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

# 省略起始 → 从开头开始
print(players[:3])

# 输出：
# ['charles', 'martina', 'michael']

# 省略结束 → 到末尾结束
print(players[2:])

# 输出：
# ['michael', 'florence', 'eli']
```

**类比：**
- `players[:3]` = "给我前3块蛋糕"（从开头切到第3块）
- `players[2:]` = "从第3块开始，后面都给我"（从第3块切到末尾）

---

## 三、负数索引切片

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

# 最后 3 个元素
print(players[-3:])

# 输出：
# ['michael', 'florence', 'eli']
```

**`[-3:]` = 从倒数第 3 个开始，到末尾。** 就像说"给我最后3块蛋糕"。

---

## 四、遍历切片

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

print("Here are the first three players on my team:")
for player in players[:3]:      # 只遍历前 3 个
    print(player.title())

# 输出：
# Here are the first three players on my team:
# Charles
# Martina
# Michael
```

## 五、复制列表（重点！）

### ✅ 正确方法：使用切片 `[:]`

```python
my_foods = ['pizza', 'falafel', 'carrot cake']

# 用切片 [:] 复制整个列表 → 创建了一个新的独立列表
friend_foods = my_foods[:]

# 修改各自的列表，互不影响
my_foods.append('cannoli')
friend_foods.append('ice cream')

print(my_foods)

# 输出：
# ['pizza', 'falafel', 'carrot cake', 'cannoli']

print(friend_foods)

# 输出：
# ['pizza', 'falafel', 'carrot cake', 'ice cream']
```

**为什么 `my_foods[:]` 能复制？** 因为 `[:]` 表示"从头到尾切一份"，相当于创建了一个新的列表。

### ❌ 错误方法：直接赋值

```python
my_foods = ['pizza', 'falafel', 'carrot cake']

# 直接赋值 → 不是复制！两个变量指向同一个列表
friend_foods = my_foods

# 修改 my_foods，friend_foods 也被改了！
my_foods.append('cannoli')
print(friend_foods)

# 输出：
# ['pizza', 'falafel', 'carrot cake', 'cannoli']  ← 也被改了！
```

**为什么直接赋值不是复制？** 因为 `friend_foods = my_foods` 只是给同一个列表起了两个名字。就像两个人共用一个书架，一个人放了新书，另一个人也能看到。

**类比：**
- `friend_foods = my_foods[:]` = 复印一份书架的清单 → 两份独立的清单
- `friend_foods = my_foods` = 两个人共用同一份清单 → 改一个，另一个也变

---

## 总结

| 语法 | 含义 | 类比 |
|------|------|------|
| `列表[2:5]` | 索引 2 到 4 | "给我第3到第5块蛋糕" |
| `列表[:3]` | 前 3 个 | "给我前3块" |
| `列表[2:]` | 从第 3 个到末尾 | "从第3块开始都给我" |
| `列表[-3:]` | 最后 3 个 | "给我最后3块" |
| `列表[:]` | 整个列表（复制） | "给我切一份一模一样的" |
