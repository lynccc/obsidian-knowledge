# 📦 Python 变量

## 核心概念

- 变量是存储值的容器
- 变量名只能包含字母、数字和下划线
- 变量名不能以数字开头
- 变量名不能是 Python 关键字

## 变量命名规则

```python
# ✅ 正确
message = "hello"
student_name = "Alice"
name_length = 10

# ❌ 错误
1_message = "hello"    # 不能以数字开头
greeting message = "hi" # 不能有空格
```

## 使用变量

```python
message = "Hello Python world!"
print(message)  # 输出: Hello Python world!

# 可以随时修改变量的值
message = "Hello Python Crash Course world!"
print(message)  # 输出: Hello Python Crash Course world!
```

## 常见错误

```python
# NameError: 变量名拼写错误
message = "Hello"
print(mesage)  # ❌ 少了一个 s

# 变量使用前必须先赋值
print(name)    # ❌ name 还没定义
```

## 命名建议

- 使用小写字母和下划线：`student_name` 而不是 `StudentName`
- 变量名要有描述性：`name` 比 `n` 好
- 慎用小写 `l` 和大写 `O`，容易和数字 1、0 混淆
