## 📌 学习建议

1. **按顺序学**，不要跳阶段
2. **每个知识点都要动手写代码**，光看不练等于没学
3. **遇到不懂的先试试**，实在不行再查笔记
4. **第三阶段的算法笔记有通俗讲解**，小白也能看懂
