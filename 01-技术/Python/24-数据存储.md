# 💾 Python 数据存储

## 核心概念

JSON = **一种通用的数据存储格式**，Python 用 `json` 模块来读写 JSON 数据

类比：**JSON 就像一个标准格式的档案袋** —— 不管是 Python、JavaScript 还是其他语言，都能读懂里面的内容。就像 PDF 文件，不管用什么电脑打开，显示都一样。

---

## 一、存储数据

### 📌 先认识：json.dump() — 把数据存进文件

```python
import json    # 导入 json 模块

numbers = [2, 3, 5, 7, 11, 13]    # 要存储的数据
filename = 'numbers.json'          # 文件名

# 以写入模式打开文件，把数据存进去
with open(filename, 'w') as f_obj:
    json.dump(numbers, f_obj)      # 把 numbers 存进文件

# 文件 numbers.json 的内容：
# [2, 3, 5, 7, 11, 13]
```

**逐行解释：**
1. `import json` — 导入 json 模块（Python 自带的，不需要安装）
2. `numbers = [2, 3, 5, 7, 11, 13]` — 要存储的数据
3. `with open(filename, 'w') as f_obj:` — 以写入模式打开文件
4. `json.dump(numbers, f_obj)` — 把数据存进文件

**`json.dump(数据, 文件对象)` = "把数据放进档案袋里"。**

---

## 二、读取数据

### 📌 先认识：json.load() — 从文件中读取数据

```python
import json

filename = 'numbers.json'

# 以读取模式打开文件，把数据取出来
with open(filename) as f_obj:
    numbers = json.load(f_obj)     # 从文件中读取数据

print(numbers)

# 输出：
# [2, 3, 5, 7, 11, 13]
```

**`json.load(文件对象)` = "从档案袋里取出数据"。** 取出来的数据类型和存进去时一样（列表还是列表，字典还是字典）。

## 三、保存用户数据

```python
import json

# 获取用户名
username = input("What is your name? ")
filename = 'username.json'

# 把用户名存进文件
with open(filename, 'w') as f_obj:
    json.dump(username, f_obj)
    print("We'll remember you when you come back, " + username + "!")

# 运行效果：
# What is your name? Eric
# We'll remember you when you come back, Eric!
```

下次运行时，可以从文件中读取用户名：

```python
import json

filename = 'username.json'

# 从文件中读取用户名
with open(filename) as f_obj:
    username = json.load(f_obj)

print("Welcome back, " + username + "!")

# 输出：
# Welcome back, Eric!
```

## 四、重构：让代码更清晰

重构 = **不改变功能，只让代码更整洁**

```python
import json

def get_stored_username():
    """如果存储了用户名，就获取它"""
    filename = 'username.json'
    try:
        with open(filename) as f_obj:
            username = json.load(f_obj)    # 尝试读取
    except FileNotFoundError:
        return None                        # 文件不存在，返回 None
    else:
        return username                    # 读取成功，返回用户名

def get_new_username():
    """提示用户输入用户名"""
    username = input("What is your name? ")
    filename = 'username.json'
    with open(filename, 'w') as f_obj:
        json.dump(username, f_obj)         # 保存用户名
    return username

def greet_user():
    """问候用户"""
    username = get_stored_username()       # 先尝试读取已存储的用户名
    if username:
        print("Welcome back, " + username + "!")   # 有存储的用户名
    else:
        username = get_new_username()               # 没有，就问用户
        print("We'll remember you when you come back, " + username + "!")

greet_user()

# 运行效果（第一次运行）：
# What is your name? Eric
# We'll remember you when you come back, Eric!

# 运行效果（第二次运行）：
# Welcome back, Eric!
```

**为什么要重构？** 把大段代码拆成小函数，每个函数只做一件事，代码更清晰、更容易维护。

**类比：** 就像整理房间 —— 把衣服放衣柜、书放书架、玩具放箱子，而不是全部堆在一起。

## 总结

| 函数 | 作用 | 类比 |
|------|------|------|
| `json.dump(数据, 文件)` | 把数据存进文件 | 把东西放进档案袋 |
| `json.load(文件)` | 从文件读取数据 | 从档案袋取出东西 |
| `import json` | 导入 json 模块 | 拿出档案袋的钥匙 |
| JSON 格式 | 通用数据格式 | 标准化的档案袋 |
