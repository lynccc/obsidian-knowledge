# 👤 Python 用户输入

## 核心概念

`input()` = **让程序暂停，等待用户输入内容**

类比：**input() 就像服务员问你"请问您要点什么？"** —— 程序会显示一个问题，然后等你回答。

```python
message = input("Tell me something, and I will repeat it back to you: ")
print(message)
```

**运行效果：**
```
Tell me something, and I will repeat it back to you: hello
hello
```

---

## 一、基本输入

```python
# 显示提示信息，等待用户输入
message = input("Tell me something, and I will repeat it back to you: ")

# 打印用户输入的内容
print(message)

# 运行效果：
# Tell me something, and I will repeat it back to you: hello
# hello
```

**逐行解释：**
1. `input("提示信息")` — 在屏幕上显示提示信息，然后等待用户输入
2. 用户输入内容并按回车
3. 输入的内容被存进 `message` 变量
4. `print(message)` — 打印出来

---

## 二、清晰的提示

```python
# 简单的提示
name = input("Please enter your name: ")
print("Hello, " + name + "!")

# 运行效果：
# Please enter your name: Eric
# Hello, Eric!
```

```python
# 多行提示（用 += 拼接字符串）
prompt = "If you tell us who you are, we can personalize the messages you see."
prompt += "\nWhat is your first name? "    # \n 表示换行

name = input(prompt)
print("Hello, " + name + "!")

# 运行效果：
# If you tell us who you are, we can personalize the messages you see.
# What is your first name? Eric
# Hello, Eric!
```

**💡 提示：** `\n` 是换行符，让提示信息换一行显示，更美观。

## 三、数值输入

### ⚠️ 重要：input() 返回的永远是字符串！

```python
# input() 返回的是字符串，不是数字
age = input("How old are you? ")
print(type(age))    # 查看类型

# 运行效果：
# How old are you? 21
# <class 'str'>   ← 是字符串类型，不是整数！
```

### 📌 先认识：int() — 把字符串转成整数

```python
# 用 int() 把字符串转成整数
age = input("How old are you? ")
age = int(age)          # 转成整数

# 现在可以做数字比较了
print(age >= 18)

# 运行效果：
# How old are you? 21
# True
```

**为什么需要 `int()`？** 因为 `input()` 返回的是字符串 "21"（文字），不是数字 21。字符串 "21" 和数字 21 对 Python 来说是不同的东西。`int()` 就是把文字 "21" 变成真正的数字 21。

### 📌 先认识：求模运算符 % — 求余数

```python
# % 求模运算符：计算除法的余数
number = input("Enter a number, and I'll tell you if it's even or odd: ")
number = int(number)

if number % 2 == 0:         # 余数为 0 → 是偶数
    print(str(number) + " is even.")
else:                        # 余数不为 0 → 是奇数
    print(str(number) + " is odd.")

# 运行效果：
# Enter a number, and I'll tell you if it's even or odd: 4
# 4 is even.
```

**`%` 求模运算符：** `4 % 2 = 0`（4 除以 2 余数是 0），`5 % 2 = 1`（5 除以 2 余数是 1）。

**类比：** 就像分苹果 —— 4 个苹果分给 2 个人，每人 2 个，剩下 0 个（偶数）。5 个苹果分给 2 个人，每人 2 个，剩下 1 个（奇数）。

## 四、Python 2 中的输入

Python 2 使用 `raw_input()` 而不是 `input()`：

```python
# Python 2 的写法
prompt = "\nTell me something:"
prompt += "\n"
message = raw_input(prompt)

# Python 3 的写法（推荐）
message = input(prompt)
```

**如果你用的是 Python 3（推荐），直接用 `input()` 就行。**

## 总结

| 概念 | 说明 | 类比 |
|------|------|------|
| `input("提示")` | 获取用户输入 | 服务员问你"要点什么？" |
| 输入默认是字符串 | input() 返回文字 | 写在纸上的字 |
| `int()` | 字符串转整数 | 把文字变成数字 |
| `%` | 求模（求余数） | 分苹果剩下的 |
| `\n` | 换行符 | 另起一行 |
