# 🔄 Python 字典操作

## 核心概念

字典有三种遍历方式：遍历键值对、遍历键、遍历值

类比：**遍历字典就像翻通讯录** —— 你可以同时看名字和电话（键值对），只看名字（键），或者只看电话（值）。

---

## 一、遍历键值对

### 📌 先认识：items() — 获取所有的键值对

```python
user_0 = {
    'username': 'efermi',
    'first': 'enrico',
    'last': 'fermi',
}

# items() 返回所有的键值对
# key 是键，value 是值
for key, value in user_0.items():
    print("\nKey: " + key)
    print("Value: " + value)

# 输出：
# Key: username
# Value: efermi
#
# Key: first
# Value: enrico
#
# Key: last
# Value: fermi
```

**`items()` = "把通讯录里每一对（名字，电话）都给我"。**

---

## 二、遍历所有键

### 📌 先认识：keys() — 获取所有的键

```python
favorite_languages = {
    'jen': 'python',
    'sarah': 'c',
    'edward': 'ruby',
    'phil': 'python',
}

# keys() 返回所有的键（名字）
for name in favorite_languages.keys():
    print(name.title())

# 输出：
# Jen
# Sarah
# Edward
# Phil
```

**`keys()` = "把通讯录里所有人的名字都给我"。**

**💡 提示：** 遍历字典时，默认就是遍历键，所以 `for name in favorite_languages:` 和 `for name in favorite_languages.keys():` 效果一样。

---

## 三、按顺序遍历键

### 📌 先认识：sorted() — 返回排序后的结果

```python
favorite_languages = {
    'jen': 'python',
    'sarah': 'c',
    'edward': 'ruby',
    'phil': 'python',
}

# sorted() 按字母顺序排列键
for name in sorted(favorite_languages.keys()):
    print(name.title() + ", thank you for taking the poll.")

# 输出：
# Edward, thank you for taking the poll.
# Jen, thank you for taking the poll.
# Phil, thank you for taking the poll.
# Sarah, thank you for taking the poll.
```

**`sorted()` = "把通讯录里的人名按字母顺序排好"。**

---

## 四、遍历所有值

### 📌 先认识：values() — 获取所有的值

```python
favorite_languages = {
    'jen': 'python',
    'sarah': 'c',
    'edward': 'ruby',
    'phil': 'python',
}

# values() 返回所有的值（语言）
print("The following languages have been mentioned:")
for language in favorite_languages.values():
    print(language.title())

# 输出：
# The following languages have been mentioned:
# Python
# C
# Ruby
# Python
```

**`values()` = "把通讯录里所有人的电话都给我"。**

### 去重：使用 set()

```python
favorite_languages = {
    'jen': 'python',
    'sarah': 'c',
    'edward': 'ruby',
    'phil': 'python',
}

# 用 set() 去除重复的值
for language in set(favorite_languages.values()):
    print(language.title())

# 输出：
# Python
# C
# Ruby
# （Python 只出现了一次，因为去重了）
```

**`set()` = 集合，自动去除重复元素。** 就像统计"有哪些不同的语言被提到了"。

---

## 总结

| 方法 | 作用 | 类比 |
|------|------|------|
| `items()` | 获取所有键值对 | "给我每一对（名字，电话）" |
| `keys()` | 获取所有键 | "给我所有人的名字" |
| `values()` | 获取所有值 | "给我所有人的电话" |
| `sorted()` | 按顺序排列 | "按字母顺序排好" |
| `set()` | 去除重复 | "去掉重复的" |
