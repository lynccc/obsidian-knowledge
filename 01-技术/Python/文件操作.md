# 📁 Python 文件操作

## 核心概念

文件操作 = **读取文件内容** 或 **把数据写入文件**

类比：**文件操作就像看书** —— 打开书（open）、读内容（read）、合上书（close）。`with` 语句会自动帮你"合上书"，不用担心忘记。

---

## 一、读取整个文件

### 📌 先认识：open() — 打开文件

### 📌 先认识：read() — 读取文件全部内容

```python
# with 语句会自动关闭文件，不需要手动 close()
with open('pi_digits.txt') as file_object:
    contents = file_object.read()    # 读取全部内容
    print(contents)

# 输出（假设 pi_digits.txt 里有这些内容）：
# 3.1415926535
#   8979323846
#   2643383279
```

**逐行解释：**
1. `with open('pi_digits.txt') as file_object:` — 打开文件，把文件对象存进 `file_object`
2. `contents = file_object.read()` — 读取文件的全部内容，存进 `contents`
3. `print(contents)` — 打印内容

**`with` 的好处：** 用 `with` 打开文件，Python 会自动在代码块结束后关闭文件。如果不用 `with`，你需要手动调用 `file_object.close()`，忘记关闭可能导致数据丢失。

**类比：** `with` 就像自动门 —— 你走进去，门自动打开；你走出来，门自动关上。不需要你手动推门。

---

## 二、逐行读取

```python
filename = 'pi_digits.txt'

with open(filename) as file_object:
    for line in file_object:          # 逐行读取
        print(line.rstrip())          # rstrip() 去掉末尾的换行符

# 输出：
# 3.1415926535
#   8979323846
#   2643383279
```

**为什么用 `rstrip()`？** 因为每行末尾都有一个看不见的换行符 `\n`，直接打印会多出空行。`rstrip()` 去掉末尾的空白字符。

---

## 三、创建文件行列表

### 📌 先认识：readlines() — 读取所有行，返回列表

```python
filename = 'pi_digits.txt'

with open(filename) as file_object:
    lines = file_object.readlines()   # 读取所有行，存成列表

for line in lines:
    print(line.rstrip())

# 输出：
# 3.1415926535
#   8979323846
#   2643383279
```

**`readlines()` = "把每一行当作一个元素，放进列表里"。** 就像把书的每一页撕下来，放进文件夹。

---

## 四、写入文件

### 📌 先认识：write() — 把内容写入文件

```python
# 'w' = 写入模式（覆盖原有内容）
filename = 'programming.txt'

with open(filename, 'w') as file_object:
    file_object.write("I love programming.\n")       # 写入一行
    file_object.write("I love creating new games.\n") # 写入另一行

# 文件内容：
# I love programming.
# I love creating new games.
```

**⚠️ 注意：**
- `'w'` 模式会**覆盖**文件原有内容！如果文件不存在，会创建新文件
- `write()` 不会自动换行，需要手动加 `\n`

### 附加到文件

```python
# 'a' = 附加模式（在原有内容后面追加）
with open(filename, 'a') as file_object:
    file_object.write("I also love finding meaning in large datasets.\n")

# 文件内容（原有内容 + 新内容）：
# I love programming.
# I love creating new games.
# I also love finding meaning in large datasets.
```

**类比：**
- `'w'` 模式 = 拿一张白纸重新写（原来的内容没了）
- `'a'` 模式 = 在笔记本后面接着写（原来的内容还在）

## 五、文件路径

### 相对路径

```python
# 相对路径：相对于当前文件的位置
with open('text_files/filename.txt') as file_object:
    # 在当前目录下的 text_files 文件夹里找 filename.txt
```

### 绝对路径

```python
# Linux/Mac 绝对路径
with open('/home/ehmatthes/other_files/text_files/filename.txt') as file_object:

# Windows 绝对路径
with open('C:\\Users\\ehmatthes\\other_files\\text_files\\filename.txt') as file_object:
```

**类比：**
- 相对路径 = "往前走 200 米到超市"（以你现在的位置为起点）
- 绝对路径 = "北京市朝阳区XX路XX号"（完整地址，不管你在哪都能找到）

## 总结

| 操作 | 语法 | 说明 | 类比 |
|------|------|------|------|
| 打开文件 | `open('文件')` | 打开文件 | 打开书 |
| `with` | 自动关闭 | 不需要手动 close | 自动门 |
| `read()` | 读取全部 | 一次读完 | 一口气看完 |
| `readlines()` | 读取所有行 | 返回列表 | 每页撕下来放文件夹 |
| `write()` | 写入 | 覆盖或新建 | 在纸上写字 |
| `'w'` | 写入模式 | 覆盖原内容 | 拿白纸重写 |
| `'a'` | 附加模式 | 追加内容 | 在后面接着写 |
