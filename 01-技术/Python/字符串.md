# 📝 Python 字符串

## 核心概念

字符串 = **一串文字**，用引号括起来

类比：**字符串就像一串珠子项链** —— 每个字符就是一颗珠子，按顺序串在一起。你可以看、可以数、可以截取一段，但不能直接把中间的珠子换成别的。

```python
"Hello"           # 用双引号
'Hello'           # 用单引号，效果一样
```

---

## 一、创建字符串

```python
# 用双引号
"This is a string."

# 用单引号
'This is also a string.'

# 字符串里包含引号时，要"交叉使用"
'I told my friend, "Python is my favorite!"'   # 外面用单引号，里面用双引号
"The language 'Python' is named after Monty Python."  # 外面用双引号，里面用单引号
```

**类比：** 就像你写信时，外面套信封（引号），信的内容里也可以有引号，但不能和信封的引号一样，否则就分不清哪里是开头哪里是结尾了。

---

## 二、大小写处理

### 📌 先认识：title() — 首字母大写

```python
name = "ada lovelace"
print(name.title())

# 输出：
# Ada Lovelace
```

**`title()` 把每个单词的第一个字母变成大写，其余变小写。** 就像写英文名字的标准格式。

### 📌 先认识：upper() — 全部大写

```python
name = "ada lovelace"
print(name.upper())

# 输出：
# ADA LOVELACE
```

### 📌 先认识：lower() — 全部小写

```python
name = "ADA LOVELACE"
print(name.lower())

# 输出：
# ada lovelace
```

**类比：** `title()` 像写标题（每个单词首字母大写），`upper()` 像大喊（全部大写），`lower()` 像小声说话（全部小写）。

---

## 三、拼接字符串

拼接 = **把几段文字连在一起**，用 `+` 号连接。

```python
first_name = "ada"
last_name = "lovelace"

# 用 + 把几个字符串连起来
full_name = first_name + " " + last_name   # 中间加一个空格

print("Hello, " + full_name.title() + "!")

# 输出：
# Hello, Ada Lovelace!
```

**⚠️ 注意：** `+` 号两边必须都是字符串，不能把字符串和数字直接相加（数字要用 `str()` 转换）。

## 四、空白处理

空白 = **看不到的字符**，比如空格、制表符、换行符。

### 添加空白

```python
# \t = 制表符（相当于按了一下 Tab 键，产生一段空白）
print("\tPython")

# 输出：
#     Python
# （前面有一段空白）
```

```python
# \n = 换行符（相当于按了一下回车键）
print("Languages:\nPython\nC")

# 输出：
# Languages:
# Python
# C
```

**类比：** `\t` 就像写文章时的"首行缩进"，`\n` 就像另起一段。

### 删除空白

### 📌 先认识：rstrip() — 删除末尾空白

```python
favorite_language = 'python '       # 注意末尾有个空格
print(favorite_language.rstrip())   # 去掉末尾的空格

# 输出：
# python
```

### 📌 先认识：lstrip() — 删除开头空白

```python
favorite_language = ' python'       # 注意开头有个空格
print(favorite_language.lstrip())   # 去掉开头的空格

# 输出：
# python
```

### 📌 先认识：strip() — 删除两端空白

```python
favorite_language = ' python '      # 两端都有空格
print(favorite_language.strip())    # 去掉两端的空格

# 输出：
# python
```

**⚠️ 重要提示：** 这些方法不会修改原来的字符串，只是返回一个新的结果。如果要保存修改，需要重新赋值：

```python
favorite_language = 'python '
favorite_language = favorite_language.rstrip()   # 重新赋值才能"永久保存"
print(favorite_language)

# 输出：
# python
```

**类比：** 就像你用橡皮擦掉纸上的污渍，但必须重新写一遍才能保留干净的版本。

## 五、避免语法错误

```python
# ❌ 错误：单引号里的撇号会让 Python 以为字符串结束了
message = 'One of Python's strengths is its diverse community.'
# Python 以为 'One of Python' 就结束了，后面的 s 不知道是什么

# ✅ 正确：用双引号包裹
message = "One of Python's strengths is its diverse community."
```

**类比：** 就像你说话时，如果句子里有"引号"，外面就要用另一种引号，否则别人分不清哪部分是引用的。

| `+` | 拼接字符串 | 把几段话连起来 |
| `\t` | 制表符 | 首行缩进 |
| `\n` | 换行符 | 另起一段 |
| `rstrip()` | 删除末尾空格 | 擦掉末尾的污渍 |
| `lstrip()` | 删除开头空格 | 擦掉开头的污渍 |
| `strip()` | 删除两端空格 | 擦掉两端的污渍 |
