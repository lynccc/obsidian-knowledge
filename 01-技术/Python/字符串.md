# 📝 Python 字符串

## 核心概念

- 字符串是一系列字符，用引号括起来
- 单引号 `'` 或双引号 `"` 都可以
- 字符串是不可变的（不能直接修改）

## 创建字符串

```python
"This is a string."
'This is also a string.'

# 包含引号的方式
'I told my friend, "Python is my favorite!"'
"The language 'Python' is named after Monty Python."
```

## 大小写处理

```python
name = "ada lovelace"

name.title()   # "Ada Lovelace" — 首字母大写
name.upper()   # "ADA LOVELACE" — 全部大写
name.lower()   # "ada lovelace" — 全部小写
```

## 拼接字符串

```python
first_name = "ada"
last_name = "lovelace"
full_name = first_name + " " + last_name

print("Hello, " + full_name.title() + "!")
# 输出: Hello, Ada Lovelace!
```

## 空白处理

### 添加空白
```python
print("Python")        # Python
print("\tPython")      #     Python（制表符）
print("Languages:\nPython\nC")  # 换行
```

### 删除空白
```python
favorite_language = 'python '

favorite_language.rstrip()   # 'python' — 删除末尾空白
favorite_language.lstrip()   # 'python ' — 删除开头空白
favorite_language.strip()    # 'python' — 删除两端空白

# 注意：要永久保存，需要重新赋值
favorite_language = favorite_language.rstrip()
```

## 避免语法错误

```python
# ❌ 单引号内有撇号会报错
message = 'One of Python's strengths is its diverse community.'

# ✅ 用双引号包裹
message = "One of Python's strengths is its diverse community."
```
