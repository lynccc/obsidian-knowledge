# ✂️ Python 切片

## 核心概念

- 切片是列表的一部分
- 语法：`列表[起始:结束]`
- 包含起始索引，不包含结束索引
- 可以省略起始或结束

## 基本切片

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

# 前3个元素
print(players[0:3])  # ['charles', 'martina', 'michael']

# 从索引1到3
print(players[1:3])  # ['martina', 'michael']

# 从索引2到末尾
print(players[2:])   # ['michael', 'florence', 'eli']

# 前3个
print(players[:3])   # ['charles', 'martina', 'michael']

# 最后3个
print(players[-3:])  # ['michael', 'florence', 'eli']
```

## 遍历切片

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']
print("Here are the first three players on my team:")
for player in players[:3]:
    print(player.title())
```

## 复制列表

```python
# ✅ 正确：使用切片复制
my_foods = ['pizza', 'falafel', 'carrot cake']
friend_foods = my_foods[:]

my_foods.append('cannoli')
friend_foods.append('ice cream')

print(my_foods)     # ['pizza', 'falafel', 'carrot cake', 'cannoli']
print(friend_foods) # ['pizza', 'falafel', 'carrot cake', 'ice cream']

# ❌ 错误：直接赋值（两个变量指向同一个列表）
my_foods = ['pizza', 'falafel', 'carrot cake']
friend_foods = my_foods  # 不是复制！

my_foods.append('cannoli')
print(friend_foods)  # ['pizza', 'falafel', 'carrot cake', 'cannoli']（也被改了！）
```
