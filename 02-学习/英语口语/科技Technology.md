# 🗣️ 科技

## 场景简介
> 日常生活中离不开科技——聊手机、电脑、网络、App 时，这些词汇和短语让你表达更流畅。

## 核心词汇

### 1. To access websites/email
- **英文**：To access websites/email
- **中文**：访问网站/邮箱
- **例句**：I can't access my email from this computer. 我用这台电脑打不开邮箱。
- **💡 用法提示**：access = 进入、访问

### 2. To back up files
- **英文**：To back up files
- **中文**：备份文件
- **例句**：You should always back up your important files. 你应该经常备份重要文件。
- **💡 用法提示**：back up = 备份，以防电脑出问题

### 3. To boot up
- **英文**：To boot up
- **中文**：启动（电脑）
- **例句**：My computer takes ages to boot up. 我的电脑启动要好长时间。
- **💡 用法提示**：boot up = 开机、启动

### 4. To bookmark a webpage
- **英文**：To bookmark a webpage
- **中文**：收藏网页
- **例句**：I bookmarked that page so I can read it later. 我收藏了那个页面，之后再看。
- **💡 用法提示**：bookmark = 书签，这里作动词用

### 5. To browse websites
- **英文**：To browse websites
- **中文**：浏览网站
- **例句**：I was just browsing some websites for holiday ideas. 我在浏览一些网站找度假灵感。
- **💡 用法提示**：browse = 随意浏览

### 6. A computer buff / A techie
- **英文**：A computer buff / A techie
- **中文**：电脑高手；科技迷
- **例句**：My brother is a real techie — he knows everything about computers. 我哥是个真正的科技迷——电脑什么都懂。
- **💡 用法提示**：buff = 爱好者、行家；techie = 科技爱好者

### 7. To crash
- **英文**：To crash
- **中文**：死机；崩溃
- **例句**：My laptop crashed and I lost all my work! 我笔记本死机了，所有工作都没了！
- **💡 用法提示**：crash = 突然停止工作

### 8. To cut and paste
- **英文**：To cut and paste
- **中文**：剪切和粘贴
- **例句**：Just cut and paste the text into the new document. 把文字剪切粘贴到新文档里就行。
- **💡 用法提示**：基本的电脑操作

### 9. A desktop PC / A laptop
- **英文**：A desktop PC / A laptop
- **中文**：台式电脑 / 笔记本电脑
- **例句**：I use a desktop at work and a laptop at home. 我上班用台式机，家里用笔记本。
- **💡 用法提示**：desktop = 台式的，laptop = 膝上的

### 10. Digital editing
- **英文**：Digital editing
- **中文**：数字编辑
- **例句**：She does digital editing for a living. 她以数字编辑为生。
- **💡 用法提示**：编辑音频、视频等数字材料

### 11. Download
- **英文**：Download
- **中文**：下载
- **例句**：I downloaded a new app yesterday. 我昨天下载了一个新 App。
- **💡 用法提示**：反义词是 upload（上传）

### 12. To enter a web address
- **英文**：To enter a web address
- **中文**：输入网址
- **例句**：Enter the web address in the address bar. 在地址栏输入网址。
- **💡 用法提示**：web address = URL

### 13. A gadget
- **英文**：A gadget
- **中文**：小工具；小设备
- **例句**：I love buying new gadgets for the kitchen. 我喜欢买新的厨房小工具。
- **💡 用法提示**：通常指小巧的科技产品

### 14. To go online / To surf the web
- **英文**：To go online / To surf the web
- **中文**：上网
- **例句**：I go online first thing every morning. 我每天早上第一件事就是上网。
- **💡 用法提示**：go online = 连接网络，surf the web = 浏览网页

### 15. High-spec (laptop)
- **英文**：High-spec (laptop)
- **中文**：高配置的（笔记本）
- **例句**：I need a high-spec laptop for video editing. 我需要一台高配笔记本做视频编辑。
- **💡 用法提示**：spec = specification（规格）的缩写

### 16. Internet security
- **英文**：Internet security
- **中文**：网络安全
- **例句**：Internet security is very important these days. 现在网络安全非常重要。
- **💡 用法提示**：保护上网安全的措施

### 17. Intranet
- **英文**：Intranet
- **中文**：内联网
- **例句**：We use the intranet to share files within the company. 我们用内联网在公司内部共享文件。
- **💡 用法提示**：公司或组织内部的网络

### 18. To navigate a website
- **英文**：To navigate a website
- **中文**：浏览/导航网站
- **例句**：This website is really easy to navigate. 这个网站很容易浏览。
- **💡 用法提示**：navigate = 导航、找到方向

### 19. Operating system
- **英文**：Operating system (OS)
- **中文**：操作系统
- **例句**：Do you use Windows or Mac as your operating system? 你用 Windows 还是 Mac 操作系统？
- **💡 用法提示**：常见的有 Windows、macOS、Linux

### 20. Send an attachment
- **英文**：Send an attachment
- **中文**：发送附件
- **例句**：Can you send me the file as an attachment? 你能把文件作为附件发给我吗？
- **💡 用法提示**：attachment = 邮件附件

### 21. Social media
- **英文**：Social media
- **中文**：社交媒体
- **例句**：I spend too much time on social media. 我在社交媒体上花了太多时间。
- **💡 用法提示**：包括 Facebook、Twitter、Instagram 等

### 22. To upgrade
- **英文**：To upgrade
- **中文**：升级
- **例句**：I need to upgrade my phone — it's too slow. 我需要升级手机——太慢了。
- **💡 用法提示**：upgrade = 更新到更好的版本

### 23. Video conferencing
- **英文**：Video conferencing
- **中文**：视频会议
- **例句**：Video conferencing has become very common since the pandemic. 疫情以来视频会议变得很普遍。
- **💡 用法提示**：也可以说 "video call"

### 24. Wireless hotspot / Wireless network
- **英文**：Wireless hotspot / Wireless network
- **中文**：无线热点 / 无线网络
- **例句**：Is there a wireless hotspot here? 这里有无线热点吗？
- **💡 用法提示**：hotspot = 可以连接 WiFi 的公共区域

### 25. Word processing
- **英文**：Word processing
- **中文**：文字处理
- **例句**：Word processing software like Microsoft Word is essential for work. 微软 Word 等文字处理软件对工作很重要。
- **💡 用法提示**：在电脑上撰写和编辑文字

## 常用句型
- My computer has crashed again! 我的电脑又死机了！
- Can you help me back up my files? 你能帮我备份一下文件吗？
- I need to upgrade my phone. 我需要升级手机。
- Do you have WiFi here? 你们这里有 WiFi 吗？
- I'll send you the document as an attachment. 我把文档作为附件发给你。
- How do I navigate this website? 这个网站怎么浏览？
- I spend way too much time on social media. 我在社交媒体上花了太多时间。
- Let's do a video conference instead of a meeting. 我们开视频会议吧，别开线下会了。
- My laptop is really slow — I think I need a new one. 我笔记本太慢了——我觉得该买新的了。
- Can you download this app for me? 你能帮我下载这个 App 吗？

## 📝 学习建议
- "crash" 是描述电脑死机最常用的词，记住 "My computer crashed"
- "back up" 是非常实用的动词短语，不仅用于文件，还可以用于数据、手机等
- "gadget" 是描述小电子设备的万能词
- "social media" 已经成为日常话题，要能流利讨论
- "upgrade" 可以用于手机、电脑、软件等各种场景
