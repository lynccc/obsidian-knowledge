# 直线方程

## 🗣️ 通俗讲解
> 直线方程就是用代数式描述一条直线。知道斜率和一个点，就能写出方程；知道两个点，也能算出斜率再写方程。本质就是"用方程代替画图"。
> - **斜率** $k$：直线的"陡峭程度"，$k > 0$ 往右上走，$k < 0$ 往右下走，$k = 0$ 水平，$k$ 不存在是竖直线
> - **截距**：直线与坐标轴的交点

## 核心概念
- **斜率**：$k = \dfrac{y_2 - y_1}{x_2 - x_1}$，表示直线的倾斜程度
- **倾斜角** $\alpha$：直线与 $x$ 轴正方向的夹角（$0° \leq \alpha < 180°$），$k = \tan \alpha$（$\alpha \neq 90°$）

## 五种方程形式对比

| 形式 | 方程 | 适用条件 | 优点 |
|------|------|----------|------|
| 点斜式 | $y - y_0 = k(x - x_0)$ | 已知点和斜率 | 最常用 |
| 斜截式 | $y = kx + b$ | 已知斜率和截距 | 直接读 $k, b$ |
| 两点式 | $\dfrac{y - y_1}{y_2 - y_1} = \dfrac{x - x_1}{x_2 - x_1}$ | 已知两点 | 不需算斜率 |
| 截距式 | $\dfrac{x}{a} + \dfrac{y}{b} = 1$ | 已知两截距 | 画图方便 |
| 一般式 | $Ax + By + C = 0$ | 通用 | 万能形式 |

## 关键公式
- **两直线平行**：$k_1 = k_2$ 且 $b_1 \neq b_2$（或 $A_1B_2 = A_2B_1$ 且不重合）
- **两直线垂直**：$k_1 k_2 = -1$（或 $A_1A_2 + B_1B_2 = 0$）
- **点到直线距离**：$d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
- **两平行线距离**：$d = \dfrac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$（$Ax+By+C_1=0$ 与 $Ax+By+C_2=0$）

## 🎯 经典例题

### 例题1：求直线方程
**问题**：求过点 $(1, 2)$ 且斜率为 $3$ 的直线方程。

**思路**：
用点斜式：$y - 2 = 3(x - 1)$
化简：$y = 3x - 1$

**答案**：$y = 3x - 1$ 或 $3x - y - 1 = 0$

### 例题2：点到直线距离
**问题**：求点 $(1, 3)$ 到直线 $3x - 4y + 5 = 0$ 的距离。

**思路**：
$$d = \dfrac{|3 \times 1 - 4 \times 3 + 5|}{\sqrt{3^2 + (-4)^2}} = \dfrac{|3 - 12 + 5|}{\sqrt{9 + 16}} = \dfrac{|-4|}{5} = \dfrac{4}{5}$$

**答案**：$d = \dfrac{4}{5}$

### 例题3：两直线位置关系
**问题**：判断直线 $l_1: 2x + y - 1 = 0$ 与 $l_2: x - 2y + 3 = 0$ 的位置关系。

**思路**：
方法一（斜率法）：
- $l_1$：$y = -2x + 1$，$k_1 = -2$
- $l_2$：$y = \dfrac{1}{2}x + \dfrac{3}{2}$，$k_2 = \dfrac{1}{2}$
- $k_1 \cdot k_2 = -2 \times \dfrac{1}{2} = -1$，所以垂直

方法二（系数法）：
- $A_1A_2 + B_1B_2 = 2 \times 1 + 1 \times (-2) = 0$，所以垂直

**答案**：$l_1 \perp l_2$

## 📝 解题技巧/口诀
- **求直线方程**：先看已知条件，选择最方便的形式
- **平行垂直口诀**："平行斜率相等，垂直斜率乘积为 -1"
- **距离公式**：点到直线代公式，注意绝对值和根号
- **一般式万能**：任何直线都能写成 $Ax + By + C = 0$，距离公式用它最方便
