# 直线方程

## 🗣️ 通俗讲解
> 直线方程就是用代数式描述一条直线。知道斜率和一个点，就能写出方程；知道两个点，也能算出斜率再写方程。本质就是"用方程代替画图"。

## 核心概念
- **斜率**：$k = \dfrac{y_2 - y_1}{x_2 - x_1}$，表示直线的倾斜程度
- **倾斜角** $\alpha$：直线与 $x$ 轴正方向的夹角，$k = \tan \alpha$（$\alpha \neq 90°$）

## 关键公式
- 点斜式：$y - y_0 = k(x - x_0)$
- 斜截式：$y = kx + b$
- 两点式：$\dfrac{y - y_1}{y_2 - y_1} = \dfrac{x - x_1}{x_2 - x_1}$
- 一般式：$Ax + By + C = 0$（$A, B$ 不同时为 0）
- 点到直线距离：$d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$

## 典型例题思路
- 求直线方程：确定条件（点、斜率、截距），选择合适形式
- 两直线关系：平行 $\Leftrightarrow k_1 = k_2$，垂直 $\Leftrightarrow k_1 k_2 = -1$
- 距离问题：点到直线直接用公式，两平行线间距离用公式
