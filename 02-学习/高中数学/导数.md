# 导数

## 🗣️ 通俗讲解
> 导数就是函数在某一点的"瞬时变化率"——可以理解为曲线在该点的切线斜率。导数 > 0 函数递增，导数 < 0 函数递减，导数 = 0 可能是极值点。它是研究函数最强大的工具。

## 核心概念
- **导数定义**：$f'(x) = \lim_{\Delta x \to 0} \dfrac{f(x + \Delta x) - f(x)}{\Delta x}$
- **几何意义**：曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处切线的斜率
- **极值**：导数为 0 且左右变号的点
- **最值**：在闭区间上比较极值和端点值

## 关键公式
- $(x^n)' = nx^{n-1}$
- $(\sin x)' = \cos x$，$(\cos x)' = -\sin x$
- $(e^x)' = e^x$，$(\ln x)' = \dfrac{1}{x}$
- $(uv)' = u'v + uv'$，$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
- 复合函数：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$

## 典型例题思路
- 求单调区间：求导→令 $f'(x) > 0$ 和 $f'(x) < 0$ 分别解出
- 求极值：令 $f'(x) = 0$→判断左右导数符号变化
- 求最值：求极值 + 端点值，取最大/最小
- 不等式证明：构造函数，用导数证明其单调性
