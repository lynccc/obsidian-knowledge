# 导数

## 🗣️ 通俗讲解
> 导数就是函数在某一点的"瞬时变化率"——可以理解为曲线在该点的切线斜率。
> - 导数 > 0：函数在"爬坡"（递增）
> - 导数 < 0：函数在"下坡"（递减）
> - 导数 = 0：可能是"山顶"或"山谷"（极值点）
>
> 它是研究函数最强大的工具，能精确判断单调性、求极值、证明不等式。

## 核心概念
- **导数定义**：$f'(x) = \lim_{\Delta x \to 0} \dfrac{f(x + \Delta x) - f(x)}{\Delta x}$
- **几何意义**：曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处切线的斜率
- **极值**：导数为 0 且左右变号的点
- **最值**：在闭区间上比较极值和端点值

## 关键公式

### 常见求导公式表
| 原函数 | 导函数 |
|--------|--------|
| $C$（常数） | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |

### 运算法则
- 和差：$(u \pm v)' = u' \pm v'$
- 积：$(uv)' = u'v + uv'$
- 商：$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
- 复合函数：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$（链式法则）

## 求极值/最值的步骤
1. **求导**：$f'(x)$
2. **令 $f'(x) = 0$**：解出驻点 $x_0$
3. **判断符号变化**：
   - 左正右负 → 极大值
   - 左负右正 → 极小值
4. **求最值**：比较极值和端点值

## 🎯 经典例题

### 例题1：求切线方程
**问题**：求曲线 $y = x^3 - 2x$ 在点 $(1, -1)$ 处的切线方程。

**思路**：
1. 求导：$y' = 3x^2 - 2$
2. $x = 1$ 时斜率 $k = 3(1)^2 - 2 = 1$
3. 切线方程：$y - (-1) = 1 \cdot (x - 1)$
4. $y = x - 2$

**答案**：$y = x - 2$

### 例题2：求单调区间
**问题**：求 $f(x) = x^3 - 3x + 1$ 的单调区间。

**思路**：
1. $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$
2. 令 $f'(x) = 0$：$x = -1$ 或 $x = 1$
3. 列表判断：
   - $x < -1$：$f'(x) > 0$，递增
   - $-1 < x < 1$：$f'(x) < 0$，递减
   - $x > 1$：$f'(x) > 0$，递增

**答案**：递增区间 $(-\infty, -1)$ 和 $(1, +\infty)$；递减区间 $(-1, 1)$。

### 例题3：求极值
**问题**：求 $f(x) = x^3 - 3x + 1$ 的极值。

**思路**：
1. 由上题知 $x = -1$ 时左增右减，是极大值点
2. $f(-1) = (-1)^3 - 3(-1) + 1 = 3$
3. $x = 1$ 时左减右增，是极小值点
4. $f(1) = 1^3 - 3(1) + 1 = -1$

**答案**：极大值 $f(-1) = 3$，极小值 $f(1) = -1$。

## 📝 解题技巧/口诀
- **求导口诀**："幂函数降次，三角函数变名，指数不变，对数变倒数"
- **极值判断**："左正右负是极大，左负右正是极小，同号不是极值点"
- **最值问题**："闭区间上比大小，极值端点都要算"
- **切线方程**："点在曲线上，斜率是导数，点斜式搞定"
