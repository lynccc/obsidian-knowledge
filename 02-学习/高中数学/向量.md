# 向量

## 🗣️ 通俗讲解
> 向量就是"有方向的箭头"，既有大小又有方向。它把几何问题变成了代数计算：
> - **平行**变成"共线"（坐标成比例）
> - **垂直**变成"数量积为 0"（坐标乘积之和为 0）
>
> 向量是连接几何和代数的桥梁。想象你从 A 点走到 B 点，这段"位移"就是一个向量——有距离（大小）也有方向。

## 核心概念
- **向量**：既有大小又有方向的量，用 $\vec{a}$ 或 $\overrightarrow{AB}$ 表示
- **零向量** $\vec{0}$：大小为 0，方向任意
- **单位向量**：模为 1 的向量
- **基底**：平面内两个不共线向量可表示任意向量
- **数量积（点积）**：$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$，结果是标量

## 关键公式

### 坐标运算
设 $\vec{a} = (x_1, y_1)$，$\vec{b} = (x_2, y_2)$：
- 加法：$\vec{a} + \vec{b} = (x_1+x_2, y_1+y_2)$
- 数乘：$\lambda\vec{a} = (\lambda x_1, \lambda y_1)$
- 数量积：$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2$
- 模：$|\vec{a}| = \sqrt{x_1^2 + y_1^2}$

### 位置关系
- **平行**：$x_1y_2 - x_2y_1 = 0$（共线条件）
- **垂直**：$x_1x_2 + y_1y_2 = 0$（数量积为 0）

### 夹角公式
$$\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \dfrac{x_1x_2 + y_1y_2}{\sqrt{x_1^2+y_1^2} \cdot \sqrt{x_2^2+y_2^2}}$$

## 🎯 经典例题

### 例题1：求向量的模
**问题**：已知 $\vec{a} = (3, 4)$，求 $|\vec{a}|$。

**思路**：
$$|\vec{a}| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

**答案**：$|\vec{a}| = 5$

### 例题2：判断垂直
**问题**：已知 $\vec{a} = (2, -1)$，$\vec{b} = (1, 2)$，判断 $\vec{a}$ 与 $\vec{b}$ 是否垂直。

**思路**：
$$\vec{a} \cdot \vec{b} = 2 \times 1 + (-1) \times 2 = 2 - 2 = 0$$

**答案**：$\vec{a} \perp \vec{b}$（数量积为 0，所以垂直）

### 例题3：求夹角
**问题**：已知 $\vec{a} = (1, \sqrt{3})$，$\vec{b} = (2, 0)$，求 $\vec{a}$ 与 $\vec{b}$ 的夹角。

**思路**：
1. $\vec{a} \cdot \vec{b} = 1 \times 2 + \sqrt{3} \times 0 = 2$
2. $|\vec{a}| = \sqrt{1 + 3} = 2$，$|\vec{b}| = 2$
3. $\cos\theta = \dfrac{2}{2 \times 2} = \dfrac{1}{2}$
4. $\theta = 60°$

**答案**：夹角为 $60°$。

## 📝 解题技巧/口诀
- **数量积公式**：$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2 = |\vec{a}||\vec{b}|\cos\theta$
- **垂直判定**：数量积为 0 → $x_1x_2 + y_1y_2 = 0$
- **平行判定**：坐标交叉相乘相减为 0 → $x_1y_2 - x_2y_1 = 0$
- **求模**：$|\vec{a}| = \sqrt{x^2 + y^2}$（勾股定理）
- **向量加法**：平行四边形法则或三角形法则
