# 集合

## 🗣️ 通俗讲解
> 集合就是"装东西的框"——把满足某个条件的对象都放在一起，就成了一个集合。比如"我们班所有同学"就是一个集合。集合之间可以做交集（共同的）、并集（全都要）、补集（别人没有的）。

## 核心概念
- **集合**：确定的对象的全体，元素满足**确定性、互异性、无序性**
- **子集**：$A \subseteq B$ 表示 A 的元素都在 B 中
- **真子集**：$A \subsetneq B$ 表示 A 是 B 的子集且 $A \neq B$
- **空集**：$\varnothing$，是任何集合的子集

## 关键公式
- 交集：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$
- 并集：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$
- 补集：$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$
- 德摩根律：$\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)$

## 典型例题思路
- 已知集合求交并补：先明确各集合元素，再按定义运算
- 含参集合问题：注意空集是任何集合的子集，分类讨论参数范围
- Venn 图辅助：画图直观判断集合关系

## 与其他概念的联系
