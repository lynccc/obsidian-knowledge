# 圆锥曲线

## 🗣️ 通俗讲解
> 圆锥曲线就是用平面去切圆锥得到的曲线：
> - **椭圆**：斜着切 → 一个"压扁的圆"
> - **抛物线**：平行于母线切 → 一个"开口的曲线"
> - **双曲线**：更陡地切 → 两片"张开的翅膀"
>
> 它们都有一个核心性质：到定点（焦点）和定线（准线）的距离满足特定比例（离心率）。
> - 离心率 $e$ 越小，椭圆越"圆"；$e$ 越大，双曲线越"张开"

## 核心概念

### 椭圆
- **定义**：到两焦点距离之和为定值 $2a$（$2a > 2c$）
- **标准方程**：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$，焦点在 $x$ 轴）
- **关系**：$c^2 = a^2 - b^2$，离心率 $e = \dfrac{c}{a} \in (0, 1)$

### 双曲线
- **定义**：到两焦点距离之差的绝对值为定值 $2a$（$2a < 2c$）
- **标准方程**：$\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$（焦点在 $x$ 轴）
- **关系**：$c^2 = a^2 + b^2$，离心率 $e = \dfrac{c}{a} > 1$
- **渐近线**：$y = \pm \dfrac{b}{a}x$

### 抛物线
- **定义**：到焦点与准线距离相等
- **标准方程**：$y^2 = 2px$（$p > 0$，开口向右）
- **焦点**：$\left(\dfrac{p}{2}, 0\right)$，准线：$x = -\dfrac{p}{2}$

## 三种曲线对比表

| 性质 | 椭圆 | 双曲线 | 抛物线 |
|------|------|--------|--------|
| 定义 | 到两焦点距离之和为定值 | 到两焦点距离之差为定值 | 到焦点与准线距离相等 |
| 离心率 | $0 < e < 1$ | $e > 1$ | $e = 1$ |
| 焦点 | $(\pm c, 0)$ | $(\pm c, 0)$ | $(\frac{p}{2}, 0)$ |
| 有渐近线？ | 无 | 有 | 无 |
| 有界性？ | 有界 | 无界 | 无界 |

## 关键公式
- **焦点弦长**（抛物线）：$|AB| = x_1 + x_2 + p$
- **椭圆焦点三角形面积**：$S = b^2 \tan\dfrac{\theta}{2}$（$\theta$ 为 $\angle F_1PF_2$）
- **直线与圆锥曲线联立**：消元后用韦达定理

## 🎯 经典例题

### 例题1：求椭圆方程
**问题**：椭圆焦点在 $x$ 轴上，焦距为 4，长轴长为 6，求椭圆标准方程。

**思路**：
1. 焦距 $2c = 4 \Rightarrow c = 2$
2. 长轴长 $2a = 6 \Rightarrow a = 3$
3. $b^2 = a^2 - c^2 = 9 - 4 = 5$

**答案**：$\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1$

### 例题2：直线与椭圆相交弦长
**问题**：直线 $y = x + 1$ 与椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 相交于 $A, B$ 两点，求 $|AB|$。

**思路**：
1. 联立方程：$\dfrac{x^2}{4} + (x+1)^2 = 1$
2. 化简：$\dfrac{x^2}{4} + x^2 + 2x + 1 = 1 \Rightarrow \dfrac{5x^2}{4} + 2x = 0$
3. $x(\dfrac{5x}{4} + 2) = 0$，得 $x_1 = 0$，$x_2 = -\dfrac{8}{5}$
4. $A(0, 1)$，$B(-\dfrac{8}{5}, -\dfrac{3}{5})$
5. $|AB| = \sqrt{(0+\frac{8}{5})^2 + (1+\frac{3}{5})^2} = \sqrt{\frac{64}{25} + \frac{64}{25}} = \dfrac{8\sqrt{2}}{5}$

**答案**：$|AB| = \dfrac{8\sqrt{2}}{5}$

## 📝 解题技巧/口诀
- **求方程口诀**："定义列等式，化简定参数"
- **弦长问题**："联立消元用韦达，弦长公式代进去"
- **焦点弦公式**（抛物线）：$|AB| = x_1 + x_2 + p$，不用算根号
- **椭圆与双曲线**：$a, b, c$ 关系要分清——椭圆 $c^2 = a^2 - b^2$，双曲线 $c^2 = a^2 + b^2$
- **韦达定理**：联立后 $x_1 + x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$
