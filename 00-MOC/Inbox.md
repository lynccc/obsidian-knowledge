## 📝 工作流程

```
🧠 有想法 → 📝 先扔这里 → 📂 有空再归档
```

### 什么时候用 Inbox？

- 💡 突然冒出的想法
- 🔗 看到想收藏的内容
- 📖 临时记录，还没想好放哪
- ❓ 有疑问，以后再研究

### 怎么整理？

1. 打开笔记，看看内容
2. 判断属于哪个分类（技术/科目/生活...）
3. 移动到对应文件夹
4. 补全 tags 和 metadata
5. 添加双向链接

## ✅ 整理检查清单

- [ ] 有相关的笔记可以链接吗？
- [ ] 内容够完整吗？需要补充吗？
