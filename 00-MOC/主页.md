---

## 🚀 快速开始

### 这是什么？

这是主人和奶茶一号共同维护的知识库。所有知识点都被拆解成**原子笔记**，通过双向链接 `[[关联]]` 形成知识网络。

### 怎么用？

| 场景 | 操作 |
|------|------|
| **我想学新东西** | 告诉奶茶一号，她来整理成笔记 |
| **我有笔记想法** | 直接在 Obsidian 里写，奶茶一号会帮你优化 |
| **查看最新内容** | 在 GitSync.md 里点 **Pull**，回 Obsidian 就能看到 |
| **同步我的修改** | 在 GitSync.md 里点 **Push**，奶茶一号就能看到 |

### 同步流程

```
你告诉奶茶一号知识点
      ↓
奶茶一号拆解成原子笔记
      ↓
添加双向链接和标签
      ↓
推送到 GitHub
      ↓
你在 GitSync.md 点 Pull
      ↓
Obsidian 自动显示新笔记 ✨
```

## 📝 笔记格式说明

每篇笔记都包含：

```yaml
---
aliases: [别名]          # 其他叫法
tags: [标签]             # 分类标签
created: 创建日期         # 创建时间
source: 来源             # 信息来源
related: [[关联笔记]]    # 相关笔记
---
```

**双向链接**：用 `[[笔记名]]` 连接相关知识，形成知识网络。

## 💡 使用技巧

1. **搜索笔记**：点左上角 🔍 搜索关键词
2. **查看关联**：点笔记里的 `[[链接]]` 跳转
3. **图谱视图**：设置 → 核心插件 → 启用"关系图谱"
4. **标签筛选**：点笔记里的标签，查看同类笔记
