# 圆的方程

## 🗣️ 通俗讲解
> 圆的方程本质上就是"到圆心距离等于半径"这个条件的代数翻译：
> - **标准方程**一眼能读出圆心 $(a, b)$ 和半径 $r$
> - **一般方程**需要配方才能看出来，但它更通用
>
> 直线与圆的关系就看圆心到直线的距离 $d$ 和半径 $r$ 谁大谁小——这就是"几何条件代数化"的典型应用。

## 核心概念
- **标准方程**：$(x-a)^2 + (y-b)^2 = r^2$，圆心 $(a, b)$，半径 $r$
- **一般方程**：$x^2 + y^2 + Dx + Ey + F = 0$
  - 圆心 $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$，半径 $r = \dfrac{1}{2}\sqrt{D^2 + E^2 - 4F}$
  - 存在条件：$D^2 + E^2 - 4F > 0$

## 关键公式

### 点与圆的关系
设点 $P(x_0, y_0)$，圆心 $C(a, b)$，半径 $r$：
- $|PC| > r$：点在圆外
- $|PC| = r$：点在圆上
- $|PC| < r$：点在圆内

### 直线与圆的位置关系
设圆心到直线距离为 $d$：
- $d > r$：**相离**（没有交点）
- $d = r$：**相切**（一个交点）
- $d < r$：**相交**（两个交点）

### 弦长公式
直线与圆相交时，弦长 $l = 2\sqrt{r^2 - d^2}$（$d$ 为圆心到直线距离）

## 🎯 经典例题

### 例题1：求圆的方程
**问题**：求以 $(1, -2)$ 为圆心，且过点 $(4, 2)$ 的圆的方程。

**思路**：
1. 半径 $r = \sqrt{(4-1)^2 + (2+2)^2} = \sqrt{9 + 16} = 5$
2. 标准方程：$(x-1)^2 + (y+2)^2 = 25$

**答案**：$(x-1)^2 + (y+2)^2 = 25$

### 例题2：直线与圆的位置关系
**问题**：判断直线 $y = x + 1$ 与圆 $x^2 + y^2 = 4$ 的位置关系。

**思路**：
1. 圆心 $(0, 0)$，半径 $r = 2$
2. 圆心到直线距离 $d = \dfrac{|0 - 0 + 1|}{\sqrt{1^2 + (-1)^2}} = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$
3. $d = \dfrac{\sqrt{2}}{2} \approx 0.71 < 2 = r$

**答案**：直线与圆相交。

### 例题3：求弦长
**问题**：直线 $y = x + 1$ 与圆 $x^2 + y^2 = 4$ 相交，求弦长。

**思路**：
1. 由上题知 $d = \dfrac{\sqrt{2}}{2}$，$r = 2$
2. 弦长 $l = 2\sqrt{r^2 - d^2} = 2\sqrt{4 - \dfrac{1}{2}} = 2\sqrt{\dfrac{7}{2}} = \sqrt{14}$

**答案**：弦长为 $\sqrt{14}$

## 📝 解题技巧/口诀
- **求圆的方程**："待定系数法——设方程、代条件、解方程组"
- **位置关系判断**："算距离 $d$，比半径 $r$，大小关系定相离相切相交"
- **弦长公式**：$l = 2\sqrt{r^2 - d^2}$，记住这个不用联立方程
- **切线问题**："圆心到切线距离 = 半径"
- **一般方程配方**：$x^2 + Dx = (x + \frac{D}{2})^2 - \frac{D^2}{4}$
