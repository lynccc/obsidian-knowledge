# 不等式

## 🗣️ 通俗讲解
> 不等式研究的是"大小关系"：
> - **均值不等式**说的是：两个正数的算术平均数 ≥ 几何平均数。简单说就是"和一定时，两数相等乘积最大；积一定时，两数相等和最小"
> - **线性规划**则是在约束条件下找最优解——像在地图上画一个区域，然后找目标函数在这个区域里的最大/最小值

## 核心概念
- **均值不等式**：$a, b > 0$ 时，$\dfrac{a+b}{2} \geq \sqrt{ab}$，等号当 $a = b$ 时成立
- **线性规划**：在不等式约束下求目标函数的最值
- **一元二次不等式**：$ax^2 + bx + c > 0$ 的解集

## 关键公式

### 均值不等式
- 基本形式：$a + b \geq 2\sqrt{ab}$（$a, b > 0$）
- 等号条件：$a = b$ 时取等
- 常用变形：$\dfrac{a^2 + b^2}{2} \geq \left(\dfrac{a+b}{2}\right)^2$

### 使用条件："一正二定三相等"
1. **一正**：$a, b$ 都是正数
2. **二定**：$a + b$ 或 $ab$ 中有一个是定值
3. **三相等**：等号能取到（$a = b$ 在取值范围内）

### 一元二次不等式解法
- $ax^2 + bx + c > 0$（$a > 0$）：
  - $\Delta > 0$：$x < x_1$ 或 $x > x_2$（$x_1 < x_2$ 是两根）
  - $\Delta = 0$：$x \neq -\dfrac{b}{2a}$
  - $\Delta < 0$：$x \in \mathbb{R}$

## 🎯 经典例题

### 例题1：均值不等式求最值
**问题**：已知 $x > 0$，求 $f(x) = x + \dfrac{1}{x}$ 的最小值。

**思路**：
1. $x > 0$，满足"一正" ✓
2. $x \cdot \dfrac{1}{x} = 1$ 是定值，满足"二定" ✓
3. $x + \dfrac{1}{x} \geq 2\sqrt{x \cdot \dfrac{1}{x}} = 2$
4. 等号当 $x = \dfrac{1}{x}$ 即 $x = 1$ 时成立，满足"三相等" ✓

**答案**：最小值为 $2$，当 $x = 1$ 时取得。

### 例题2：均值不等式求最值（需凑项）
**问题**：已知 $x > 2$，求 $f(x) = x + \dfrac{4}{x-2}$ 的最小值。

**思路**：
1. 令 $t = x - 2 > 0$，则 $f(x) = (t + 2) + \dfrac{4}{t} = t + \dfrac{4}{t} + 2$
2. $t + \dfrac{4}{t} \geq 2\sqrt{t \cdot \dfrac{4}{t}} = 4$
3. 等号当 $t = \dfrac{4}{t}$ 即 $t = 2$（$x = 4$）时成立

**答案**：最小值为 $6$，当 $x = 4$ 时取得。

### 例题3：线性规划
**问题**：已知 $x, y$ 满足约束条件 $\begin{cases} x + y \leq 4 \\ x \geq 0 \\ y \geq 0 \end{cases}$，求 $z = 2x + y$ 的最大值。

**思路**：
1. 画可行域：三角形，顶点为 $(0,0)$，$(4,0)$，$(0,4)$
2. 目标函数 $z = 2x + y$，即 $y = -2x + z$，斜率为 $-2$
3. 平移直线 $y = -2x$，过 $(4,0)$ 时 $z$ 最大
4. $z_{max} = 2 \times 4 + 0 = 8$

**答案**：最大值为 $8$。

## 📝 解题技巧/口诀
- **均值不等式口诀**："一正二定三相等，缺一不可用均值"
- **凑定值技巧**：
  - 求 $a + b$ 的最小值 → 需要 $ab$ 是定值
  - 求 $ab$ 的最大值 → 需要 $a + b$ 是定值
- **线性规划口诀**："画可行域，平移目标直线，找最优顶点"
- **解不等式**："因式分解 → 标根 → 穿针引线（数轴标根法）"
