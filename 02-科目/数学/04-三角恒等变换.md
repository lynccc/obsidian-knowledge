# 三角恒等变换

## 🗣️ 通俗讲解
> 三角恒等变换就是三角函数的"运算规则手册"。和差公式、二倍角公式这些工具，让你能把复杂的三角式化简成简单的形式。核心思想：降幂、合一、化简。

## 核心概念
- **和差公式**：$\sin(\alpha \pm \beta)$、$\cos(\alpha \pm \beta)$、$\tan(\alpha \pm \beta)$
- **二倍角公式**：和差公式的特例（令 $\beta = \alpha$）
- **辅助角公式**：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$

## 关键公式
- $\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
- $\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$
- $\sin 2\alpha = 2\sin\alpha\cos\alpha$
- $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$
- 降幂：$\sin^2\alpha = \dfrac{1-\cos 2\alpha}{2}$，$\cos^2\alpha = \dfrac{1+\cos 2\alpha}{2}$

## 典型例题思路
- 化简求值：统一角度→用和差/二倍角展开→合并同类项
- 辅助角合一：把 $a\sin x + b\cos x$ 合成一个三角函数
- 证明恒等式：从复杂的一边化简到简单的一边
