# 统计

## 🗣️ 通俗讲解
> 统计就是"用数据说话"的艺术：
> - **均值**（平均数）：告诉你"平均水平"是多少
> - **中位数**：把数据从小到大排，最中间的那个数
> - **众数**：出现次数最多的数
> - **方差**：告诉你数据"波动大小"——方差越大，数据越分散
>
> 想象一个班的考试成绩：均值是平均分，方差是成绩的"参差不齐"程度。

## 核心概念
- **抽样方法**：简单随机抽样、系统抽样、分层抽样
- **频率分布直方图**：横轴是数据区间，纵轴是频率/组距，面积之和为 1
- **数字特征**：刻画数据集中趋势和离散程度

## 均值、中位数、众数的区别

| 特征 | 定义 | 优点 | 缺点 |
|------|------|------|------|
| 均值 | 所有数据的平均 | 利用所有信息 | 受极端值影响大 |
| 中位数 | 排序后最中间的数 | 不受极端值影响 | 不利用所有信息 |
| 众数 | 出现次数最多的数 | 反映最常见情况 | 可能不唯一 |

## 关键公式
- **平均数**：$\bar{x} = \dfrac{1}{n}\sum_{i=1}^{n} x_i$
- **方差**：$s^2 = \dfrac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$
- **标准差**：$s = \sqrt{s^2}$（方差的算术平方根，与数据同单位）
- **方差简化公式**：$s^2 = \dfrac{1}{n}\sum x_i^2 - \bar{x}^2$
- **线性回归**：$\hat{y} = \hat{b}x + \hat{a}$，最小二乘法求系数

## 方差和标准差的含义
- **方差**衡量数据的离散程度：方差越大，数据越分散
- **标准差**是方差的算术平方根，与原始数据单位相同，更直观
- **经验法则**（正态分布下）：
  - 约 68% 数据在 $[\bar{x} - s, \bar{x} + s]$ 内
  - 约 95% 数据在 $[\bar{x} - 2s, \bar{x} + 2s]$ 内

## 频率分布直方图的读法
- **横轴**：数据的取值区间（组距）
- **纵轴**：$\dfrac{\text{频率}}{\text{组距}}$（不是频率！）
- **面积**：每个小矩形面积 = 该组的频率
- **总面积**：所有矩形面积之和 = 1

## 🎯 经典例题

### 例题1：求均值和方差
**问题**：数据 $2, 4, 6, 8, 10$，求均值和方差。

**思路**：
1. 均值 $\bar{x} = \dfrac{2+4+6+8+10}{5} = \dfrac{30}{5} = 6$
2. 方差 $s^2 = \dfrac{(2-6)^2 + (4-6)^2 + (6-6)^2 + (8-6)^2 + (10-6)^2}{5}$
3. $s^2 = \dfrac{16+4+0+4+16}{5} = \dfrac{40}{5} = 8$

**答案**：均值 $6$，方差 $8$。

### 例题2：频率分布直方图
**问题**：某班 50 名同学的成绩频率分布直方图中，$[80, 90)$ 这一组的矩形高度为 $0.03$，组距为 $10$，求该组的人数。

**思路**：
1. 频率 = 高度 × 组距 = $0.03 \times 10 = 0.3$
2. 人数 = 频率 × 总人数 = $0.3 \times 50 = 15$

**答案**：该组有 $15$ 人。

### 例题3：均值和方差的性质
**问题**：数据 $x_1, x_2, \ldots, x_n$ 的均值为 $\bar{x}$，方差为 $s^2$。求数据 $2x_1+1, 2x_2+1, \ldots, 2x_n+1$ 的均值和方差。

**思路**：
1. 新均值 $= 2\bar{x} + 1$（线性变换：均值也跟着变）
2. 新方差 $= 2^2 s^2 = 4s^2$（方差只受倍数影响，平移不影响方差）

**答案**：均值 $2\bar{x} + 1$，方差 $4s^2$。

## 📝 解题技巧/口诀
- **均值性质**：$y = ax + b$ 变换后，$\bar{y} = a\bar{x} + b$
- **方差性质**：$y = ax + b$ 变换后，$s_y^2 = a^2 s_x^2$（平移不影响方差）
- **频率分布直方图**：纵轴是频率/组距，面积才是频率
- **抽样方法选择**：
  - 总体个数少 → 简单随机抽样
  - 总体均匀分段 → 系统抽样
  - 总体差异大 → 分层抽样
