# 集合

## 🗣️ 通俗讲解
> 集合就是"装东西的框"——把满足某个条件的对象都放在一起，就成了一个集合。比如"我们班所有同学"就是一个集合。
> - **交集** $A \cap B$：两个框重叠的部分（既在A又在B的）
> - **并集** $A \cup B$：两个框合起来的所有东西（在A或在B的）
> - **补集** $\complement_U A$：大框里去掉A剩下的部分

> 用韦恩图（Venn Diagram）画出来最直观：两个圆圈重叠的部分是交集，合起来的整个区域是并集。

## 核心概念
- **集合**：确定的对象的全体，元素满足**确定性、互异性、无序性**
- **子集**：$A \subseteq B$ 表示 A 的元素都在 B 中
- **真子集**：$A \subsetneq B$ 表示 A 是 B 的子集且 $A \neq B$
- **空集**：$\varnothing$，不含任何元素的集合

## 关键公式
- 交集：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$
- 并集：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$
- 补集：$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$
- 德摩根律：$\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)$
- 子集个数：含 $n$ 个元素的集合有 $2^n$ 个子集

## ⚠️ 易错点
- **空集是任何集合的子集**：$\varnothing \subseteq A$ 恒成立！
- **空集是任何非空集合的真子集**：$\varnothing \subsetneq A$（$A \neq \varnothing$）
- **子集个数别忘了空集和自身**：$\{1,2,3\}$ 有 $2^3 = 8$ 个子集

## 🎯 经典例题

### 例题1：集合运算求参数范围
**问题**：已知集合 $A = \{x \mid x^2 - 3x + 2 = 0\}$，$B = \{x \mid x^2 - 2x + a = 0\}$，若 $B \subseteq A$，求 $a$ 的取值范围。

**思路**：
1. $A = \{1, 2\}$（解方程 $x^2 - 3x + 2 = 0$）
2. $B \subseteq A$，则 $B$ 可能是 $\varnothing$、$\{1\}$、$\{2\}$、$\{1,2\}$
3. 若 $B = \varnothing$：$\Delta = 4 - 4a < 0 \Rightarrow a > 1$
4. 若 $B = \{1\}$：$1$ 是重根，$\Delta = 0$ 且 $1+1=2$，$1 \times 1 = a$，得 $a = 1$
5. 若 $B = \{2\}$：$2$ 是重根，$\Delta = 0$ 且 $2+2=4 \neq 2$，矛盾
6. 若 $B = \{1,2\}$：$1+2=3 \neq 2$，矛盾

**答案**：$a \geq 1$。

### 例题2：子集个数问题
**问题**：集合 $A = \{1, 2, 3\}$，求 $A$ 的子集个数、真子集个数、非空子集个数。

**思路**：
1. 子集个数：$2^3 = 8$ 个（包括 $\varnothing$ 和自身）
2. 真子集个数：$2^3 - 1 = 7$ 个（去掉自身）
3. 非空子集个数：$2^3 - 1 = 7$ 个（去掉 $\varnothing$）

**答案**：子集 8 个，真子集 7 个，非空子集 7 个。

## 📝 解题技巧/口诀
- **集合运算口诀**："交集取公共，并集全都要，补集取剩下的"
- **子集个数公式**：$n$ 个元素有 $2^n$ 个子集
- **含参集合问题**：先解出集合元素，再根据集合关系列不等式
- **空集陷阱**：$B \subseteq A$ 时，$B$ 可能是空集！必须讨论
