# 函数性质

## 🗣️ 通俗讲解
> 函数性质就是描述函数"长什么样"的三个特征：
> - **单调性**就像爬坡——上坡是增函数（越走越高），下坡是减函数（越走越低）
> - **奇偶性**就像照镜子——偶函数左右对称（照镜子完全一样），奇函数中心对称（旋转180°重合）
> - **周期性**就像钟表——每隔固定时间就重复一遍，$\sin x$ 每 $2\pi$ 就"重播"一次

## 核心概念

### 单调性（爬坡/下坡）
- **增函数**：在区间 $D$ 上，$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$（上坡）
- **减函数**：在区间 $D$ 上，$x_1 < x_2 \Rightarrow f(x_1) > f(x_2)$（下坡）
- **判断方法**：
  - **定义法**：取 $x_1 < x_2$，计算 $f(x_1) - f(x_2)$ 判断正负
  - **导数法**：$f'(x) > 0$ 递增，$f'(x) < 0$ 递减

### 奇偶性（对称）
- **偶函数**：$f(-x) = f(x)$，图像关于 $y$ 轴对称（像蝴蝶翅膀）
- **奇函数**：$f(-x) = -f(x)$，图像关于原点对称（旋转180°重合）
- **前提条件**：定义域必须关于原点对称！

### 周期性（循环）
- 存在 $T > 0$ 使 $f(x+T) = f(x)$ 恒成立
- 常见周期：$\sin x, \cos x$ 周期 $2\pi$；$\tan x$ 周期 $\pi$

## 关键公式
- 增函数判定：$\dfrac{f(x_1) - f(x_2)}{x_1 - x_2} > 0$
- 奇函数前提：定义域关于原点对称，若 $0$ 在定义域内则 $f(0) = 0$
- 周期函数：$f(x+T) = f(x)$ 对所有 $x$ 成立

## 🎯 经典例题

### 例题1：判断函数奇偶性
**问题**：判断 $f(x) = x^3 + x$ 的奇偶性。

**思路**：
1. 定义域为 $\mathbb{R}$，关于原点对称 ✓
2. 计算 $f(-x) = (-x)^3 + (-x) = -x^3 - x = -(x^3 + x) = -f(x)$
3. 满足 $f(-x) = -f(x)$

**答案**：$f(x)$ 是奇函数。

### 例题2：利用单调性比较大小
**问题**：已知 $f(x)$ 在 $\mathbb{R}$ 上单调递增，且 $f(2a-1) > f(a+3)$，求 $a$ 的取值范围。

**思路**：
1. 因为 $f(x)$ 单调递增，所以 $f(2a-1) > f(a+3) \Leftrightarrow 2a-1 > a+3$
2. 解不等式：$2a - 1 > a + 3 \Rightarrow a > 4$

**答案**：$a > 4$，即 $a \in (4, +\infty)$。

### 例题3：已知奇偶性求参数
**问题**：若 $f(x) = ax^2 + bx + 3a + b$ 是偶函数，求 $a, b$ 的值。

**思路**：
1. 偶函数满足 $f(-x) = f(x)$
2. $f(-x) = a(-x)^2 + b(-x) + 3a + b = ax^2 - bx + 3a + b$
3. 对比系数：$-b = b \Rightarrow b = 0$
4. 偶函数定义域关于原点对称，$a$ 可取任意值（但需保证定义域对称）

**答案**：$b = 0$，$a$ 为任意实数。

## 📝 解题技巧/口诀
- **判断奇偶性口诀**："先看定义域对不对称，再算 $f(-x)$ 等不等于 $\pm f(x)$"
- **单调性证明**：设 $x_1 < x_2$，作差 $f(x_1) - f(x_2)$，因式分解判断正负
- **周期性应用**：$f(x)$ 周期为 $T$，则 $f(a) = f(a + nT)$（$n$ 为整数）
- **奇偶性简化**：偶函数只需研究 $[0, +\infty)$，奇函数只需研究 $(0, +\infty)$
