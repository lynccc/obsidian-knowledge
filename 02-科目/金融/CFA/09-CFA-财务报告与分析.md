# 财务报告与分析（Financial Reporting and Analysis）

> ⚠️ **来源说明：** 以下内容基于通用会计与财务分析原理整理，非特指某版 CFA 教材。待主人提供教材后补充具体例题和 IFRS/GAAP 细节差异。

## 三大财务报表

### 1. 资产负债表（Balance Sheet）

$$Assets = Liabilities + Equity$$

| 项目 | 说明 |
|------|------|
| 流动资产 | 现金、应收账款、存货、预付费用 |
| 非流动资产 | 固定资产、无形资产、商誉 |
| 流动负债 | 应付账款、短期借款、预收款项 |
| 非流动负债 | 长期借款、应付债券 |
| 股东权益 | 股本、留存收益、其他综合收益 |

### 2. 利润表（Income Statement）

$$Revenue - Expenses = Net\ Income$$

关键项目：
- 营业收入（Revenue）
- 营业成本（COGS）→ 毛利（Gross Profit）
- 营业费用（SG&A, R&D）→ 营业利润（Operating Income）
- 利息费用、税费 → 净利润（Net Income）

### 3. 现金流量表（Cash Flow Statement）

| 类别 | 内容 |
|------|------|
| 经营活动（CFO） | 日常业务产生的现金流 |
| 投资活动（CFI） | 购置/处置长期资产 |
| 筹资活动（CFF） | 借款/还款、发股/回购、分红 |

## 关键财务比率

### 流动性比率
- **流动比率** = 流动资产 / 流动负债
- **速动比率** = (流动资产 - 存货) / 流动负债

### 盈利能力比率
- **毛利率** = 毛利 / 营收
- **净利率** = 净利润 / 营收
- **ROA** = 净利润 / 总资产
- **ROE** = 净利润 / 股东权益

### 杜邦分析（DuPont Analysis）

$$ROE = \frac{Net\ Income}{Revenue} \times \frac{Revenue}{Assets} \times \frac{Assets}{Equity}$$

即：ROE = 净利率 × 资产周转率 × 权益乘数

## IFRS vs US GAAP 主要差异

| 项目 | IFRS | US GAAP |
|------|------|---------|
| 存货 | 不允许 LIFO | 允许 LIFO |
| 开发费用 | 可资本化 | 通常费用化 |
| 固定资产重估 | 允许 | 不允许 |
| 减值转回 | 允许 | 不允许 |
| 收入确认 | IFRS 15（五步法） | ASC 606（类似） |
