# 权益投资（Equity Investments）

> ⚠️ **来源说明：** 以下内容基于通用股票市场与估值知识整理，非特指某版 CFA 教材。待主人提供教材后补充具体例题。

## 证券市场结构

### 订单类型
- **市价单（Market Order）**：立即以最优市价成交
- **限价单（Limit Order）**：指定价格或更优价格成交
- **止损单（Stop Order）**：达到触发价后转为市价单

### 市场参与者
- 做市商（Dealer）：提供流动性
- 经纪商（Broker）：代理交易
- 交易所 vs OTC（场外市场）

## 有效市场假说（EMH）

| 形式 | 价格反映的信息 | 能否通过基本面/技术分析获利 |
|------|--------------|-------------------------|
| 弱式（Weak） | 历史价格信息 | 不能通过技术分析 |
| 半强式（Semi-strong） | 所有公开信息 | 不能通过基本面分析 |
| 强式（Strong） | 所有信息（含内幕） | 不能通过任何分析 |

## 权益估值模型

### 1. 股利贴现模型（DDM）

$$P_0 = \frac{D_1}{r - g}$$

- D₁ = 下期股利
- r = 要求收益率
- g = 股利增长率（g = ROE × 留存比率）

**适用条件：** 公司有稳定股利政策，g < r

### 2. 乘数法（Multiples）

**市盈率（P/E）：**

$$P/E = \frac{Price}{EPS}$$

**市净率（P/B）：**

$$P/B = \frac{Price}{Book\ Value\ per\ Share}$$

**市销率（P/S）：**

$$P/S = \frac{Price}{Revenue\ per\ Share}$$

### 3. 自由现金流模型（FCF）

**公司自由现金流（FCFF）：**

$$FCFF = EBIT \times (1-t) + D\&A - \Delta WC - CapEx$$

**股权自由现金流（FCFE）：**

$$FCFE = FCFF - Interest \times (1-t) + Net\ Borrowing$$

## 行业分析框架

- **波特五力模型**：供应商议价力、买方议价力、新进入者威胁、替代品威胁、行业竞争
- **行业生命周期**：初创期 → 成长期 → 成熟期 → 衰退期
