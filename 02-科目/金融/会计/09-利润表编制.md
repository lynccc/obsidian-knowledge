# 09-利润表编制

## 概念说明

利润表是反映企业在一定期间内经营成果的报表。它回答一个问题：**这段时间企业赚了多少钱？**

利润表的结构就像一个漏斗：
1. 先算主营业务利润（卖东西赚了多少）
2. 减去期间费用（管理费、销售费、财务费）
3. 得到利润总额
4. 减去所得税
5. 最后得到净利润

## 核心要点

### 利润表结构

```
主营业务收入
减：主营业务成本
= 主营业务利润（毛利）

减：管理费用
减：销售费用
减：财务费用
= 利润总额

减：所得税费用
= 净利润
```

### 各项目含义

| 项目 | 含义 |
|------|------|
| 主营业务收入 | 卖商品收到的钱 |
| 主营业务成本 | 卖出去商品的进货成本 |
| 主营业务利润 | 卖东西赚的毛利 |
| 管理费用 | 行政管理发生的费用 |
| 销售费用 | 销售部门发生的费用 |
| 财务费用 | 借款利息等 |
| 利润总额 | 扣除费用后的利润 |
| 所得税费用 | 要交的所得税 |
| 净利润 | 最终到手的利润 |

### 关键公式

$$主营业务利润 = 主营业务收入 - 主营业务成本$$

$$利润总额 = 主营业务利润 - 管理费用 - 销售费用 - 财务费用$$

$$净利润 = 利润总额 - 所得税费用$$

## 练习题

### 题目1

**题目描述：** 某企业本期数据如下：主营业务收入25万元，主营业务成本12万元，管理费用6万元，销售费用1.2万元，财务费用0.8万元，所得税费用1万元。编制利润表并计算各项目。

**解答：**
```
主营业务收入：          250000
减：主营业务成本：      120000
= 主营业务利润：        130000

减：管理费用：          60000
减：销售费用：          12000
减：财务费用：          8000
= 利润总额：            50000

减：所得税费用：        10000
= 净利润：              40000
```

**解析：** 按照利润表的结构，从上到下逐步计算。主营业务收入25万减去成本12万，得到毛利13万；再减去三项费用（6万+1.2万+0.8万=8万），得到利润总额5万；最后减去所得税1万，得到净利润4万。

### 题目2

**题目描述：** 某企业本期主营业务收入100万元，主营业务成本60万元，管理费用15万元，销售费用8万元，财务费用2万元。所得税率25%。编制利润表。

**解答：**
```
主营业务收入：          1000000
减：主营业务成本：      600000
= 主营业务利润：        400000

减：管理费用：          150000
减：销售费用：          80000
减：财务费用：          20000
= 利润总额：            150000

减：所得税费用：        37500（150000 × 25%）
= 净利润：              112500
```

**解析：** 这道题需要先算利润总额，再根据税率计算所得税。利润总额15万 × 25% = 3.75万所得税。净利润 = 15万 - 3.75万 = 11.25万。

### 题目3

**题目描述：** 某企业本月数据：主营业务收入50万元，主营业务成本30万元，管理费用8万元，销售费用5万元，财务费用1万元。计算：（1）主营业务利润；（2）利润总额；（3）如果所得税率25%，净利润是多少？

**解答：**
```
（1）主营业务利润 = 50万 - 30万 = 20万
（2）利润总额 = 20万 - 8万 - 5万 - 1万 = 6万
（3）所得税 = 6万 × 25% = 1.5万
    净利润 = 6万 - 1.5万 = 4.5万
```

**解析：** 分步计算，每一步都用上一步的结果。主营业务利润是收入减成本，利润总额是毛利减费用，净利润是利润总额减所得税。

### 题目4

**题目描述：** 某企业连续两个月的数据如下，计算各月净利润：

| 项目 | 1月 | 2月 |
|------|-----|-----|
| 主营业务收入 | 80万 | 100万 |
| 主营业务成本 | 50万 | 60万 |
| 管理费用 | 10万 | 12万 |
| 销售费用 | 5万 | 6万 |
| 财务费用 | 2万 | 3万 |
| 所得税率 | 25% | 25% |

**解答：**
```
1月：
主营业务利润 = 80万 - 50万 = 30万
利润总额 = 30万 - 10万 - 5万 - 2万 = 13万
所得税 = 13万 × 25% = 3.25万
净利润 = 13万 - 3.25万 = 9.75万

2月：
主营业务利润 = 100万 - 60万 = 40万
利润总额 = 40万 - 12万 - 6万 - 3万 = 19万
所得税 = 19万 × 25% = 4.75万
净利润 = 19万 - 4.75万 = 14.25万

累计净利润 = 9.75万 + 14.25万 = 24万
```

**解析：** 每个月独立计算净利润，然后可以累加得到累计净利润。这是利润表的动态分析，可以观察企业盈利的变化趋势。

### 题目5

**题目描述：** 某企业年度利润表显示：主营业务收入200万元，净利润40万元。已知管理费用20万元，销售费用10万元，财务费用5万元，所得税率25%。反推主营业务成本。

**解答：**
```
设主营业务成本为X

利润总额 = 净利润 ÷ (1 - 25%) = 40万 ÷ 0.75 = 53.33万
或：利润总额 × (1-25%) = 净利润 → 利润总额 = 净利润 ÷ 75%

主营业务利润 = 利润总额 + 管理费用 + 销售费用 + 财务费用
           = 53.33万 + 20万 + 10万 + 5万 = 88.33万

主营业务成本 = 主营业务收入 - 主营业务利润
           = 200万 - 88.33万 = 111.67万
```

**解析：** 这是逆向计算题。从净利润倒推利润总额（净利润 ÷ (1-税率)），再从利润总额倒推主营业务利润（加上各项费用），最后从主营业务利润倒推主营业务成本（收入减毛利）。这类题考察对利润表结构的深入理解。
