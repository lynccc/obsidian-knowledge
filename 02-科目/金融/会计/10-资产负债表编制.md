# 10-资产负债表编制

## 概念说明

资产负债表是反映企业在某一**特定日期**（比如12月31日）财务状况的报表。它回答一个问题：**这一天企业有多少资产、欠多少债、所有者权益是多少？**

资产负债表的核心等式：**资产 = 负债 + 所有者权益**

这张表就像企业的"体检报告"，让你看到企业的"家底"。

## 核心要点

### 资产负债表结构

```
资产：
  货币资金
  应收账款
  存货
  固定资产
  资产合计

负债：
  应付账款
  其他应付款
  应付工资
  长期借款
  负债合计

所有者权益：
  实收资本
  未分配利润
  所有者权益合计

负债和所有者权益合计 = 资产合计
```

### 各项目含义

#### 资产类

| 项目 | 含义 | 填列方法 |
|------|------|----------|
| 货币资金 | 库存现金 + 银行存款 | 两个科目余额合计 |
| 应收账款 | 别人欠我们的货款 | 应收账款科目余额 |
| 存货 | 库存商品等 | 库存商品科目余额 |
| 固定资产 | 设备、房屋等 | 固定资产科目余额 |

#### 负债类

| 项目 | 含义 | 填列方法 |
|------|------|----------|
| 应付账款 | 欠供应商的货款 | 应付账款科目余额 |
| 其他应付款 | 其他各种应付款 | 应付利息+应付股利等 |
| 应付工资 | 欠员工的工资 | 应付工资科目余额 |
| 长期借款 | 一年以上的借款 | 长期借款科目余额 |

#### 所有者权益类

| 项目 | 含义 | 填列方法 |
|------|------|----------|
| 实收资本 | 投资者投入的资本 | 实收资本科目余额 |
| 未分配利润 | 留在企业的利润 | 未分配利润科目余额 |

## 练习题

### 题目1

**题目描述：** 某企业2025年12月31日各科目余额如下：库存现金2万元，银行存款18万元，应收账款25万元，库存商品30万元，固定资产100万元，应付账款15万元，短期借款20万元，实收资本100万元，未分配利润40万元。编制资产负债表。

**解答：**
```
资产负债表
2025年12月31日

资产：
  货币资金：    20万（库存现金2万+银行存款18万）
  应收账款：    25万
  存货：        30万（库存商品30万）
  固定资产：    100万
  资产合计：    175万

负债：
  应付账款：    15万
  短期借款：    20万
  负债合计：    35万

所有者权益：
  实收资本：    100万
  未分配利润：  40万
  所有者权益合计：140万

负债和所有者权益合计：175万
```

**解析：** 资产合计175万 = 负债35万 + 所有者权益140万，等式平衡。注意：货币资金是库存现金和银行存款的合计；存货通常就是库存商品的余额。

### 题目2

**题目描述：** 某企业年初和年末数据对比如下：

| 项目 | 年初 | 年末 |
|------|------|------|
| 货币资金 | 50万 | 60万 |
| 应收账款 | 30万 | 20万 |
| 存货 | 40万 | 35万 |
| 固定资产 | 120万 | 110万 |
| 应付账款 | 25万 | 30万 |
| 实收资本 | 100万 | 100万 |
| 未分配利润 | 115万 | 95万 |

分析资产负债表的变化。

**解答：**
```
年初：
资产合计 = 50+30+40+120 = 240万
负债合计 = 25万
所有者权益 = 100+115 = 215万
验证：25+215 = 240万 ✓

年末：
资产合计 = 60+20+35+110 = 225万
负债合计 = 30万
所有者权益 = 100+95 = 195万
验证：30+195 = 225万 ✓

变化分析：
- 资产减少15万（240→225）
- 负债增加5万（25→30）
- 所有者权益减少20万（215→195）
```

**解析：** 资产减少15万，负债增加5万，所有者权益减少20万。所有者权益减少20万说明企业可能发生了亏损或者分配了股利。实收资本没变，说明变化全在未分配利润上（减少了20万）。

### 题目3（串讲经典计算题）⭐⭐⭐

**题目描述：** 某企业期初资产总额1000万元，本月发生以下业务：（1）接受投资者投入资本100万元存入银行；（2）用银行存款偿还应付货款20万元；（3）销售商品售价90万元（成本80万元），货款已收存入银行。计算月末资产总额。

**解答：**
```
月末资产总额 = 期初资产 + 接受投资 - 偿还货款 + 销售净增
            = 1000 + 100 - 20 + (90 - 80)
            = 1000 + 100 - 20 + 10
            = 1090万元
```

**逐笔分析：**
| 业务 | 资产变动 | 说明 |
|------|---------|------|
| 期初余额 | 1000万 | 基数 |
| 接受投资 | +100万 | 银行存款增加100万（资产增），实收资本增加100万（权益增） |
| 偿还货款 | -20万 | 银行存款减少20万（资产减），应付账款减少20万（负债减） |
| 销售商品 | +10万 | 银行存款增加90万（收入），库存商品减少80万（成本），净增10万 |
| **月末余额** | **1090万** | |

**解析：** 销售商品对资产的影响是净增10万：收到90万银行存款，发出80万商品（库存商品减少80万），资产净增10万。这笔业务同时增加了收入90万和成本80万，利润增加10万（未分配利润增加10万），等式仍然平衡：资产1090万 = 负债(原负债-20万) + 所有者权益(原权益+100万+10万)。

### 题目4

**题目描述：** 企业年末数据：货币资金80万，应收账款50万，存货60万，固定资产200万。应付账款40万，短期借款30万，实收资本150万，未分配利润170万。验证资产负债表是否平衡。

**解答：**
```
资产合计 = 80+50+60+200 = 390万
负债合计 = 40+30 = 70万
所有者权益合计 = 150+170 = 320万

验证：70+320 = 390万 ✓ 平衡
```

**解析：** 资产负债表必须平衡，即资产合计必须等于负债加所有者权益合计。如果不平衡，说明计算有误或者有遗漏的科目。

### 题目5

**题目描述：** 某企业年初资产合计500万，年内发生以下业务：（1）收入200万，费用150万，所得税率25%；（2）分配股利10万；（3）没有其他业务。计算年末未分配利润和资产变化。

**解答：**
```
净利润 = (200万-150万) × (1-25%) = 50万 × 75% = 37.5万
年末未分配利润 = 年初未分配利润 + 37.5万 - 10万

假设年初未分配利润为X，则年末为X+27.5万

资产变化：
- 收入增加资产200万
- 费用减少资产150万
- 所得税减少资产12.5万（50万×25%）
- 分配股利减少资产10万
- 资产净增加 = 200-150-12.5-10 = 27.5万
```

**解析：** 净利润会增加所有者权益（未分配利润），分配股利会减少未分配利润。资产的变化等于净利润减去已分配的股利。这道题展示了利润分配对资产负债表的影响。

### 题目6

**题目描述：** 某企业年初资产负债表显示：资产合计300万，负债100万，所有者权益200万（实收资本150万，未分配利润50万）。年末资产合计350万，负债120万。计算年末未分配利润。

**解答：**
```
年末所有者权益 = 年末资产 - 年末负债 = 350万 - 120万 = 230万
年末未分配利润 = 年末所有者权益 - 实收资本 = 230万 - 150万 = 80万

验证：年初未分配利润50万，年末80万，增加30万
说明当年净利润减去分配的股利后，未分配利润增加了30万
```

**解析：** 从资产负债表的等式出发，先算出年末所有者权益（资产-负债），再减去实收资本得到未分配利润。未分配利润从50万增加到80万，说明企业当年有盈利且大部分留在了企业里。
