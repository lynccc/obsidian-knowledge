# 06-费用支付业务

## 概念说明

企业在日常经营中会发生各种费用，比如发工资、付房租、买办公用品等。这些费用需要按照用途分类记录。

费用支付业务的核心逻辑：
- 费用增加（记借方）—— 钱花出去了，产生了费用
- 资产减少（记贷方）—— 银行存款或现金减少了

注意：提取现金只是资产内部转换（银行存款变成库存现金），不涉及费用。

## 核心要点

### 费用支付业务分录

| 业务场景 | 借方 | 贷方 |
|----------|------|------|
| 提取现金 | 库存现金 | 银行存款 |
| 支付管理费用 | 管理费用 | 库存现金/银行存款 |
| 支付销售费用 | 销售费用 | 库存现金/银行存款 |
| 支付办公费 | 管理费用 | 银行存款 |
| 支付租金 | 管理费用 | 银行存款 |
| 支付广告费 | 销售费用 | 银行存款 |

### 费用分类要点

- **管理费用**：行政管理部门发生的费用（工资、办公费、租金等）
- **销售费用**：销售部门发生的费用（销售人员工资、广告费、运输费等）
- **财务费用**：与筹资相关的费用（利息、手续费等），在[[05-资金筹集业务]]中已讲

## 公式/分录模板

### 提取现金

```
借：库存现金        （金额）
贷：银行存款        （金额）
```

### 支付工资

```
借：管理费用        （管理人员工资）
借：销售费用        （销售人员工资）
贷：库存现金        （工资总额）
```

### 支付办公费

```
借：管理费用        （金额）
贷：银行存款        （金额）
```

### 支付租金

```
借：管理费用        （金额）
贷：银行存款        （金额）
```

### 支付广告费

```
借：销售费用        （金额）
贷：银行存款        （金额）
```

## 练习题

### 题目1

**题目描述：** 企业从银行提取现金5万元备用。写出会计分录。

**解答：**
```
借：库存现金    50000
贷：银行存款    50000
```

**解析：** 提取现金只是钱的形式变了（从银行账户变成手头现金），不涉及费用。库存现金增加（资产增加，记借方），银行存款减少（资产减少，记贷方）。资产内部一增一减。

### 题目2

**题目描述：** 企业用现金支付管理人员工资3万元、销售人员工资2万元。写出会计分录。

**解答：**
```
借：管理费用    30000
借：销售费用    20000
贷：库存现金    50000
```

**解析：** 工资按照人员归属分别计入管理费用和销售费用。管理人员工资属于管理费用，销售人员工资属于销售费用。一贷多借，借贷相等。

### 题目3

**题目描述：** 企业用银行存款支付办公室租金1.5万元。写出会计分录。

**解答：**
```
借：管理费用    15000
贷：银行存款    15000
```

**解析：** 办公室租金属于管理费用（行政管理部门使用的场所），用银行存款支付（资产减少）。费用增加记借方，资产减少记贷方。

### 题目4

**题目描述：** 企业用银行存款支付产品广告费8000元。写出会计分录。

**解答：**
```
借：销售费用    8000
贷：银行存款    8000
```

**解析：** 广告费是为了促进销售而发生的费用，属于销售费用。用银行存款支付，银行存款减少。

### 题目5

**题目描述：** 某企业本月发生以下费用：（1）提取现金10万元；（2）用现金支付管理人员工资6万元；（3）用现金支付销售人员工资4万元；（4）用银行存款支付办公费5000元；（5）用银行存款支付广告费1.2万元。写出所有分录。

**解答：**
```
业务（1）：
借：库存现金    100000
贷：银行存款    100000

业务（2）：
借：管理费用    60000
贷：库存现金    60000

业务（3）：
借：销售费用    40000
贷：库存现金    40000

业务（4）：
借：管理费用    5000
贷：银行存款    5000

业务（5）：
借：销售费用    12000
贷：银行存款    12000
```

**解析：** 提取现金（业务1）不是费用，只是资产内部转换。业务2-5才是费用支付，要按用途分别计入管理费用或销售费用。注意支付方式不同（现金还是银行存款），贷方科目不同。
