# 01-会计基础等式

## 概念说明

会计基础等式，也叫**会计恒等式**，是整个会计体系的基石。它表达了一个简单而深刻的道理：**企业的资产，要么是借来的（负债），要么是自己投入的（所有者权益）**。

想象一下：你开了一家小店，手里有10万元。其中3万是你从银行借的，7万是你自己的存款。那么你的资产（10万）= 负债（3万）+ 所有者权益（7万）。这就是最基本的等式。

## 核心要点

### 会计恒等式

$$资产 = 负债 + 所有者权益$$

- **资产**：企业拥有的、能带来经济利益的资源。比如现金、银行存款、存货、设备等
- **负债**：企业欠别人的钱。比如欠供应商的货款、银行贷款等
- **所有者权益**：企业所有者（股东）在企业中的权益，等于资产减去负债。比如投入的资本、累积的利润等

### 收入费用与净利润的关系

$$收入 - 费用 = 净利润$$

净利润最终会累加到所有者权益中的**未分配利润**项目。也就是说，企业赚的钱，要么分配给股东（变成应付股利），要么留在企业里（未分配利润），都属于所有者权益的一部分。

### 借贷记账法基本原则

| 要素 | 增加 | 减少 |
|------|------|------|
| 资产 | 借方 | 贷方 |
| 负债 | 贷方 | 借方 |
| 所有者权益 | 贷方 | 借方 |
| 收入 | 贷方 | 借方 |
| 费用 | 借方 | 贷方 |

**记忆口诀**：资产费用借增贷减，负债权益收入贷增借减。

## 公式/分录模板

```
基本等式：资产 = 负债 + 所有者权益
扩展等式：资产 = 负债 + 所有者权益 + 收入 - 费用
```

### 举例说明

1. 企业用银行存款10万元购买设备
   - 资产内部一增一减：固定资产增加（借），银行存款减少（贷）
   - 等式不变：10万资产 → 设备+10万，银行存款-10万

2. 企业向银行借款20万元
   - 资产增加：银行存款+20万（借）
   - 负债增加：短期借款+20万（贷）
   - 等式两边同时增加

3. 企业销售商品收入5万元（已收款）
   - 资产增加：银行存款+5万（借）
   - 收入增加：主营业务收入+5万（贷）
   - 收入最终转入所有者权益，等式平衡

## 练习题

### 题目1

**题目描述：** 某企业资产总额100万元，负债总额40万元，计算所有者权益总额。

**解答：** 所有者权益 = 资产 - 负债 = 100万 - 40万 = **60万元**

**解析：** 直接运用会计恒等式。资产永远等于负债加所有者权益，所以知道了任意两个，就能算出第三个。

### 题目2

**题目描述：** 企业用银行存款偿还应付账款5万元，资产总额如何变化？

**解答：** 资产总额**不变**。银行存款减少5万（资产减少），应付账款减少5万（负债减少）。等式两边同时减少5万，仍然平衡。

**解析：** 这是资产和负债同时减少的情况。等式的左边（资产）和右边（负债）都减了5万，平衡关系保持不变。

### 题目3

**题目描述：** 企业接受投资者投入资本30万元存入银行，分析对等式的影响。

**解答：**
- 资产增加：银行存款 +30万（借方）
- 所有者权益增加：实收资本 +30万（贷方）
- 等式两边同时增加30万

**解析：** 投资者投入资本，一方面企业银行存款增加（资产增加），另一方面所有者在企业中的权益增加（实收资本增加）。这是典型的等式两边同增的业务。

### 题目4

**题目描述：** 企业本月收入10万元，费用6万元，净利润是多少？对所有者权益有什么影响？

**解答：** 净利润 = 10万 - 6万 = **4万元**。净利润4万元最终会转入所有者权益中的未分配利润，使所有者权益增加4万元。

**解析：** 收入减去费用等于净利润。净利润是企业经营的成果，属于所有者的权益。如果不分配给股东，就会留在企业里成为未分配利润。
