# 17-会计分录编制方法

## 概念说明

借贷记账法是会计分录的核心方法，核心规则是"有借必有贷，借贷必相等"。掌握分录编制方法，是学好会计的关键。

## 核心要点

### 借贷记账法核心规则

- **有借必有贷，借贷必相等**：每一笔分录都必须同时有借方和贷方，且金额相等
- **切记：借和贷与字面意思无关！** "借"和"贷"只是记账符号，不代表"借钱"或"贷款"

### ⚠️ 核心口诀（必背）

```
资成费（资产、成本、费用）→ 借增贷减
负所收（负债、所有者权益、收入）→ 借减贷增
```

**切记：借和贷与字面意思无关！**
- "借"和"贷"只是记账符号，不要从字面理解
- "借"不代表"借钱"，"贷"不代表"贷款"
- 借在左，贷在右，仅此而已

### 账户结构口诀

**"资成费借增贷减，负所收借减贷增"**

| 科目类型 | 增加方向 | 减少方向 | 记忆口诀 |
|----------|----------|----------|----------|
| **资**产类 | 借方 | 贷方 | 资成费借增贷减 |
| **成**本类 | 借方 | 贷方 | 资成费借增贷减 |
| **费**用类 | 借方 | 贷方 | 资成费借增贷减 |
| **负**债类 | 贷方 | 借方 | 负所收借减贷增 |
| **所**有者权益类 | 贷方 | 借方 | 负所收借减贷增 |
| **收**入类 | 贷方 | 借方 | 负所收借减贷增 |

### 分录填空法（四步法）

```
第一步：分析业务涉及哪些会计要素（资产/负债/权益/收入/费用）
第二步：判断各要素是增加还是减少
第三步：根据账户结构确定借贷方向
第四步：写出完整分录，检查借贷是否相等
```

### 资产类账户余额计算

$$期末余额 = 期初借方余额 + 本期借方发生额 - 本期贷方发生额$$

### 负债类账户余额计算

$$期末余额 = 期初贷方余额 + 本期贷方发生额 - 本期借方发生额$$

### 收入类与费用类账户

- **收入类**：贷增借减，期末无余额（结转到本年利润）
- **费用类**：借增贷减，期末无余额（结转到本年利润）
- 两者结构**完全相反**

### 正数原则

- 日常业务只记正数
- 负数仅用于调整差错
- 这是会计实务中的基本规范

### 检查方法

分录编制完成后，检查：
1. 借贷金额是否相等
2. 会计恒等式是否平衡（资产 = 负债 + 所有者权益）
3. 分录逻辑是否合理

### "左借右贷"标准格式

```
借：科目名称    金额
贷：科目名称    金额
```

**格式要求：**
- 借方在上，贷方在下
- 借方科目靠左，贷方科目缩进（或写"贷"字）
- 金额对齐
- 一借多贷或一贷多借时，借贷方金额合计必须相等

## 公式/分录模板

### 常用分录模板

#### 1. 收到投资

```
借：银行存款        XXX
贷：实收资本        XXX
```

#### 2. 购买原材料（赊购）

```
借：原材料          XXX
贷：应付账款        XXX
```

#### 3. 销售商品（赊销）

```
借：应收账款        XXX
贷：主营业务收入    XXX
```

#### 4. 结转销售成本

```
借：主营业务成本    XXX
贷：库存商品        XXX
```

#### 5. 支付费用

```
借：管理费用        XXX
贷：银行存款        XXX
```

#### 6. 收到货款

```
借：银行存款        XXX
贷：应收账款        XXX
```

## 练习题

### 题目1（选择题）

**题目描述：** 下列关于借贷记账法的表述中，正确的是（ ）。

A. "借"表示增加，"贷"表示减少  
B. "借"表示减少，"贷"表示增加  
C. "借"和"贷"只是记账符号，与增减无固定关系  
D. "借"表示收入，"贷"表示费用

**答案：C**

**解析：** 在借贷记账法中，"借"和"贷"只是记账符号，不直接代表增加或减少。资产类、成本类、费用类账户借方表示增加；负债类、所有者权益类、收入类账户贷方表示增加。所以不能简单地说"借=增"或"贷=增"。

### 题目2（选择题）

**题目描述：** 企业用银行存款偿还应付账款5万元，该笔分录正确的是（ ）。

A. 借：应付账款 5万，贷：银行存款 5万  
B. 借：银行存款 5万，贷：应付账款 5万  
C. 借：应付账款 5万，贷：库存现金 5万  
D. 借：管理费用 5万，贷：应付账款 5万

**答案：A**

**解析：** 偿还应付账款：（1）应付账款减少（负债减少记借方）；（2）银行存款减少（资产减少记贷方）。所以是借：应付账款，贷：银行存款。

### 题目3（判断题）

**题目描述：** 在借贷记账法下，收入类账户的结构与费用类账户的结构完全相同。（ ）

**答案：✗（错误）**

**解析：** 收入类账户与费用类账户的结构完全相反。收入类账户：贷方记增加，借方记减少（贷增借减）。费用类账户：借方记增加，贷方记减少（借增贷减）。两者方向相反。

### 题目4（计算题）

**题目描述：** 某企业"银行存款"账户期初借方余额为100万元，本期借方发生额为80万元，本期贷方发生额为60万元。该账户的期末余额为（ ）。

A. 120万元  
B. 80万元  
C. 140万元  
D. 60万元

**答案：A**

**解析：** 资产类账户期末余额 = 期初借方余额 + 本期借方发生额 - 本期贷方发生额 = 100 + 80 - 60 = 120万元。银行存款是资产类账户，增加记借方，减少记贷方。

### 题目5（分录题）

**题目描述：** 编制以下业务的会计分录：

（1）收到投资者投入资本200万元，存入银行  
（2）用银行存款购买设备一台，价值50万元  
（3）销售商品一批，售价30万元，货款尚未收到  
（4）用银行存款支付本月办公费2万元

**解答：**

```
（1）借：银行存款        2,000,000
     贷：实收资本        2,000,000

（2）借：固定资产          500,000
     贷：银行存款          500,000

（3）借：应收账款          300,000
     贷：主营业务收入      300,000

（4）借：管理费用           20,000
     贷：银行存款           20,000
```

**解析：**
- （1）收到投资：资产（银行存款）增加记借方，权益（实收资本）增加记贷方
- （2）购买设备：资产（固定资产）增加记借方，资产（银行存款）减少记贷方
- （3）赊销商品：资产（应收账款）增加记借方，收入（主营业务收入）增加记贷方
- （4）支付费用：费用（管理费用）增加记借方，资产（银行存款）减少记贷方

### 题目6（选择题）

**题目描述：** 下列会计分录中，属于一借多贷的是（ ）。

A. 借：银行存款 10万，贷：应收账款 10万  
B. 借：原材料 8万，贷：银行存款 5万，应付账款 3万  
C. 借：管理费用 2万，销售费用 3万，贷：银行存款 5万  
D. 借：银行存款 20万，贷：实收资本 20万

**答案：B**

**解析：** 一借多贷是指借方只有一个科目，贷方有多个科目。B选项借方是"原材料"一个科目，贷方是"银行存款"和"应付账款"两个科目，属于一借多贷。C是一贷多借（借方两个，贷方一个）。

### 题目7（综合题）

**题目描述：** 某企业"应付账款"账户期初贷方余额为30万元，本期贷方发生额为20万元，本期借方发生额为25万元。该账户的期末余额为（ ）。

A. 借方25万元  
B. 贷方25万元  
C. 借方35万元  
D. 贷方35万元

**答案：B**

**解析：** 负债类账户期末余额 = 期初贷方余额 + 本期贷方发生额 - 本期借方发生额 = 30 + 20 - 25 = 25万元（贷方余额）。应付账款是负债类账户，增加记贷方，减少记借方。
