## 重点公式速查

```
会计恒等式：资产 = 负债 + 所有者权益
利润公式：  净利润 = 收入 - 费用 - 所得税
毛利公式：  毛利率 = (收入 - 成本) ÷ 收入 × 100%
可变现净值：售价 - 进一步加工成本 - 销售费用 - 相关税费
资产负债率：负债总额 ÷ 资产总额 × 100%
ROE：       净利润 ÷ 净资产 × 100%
PE：        股价 ÷ 每股收益
资产余额：  期末 = 期初借方 + 本期借方 - 本期贷方
负债余额：  期末 = 期初贷方 + 本期贷方 - 本期借方
现金净增：  经营净额 + 投资净额 + 筹资净额
```

## 借贷方向速查

| 科目类型 | 增加 | 减少 |
|----------|------|------|
| 资产 | 借方 | 贷方 |
| 成本 | 借方 | 贷方 |
| 费用 | 借方 | 贷方 |
| 负债 | 贷方 | 借方 |
| 所有者权益 | 贷方 | 借方 |
| 收入 | 贷方 | 借方 |

**记忆口诀**：资成费借增贷减，负所收借减贷增。

## 口诀速查

| 口诀 | 含义 |
|------|------|
| 资成费借增贷减，负所收借减贷增 | 借贷方向 |
| 主持会货 | 四大假设：会计主体、持续经营、会计分期、货币计量 |
| 历重现可公 | 五种计量属性：历史成本、重置成本、现值、可变现净值、公允价值 |
| 可可明谨重实相及 | 八大原则：可比性、可靠性、明晰性、谨慎性、重要性、实质重于形式、相关性、及时性 |
| 三财三营 | 六大要素：三财务状况+三经营成果 |
| 毛利两不要 | 毛利率计算不要费用、不要税 |
| 售价减三样 | 可变现净值=售价-加工-销售-税 |
| 设备股票利息 | 投资活动包括买设备、买卖股票、收债券利息 |
| 借贷分红 | 筹资活动包括借钱、还钱、分配股利 |

## 常用科目一览

### 资产类（借增贷减）

- 库存现金、银行存款、应收账款、库存商品、固定资产、待摊费用、交易性金融资产、原材料

### 负债类（贷增借减）

- 应付账款、短期借款、应付利息、应付股利、应交税费、预收账款

### 所有者权益类（贷增借减）

- 实收资本、未分配利润、本年利润

### 损益类

- 主营业务收入（贷增）、其他业务收入（贷增）、营业外收入（贷增）
- 主营业务成本（借增）、管理费用（借增）、销售费用（借增）、财务费用（借增）、所得税费用（借增）
