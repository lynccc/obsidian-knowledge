# 23-案例分析题汇编

## 概念说明

案例分析题是会计考试中的重要题型，考查对会计原则、假设和处理方法的综合运用能力。本笔记整理了典型案例，帮助理解会计处理中的常见错误和违规情形。

## 练习题

### 案例1：会计假设违反分析

**案例背景：** M公司在日常经营中存在以下情况：

#### 情形1：经理报销个人费用

**违规描述：** M公司经理将自己家庭的旅游费用5万元拿到公司报销，计入管理费用。

**违反的原则：** [[16-会计四大假设|会计主体假设]]

**分析：** 会计主体假设要求严格区分企业的经济活动与所有者（或管理者）个人的经济活动。经理的家庭旅游费用不属于企业的经营支出，不应计入公司账目。这种行为混淆了会计主体的界限，导致费用虚增、利润失真。

**正确处理：** 该费用不应在公司账目中列支，应由经理个人承担。

#### 情形2：混合记账

**违规描述：** M公司同时经营餐饮和零售两个业务，但将两个业务的收支混在一起记账，没有分别核算。

**违反的原则：** [[16-会计四大假设|会计主体假设]]（可理解为内部会计主体的混淆）

**分析：** 虽然餐饮和零售都属于M公司，但为了清晰反映各业务的经营成果，应分别设置明细账进行核算。混合记账无法了解各业务的盈利情况，不利于经营决策。

**正确处理：** 按业务类型分别设置明细账，分别核算各业务的收入、成本和费用。

#### 情形3：清算状态下的正常核算

**违规描述：** M公司已宣告破产进入清算程序，但仍按正常的历史成本基础编制财务报表。

**违反的原则：** [[16-会计四大假设|持续经营假设]]

**分析：** 企业进入破产清算，说明持续经营的前提已不存在。此时应改用清算基础编制财务报表，资产应按可变现净值计量，而非历史成本。在清算状态下，资产的账面价值可能远高于其可变现净值。

**正确处理：** 改用清算基础编制财务报表，资产按可变现净值计量。

#### 情形4：选择性记账

**违规描述：** M公司只将金额超过1万元的业务记入账簿，金额较小的业务不记账。

**违反的原则：** [[15-会计基础概念与原则|可靠性原则]]和[[16-会计四大假设|会计分期假设]]

**分析：** 会计信息要求真实、完整。不记录小额业务会导致账目不完整，违反可靠性原则。同时，不及时记录业务也违反了及时性要求。虽然重要性原则允许对不重要的事项简化处理，但不能完全不记录。

**正确处理：** 所有经济业务都应及时、完整地记录，不得遗漏。

### 案例2：会计处理错误分析

#### 错误1：合伙人虚报费用

**错误描述：** 某合伙企业合伙人将个人消费10万元以"业务招待费"名义报销。

**违反的原则：** [[16-会计四大假设|会计主体假设]]

**分析：** 合伙人个人消费不属于企业的经营费用。虚报费用会导致：（1）费用虚增10万；（2）利润虚减10万；（3）少缴企业所得税（如果按利润计税）；（4）损害其他合伙人的利益。

**正确处理：** 个人消费不得在企业报销，应由合伙人个人承担。已报销的应冲回，补缴税款。

#### 错误2：编制半月报表

**错误描述：** 某企业每月编制两次财务报表（上半月和下半月），认为这样能提供更及时的信息。

**违反的原则：** [[16-会计四大假设|会计分期假设]]

**分析：** 会计分期假设要求将企业持续经营的期间划分为相等的期间（年度、季度、月度等）。半月不是一个标准的会计期间，且过于频繁的编报会增加成本，信息的可靠性也可能下降。会计分期要兼顾及时性和成本效益。

**正确处理：** 按标准的会计期间（月度、季度、年度）编制财务报表。如有特殊需要，可以编制内部管理报表，但不是正式的财务报表。

#### 错误3：混淆资本性支出和收益性支出

**错误描述：** 企业购买一台价值5万元的设备，直接计入当期管理费用。

**违反的原则：** [[15-会计基础概念与原则|划分收益性支出与资本性支出原则]]

**分析：** 设备的使用寿命超过一个会计年度，属于资本性支出，应确认为固定资产，分期计提折旧。直接计入当期费用会导致：（1）当期费用虚增；（2）以后各期费用虚减；（3）资产虚减。

**正确处理：** 确认为固定资产，按使用寿命分期计提折旧。

#### 错误4：提前确认收入

**错误描述：** 企业与客户签订销售合同，商品尚未发出，就确认了收入。

**违反的原则：** [[15-会计基础概念与原则|权责发生制]]

**分析：** 收入确认的条件之一是商品已发出或服务已提供。商品未发出就确认收入，属于提前确认收入，会导致收入和利润虚增。这是财务造假的常见手法之一。

**正确处理：** 商品发出时才确认收入。签订合同时不确认收入。

#### 错误5：不计提折旧

**错误描述：** 企业拥有的固定资产从未计提折旧，账面上仍按原值反映。

**违反的原则：** [[15-会计基础概念与原则|权责发生制]]和[[15-会计基础概念与原则|配比原则]]

**分析：** 固定资产在使用过程中会发生损耗，其成本应按受益期间分期摊销（计提折旧）。不计提折旧会导致：（1）资产价值虚高；（2）当期费用虚减；（3）利润虚增。

**正确处理：** 按固定资产的使用寿命和折旧方法，分期计提折旧。

#### 错误6：期末不进行账项调整

**错误描述：** 企业月末没有进行待摊费用摊销和预提费用计提，直接编制报表。

**违反的原则：** [[15-会计基础概念与原则|权责发生制]]

**分析：** 权责发生制要求按费用的归属期间确认，而非按现金收付时间。不进行账项调整会导致：（1）已支付但应由以后各期负担的费用全部计入当期（待摊费用未摊销）；（2）已发生但尚未支付的费用未计入当期（预提费用未计提）。

**正确处理：** 月末进行账项调整，包括待摊费用摊销、预提费用计提等。

### 案例3：权责发生制应用分析

**案例背景：** 某企业2025年度发生以下经济业务：

| 序号 | 业务内容 | 金额 |
|------|---------|------|
| 1 | 销售商品（已收款） | 500,000元 |
| 2 | 销售商品（赊销） | 300,000元 |
| 3 | 预收货款（商品未发出） | 100,000元 |
| 4 | 收到上月销售货款 | 155,800元 |
| 5 | 出租设备收入（已收款） | 50,000元 |
| 6 | 出售固定资产收入 | 80,000元 |
| **收入小计** | | **1,055,800元** |

| 序号 | 业务内容 | 金额 |
|------|---------|------|
| 7 | 购买商品（已付款） | 200,000元 |
| 8 | 购买商品（赊购） | 100,000元 |
| 9 | 支付本月工资 | 80,000元 |
| 10 | 支付下月租金 | 30,000元 |
| 11 | 计提本月折旧 | 50,000元 |
| 12 | 支付上月水电费 | 27,380元 |
| 13 | 支付广告费 | 60,000元 |
| 14 | 支付罚款 | 50,000元 |
| **费用小计** | | **597,380元** |

#### 分析：按权责发生制计算收入和费用

**收入分析：**

| 业务 | 权责发生制处理 | 确认金额 |
|------|---------------|---------|
| 1. 销售商品（已收款） | 商品已发出，确认收入 | 500,000 |
| 2. 销售商品（赊销） | 商品已发出，确认收入 | 300,000 |
| 3. 预收货款 | 商品未发出，不确认收入 | 0 |
| 4. 收到上月货款 | 收入已在上月确认 | 0 |
| 5. 出租设备收入 | 服务已提供，确认收入 | 50,000 |
| 6. 出售固定资产 | 不是日常活动，计入营业外收入 | 80,000 |
| **收入合计** | | **930,000** |

**费用分析：**

| 业务 | 权责发生制处理 | 确认金额 |
|------|---------------|---------|
| 7. 购买商品（已付款） | 商品入库，计入成本 | 200,000 |
| 8. 购买商品（赊购） | 商品入库，计入成本 | 100,000 |
| 9. 支付本月工资 | 本月费用，确认 | 80,000 |
| 10. 支付下月租金 | 下月费用，不确认（待摊） | 0 |
| 11. 计提折旧 | 本月费用，确认 | 50,000 |
| 12. 支付上月水电费 | 上月费用已在上月确认 | 0 |
| 13. 支付广告费 | 本月费用，确认 | 60,000 |
| 14. 支付罚款 | 营业外支出，确认 | 50,000 |
| **费用合计** | | **540,000** |

**利润计算：**
```
利润总额 = 收入 - 费用 = 930,000 - 540,000 = 390,000元
```

**关键差异分析：**
- 预收货款10万：权责发生制不确认收入（商品未发出）
- 收到上月货款15.58万：权责发生制不确认收入（上月已确认）
- 支付下月租金3万：权责发生制不确认费用（下月负担）
- 支付上月水电费2.738万：权责发生制不确认费用（上月已确认）
