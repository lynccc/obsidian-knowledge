# 05-销售业务

## 概念说明

销售业务是企业把商品卖出去、获得收入的过程。这是企业赚钱的核心环节。

根据收款方式不同，分为：
1. **现销**：一手交货，一手收钱。银行存款直接增加。
2. **赊销**：先交货，后收钱。产生应收账款（客户欠我们的钱）。

销售业务涉及两个关键步骤：
1. **确认收入**：卖出去了，记录收入
2. **结转成本**：卖出去的商品，其成本要从库存中转出

## 核心要点

### 销售业务分录

| 业务场景 | 借方 | 贷方 |
|----------|------|------|
| 现销确认收入 | 银行存款 | 主营业务收入 |
| 赊销确认收入 | 应收账款 | 主营业务收入 |
| 结转销售成本 | 主营业务成本 | 库存商品 |
| 收到前欠货款 | 银行存款 | 应收账款 |

### 关键理解

- **现销**：资产增加（银行存款），收入增加（主营业务收入），等式右边收入增加
- **赊销**：资产增加（应收账款），收入增加（主营业务收入），等式右边收入增加
- **结转成本**：费用增加（主营业务成本），资产减少（库存商品），等式左边一增一减
- **收到前欠货款**：资产一增一减（银行存款增加，应收账款减少），等式不变

## 公式/分录模板

### 现销确认收入

```
借：银行存款        （售价）
贷：主营业务收入    （售价）
```

### 赊销确认收入

```
借：应收账款        （售价）
贷：主营业务收入    （售价）
```

### 结转销售成本

```
借：主营业务成本    （成本价）
贷：库存商品        （成本价）
```

### 收到前欠货款

```
借：银行存款        （金额）
贷：应收账款        （金额）
```

## 练习题

### 题目1

**题目描述：** 企业销售商品一批，售价10万元，货款已收到存入银行。该批商品成本为6万元。写出会计分录。

**解答：**
```
确认收入：
借：银行存款        100000
贷：主营业务收入    100000

结转成本：
借：主营业务成本    60000
贷：库存商品        60000
```

**解析：** 销售业务需要写两笔分录。第一笔确认收入，银行存款增加（资产增加），主营业务收入增加（收入增加）。第二笔结转成本，把卖出商品的成本从库存中转出，变成主营业务成本（费用增加）。收入10万减去成本6万，这笔销售贡献了4万毛利。

### 题目2

**题目描述：** 企业赊销商品一批，售价8万元，货款尚未收到。该批商品成本为5万元。写出会计分录。

**解答：**
```
确认收入：
借：应收账款        80000
贷：主营业务收入    80000

结转成本：
借：主营业务成本    50000
贷：库存商品        50000
```

**解析：** 赊销与现销的区别在于，货款没有立即收到，而是形成了应收账款（客户欠我们的钱，资产增加）。收入确认时点是商品发出时，不是收到钱时。

### 题目3

**题目描述：** 企业收到客户前欠货款8万元，存入银行。写出会计分录。

**解答：**
```
借：银行存款    80000
贷：应收账款    80000
```

**解析：** 收到前欠货款，银行存款增加（资产增加），应收账款减少（资产减少）。这是资产内部的一增一减，总额不变。注意：这笔业务不涉及收入，收入在赊销时已经确认过了。

### 题目4

**题目描述：** 某企业本月销售业务如下：（1）现销商品售价15万元，成本9万元；（2）赊销商品售价10万元，成本7万元；（3）收到前欠货款4万元。写出所有分录。

**解答：**
```
业务（1）确认收入：
借：银行存款        150000
贷：主营业务收入    150000

业务（1）结转成本：
借：主营业务成本    90000
贷：库存商品        90000

业务（2）确认收入：
借：应收账款        100000
贷：主营业务收入    100000

业务（2）结转成本：
借：主营业务成本    70000
贷：库存商品        70000

业务（3）：
借：银行存款    40000
贷：应收账款    40000
```

**解析：** 每笔销售业务都需要写确认收入和结转成本两笔分录。业务（3）收到前欠货款不是销售业务，只是应收账款的收回，不涉及收入和成本。

### 题目5

**题目描述：** 企业销售商品售价20万元，成本12万元，其中60%货款已收到，40%为赊销。写出分录。

**解答：**
```
确认收入：
借：银行存款        120000
借：应收账款        80000
贷：主营业务收入    200000

结转成本：
借：主营业务成本    120000
贷：库存商品        120000
```

**解析：** 一笔销售业务部分收款、部分赊销时，可以合并写一笔分录。银行存款（已收的60%即12万）和应收账款（未收的40%即8万）都记借方，主营业务收入记贷方20万。一贷多借，借贷相等。
