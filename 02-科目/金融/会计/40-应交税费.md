# 40-应交税费

> 应交税费是企业应向国家缴纳的各种税款，其中增值税是最重要、最复杂的税种，是会计考试的必考内容。

## 概念说明

**应交税费**是指企业按照税法规定应缴纳的各种税费，包括增值税、所得税、城建税、教育费附加等。

打个比方：你买东西时付的钱里包含了税，企业卖东西时收的钱里也包含了税。企业要定期把这些税交给国家。增值税是最常见的一种——商品每经过一个流通环节，就对"增值"部分征税。

## 核心要点

### 一、增值税概述

**增值税**是对商品和服务在流转过程中产生的**增值额**征收的一种税。

#### 关键概念

| 概念 | 含义 |
|------|------|
| **销项税额** | 卖东西时向客户收取的税（收入的一部分） |
| **进项税额** | 买东西时支付给供应商的税（成本的一部分） |
| **应纳税额** | 销项税额 - 进项税额（差额交给国家） |
| **进项税额转出** | 已抵扣的进项税因某些原因不能抵扣了，需要转出 |

> **通俗理解：** 你进货花了113元（含税13元），卖出去收了226元（含税26元）。你交给国家的税 = 26 - 13 = 13元。这13元就是你"增值"部分应交的税。

#### 增值税计算公式

```
应纳税额 = 当期销项税额 - 当期进项税额
```

- 销项税额 > 进项税额：应交税（差额交给国家）
- 销项税额 < 进项税额：留抵税额（下期继续抵扣）

### 二、一般纳税人的增值税核算

#### 购进（进项税额可抵扣）

```
借：原材料/库存商品        （不含税价）
    应交税费——应交增值税（进项税额）
贷：银行存款/应付账款        （含税价）
```

#### 销售（确认销项税额）

```
借：银行存款/应收账款        （含税价）
贷：主营业务收入              （不含税价）
    应交税费——应交增值税（销项税额）
```

#### 缴纳增值税

```
借：应交税费——应交增值税（已交税金）
贷：银行存款
```

#### 进项税额转出

某些情况下，已抵扣的进项税额不能继续抵扣，需要转出：

```
借：原材料/管理费用等
贷：应交税费——应交增值税（进项税额转出）
```

**需要进项税额转出的情形：**
- 用于集体福利或个人消费的购进货物
- 非正常损失的购进货物
- 用于简易计税项目的购进货物

### 三、小规模纳税人的增值税核算

小规模纳税人**不能抵扣**进项税额，增值税直接计入成本。

```
购进：
借：原材料（含税价，进项税额不能抵扣）
贷：银行存款

销售：
借：银行存款
贷：主营业务收入（不含税价）
    应交税费——应交增值税（销项税额）

不含税价 = 含税价 ÷ (1 + 征收率)
```

### 四、其他常见税费

| 税种 | 计税依据 | 分录 |
|------|----------|------|
| **城建税** | 应交增值税 × 7%（城市） | 借：税金及附加，贷：应交税费 |
| **教育费附加** | 应交增值税 × 3% | 借：税金及附加，贷：应交税费 |
| **企业所得税** | 利润总额 × 25% | 借：所得税费用，贷：应交税费 |
| **个人所得税** | 代扣代缴 | 借：应付职工薪酬，贷：应交税费 |

### 五、税金及附加

"税金及附加"科目核算企业经营活动发生的消费税、城建税、教育费附加、资源税、房产税、城镇土地使用税、车船税、印花税等。

```
借：税金及附加
贷：应交税费——应交城建税
    应交税费——应交教育费附加
```

## 公式汇总

```
增值税应纳税额 = 销项税额 - 进项税额
销项税额 = 不含税销售额 × 税率
进项税额 = 不含税买价 × 税率
不含税价 = 含税价 ÷ (1 + 税率)
城建税 = 应交增值税 × 7%
教育费附加 = 应交增值税 × 3%
```

## 练习题

### 题目1（选择题）

**题目描述：** 一般纳税人购入原材料，增值税专用发票上注明价款10万元，增值税1.3万元。原材料已入库，款项已付。该批原材料的入账价值为（ ）。

A. 11.3万元  
B. 10万元  
C. 8.7万元  
D. 1.3万元

**答案：B**

**解析：** 一般纳税人购入原材料，增值税进项税额可以抵扣，不计入原材料成本。原材料入账价值 = 不含税价款 = 10万元。

### 题目2（分录题）⭐⭐

**题目描述：** 企业为增值税一般纳税人，本月销售商品一批，售价20万元，增值税2.6万元，款项已收存银行。该批商品成本12万元。写出确认收入和结转成本的分录。

**解答：**
```
确认收入：
借：银行存款            226,000
贷：主营业务收入        200,000
    应交税费——应交增值税（销项税额）  26,000

结转成本：
借：主营业务成本        120,000
贷：库存商品            120,000
```

**解析：** 含税售价22.6万 = 不含税售价20万 + 增值税2.6万。收入按不含税价确认，增值税作为销项税额单独核算。

### 题目3（计算题）

**题目描述：** 某一般纳税人本月进项税额8万元，销项税额12万元。计算本月应纳增值税额。

**解答：**
```
应纳税额 = 销项税额 - 进项税额 = 12万 - 8万 = 4万元
```

**解析：** 增值税是对"增值"部分征税。企业买东西付了8万税（进项），卖东西收了12万税（销项），差额4万交给国家。

### 题目4（选择题）

**题目描述：** 小规模纳税人购入原材料，增值税应（ ）。

A. 计入原材料成本  
B. 单独核算，可以抵扣  
C. 计入管理费用  
D. 不做处理

**答案：A**

**解析：** 小规模纳税人不能抵扣进项税额，增值税应计入原材料成本。

### 题目5（分录题）

**题目描述：** 企业计提本月城建税7000元、教育费附加3000元。写出分录。

**解答：**
```
借：税金及附加    10,000
贷：应交税费——应交城建税      7,000
    应交税费——应交教育费附加  3,000
```

**解析：** 城建税和教育费附加是增值税的附加税，计入"税金及附加"科目。

### 题目6（判断题）

**题目描述：** 一般纳税人将购进的货物用于集体福利，其进项税额可以继续抵扣。（ ）

**答案：✗**

**解析：** 用于集体福利或个人消费的购进货物，其进项税额不得抵扣，已经抵扣的需要做进项税额转出。

### 题目7（计算题）

**题目描述：** 某企业为增值税一般纳税人，本月购入原材料一批，取得增值税专用发票注明价款50万元，增值税6.5万元。本月销售商品一批，开具增值税专用发票注明价款80万元，增值税10.4万元。计算本月应纳增值税额。

**解答：**
```
进项税额 = 6.5万元
销项税额 = 10.4万元
应纳增值税 = 10.4 - 6.5 = 3.9万元
```

**解析：** 销项税额10.4万 - 进项税额6.5万 = 应纳增值税3.9万元。如果进项大于销项，差额为留抵税额，下期继续抵扣。

### 题目8（综合题）

**题目描述：** 某一般纳税人本月发生以下业务：（1）购入原材料30万元，增值税3.9万元，已付款；（2）销售商品50万元，增值税6.5万元，已收款；（3）计提城建税和教育费附加。写出所有分录。

**解答：**
```
业务（1）购入原材料：
借：原材料                            300,000
借：应交税费——应交增值税（进项税额）   39,000
贷：银行存款                          339,000

业务（2）销售商品：
借：银行存款                          565,000
贷：主营业务收入                      500,000
    应交税费——应交增值税（销项税额）   65,000

业务（3）计提附加税（应纳增值税 = 6.5 - 3.9 = 2.6万）：
城建税 = 2.6万 × 7% = 0.182万
教育费附加 = 2.6万 × 3% = 0.078万

借：税金及附加    2,600
贷：应交税费——应交城建税        1,820
    应交税费——应交教育费附加      780
```

**解析：** 先计算进项税额和销项税额，再算出应纳增值税。城建税和教育费附加以应纳增值税为基数计算。
