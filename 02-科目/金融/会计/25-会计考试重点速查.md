# 24-会计考试重点速查

## 概念说明

本笔记是会计考试的考前速查手册，汇总了最重要的知识点、公式和口诀，适合考前快速复习。

## 核心要点

### 十大考点速查表

| 序号 | 考点 | 核心内容 | 易混淆点 | 难度 |
|------|------|---------|---------|------|
| 1 | 会计等式 | 资产=负债+所有者权益 | 等式两边同增同减 vs 一边一增一减 | ⭐ |
| 2 | 借贷方向 | 资成费借增贷减，负所收贷增借减 | 收入和费用的方向容易混 | ⭐⭐ |

### 公式速查

#### 基本公式

```
会计恒等式：资产 = 负债 + 所有者权益
利润公式：  净利润 = 收入 - 费用 - 所得税
毛利公式：  毛利 = 收入 - 成本
```

#### 财务指标

```
资产负债率 = 负债总额 ÷ 资产总额 × 100%
ROE（净资产收益率） = 净利润 ÷ 净资产 × 100%
PE（市盈率） = 股价 ÷ 每股收益
毛利率 = (收入 - 成本) ÷ 收入 × 100%
```

#### 存货计量

```
可变现净值 = 售价 - 进一步加工成本 - 销售费用 - 相关税费
```

#### 应收账款变动

```
本期收款 = 期初应收 + 本期收入 - 期末应收
```

#### 现金流量

```
现金净增加 = 经营活动净额 + 投资活动净额 + 筹资活动净额
期末现金 = 期初现金 + 现金净增加
```

#### 账户余额

```
资产类余额 = 期初借方 + 本期借方 - 本期贷方
负债类余额 = 期初贷方 + 本期贷方 - 本期借方
```

### 口诀速查

#### 借贷方向口诀

```
资成费，借增贷减
负所收，贷增借减
```

展开：
- **资**产 → 增加记**借**方，减少记**贷**方
- **成**本 → 增加记**借**方，减少记**贷**方
- **费**用 → 增加记**借**方，减少记**贷**方
- **负**债 → 增加记**贷**方，减少记**借**方
- **所**有者权益 → 增加记**贷**方，减少记**借**方
- **收**入 → 增加记**贷**方，减少记**借**方

#### 会计等式口诀

```
有借必有贷，借贷必相等
资产 = 负债 + 所有者权益
```

#### 会计假设口诀

```
主持会货（主持会议要花钱）
主 → 会计主体
持 → 持续经营
会 → 会计分期
货 → 货币计量
```

#### 凭证选择口诀

```
收款看增加，付款看减少，转账啥都不涉及
涉及现金/银行存款增加 → 收款凭证
涉及现金/银行存款减少 → 付款凭证
不涉及现金/银行存款   → 转账凭证
```

### 记忆技巧汇总

#### 1. 借贷方向怎么记？

记住一个核心：**资产在借方**（左边）。

资产增加记借方（左边），那么与资产对立的负债和权益就记贷方（右边）。费用和资产方向相同（都是借增），收入和权益方向相同（都是贷增）。

#### 2. 待摊和预提怎么分？

- **待摊**：先**付**后摊 → 钱已经付了 → 是资产（我预付了钱，有权享受服务）
- **预提**：先**提**后付 → 钱还没付 → 是负债（我享受了服务，欠着钱）

#### 3. 收入确认条件怎么记？

```
商品发出了吗？→ 发出了
钱能收到吗？  → 能
金额确定吗？  → 确定
成本知道吗？  → 知道
四个都是"是" → 确认收入
```

#### 4. 三大报表怎么分？

```
资产负债表 → 某一天的"照片" → 权责发生制
利润表     → 一段期间的"视频" → 权责发生制
现金流量表 → 一段期间的"银行流水" → 收付实现制
```

#### 5. 财务指标怎么记？

```
资产负债率 → 借了多少钱 / 总共有多少钱 → 衡量风险
ROE        → 赚了多少钱 / 股东投了多少钱 → 衡量赚钱能力
PE         → 股价 / 每股收益 → 衡量估值高低
毛利率     → (卖价-成本) / 卖价 → 衡量产品赚钱能力
```

## 练习题

### 题目1（快速判断）

**题目描述：** 根据口诀快速判断：应收账款增加记哪方？

**解答：** 记**借方**。应收账款是资产类科目，资产增加记借方。

### 题目2（快速判断）

**题目描述：** 根据口诀快速判断：应付账款减少记哪方？

**解答：** 记**借方**。应付账款是负债类科目，负债减少记借方。

### 题目3（快速判断）

**题目描述：** 根据口诀快速判断：主营业务收入增加记哪方？

**解答：** 记**贷方**。主营业务收入是收入类科目，收入增加记贷方。

### 题目4（公式应用）

**题目描述：** 某企业资产总额800万，负债300万，本年净利润100万。计算ROE和资产负债率。

**解答：**
```
净资产 = 800万 - 300万 = 500万
ROE = 100万 ÷ 500万 × 100% = 20%
资产负债率 = 300万 ÷ 800万 × 100% = 37.5%
```

### 题目5（口诀应用）

**题目描述：** 企业购买一台设备，用银行存款支付。应该编制什么凭证？

**解答：** 编制**付款凭证**。涉及银行存款减少，用付款凭证。
