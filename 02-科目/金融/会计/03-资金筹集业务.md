# 03-资金筹集业务

## 概念说明

资金筹集是企业经营的第一步。企业需要钱才能运转，钱从哪来？主要有两个来源：

1. **投资者投入**：股东把钱投进来，换取企业的股份。这笔钱不用还，但投资者要分享利润。
2. **银行借款**：向银行借钱，约定好利息和还款时间。这笔钱要还，还要付利息。

两种方式各有优劣：投资者投入不需要还本付息，但要分享利润；银行借款不影响股权，但要承担还本付息的压力。

## 核心要点

### 业务类型与分录

| 业务 | 借方 | 贷方 |
|------|------|------|
| 投资者投入 | 银行存款 | 实收资本 |
| 银行借款 | 银行存款 | 短期借款 |
| 支付借款利息 | 财务费用 | 银行存款 |
| 偿还借款 | 短期借款 | 银行存款 |

### 关键理解

- **投资者投入**：资产（银行存款）增加，所有者权益（实收资本）增加，等式两边同增
- **银行借款**：资产（银行存款）增加，负债（短期借款）增加，等式两边同增
- **支付利息**：费用（财务费用）增加，资产（银行存款）减少，等式左边一增一减
- **偿还借款**：负债（短期借款）减少，资产（银行存款）减少，等式两边同减

## 公式/分录模板

### 投资者投入资本

```
借：银行存款        （金额）
贷：实收资本        （金额）
```

### 银行借款

```
借：银行存款        （金额）
贷：短期借款        （金额）
```

### 支付借款利息

```
借：财务费用        （利息金额）
贷：银行存款        （利息金额）
```

### 偿还借款本金

```
借：短期借款        （本金金额）
贷：银行存款        （本金金额）
```

## 练习题

### 题目1

**题目描述：** 企业收到投资者投入的资本50万元，款项已存入银行。写出会计分录。

**解答：**
```
借：银行存款    500000
贷：实收资本    500000
```

**解析：** 投资者投入资本，企业银行存款增加（资产增加，记借方），同时投资者在企业中的权益增加（实收资本增加，记贷方）。这是等式两边同增的业务。

### 题目2

**题目描述：** 企业向银行借入短期借款20万元，存入银行。写出会计分录。

**解答：**
```
借：银行存款    200000
贷：短期借款    200000
```

**解析：** 银行借款到账，银行存款增加（资产增加，记借方），同时欠银行的债务增加（短期借款增加，记贷方）。这也是等式两边同增的业务。

### 题目3

**题目描述：** 企业用银行存款支付本月银行借款利息3000元。写出会计分录。

**解答：**
```
借：财务费用    3000
贷：银行存款    3000
```

**解析：** 支付利息是企业的财务费用（费用增加，记借方），同时银行存款减少（资产减少，记贷方）。利息支出属于筹资活动的成本。

### 题目4

**题目描述：** 企业用银行存款偿还到期的短期借款15万元。写出会计分录。

**解答：**
```
借：短期借款    150000
贷：银行存款    150000
```

**解析：** 偿还借款，欠银行的钱减少了（负债减少，记借方），同时银行存款减少（资产减少，记贷方）。这是等式两边同减的业务。

### 题目5

**题目描述：** 某公司成立，投资者甲投入80万元存入银行，投资者乙投入设备价值30万元。写出会计分录。

**解答：**
```
借：银行存款    800000
贷：实收资本    800000

借：固定资产    300000
贷：实收资本    300000
```

**解析：** 两位投资者分别以不同形式投入资本。甲投入现金，银行存款增加；乙投入设备，固定资产增加。两种情况都是资产增加，所有者权益（实收资本）增加。注意要分开写两笔分录，因为涉及不同的资产科目。
