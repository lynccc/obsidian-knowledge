# 18-财务报表综合

## 概念说明

财务报表是会计工作的最终产物，三大报表各有侧重，相互关联。掌握报表编制基础和勾稽关系，是理解会计全貌的关键。

## 核心要点

### 三大报表编制基础

| 报表 | 编制基础 | 说明 |
|------|----------|------|
| **资产负债表** | 权责发生制 | 反映某一时点的财务状况 |
| **利润表** | 权责发生制 | 反映某一期间的经营成果 |
| **现金流量表** | 收付实现制 | 反映某一期间的现金流入流出 |

### 勾稽关系

```
利润表净利润 ──→ 资产负债表未分配利润
现金流量表余额 ──→ 资产负债表货币资金
```

- **利润表与资产负债表**：利润表的净利润经过利润分配后，进入资产负债表的"未分配利润"项目
- **现金流量表与资产负债表**：现金流量表的"现金及现金等价物净增加额"应等于资产负债表中货币资金的变动额

### 关键财务指标

#### 1. ROE（净资产收益率）

$$ROE = \frac{净利润}{净资产} \times 100\%$$

- 衡量股东投入资本的回报效率
- ROE越高，说明企业盈利能力越强

#### 2. 市盈率（PE）

$$市盈率 = \frac{每股股价}{每股盈利} = \frac{市值}{净利润}$$

- 衡量股票的估值水平
- 市盈率越高，说明市场对该公司期望越高（或估值偏高）

#### 3. 资产负债率

$$资产负债率 = \frac{负债总额}{资产总额} \times 100\%$$

- 衡量企业的财务风险
- 比率越高，财务风险越大

#### 4. 毛利率

$$毛利率 = \frac{收入 - 成本}{收入} \times 100\%$$

- 衡量产品或服务的基本盈利能力
- 注意：毛利率计算中的"成本"仅指直接成本（主营业务成本），不含期间费用和税金

### 经验判断标准

| 指标 | 健康范围 | 说明 |
|------|----------|------|
| 资产负债率 | 30%-70% | >70%有较高破产风险，<30%较稳健 |
| ROE | >15% | 越高越好 |
| 市盈率 | 10-30倍 | 因行业而异 |

### 好的投资标的特征

```
较高净利润 + 较高ROE + 较低资产负债率 + 较低市盈率
```

- 较高净利润：企业赚钱能力强
- 较高ROE：股东回报率高
- 较低资产负债率：财务风险低
- 较低市盈率：估值合理，买入成本低

## 公式/分录模板

### 可变现净值

$$可变现净值 = 售价 - 完工成本 - 销售费用 - 税费$$

### 毛利率

$$毛利率 = \frac{收入 - 成本}{收入} \times 100\%$$

### 资产负债率

$$资产负债率 = \frac{负债}{资产} \times 100\%$$

### ROE

$$ROE = \frac{净利润}{净资产} \times 100\%$$

### 市盈率

$$市盈率 = \frac{股价}{每股盈利}$$

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，以收付实现制为编制基础的财务报表是（ ）。

A. 资产负债表  
B. 利润表  
C. 现金流量表  
D. 所有者权益变动表

**答案：C**

**解析：** 现金流量表以收付实现制为基础编制，反映企业一定期间内现金的流入和流出。资产负债表和利润表以权责发生制为基础编制。

### 题目2（选择题）

**题目描述：** 某企业净利润为500万元，净资产为2000万元，则ROE为（ ）。

A. 25%  
B. 4%  
C. 400%  
D. 50%

**答案：A**

**解析：** ROE = 净利润 / 净资产 × 100% = 500 / 2000 × 100% = 25%。说明每1元股东投入能获得0.25元的净利润回报。

### 题目3（选择题）

**题目描述：** 某公司资产总额为1000万元，负债总额为750万元，该公司的资产负债率为（ ）。

A. 25%  
B. 75%  
C. 33%  
D. 133%

**答案：B**

**解析：** 资产负债率 = 负债 / 资产 × 100% = 750 / 1000 × 100% = 75%。该比率超过70%，有较高的破产风险，财务状况不够稳健。

### 题目4（选择题）

**题目描述：** 某企业营业收入为100万元，营业成本为60万元，毛利率为（ ）。

A. 60%  
B. 40%  
C. 66.7%  
D. 150%

**答案：B**

**解析：** 毛利率 = (收入 - 成本) / 收入 × 100% = (100 - 60) / 100 × 100% = 40%。毛利率衡量产品本身的基本盈利能力，不考虑期间费用和税金。

### 题目5（判断题）

**题目描述：** 利润表中的净利润应等于资产负债表中未分配利润的期末数。（ ）

**答案：✗（错误）**

**解析：** 利润表中的净利润是当期的经营成果，而资产负债表中的未分配利润是累计数（期初未分配利润 + 本期净利润 - 本期分配的股利）。只有在期初未分配利润为零且本期未分配股利的情况下，两者才相等。

### 题目6（综合题）

**题目描述：** 某公司股票市价为每股20元，每股盈利为2元，净利润为1000万元，净资产为4000万元，负债总额为3000万元。请计算：（1）市盈率（2）ROE（3）资产负债率（4）判断该公司是否为较好的投资标的。

**解答：**

```
（1）市盈率 = 股价 / 每股盈利 = 20 / 2 = 10倍
（2）ROE = 净利润 / 净资产 = 1000 / 4000 = 25%
（3）资产负债率 = 负债 / 资产 = 3000 / (4000+3000) = 42.9%
（4）判断：
    - ROE = 25%（>15%，盈利能力强）✓
    - 资产负债率 = 42.9%（<70%，财务风险适中）✓
    - 市盈率 = 10倍（<30倍，估值合理）✓
    - 结论：该公司是较好的投资标的
```

**解析：** 该公司ROE较高（25%），说明盈利能力强；资产负债率适中（42.9%），财务风险可控；市盈率较低（10倍），估值合理。综合来看，符合"较高ROE + 较低资产负债率 + 较低市盈率"的好投资标的特征。
