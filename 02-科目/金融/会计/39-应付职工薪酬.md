# 39-应付职工薪酬

> 应付职工薪酬是企业应付给职工的各种报酬，包括工资、奖金、社保、公积金等，是企业最重要的流动负债之一。

## 概念说明

**应付职工薪酬**是指企业为获得职工提供的服务而给予各种形式的报酬以及其他相关支出。

简单说：企业给员工发的所有钱和福利，都叫"职工薪酬"。不只是工资，还包括奖金、社保、公积金、福利费等。

## 核心要点

### 一、职工薪酬的构成

| 类别 | 内容 |
|------|------|
| **短期薪酬** | 工资、奖金、津贴、补贴、职工福利费、社保、公积金、工会经费、职工教育经费 |
| **离职后福利** | 养老保险（企业承担部分）、失业保险等 |
| **辞退福利** | 解除劳动关系的补偿 |
| **其他长期职工福利** | 长期带薪缺勤、长期残疾福利等 |

### 二、工资的核算

#### 计提工资

```
借：管理费用          （管理人员工资）
    销售费用          （销售人员工资）
    制造费用          （车间管理人员工资）
    生产成本          （生产工人工资）
贷：应付职工薪酬——工资
```

#### 发放工资

```
借：应付职工薪酬——工资
贷：银行存款（实际发放金额）
    其他应付款——社保（个人承担部分）
    其他应付款——公积金（个人承担部分）
    应交税费——应交个人所得税（代扣个税）
```

> **注意：** 工资中要扣除个人承担的社保、公积金和个人所得税，实际发放的是"净工资"。

### 三、社保和公积金的核算

社保和公积金由**企业承担**和**个人承担**两部分组成。

#### 企业承担部分（计提）

```
借：管理费用/销售费用/制造费用/生产成本
贷：应付职工薪酬——社保（企业部分）
    应付职工薪酬——公积金（企业部分）
```

#### 个人承担部分（从工资中扣除）

```
借：应付职工薪酬——工资
贷：其他应付款——社保（个人部分）
    其他应付款——公积金（个人部分）
```

#### 缴纳社保和公积金

```
借：应付职工薪酬——社保（企业部分）
    应付职工薪酬——公积金（企业部分）
    其他应付款——社保（个人部分）
    其他应付款——公积金（个人部分）
贷：银行存款
```

### 四、职工福利费

```
借：管理费用/销售费用/制造费用/生产成本
贷：应付职工薪酬——职工福利费

实际支付：
借：应付职工薪酬——职工福利费
贷：银行存款
```

### 五、工会经费和职工教育经费

```
借：管理费用
贷：应付职工薪酬——工会经费
    应付职工薪酬——职工教育经费
```

## 薪酬计入哪个科目？

| 人员类别 | 工资计入 | 社保/公积金计入 |
|----------|---------|----------------|
| 管理人员 | 管理费用 | 管理费用 |
| 销售人员 | 销售费用 | 销售费用 |
| 车间管理人员 | 制造费用 | 制造费用 |
| 生产工人 | 生产成本 | 生产成本 |

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，不属于职工薪酬的是（ ）。

A. 工资  
B. 社保  
C. 差旅费  
D. 住房公积金

**答案：C**

**解析：** 差旅费属于管理费用，不是职工薪酬。职工薪酬包括工资、奖金、社保、公积金、福利费等。

### 题目2（分录题）⭐⭐

**题目描述：** 企业本月计提管理人员工资5万元，销售人员工资3万元。从工资中代扣个人社保0.8万元、个人公积金0.5万元、个人所得税0.2万元。写出计提和发放的分录。

**解答：**
```
计提工资：
借：管理费用    50,000
借：销售费用    30,000
贷：应付职工薪酬——工资    80,000

发放工资（实际发放 = 80,000 - 8,000 - 5,000 - 2,000 = 65,000）：
借：应付职工薪酬——工资    80,000
贷：银行存款              65,000
贷：其他应付款——社保       8,000
贷：其他应付款——公积金     5,000
贷：应交税费——应交个人所得税  2,000
```

**解析：** 计提工资时，按人员归属分别计入管理费用和销售费用。发放工资时，扣除个人承担的社保、公积金和个人所得税，实际发放净工资。

### 题目3（选择题）

**题目描述：** 企业缴纳社会保险费时，企业承担部分应借记的科目是（ ）。

A. 管理费用  
B. 应付职工薪酬——社保  
C. 其他应付款  
D. 应交税费

**答案：B**

**解析：** 缴纳社保时，企业承担部分从"应付职工薪酬——社保"中支付（之前已计提），个人承担部分从"其他应付款——社保"中支付。

### 题目4（判断题）

**题目描述：** 生产工人的工资应计入管理费用。（ ）

**答案：✗**

**解析：** 生产工人的工资应计入**生产成本**，不是管理费用。管理人员的工资才计入管理费用。

### 题目5（分录题）

**题目描述：** 企业计提本月社保（企业承担部分）：管理人员2万元，销售人员1万元。写出分录。

**解答：**
```
借：管理费用    20,000
借：销售费用    10,000
贷：应付职工薪酬——社保    30,000
```

**解析：** 企业承担的社保按人员归属分别计入管理费用和销售费用。这部分是企业的成本，不是从工资中扣除的。

### 题目6（选择题）

**题目描述：** 企业从职工工资中代扣的个人所得税，应贷记的科目是（ ）。

A. 应付职工薪酬  
B. 应交税费——应交个人所得税  
C. 其他应付款  
D. 管理费用

**答案：B**

**解析：** 代扣的个人所得税是企业代税务局收取的，应贷记"应交税费——应交个人所得税"。

### 题目7（综合题）

**题目描述：** 某企业本月工资总额10万元，其中管理人员4万、销售人员3万、生产工人3万。企业承担社保3万元（按人员比例分配）。个人承担社保1万元、公积金0.8万元、个税0.3万元。编制计提工资、计提企业社保、发放工资、缴纳社保公积金的全部分录。

**解答：**

```
1. 计提工资：
借：管理费用        40,000
借：销售费用        30,000
借：生产成本        30,000
贷：应付职工薪酬——工资    100,000

2. 计提企业社保（按人员比例分配：管理1.2万、销售0.9万、生产0.9万）：
借：管理费用        12,000
借：销售费用         9,000
借：生产成本         9,000
贷：应付职工薪酬——社保     30,000

3. 发放工资（实际发放 = 10万 - 1万 - 0.8万 - 0.3万 = 7.9万）：
借：应付职工薪酬——工资    100,000
贷：银行存款              79,000
贷：其他应付款——社保       10,000
贷：其他应付款——公积金      8,000
贷：应交税费——应交个人所得税   3,000

4. 缴纳社保和公积金（企业3万 + 个人1万 = 社保4万；公积金0.8万）：
借：应付职工薪酬——社保     30,000
借：其他应付款——社保       10,000
借：其他应付款——公积金      8,000
贷：银行存款              48,000
```

### 题目8（选择题）

**题目描述：** 车间管理人员的工资应计入（ ）。

A. 管理费用  
B. 销售费用  
C. 制造费用  
D. 生产成本

**答案：C**

**解析：** 车间管理人员的工资计入制造费用。生产工人的工资计入生产成本，管理人员的工资计入管理费用。
