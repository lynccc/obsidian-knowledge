# 07-待摊费用与预提费用

## 概念说明

有些费用的支付时间和归属期间不一致，需要特殊处理：

**待摊费用**：钱先付了，但费用要分几个月摊销。比如一次付了3个月的房租，每个月只能确认1/3的费用。特点是**先付后摊**，属于**资产**。

**预提费用**：费用已经发生了，但钱还没付。比如银行利息是按季度付的，但每个月都要确认当月的利息费用。特点是**先提后付**，属于**负债**。

## 核心要点

### 待摊费用

- **定义**：已经支付但应由本期和以后各期分别负担的费用
- **性质**：属于资产类科目（借增贷减）
- **处理方式**：支付时全额计入待摊费用，然后分期摊销

### 预提费用

- **定义**：预先计入成本费用但尚未支付的费用
- **性质**：属于负债类科目（贷增借减）
- **处理方式**：每期预提计入费用，实际支付时冲减预提

## 公式/分录模板

### 待摊费用处理

**支付时：**
```
借：待摊费用        （总金额）
贷：银行存款        （总金额）
```

**每月摊销时：**
```
借：管理费用        （每月摊销额）
贷：待摊费用        （每月摊销额）
```

### 预提费用处理

**每月预提时：**
```
借：财务费用        （每月应负担金额）
贷：应付利息        （每月应负担金额）
```

**实际支付时：**
```
借：应付利息        （已预提金额）
借：财务费用        （当月应负担金额，如有）
贷：银行存款        （实际支付金额）
```

### 特殊情况：支付金额包含预提和待摊

当实际支付的金额中，一部分是当月应负担的费用，剩余部分属于以后各期时：
```
借：管理费用        （当月应负担部分）
借：待摊费用        （以后各期负担部分）
贷：银行存款        （实际支付总额）
```

## 练习题

### 题目1

**题目描述：** 企业预付3个月的办公室租金共3万元，用银行存款支付。写出支付时和每月摊销时的分录。

**解答：**
```
支付时：
借：待摊费用    30000
贷：银行存款    30000

每月摊销时（第1个月、第2个月、第3个月各做一次）：
借：管理费用    10000
贷：待摊费用    10000
```

**解析：** 预付3个月租金3万元，每月应负担1万元。支付时全部计入待摊费用（资产增加），然后每月摊销1万元（资产减少，费用增加）。3个月后待摊费用余额为0，全部转入管理费用。

### 题目2

**题目描述：** 企业3月末计提银行借款利息10万元，尚未支付。写出会计分录。

**解答：**
```
借：财务费用    100000
贷：应付利息    100000
```

**解析：** 虽然利息还没付，但3月份已经产生了利息费用，需要在3月份确认。费用增加记借方，应付利息（负债）增加记贷方。这就是预提费用——先计入费用，后支付。

### 题目3

**题目描述：** 企业4月末用银行存款支付第二季度（4-6月）借款利息共30万元，其中4月应负担10万元。写出会计分录。

**解答：**
```
借：管理费用    100000
借：待摊费用    200000
贷：银行存款    300000
```

**解析：** 支付30万元利息中，4月份应负担10万元（直接计入当期费用），5-6月的20万元属于以后各期负担，计入待摊费用。以后每月再从待摊费用中摊销10万元到财务费用。

### 题目4

**题目描述：** 承接题目2和题目3，假设3月末已预提利息10万元，4月末支付时应如何处理？

**解答：**
```
4月末支付利息时：
借：应付利息    100000（冲减3月已预提的部分）
借：管理费用    100000（4月当月应负担部分）
借：待摊费用    100000（5-6月待摊部分）
贷：银行存款    300000
```

**解析：** 3月已经预提了10万元利息（应付利息），4月支付时首先要冲减这笔预提（应付利息减少，记借方）。同时4月当月的10万元直接计入费用，剩余10万元（5-6月）计入待摊费用。

### 题目5

**题目描述：** 企业1月初支付全年保险费12万元（银行存款），分12个月摊销。写出1月支付和1-12月摊销的分录。

**解答：**
```
1月支付时：
借：待摊费用    120000
贷：银行存款    120000

1-12月每月摊销：
借：管理费用    10000
贷：待摊费用    10000
```

**解析：** 一次性支付全年保险费12万元，每月应负担1万元。支付时全额计入待摊费用（资产），然后每月摊销1万元到管理费用。12个月后待摊费用余额为0。这是典型的待摊费用处理方式。
