# 04-采购业务

## 概念说明

采购业务是企业购买商品、原材料或设备的过程。根据付款方式不同，分为：

1. **现购**：一手交钱，一手交货。用银行存款或现金直接支付。
2. **赊购**：先拿货，后付款。产生应付账款（欠供应商的钱）。
3. **购买固定资产**：买设备、房屋等长期使用的资产。

采购是企业经营的起点，没有采购就没有商品可卖。

## 核心要点

### 采购业务分录

| 业务场景 | 借方 | 贷方 |
|----------|------|------|
| 现购商品入库 | 库存商品 | 银行存款 |
| 赊购商品入库 | 库存商品 | 应付账款 |
| 购买固定资产 | 固定资产 | 银行存款 |
| 偿还应付账款 | 应付账款 | 银行存款 |

### 关键理解

- **现购**：资产一增一减（库存商品增加，银行存款减少），等式不变
- **赊购**：资产增加（库存商品），负债增加（应付账款），等式两边同增
- **购买固定资产**：资产一增一减（固定资产增加，银行存款减少），等式不变
- **偿还应付账款**：资产减少（银行存款），负债减少（应付账款），等式两边同减

## 公式/分录模板

### 现购商品入库

```
借：库存商品        （金额）
贷：银行存款        （金额）
```

### 赊购商品入库

```
借：库存商品        （金额）
贷：应付账款        （金额）
```

### 购买固定资产

```
借：固定资产        （金额）
贷：银行存款        （金额）
```

### 偿还应付账款

```
借：应付账款        （金额）
贷：银行存款        （金额）
```

## 练习题

### 题目1

**题目描述：** 企业用银行存款购入商品一批，价值8万元，商品已验收入库。写出会计分录。

**解答：**
```
借：库存商品    80000
贷：银行存款    80000
```

**解析：** 这是现购业务。商品入库，库存商品增加（资产增加，记借方）；用银行存款支付，银行存款减少（资产减少，记贷方）。资产内部一增一减，总额不变。

### 题目2

**题目描述：** 企业从供应商处赊购商品一批，价值5万元，商品已入库，货款尚未支付。写出会计分录。

**解答：**
```
借：库存商品    50000
贷：应付账款    50000
```

**解析：** 这是赊购业务。商品入库，库存商品增加（资产增加，记借方）；货款未付，产生应付账款（负债增加，记贷方）。等式两边同时增加。

### 题目3

**题目描述：** 企业用银行存款购买一台设备，价值12万元。写出会计分录。

**解答：**
```
借：固定资产    120000
贷：银行存款    120000
```

**解析：** 购买固定资产，设备增加（资产增加，记借方）；用银行存款支付，银行存款减少（资产减少，记贷方）。资产内部一增一减，总额不变。注意：固定资产是长期使用的资产，不是库存商品。

### 题目4

**题目描述：** 企业用银行存款偿还前欠供应商货款5万元。写出会计分录。

**解答：**
```
借：应付账款    50000
贷：银行存款    50000
```

**解析：** 偿还欠款，应付账款减少（负债减少，记借方）；用银行存款支付，银行存款减少（资产减少，记贷方）。等式两边同时减少。

### 题目5

**题目描述：** 某企业本月发生以下采购业务：（1）用银行存款购入商品10万元；（2）赊购商品6万元；（3）购买设备20万元用银行存款支付。写出所有分录。

**解答：**
```
业务（1）：
借：库存商品    100000
贷：银行存款    100000

业务（2）：
借：库存商品    60000
贷：应付账款    60000

业务（3）：
借：固定资产    200000
贷：银行存款    200000
```

**解析：** 三笔业务要分开写分录。（1）是现购，资产内部变动；（2）是赊购，资产和负债同增；（3）是购买固定资产，也是资产内部变动。每笔业务单独记录，不能合并。
