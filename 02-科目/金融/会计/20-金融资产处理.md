# 20-金融资产处理

## 概念说明

金融资产是企业持有的以收取合同现金流量或出售金融资产为目标的资产。交易性金融资产是最常见的类型，以公允价值计量，其变动计入当期损益。

## 核心要点

### 交易性金融资产

- 以**公允价值**计量
- 公允价值变动计入**当期损益**（公允价值变动损益）
- **未实现收益也需确认**：即使没有出售，只要期末市价变动，就要确认收益或损失

### 交易性金融资产的会计处理

| 业务 | 会计分录 |
|------|----------|
| 购买时 | 借：交易性金融资产，贷：银行存款 |
| 期末公允价值上升 | 借：交易性金融资产，贷：公允价值变动损益 |
| 期末公允价值下降 | 借：公允价值变动损益，贷：交易性金融资产 |
| 出售时 | 借：银行存款，贷：交易性金融资产 |

### 案例分析

**甲公司买入1万股，每股9元，月末市价9.5元**

```
买入时：
借：交易性金融资产    90,000
贷：银行存款          90,000

月末公允价值变动（9.5-9）×10,000 = 5,000元：
借：交易性金融资产     5,000
贷：公允价值变动损益   5,000
```

- 即使没有卖出，也要确认5000元的公允价值变动收益
- 这5000元会增加当期利润

### 现金流量表分类

| 活动类型 | 典型业务 |
|----------|----------|
| **经营活动** | 支付职工薪酬、支付广告费、支付所得税、销售商品收现 |
| **投资活动** | 购建固定资产、取得长期股权投资、买卖金融资产、收到债券利息 |
| **筹资活动** | 分配股利、发行债券、取得借款、偿还借款 |

### 特殊情形

**收到债券利息 → 投资活动（不是筹资活动）**

- 债券投资属于投资活动
- 收到的利息是投资回报，属于投资活动现金流入
- 不要与"发行债券"混淆（发行债券才是筹资活动）

### 三大活动现金流量对比

| 项目 | 经营活动 | 投资活动 | 筹资活动 |
|------|----------|----------|----------|
| 现金流入 | 销售收现、税费返还 | 收回投资、投资收益 | 吸收投资、取得借款 |
| 现金流出 | 购买商品、支付薪酬 | 购建资产、投资支付 | 偿还借款、分配股利 |

## 公式/分录模板

### 公允价值变动收益

$$公允价值变动收益 = (期末市价 - 初始成本) \times 持有数量$$

### 交易性金融资产分录模板


## 练习题

### 题目1（选择题）

**题目描述：** 企业购入交易性金融资产时，发生的交易费用应计入（ ）。

A. 交易性金融资产成本  
B. 投资收益  
C. 财务费用  
D. 管理费用

**答案：B**

**解析：** 交易性金融资产以公允价值计量，购买时发生的交易费用不计入资产成本，而是直接计入当期损益（投资收益借方，表示投资收益减少）。

### 题目2（选择题）

**题目描述：** 甲公司2024年1月购入股票1万股，每股10元。2024年12月31日，该股票市价为每股12元。甲公司应确认的公允价值变动收益为（ ）。

A. 0元（未出售不确认）  
B. 20,000元  
C. 120,000元  
D. 100,000元

**答案：B**

**解析：** 交易性金融资产以公允价值计量，即使未出售，期末市价变动也要确认。公允价值变动收益 = (12 - 10) × 10,000 = 20,000元。未实现收益也需确认，这是交易性金融资产的特点。

### 题目3（选择题）

**题目描述：** 下列各项中，属于投资活动现金流量的是（ ）。

A. 支付职工薪酬  
B. 支付广告费  
C. 购买固定资产  
D. 分配股利

**答案：C**

**解析：** 购买固定资产属于投资活动。A和B属于经营活动，D属于筹资活动。

### 题目4（选择题）

**题目描述：** 企业收到债券利息收入，在现金流量表中应列示为（ ）。

A. 经营活动现金流入  
B. 投资活动现金流入  
C. 筹资活动现金流入  
D. 不需要列示

**答案：B**

**解析：** 债券投资属于投资活动，收到的债券利息是投资回报，应列示为投资活动现金流入。注意不要与"发行债券"混淆，发行债券收到的现金才属于筹资活动。

### 题目5（综合题）

**题目描述：** 乙公司发生以下业务，请判断各业务在现金流量表中的分类：

（1）销售商品收到现金50万元  
（2）购买设备支付30万元  
（3）支付职工工资10万元  
（4）向银行借款20万元  
（5）支付所得税5万元  
（6）收到债券利息2万元  
（7）分配现金股利8万元

**解答：**

```
（1）经营活动现金流入——销售商品、提供劳务收到的现金
（2）投资活动现金流出——购建固定资产、无形资产支付的现金
（3）经营活动现金流出——支付给职工以及为职工支付的现金
（4）筹资活动现金流入——取得借款收到的现金
（5）经营活动现金流出——支付的各项税费
（6）投资活动现金流入——取得投资收益收到的现金
（7）筹资活动现金流出——分配股利、利润或偿付利息支付的现金
```

**解析：**
- 经营活动：与日常经营直接相关的收支（销售、工资、税费）
- 投资活动：与长期资产和投资相关的收支（设备、债券利息）
- 筹资活动：与融资相关的收支（借款、分配股利）
- 特别注意：收到债券利息属于投资活动，不是筹资活动
