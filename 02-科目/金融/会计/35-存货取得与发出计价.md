# 35-存货取得与发出计价

> 存货是企业最重要的流动资产之一，取得时按实际成本入账，发出时可选择先进先出法或加权平均法，期末需进行减值测试。

## 概念说明

**存货**是指企业在日常活动中持有以备出售的商品、处在生产过程中的在产品、在生产或提供劳务过程中耗用的材料和物料等。

打个比方：面包店的面粉是"原材料"，正在烤的面包是"在产品"，烤好的面包是"库存商品"，这些都属于存货。

## 核心要点

### 一、存货的取得计价

存货取得时按**实际成本**入账，不同取得方式成本构成不同：

| 取得方式 | 成本构成 |
|----------|----------|
| **外购** | 买价 + 运输费 + 装卸费 + 保险费 + 入库前挑选整理费 + 相关税金（不含可抵扣增值税） |
| **自制** | 直接材料 + 直接人工 + 制造费用 |
| **委托加工** | 实际耗用材料 + 加工费 + 运输费 + 相关税金 |
| **投资者投入** | 按合同或协议约定的价值（公允） |

#### 外购存货分录

```
借：原材料（或库存商品）
    应交税费——应交增值税（进项税额）  ← 可抵扣的增值税
贷：银行存款（或应付账款）
```

> **注意：** 增值税进项税额可以抵扣，不计入存货成本。但如果是小规模纳税人，增值税进项税额不能抵扣，要计入存货成本。

### 二、存货的发出计价

存货是分批购入的，每次购入价格可能不同。发出存货时，如何确定发出成本？

#### 1. 先进先出法（FIFO）

**核心思想：** 先购入的存货先发出，就像排队一样，先来的先走。

**特点：**
- 期末存货成本接近市价（最新购入的留在库里）
- 物价上涨时，发出成本偏低，利润偏高
- 物价下跌时，发出成本偏高，利润偏低

#### 2. 月末一次加权平均法

**核心思想：** 月末用加权平均单价计算发出成本，把价格波动"平均"掉。

**公式：**
```
加权平均单价 = (月初存货成本 + 本月购入总成本) ÷ (月初存货数量 + 本月购入总数量)
发出存货成本 = 加权平均单价 × 发出数量
期末存货成本 = 加权平均单价 × 期末数量
```

**特点：**
- 计算简单，只在月末计算一次
- 价格波动被平均化，利润平稳

#### 3. 移动加权平均法

**核心思想：** 每次购入后都重新计算平均单价，随时掌握最新成本。

**公式：**
```
移动加权平均单价 = (原有存货成本 + 本次购入成本) ÷ (原有存货数量 + 本次购入数量)
```

**特点：**
- 每次购入都要重新计算
- 管理成本较高，但成本更准确

### 三、存货的清查与减值

#### 存货清查

| 情况 | 处理 |
|------|------|
| **盘盈**（实际 > 账面） | 冲减管理费用 |
| **盘亏**（实际 < 账面） | 计入管理费用（正常损耗）或营业外支出（非常损失） |

#### 存货减值（成本与可变现净值孰低法）

**规则：** 期末存货按**成本**与**可变现净值**孰低计量。

```
可变现净值 = 售价 - 进一步加工成本 - 销售费用 - 相关税费
```

- 如果 成本 < 可变现净值 → 按成本计量，不需调整
- 如果 成本 > 可变现净值 → 按可变现净值计量，差额计提**存货跌价准备**

**计提减值分录：**
```
借：资产减值损失——存货跌价损失
贷：存货跌价准备
```

**转回减值分录（价值恢复时）：**
```
借：存货跌价准备
贷：资产减值损失——存货跌价损失
```

> **注意：** 存货跌价准备可以转回（[[15-会计基础概念与原则|谨慎性原则]]），但固定资产减值准备不能转回。

## 公式汇总

```
存货取得成本 = 买价 + 运费 + 装卸费 + 保险费 + 税金（不含可抵扣增值税）

先进先出法：先购入的先发出

加权平均单价 = (月初成本 + 本月购入总成本) ÷ (月初数量 + 本月购入总数量)
发出成本 = 加权平均单价 × 发出数量

可变现净值 = 售价 - 加工成本 - 销售费用 - 税费
存货跌价准备 = 成本 - 可变现净值（当成本 > 可变现净值时）
```

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，应计入外购存货成本的是（ ）。

A. 增值税进项税额  
B. 运输途中的合理损耗  
C. 采购人员差旅费  
D. 入库后的仓储费

**答案：B**

**解析：** 运输途中的合理损耗应计入存货成本。增值税进项税额可以抵扣不计入成本；采购人员差旅费和入库后仓储费计入当期损益。

### 题目2（计算题）⭐⭐

**题目描述：** 某企业采用先进先出法核算存货。A材料期初结存200公斤，单价10元。本月购入300公斤，单价12元。本月发出400公斤。计算本月发出成本和期末存货成本。

**解答：**
```
先进先出法：
先发出期初的200公斤：200 × 10 = 2,000元
再发出本月购入的200公斤：200 × 12 = 2,400元
本月发出成本 = 2,000 + 2,400 = 4,400元

期末存货 = 本月购入剩余的100公斤
期末存货成本 = 100 × 12 = 1,200元
```

**解析：** 先进先出法假设先购入的先发出。期初200公斤（10元）全部发出，再从本月购入的300公斤中发出200公斤（12元），剩余100公斤（12元）留在期末。

### 题目3（计算题）⭐⭐

**题目描述：** 某企业采用月末一次加权平均法核算存货。A材料月初结存100公斤，单价8元。本月5日购入200公斤，单价9元；本月15日购入300公斤，单价10元。本月发出500公斤。计算加权平均单价、发出成本和期末成本。

**解答：**
```
月初成本 = 100 × 8 = 800元
本月购入成本 = 200 × 9 + 300 × 10 = 1,800 + 3,000 = 4,800元
总成本 = 800 + 4,800 = 5,600元

总数量 = 100 + 200 + 300 = 600公斤
加权平均单价 = 5,600 ÷ 600 = 9.33元/公斤

发出成本 = 500 × 9.33 = 4,665元
期末存货成本 = 100 × 9.33 = 933元（或 5,600 - 4,665 = 935元，差异为四舍五入）
```

**解析：** 月末一次加权平均法只在月末计算一次平均单价，用总成本除以总数量。发出和期末存货都用这个平均单价计算。

### 题目4（选择题）

**题目描述：** 物价持续上涨时，采用先进先出法会导致（ ）。

A. 发出成本偏高，利润偏低  
B. 发出成本偏低，利润偏高  
C. 发出成本和利润都不变  
D. 无法确定

**答案：B**

**解析：** 物价上涨时，先进先出法先发出早期低价购入的存货，发出成本偏低，导致利润偏高。这是先进先出法的一个特点，考试常考。

### 题目5（选择题）

**题目描述：** 存货期末按成本与可变现净值孰低计量，体现的会计信息质量要求是（ ）。

A. 可靠性  
B. 谨慎性  
C. 可比性  
D. 及时性

**答案：B**

**解析：** 成本与可变现净值孰低法是不高估资产的体现，属于[[15-会计基础概念与原则|谨慎性原则]]。当存货贬值时，按较低的可变现净值计量，避免虚增资产。

### 题目6（分录题）

**题目描述：** 某批存货成本为10万元，可变现净值为8万元。计提存货跌价准备。

**解答：**
```
借：资产减值损失——存货跌价损失    20,000
贷：存货跌价准备                    20,000
```

**解析：** 成本10万 > 可变现净值8万，差额2万应计提存货跌价准备。资产减值损失增加（费用增加，记借方），存货跌价准备增加（资产备抵，记贷方）。

### 题目7（判断题）

**题目描述：** 企业可以根据需要随意变更存货的计价方法。（ ）

**答案：✗**

**解析：** [[15-会计基础概念与原则|可比性原则]]要求企业不得随意变更会计政策。存货计价方法的变更属于会计政策变更，只有在法规要求或能提供更可靠信息时才可变更。

### 题目8（综合题）

**题目描述：** 某企业本月A材料收发情况如下，分别用先进先出法和加权平均法计算发出成本和期末成本。

| 日期 | 事项 | 数量（公斤） | 单价（元） |
|------|------|-------------|-----------|
| 1日 | 期初结存 | 200 | 10 |
| 5日 | 购入 | 300 | 11 |
| 10日 | 发出 | 350 | - |
| 15日 | 购入 | 400 | 12 |
| 25日 | 发出 | 350 | - |

**解答：**

**先进先出法：**
```
10日发出350公斤：
  期初200×10 = 2,000
  5日购入150×11 = 1,650
  发出成本 = 3,650元

25日发出350公斤：
  5日购入剩余150×11 = 1,650
  15日购入200×12 = 2,400
  发出成本 = 4,050元

本月总发出成本 = 3,650 + 4,050 = 7,700元
期末存货 = 15日购入剩余200×12 = 2,400元
```

**加权平均法：**
```
总成本 = 200×10 + 300×11 + 400×12 = 2,000+3,300+4,800 = 10,100元
总数量 = 200+300+400 = 900公斤
加权平均单价 = 10,100 ÷ 900 = 11.22元/公斤

本月总发出 = 350+350 = 700公斤
发出成本 = 700 × 11.22 = 7,854元
期末存货 = 200 × 11.22 = 2,244元
```
