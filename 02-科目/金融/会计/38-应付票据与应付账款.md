# 38-应付票据与应付账款

> 应付票据和应付账款是企业最常见的流动负债，代表企业欠供应商的钱。合同负债则是新收入准则下的预收款科目。

## 概念说明

企业采购商品时，不一定每次都付现金。有时候给供应商开一张票据（应付票据），有时候先欠着以后再付（应付账款），有时候客户先付钱但商品还没发出（合同负债）。这些都是企业的**流动负债**——短期内要还的钱。

## 核心要点

### 一、应付账款

**应付账款**是企业因购买商品、接受劳务等经营活动应支付的款项。

| 业务 | 分录 |
|------|------|
| 赊购商品 | 借：原材料/库存商品，贷：应付账款 |
| 支付货款 | 借：应付账款，贷：银行存款 |
| 无法支付的应付账款 | 借：应付账款，贷：营业外收入 |

> **与[[06-采购业务]]的关系：** 赊购商品时，资产增加（库存商品），负债增加（应付账款）。

#### 应付账款入账时间

- 商品已验收入库、发票已到：按发票金额入账
- 商品已入库、发票未到：月末暂估入账，下月初冲回

### 二、应付票据

**应付票据**是企业开出、承兑的商业汇票，包括银行承兑汇票和商业承兑汇票。

| 业务 | 分录 |
|------|------|
| 开出商业汇票采购 | 借：原材料等，贷：应付票据 |
| 支付银行承兑汇票手续费 | 借：财务费用，贷：银行存款 |
| 汇票到期支付 | 借：应付票据，贷：银行存款 |
| 汇票到期无力支付（商业承兑） | 借：应付票据，贷：应付账款 |
| 汇票到期无力支付（银行承兑） | 借：应付票据，贷：短期借款 |

#### 银行承兑汇票 vs 商业承兑汇票

| 对比项 | 银行承兑汇票 | 商业承兑汇票 |
|--------|-------------|-------------|
| 承兑人 | 银行 | 企业 |
| 信用程度 | 高 | 较低 |
| 无力支付时 | 银行垫付，转为短期借款 | 转为应付账款 |
| 手续费 | 有 | 无 |

### 三、合同负债

**合同负债**是新收入准则下的科目，指企业已收或应收客户对价而应向客户转让商品的义务。

简单说：**合同负债就是预收账款的升级版**。

| 业务 | 分录 |
|------|------|
| 预收客户货款 | 借：银行存款，贷：合同负债 |
| 发出商品，确认收入 | 借：合同负债，贷：主营业务收入 |

> **合同负债 vs 预收账款：** 合同负债强调的是"合同义务"，必须与合同相关；预收账款范围更广。在新收入准则下，与合同相关的预收款应使用"合同负债"科目。

### 四、应付账款与应付票据的区别

| 对比项 | 应付账款 | 应付票据 |
|--------|----------|----------|
| 是否有票据 | 无 | 有（商业汇票） |
| 付款期限 | 信用期内 | 票据到期日 |
| 法律效力 | 较弱 | 较强（票据法约束） |
| 是否可转让 | 不可 | 可以背书转让 |

## 练习题

### 题目1（选择题）

**题目描述：** 企业赊购商品一批，应贷记的科目是（ ）。

A. 应收账款  
B. 应付账款  
C. 应付票据  
D. 合同负债

**答案：B**

**解析：** 赊购商品，形成应付账款（欠供应商的货款）。如果开出商业汇票，则贷记应付票据。

### 题目2（选择题）

**题目描述：** 企业开出银行承兑汇票到期无力支付，应（ ）。

A. 转为应付账款  
B. 转为短期借款  
C. 转为营业外收入  
D. 不做处理

**答案：B**

**解析：** 银行承兑汇票到期无力支付时，银行会垫付，企业对银行的欠款转为短期借款。商业承兑汇票则转为应付账款。

### 题目3（分录题）

**题目描述：** 企业购入原材料一批，价值5万元，开出3个月期商业承兑汇票一张。写出分录。

**解答：**
```
借：原材料        50,000
贷：应付票据      50,000
```

**解析：** 开出商业汇票采购，应付票据增加（负债增加），原材料增加（资产增加）。

### 题目4（选择题）

**题目描述：** 企业预收客户货款3万元，商品尚未发出。应贷记的科目是（ ）。

A. 主营业务收入  
B. 应收账款  
C. 合同负债  
D. 营业外收入

**答案：C**

**解析：** 预收货款但商品未发出，不确认收入。应贷记合同负债（或预收账款），待商品发出时再转入主营业务收入。[[17-权责发生制与收付实现制|权责发生制]]下，收入在商品发出时确认。

### 题目5（判断题）

**题目描述：** 应付票据到期无力支付时，一律转为应付账款。（ ）

**答案：✗**

**解析：** 银行承兑汇票到期无力支付时，转为短期借款（银行垫付）；商业承兑汇票到期无力支付时，才转为应付账款。

### 题目6（分录题）

**题目描述：** 企业之前预收客户货款5万元，本月发出商品，确认收入。写出分录。

**解答：**
```
预收时（之前已做）：
借：银行存款    50,000
贷：合同负债    50,000

发出商品确认收入：
借：合同负债        50,000
贷：主营业务收入    50,000
```

**解析：** 预收时负债增加，商品发出时负债减少、收入增加。这是[[17-权责发生制与收付实现制|权责发生制]]的典型应用。

### 题目7（选择题）

**题目描述：** 企业无法支付的应付账款，应转入（ ）。

A. 资本公积  
B. 营业外收入  
C. 主营业务收入  
D. 其他业务收入

**答案：B**

**解析：** 无法支付的应付账款属于企业的"意外之财"，应计入营业外收入。

### 题目8（综合题）

**题目描述：** 某企业本月发生以下业务：（1）赊购商品8万元；（2）开出银行承兑汇票采购材料5万元，支付手续费200元；（3）预收客户货款3万元；（4）偿还前欠货款6万元。写出所有分录。

**解答：**
```
业务（1）：
借：原材料        80,000
贷：应付账款      80,000

业务（2）：
借：原材料        50,000
贷：应付票据      50,000

借：财务费用        200
贷：银行存款        200

业务（3）：
借：银行存款      30,000
贷：合同负债      30,000

业务（4）：
借：应付账款      60,000
贷：银行存款      60,000
```

**解析：** 四笔业务分别涉及应付账款、应付票据、合同负债三种负债科目。银行承兑汇票的手续费计入财务费用。预收货款确认为合同负债。
