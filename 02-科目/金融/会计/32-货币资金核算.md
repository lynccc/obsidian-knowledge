# 32-货币资金核算

> 货币资金是企业流动性最强的资产，包括库存现金、银行存款和其他货币资金，是企业日常经营的"血液"。

## 概念说明

**货币资金**是指企业生产经营过程中处于货币形态的资产，包括**库存现金**、**银行存款**和**其他货币资金**。

想象一下你自己的钱包：手头的现金就是"库存现金"，银行卡里的钱就是"银行存款"，支付宝/微信里的钱（如果专门用来投资理财）就类似"其他货币资金"。企业也一样，只是规模更大、管理更严格。

## 核心要点

### 一、库存现金

#### 库存现金管理制度

| 管理要点 | 具体规定 |
|----------|----------|
| **使用范围** | 职工工资、差旅费、1000元以下零星支出等 |
| **库存限额** | 一般3-5天日常零星开支所需 |
| **坐支限制** | 不得"坐支"（即不得从收入的现金中直接支付） |
| **收支分离** | 现金收入当日送存银行，支出按规定从银行提取 |
| **钱账分管** | 出纳管钱，会计管账，不能一人兼任 |

#### 库存现金分录

| 业务 | 分录 |
|------|------|
| 从银行提取现金 | 借：库存现金，贷：银行存款 |
| 用现金支付费用 | 借：管理费用等，贷：库存现金 |
| 收到现金销售收入 | 借：库存现金，贷：主营业务收入 |
| 现金送存银行 | 借：银行存款，贷：库存现金 |

#### 现金清查

| 情况 | 处理方式 |
|------|----------|
| **现金溢余**（实际 > 账面） | 先记入"待处理财产损溢"，查明原因后转入"营业外收入"或其他应付款 |
| **现金短缺**（实际 < 账面） | 先记入"待处理财产损溢"，查明原因后转入"管理费用"或其他应收款 |

### 二、银行存款

银行存款是企业存放在银行或其他金融机构的货币资金。[[22-会计凭证与账簿|银行存款日记账]]由出纳逐日逐笔登记。

#### 银行存款核算要点

- 存入现金：借：银行存款，贷：库存现金
- 提取现金：借：库存现金，贷：银行存款
- 转账收款：借：银行存款，贷：应收账款等
- 转账付款：借：应付账款等，贷：银行存款

#### 未达账项

企业银行存款日记账余额与银行对账单余额不一致的原因：
1. **企业已收，银行未收**
2. **企业已付，银行未付**
3. **银行已收，企业未收**
4. **银行已付，企业未付**

> 需要编制[[34-银行存款余额调节表|银行存款余额调节表]]进行核对。

### 三、其他货币资金

其他货币资金是指企业除库存现金、银行存款以外的各种货币资金，主要包括：

| 类型 | 说明 | 举例 |
|------|------|------|
| **外埠存款** | 到外地进行临时或零星采购而汇往采购地的款项 | 汇款到外地采购 |
| **银行汇票存款** | 为取得银行汇票按规定存入银行的款项 | 申请银行汇票 |
| **银行本票存款** | 为取得银行本票按规定存入银行的款项 | 申请银行本票 |
| **信用证保证金存款** | 为开具信用证而存入银行的保证金 | 国际贸易信用证 |
| **存出投资款** | 已存入证券公司但尚未进行投资的资金 | 证券账户资金 |
| **信用卡存款** | 为取得信用卡而存入银行的款项 | 企业信用卡 |

#### 其他货币资金分录

| 业务 | 分录 |
|------|------|
| 将款项汇往采购地开立采购专户 | 借：其他货币资金——外埠存款，贷：银行存款 |
| 申请银行汇票 | 借：其他货币资金——银行汇票，贷：银行存款 |
| 采购完成，用其他货币资金支付 | 借：原材料等，贷：其他货币资金 |
| 余款退回 | 借：银行存款，贷：其他货币资金 |

## 公式汇总

```
库存现金限额 = 3-5天日常零星开支
银行存款余额调节表：
  企业账面余额 + 银行已收企业未收 - 银行已付企业未付
  = 银行对账单余额 + 企业已收银行未收 - 企业已付银行未付
```

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，不属于货币资金的是（ ）。

A. 库存现金  
B. 银行存款  
C. 应收账款  
D. 其他货币资金

**答案：C**

**解析：** 货币资金包括库存现金、银行存款和其他货币资金。应收账款属于应收款项，不是货币资金。

### 题目2（判断题）

**题目描述：** 企业可以用收入的现金直接支付费用，这叫"坐支"。（ ）

**答案：✗**

**解析：** "坐支"是不允许的。企业收入的现金应于当日送存银行，支出应按规定从银行提取，不得从现金收入中直接支付。

### 题目3（选择题）

**题目描述：** 现金日记账应由（ ）登记。

A. 会计  
B. 出纳  
C. 财务经理  
D. 审计人员

**答案：B**

**解析：** 现金日记账和银行存款日记账必须由出纳人员登记，体现"钱账分管"的内部控制原则。

### 题目4（分录题）

**题目描述：** 企业从银行提取现金2万元备用，写出会计分录。

**解答：**
```
借：库存现金    20,000
贷：银行存款    20,000
```

**解析：** 提取现金是资产内部转换——银行存款减少，库存现金增加，货币资金总额不变。

### 题目5（选择题）

**题目描述：** 企业将款项汇往外地开立采购专户，应借记的科目是（ ）。

A. 银行存款  
B. 应收账款  
C. 其他货币资金——外埠存款  
D. 预付账款

**答案：C**

**解析：** 汇往外地的采购专户属于外埠存款，是其他货币资金的一种。

### 题目6（分录题）

**题目描述：** 企业申请银行汇票一张，金额5万元，用银行存款支付。写出分录。

**解答：**
```
借：其他货币资金——银行汇票    50,000
贷：银行存款                  50,000
```

**解析：** 申请银行汇票时，资金从银行存款转入其他货币资金。实际使用汇票采购时，再从其他货币资金转入原材料等科目。

### 题目7（选择题）

**题目描述：** 下列各项中，属于其他货币资金的有（ ）。

A. 银行汇票存款  
B. 信用卡存款  
C. 存出投资款  
D. 以上都是

**答案：D**

**解析：** 其他货币资金包括外埠存款、银行汇票存款、银行本票存款、信用证保证金存款、存出投资款、信用卡存款等。

### 题目8（判断题）

**题目描述：** 企业的库存现金限额由企业自行决定，没有上限。（ ）

**答案：✗**

**解析：** 库存现金限额由开户银行根据企业实际需要核定，一般为3-5天日常零星开支所需的量，边远地区可适当放宽但不超过15天。
