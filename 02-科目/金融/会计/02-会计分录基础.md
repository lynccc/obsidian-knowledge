# 02-会计分录基础

## 概念说明

会计分录，简单说就是**记录每一笔经济业务的借贷对应关系**。就像记账一样，只不过用的是"借"和"贷"这两个符号来表示资金的来源和去向。

比如：你用银行存款买了1万元的货物。这笔业务的分录就是：
- 借：库存商品 1万（货物来了，资产增加）
- 贷：银行存款 1万（钱出去了，资产减少）

每一笔分录，**借贷金额必须相等**，这是铁律。

## 核心要点

### 什么是会计分录

会计分录是对每笔经济业务确定其**应借、应贷账户名称及其金额**的记录。由三要素组成：
1. **会计科目**（账户名称）
2. **记账方向**（借方或贷方）
3. **金额**

### 分录书写格式

```
借：科目名称    金额
贷：科目名称    金额
```

**书写规则：**
- 借方在上，贷方在下
- 借贷金额对齐
- 一借多贷或一贷多借时，借方合计 = 贷方合计
- 多借多贷时，每笔借贷都要列明

### ⚠️ 核心口诀（必背）

```
资成费（资产、成本、费用）→ 借增贷减
负所收（负债、所有者权益、收入）→ 借减贷增
```

**切记：借和贷与字面意思无关！**
- "借"和"贷"只是记账符号，不要从字面理解
- "借"不代表"借钱"，"贷"不代表"贷款"
- 借在左，贷在右，仅此而已

### 常用科目分类

#### 资产类（借增贷减）

| 科目 | 说明 |
|------|------|
| 库存现金 | 手头的现金 |
| 银行存款 | 银行账户里的钱 |
| 应收账款 | 别人欠我们的货款 |
| 库存商品 | 仓库里的商品 |
| 固定资产 | 设备、房屋等长期使用的资产 |
| 待摊费用 | 已付但应由以后各期负担的费用 |

#### 负债类（贷增借减）

| 科目 | 说明 |
|------|------|
| 应付账款 | 我们欠供应商的货款 |
| 短期借款 | 向银行借的一年内要还的款 |
| 应付利息 | 欠银行的利息 |
| 应付股利 | 欠股东的分红 |
| 应交税费 | 欠税务局的税 |

#### 所有者权益类（贷增借减）

| 科目 | 说明 |
|------|------|
| 实收资本 | 投资者投入的资本 |
| 未分配利润 | 留在企业里的利润 |

#### 损益类

**收入类（贷增借减）：**
| 科目 | 说明 |
|------|------|
| 主营业务收入 | 主要经营活动的收入 |

**费用类（借增贷减）：**
| 科目 | 说明 |
|------|------|
| 主营业务成本 | 卖出商品的成本 |
| 管理费用 | 行政管理部门的费用 |
| 销售费用 | 销售部门的费用 |
| 财务费用 | 利息、手续费等 |
| 所得税费用 | 企业所得税 |

## 公式/分录模板

### 借贷记账法核心规则

```
资产 + 费用 = 负债 + 所有者权益 + 收入

左边增加记借方，减少记贷方
右边增加记贷方，减少记借方
```

### 分录编制步骤

1. 分析经济业务涉及哪些科目
2. 判断这些科目属于哪一类（资产/负债/权益/收入/费用）
3. 根据增减判断借贷方向
4. 确定金额
5. 检查借贷是否相等

## 练习题

### 题目1

**题目描述：** 判断以下科目的借贷方向：银行存款增加应记在哪方？

**解答：** 银行存款是资产类科目，增加记**借方**。

**解析：** 资产类科目增加记借方，减少记贷方，这是借贷记账法的基本规则。

### 题目2

**题目描述：** 判断以下科目的借贷方向：应付账款增加应记在哪方？

**解答：** 应付账款是负债类科目，增加记**贷方**。

**解析：** 负债类科目增加记贷方，减少记借方。应付账款增加意味着欠别人更多钱了，是负债增加。

### 题目3

**题目描述：** 判断以下科目的借贷方向：主营业务收入增加应记在哪方？

**解答：** 主营业务收入是收入类科目，增加记**贷方**。

**解析：** 收入类科目与所有者权益类科目方向相同，增加记贷方。收入最终会增加所有者权益，所以方向一致。

### 题目4

**题目描述：** 判断以下科目的借贷方向：管理费用增加应记在哪方？

**解答：** 管理费用是费用类科目，增加记**借方**。

**解析：** 费用类科目与资产类科目方向相同，增加记借方。费用最终会减少所有者权益，所以方向与权益相反。

### 题目5

**题目描述：** 企业用银行存款5000元支付办公费，写出会计分录。

**解答：**
```
借：管理费用    5000
贷：银行存款    5000
```

**解析：** 办公费属于管理费用（费用增加，记借方），用银行存款支付（资产减少，记贷方）。一借一贷，金额相等。
