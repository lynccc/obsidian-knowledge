# 29-记账原理习题精选

## 概念说明

本笔记整理记账原理章节的习题，包含12道选择题和2道业务题。

## 选择题（12道）

### 题目1

**题目描述：** 借贷记账法的记账规则是（ ）。

A. 有借必有贷，借贷必相等  
B. 有增必有减，增减必相等  
C. 借方记增加，贷方记减少  
D. 贷方记增加，借方记减少

**答案：A**

**解析：** 借贷记账法的核心规则是"有借必有贷，借贷必相等"。C和D都不全面，不同账户类型增减方向不同。

### 题目2

**题目描述：** 下列账户中，借方登记增加额的是（ ）。

A. 应付账款  
B. 实收资本  
C. 主营业务收入  
D. 管理费用

**答案：D**

**解析：** 费用类账户借方记增加。A、B是权益类账户贷方记增加，C是收入类账户贷方记增加。

### 题目3

**题目描述：** 某企业"银行存款"账户期初借方余额为100万元，本期借方发生额为80万元，本期贷方发生额为60万元，期末余额为（ ）。

A. 120万元  
B. 80万元  
C. 140万元  
D. 60万元

**答案：A**

**解析：** 资产类账户期末余额 = 期初借方余额 + 本期借方发生额 - 本期贷方发生额 = 100 + 80 - 60 = 120万元。

### 题目4

**题目描述：** 下列关于借贷记账法的表述中，正确的是（ ）。

A. "借"表示增加，"贷"表示减少  
B. "借"表示减少，"贷"表示增加  
C. "借"和"贷"只是记账符号，与增减无固定关系  
D. "借"表示收入，"贷"表示费用

**答案：C**

**解析：** "借"和"贷"只是记账符号，不直接代表增加或减少。资产类借方增加，负债类贷方增加。

### 题目5

**题目描述：** 企业用银行存款偿还应付账款5万元，应编制的分录是（ ）。

A. 借：应付账款 5万，贷：银行存款 5万  
B. 借：银行存款 5万，贷：应付账款 5万  
C. 借：应付账款 5万，贷：库存现金 5万  
D. 借：管理费用 5万，贷：银行存款 5万

**答案：A**

**解析：** 偿还应付账款：负债（应付账款）减少记借方，资产（银行存款）减少记贷方。

### 题目6

**题目描述：** 收入类账户的结构与（ ）账户的结构相同。

A. 资产类  
B. 负债类  
C. 费用类  
D. 成本类

**答案：B**

**解析：** 收入类账户与负债类账户结构相同：贷方记增加，借方记减少。资产类、费用类、成本类账户都是借方记增加。

### 题目7

**题目描述：** 下列会计分录中，属于一借多贷的是（ ）。

A. 借：银行存款 10万，贷：应收账款 10万  
B. 借：原材料 8万，贷：银行存款 5万，应付账款 3万  
C. 借：管理费用 2万，销售费用 3万，贷：银行存款 5万  
D. 借：银行存款 20万，贷：实收资本 20万

**答案：B**

**解析：** 一借多贷：借方一个科目，贷方多个科目。B选项借方是"原材料"一个科目，贷方是"银行存款"和"应付账款"两个科目。

### 题目8

**题目描述：** "应付账款"账户期初贷方余额30万元，本期贷方发生额20万元，本期借方发生额25万元，期末余额为（ ）。

A. 借方25万元  
B. 贷方25万元  
C. 借方35万元  
D. 贷方35万元

**答案：B**

**解析：** 负债类账户期末余额 = 期初贷方余额 + 本期贷方发生额 - 本期借方发生额 = 30 + 20 - 25 = 25万元（贷方余额）。

### 题目9

**题目描述：** 下列经济业务中，会导致资产和负债同时增加的是（ ）。

A. 用银行存款购买原材料  
B. 赊购原材料  
C. 用银行存款偿还借款  
D. 收到投资者投入资本

**答案：B**

**解析：** 赊购原材料：借：原材料（资产增加），贷：应付账款（负债增加）。A是资产内部变动，C是资产和负债同时减少，D是资产和权益同时增加。

### 题目10

**题目描述：** 下列经济业务中，会导致资产和所有者权益同时增加的是（ ）。

A. 向银行借款  
B. 赊购原材料  
C. 收到投资者投入资本  
D. 用银行存款支付费用

**答案：C**

**解析：** 收到投资者投入：借：银行存款（资产增加），贷：实收资本（权益增加）。A是资产和负债同时增加，B是资产和负债同时增加，D是资产减少、费用增加。

### 题目11

**题目描述：** 会计分录的书写格式是（ ）。

A. 先写贷方，后写借方  
B. 先写借方，后写贷方  
C. 借贷同时写  
D. 没有固定格式

**答案：B**

**解析：** 会计分录的标准格式是"左借右贷"：先写借方科目和金额，再写贷方科目和金额（贷方通常缩进）。

### 题目12

**题目描述：** 下列各项中，不正确的是（ ）。

A. 资产增加记借方  
B. 负债增加记贷方  
C. 收入增加记借方  
D. 费用增加记借方

**答案：C**

**解析：** 收入类账户增加记贷方，不是借方。A、B、D都是正确的。

## 业务题

### 业务题1：8笔业务要素变化分析

**业务描述：**

| 序号 | 业务内容 | 资产 | 负债 | 所有者权益 |
|------|----------|------|------|-----------|
| 1 | 收到投资100万 | +100 | | +100 |
| 2 | 向银行借款50万 | +50 | +50 | |
| 3 | 购买设备30万 | +30/-30 | | |
| 4 | 赊购材料20万 | +20 | +20 | |
| 5 | 销售商品（赊销）40万 | +40 | | +40 |
| 6 | 用存款还借款10万 | -10 | -10 | |
| 7 | 支付费用5万 | -5 | | -5 |
| 8 | 分配股利8万 | | +8 | -8 |

**分析：**
- 业务1：资产（银行存款）增加，权益（实收资本）增加
- 业务2：资产（银行存款）增加，负债（短期借款）增加
- 业务3：资产（固定资产）增加，资产（银行存款）减少（资产内部变动）
- 业务4：资产（原材料）增加，负债（应付账款）增加
- 业务5：资产（应收账款）增加，收入（主营业务收入）增加→权益增加
- 业务6：资产（银行存款）减少，负债（短期借款）减少
- 业务7：资产（银行存款）减少，费用（管理费用）增加→权益减少
- 业务8：负债（应付股利）增加，权益（未分配利润）减少

### 业务题2：10笔业务完整会计分录

**业务描述及分录：**

**（1）收到投资者投入资本200万元，存入银行**
```
借：银行存款        2,000,000
贷：实收资本        2,000,000
```

**（2）向银行借入短期借款100万元**
```
借：银行存款        1,000,000
贷：短期借款        1,000,000
```

**（3）用银行存款购买设备一台，价值50万元**
```
借：固定资产          500,000
贷：银行存款          500,000
```

**（4）赊购原材料一批，价值30万元**
```
借：原材料            300,000
贷：应付账款          300,000
```

**（5）销售商品一批，售价60万元，成本35万元，货款未收**
```
借：应收账款          600,000
贷：主营业务收入      600,000

借：主营业务成本      350,000
贷：库存商品          350,000
```

**（6）收到客户偿还的货款40万元**
```
借：银行存款          400,000
贷：应收账款          400,000
```

**（7）用银行存款偿还应付账款20万元**
```
借：应付账款          200,000
贷：银行存款          200,000
```

**（8）用银行存款支付管理费用5万元**
```
借：管理费用           50,000
贷：银行存款           50,000
```

**（9）计提本月折旧3万元**
```
借：管理费用           30,000
贷：累计折旧           30,000
```

**（10）用银行存款偿还短期借款50万元**
```
借：短期借款          500,000
贷：银行存款          500,000
```

**分录验证：**
- 所有分录借贷金额相等 ✓
- 会计恒等式平衡 ✓
