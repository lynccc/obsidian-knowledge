# 08-利润分配业务

## 概念说明

企业经营一年赚了钱（净利润），这些钱怎么处理？这就是利润分配业务。

利润分配的基本流程：
1. **计算所得税**：赚了利润要交税
2. **结转本年利润**：把收入和费用都转到"本年利润"科目，算出净利润
3. **分配股利**：把利润分给股东（或者留在企业里）

净利润最终会转入所有者权益中的**未分配利润**。

## 核心要点

### 利润分配流程

1. **计提所得税**：所得税费用增加，应交税费增加
2. **结转本年利润**：
   - 收入类科目 → 本年利润（贷方）
   - 费用类科目 → 本年利润（借方）
3. **净利润转入未分配利润**：本年利润 → 未分配利润
4. **分配股利**：未分配利润 → 应付股利
5. **支付股利**：应付股利 → 银行存款

### 净利润计算

$$净利润 = 收入总额 - 费用总额 - 所得税费用$$

## 公式/分录模板

### 计提所得税

```
借：所得税费用      （所得税金额）
贷：应交税费        （所得税金额）
```

### 结转本年利润（收入类）

```
借：主营业务收入    （金额）
贷：本年利润        （金额）
```

### 结转本年利润（费用类）

```
借：本年利润        （金额）
贷：主营业务成本    （金额）
贷：管理费用        （金额）
贷：销售费用        （金额）
贷：财务费用        （金额）
贷：所得税费用      （金额）
```

### 净利润转入未分配利润

```
借：本年利润        （净利润）
贷：未分配利润      （净利润）
```

### 分配股利

```
借：未分配利润      （股利金额）
贷：应付股利        （股利金额）
```

### 支付股利

```
借：应付股利        （股利金额）
贷：银行存款        （股利金额）
```

## 练习题

### 题目1

**题目描述：** 企业本月实现收入200万元，发生费用119万元（其中主营业务成本80万，管理费用25万，销售费用10万，财务费用4万）。计算净利润并写出结转分录。

**解答：**
```
利润总额 = 200万 - 119万 = 81万

结转收入：
借：主营业务收入    2000000
贷：本年利润        2000000

结转费用：
借：本年利润        1190000
贷：主营业务成本    800000
贷：管理费用        250000
贷：销售费用        100000
贷：财务费用        40000
```

**解析：** 结转本年利润就是把所有收入和费用都转到"本年利润"科目。收入从借方转出（原来记贷方，现在从借方转出），费用从贷方转出（原来记借方，现在从贷方转出）。结转后，本年利润的贷方余额就是净利润81万。

### 题目2

**题目描述：** 承接题目1，假设所得税税率为25%，计提所得税并写出分录。

**解答：**
```
所得税费用 = 81万 × 25% = 20.25万

借：所得税费用    202500
贷：应交税费      202500
```

**解析：** 企业所得税按利润总额的25%计算。所得税费用增加（费用增加，记借方），应交税费增加（负债增加，记贷方）。这笔税款以后要交给税务局。

### 题目3

**题目描述：** 承接题目2，结转所得税费用并计算净利润。

**解答：**
```
结转所得税费用：
借：本年利润        202500
贷：所得税费用      202500

净利润 = 81万 - 20.25万 = 60.75万

结转净利润：
借：本年利润        607500
贷：未分配利润      607500
```

**解析：** 所得税费用也要结转到本年利润。最终本年利润的贷方余额就是净利润60.75万，再转入未分配利润。至此，本年利润科目余额为0。

### 题目4

**题目描述：** 承接题目3，企业决定分配股利20万元，写出分录。

**解答：**
```
分配股利：
借：未分配利润    200000
贷：应付股利      200000

支付股利：
借：应付股利      200000
贷：银行存款      200000
```

**解析：** 分配股利是从净利润中拿出一部分分给股东。未分配利润减少（所有者权益减少，记借方），应付股利增加（负债增加，记贷方）。实际支付时，应付股利减少，银行存款减少。

### 题目5

**题目描述：** 某企业年度数据：收入500万元，费用300万元（含各项费用），所得税率25%。企业决定将净利润的60%分配股利。计算：（1）利润总额；（2）所得税；（3）净利润；（4）分配股利金额；（5）年末未分配利润。

**解答：**
```
（1）利润总额 = 500万 - 300万 = 200万
（2）所得税 = 200万 × 25% = 50万
（3）净利润 = 200万 - 50万 = 150万
（4）分配股利 = 150万 × 60% = 90万
（5）年末未分配利润 = 150万 - 90万 = 60万
```

**解析：** 这是一道综合计算题。先算利润总额（收入-费用），再算所得税（利润总额×税率），然后算净利润（利润总额-所得税），最后算股利分配（净利润×分配比例）和年末未分配利润（净利润-股利）。
