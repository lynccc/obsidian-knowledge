# 41-所有者权益

> 所有者权益是企业资产扣除负债后由所有者享有的剩余权益，包括实收资本、资本公积、其他综合收益和留存收益。

## 概念说明

**所有者权益**是指企业资产扣除负债后，由所有者（股东）享有的剩余权益。用公式表示：

> **所有者权益 = 资产 - 负债**

打个比方：你开了一家店，总资产100万，欠银行和供应商40万，那属于你的部分就是60万。这60万就是所有者权益。

## 核心要点

### 一、实收资本

**实收资本**是指投资者按照合同、协议或章程约定，实际投入企业的资本。

#### 投资者投入资本

| 投资形式 | 分录 |
|----------|------|
| 以现金投资 | 借：银行存款，贷：实收资本 |
| 以固定资产投资 | 借：固定资产，贷：实收资本 |
| 以无形资产投资 | 借：无形资产，贷：实收资本 |
| 超出注册资本部分 | 借：银行存款，贷：实收资本、资本公积 |

#### 减少注册资本

```
借：实收资本
贷：银行存款
```

> **注意：** 实收资本一般不能随意减少，需要经过法定程序（如股东会决议）。

### 二、资本公积

**资本公积**是指企业收到的投资者超出其在注册资本（或股本）中所占份额的投资额，以及直接计入所有者权益的利得和损失。

#### 资本公积的构成

| 类型 | 来源 | 举例 |
|------|------|------|
| **资本溢价（股本溢价）** | 投资者投入超出注册资本部分 | 投资100万，注册资本80万，差额20万 |
| **其他资本公积** | 其他原因形成的 | 权益法核算的长期股权投资变动等 |

#### 资本溢价的分录

```
投资者投入100万，其中80万计入注册资本，20万为资本溢价：
借：银行存款    1,000,000
贷：实收资本      800,000
    资本公积——资本溢价  200,000
```

### 三、其他综合收益

**其他综合收益**是指企业根据会计准则规定未在当期损益中确认的各项利得和损失。

主要包括：
- 以公允价值计量且其变动计入其他综合收益的金融资产的公允价值变动
- 外币报表折算差额
- 权益法下被投资单位其他综合收益变动

> **考试重点：** 其他综合收益不影响当期利润，但影响所有者权益总额。

### 四、留存收益

**留存收益**是指企业从历年实现的利润中提取或形成的留存于企业的内部积累，包括**盈余公积**和**未分配利润**。

#### 盈余公积

| 类型 | 提取比例 | 用途 |
|------|----------|------|
| **法定盈余公积** | 净利润的10% | 弥补亏损、转增资本、扩大经营 |
| **任意盈余公积** | 由股东会决定 | 同上 |

> **注意：** 法定盈余公积累计额达到注册资本的50%时，可以不再提取。

#### 提取盈余公积的分录

```
借：利润分配——提取法定盈余公积
    利润分配——提取任意盈余公积
贷：盈余公积——法定盈余公积
    盈余公积——任意盈余公积
```

#### 未分配利润

**未分配利润**是企业实现的净利润经过弥补亏损、提取盈余公积和向投资者分配利润后留存在企业的、历年结存的利润。

```
年末未分配利润 = 年初未分配利润 + 本年净利润 - 提取盈余公积 - 分配股利
```

### 五、所有者权益各项目关系

```
所有者权益 = 实收资本 + 资本公积 + 其他综合收益 + 盈余公积 + 未分配利润
```

#### 各项目增减变动

| 项目 | 增加 | 减少 |
|------|------|------|
| 实收资本 | 投资者投入 | 减少注册资本 |
| 资本公积 | 资本溢价 | 转增资本 |
| 其他综合收益 | 公允价值上升等 | 公允价值下降等 |
| 盈余公积 | 提取盈余公积 | 弥补亏损、转增资本 |
| 未分配利润 | 净利润 | 提取盈余公积、分配股利 |

## 公式汇总

```
所有者权益 = 资产 - 负债
未分配利润 = 年初未分配利润 + 净利润 - 提取盈余公积 - 分配股利
法定盈余公积 = 净利润 × 10%（累计达注册资本50%可不再提取）
```

## 练习题

### 题目1（选择题）

**题目描述：** 投资者投入资本80万元，其中60万元计入注册资本，差额应计入（ ）。

A. 盈余公积  
B. 未分配利润  
C. 资本公积  
D. 营业外收入

**答案：C**

**解析：** 投资者投入超出注册资本的部分计入资本公积——资本溢价。80万中60万计入实收资本，20万计入资本公积。

### 题目2（选择题）

**题目描述：** 下列各项中，不属于留存收益的是（ ）。

A. 盈余公积  
B. 未分配利润  
C. 资本公积  
D. A和B

**答案：C**

**解析：** 留存收益包括盈余公积和未分配利润。资本公积不属于留存收益，它是由投资者投入形成的。

### 题目3（分录题）

**题目描述：** 企业本年净利润100万元，按10%提取法定盈余公积，按5%提取任意盈余公积。写出分录。

**解答：**
```
法定盈余公积 = 100万 × 10% = 10万
任意盈余公积 = 100万 × 5% = 5万

借：利润分配——提取法定盈余公积    100,000
借：利润分配——提取任意盈余公积     50,000
贷：盈余公积——法定盈余公积        100,000
    盈余公积——任意盈余公积         50,000
```

**解析：** 提取盈余公积是从净利润中拿出一部分作为企业的发展基金。法定盈余公积必须提取（10%），任意盈余公积由企业自行决定。

### 题目4（判断题）

**题目描述：** 法定盈余公积必须每年提取，没有上限。（ ）

**答案：✗**

**解析：** 法定盈余公积累计额达到注册资本的50%时，可以不再提取。不是没有上限的。

### 题目5（计算题）

**题目描述：** 某企业年初未分配利润50万元，本年净利润80万元，提取盈余公积12万元，分配股利20万元。计算年末未分配利润。

**解答：**
```
年末未分配利润 = 50 + 80 - 12 - 20 = 98万元
```

**解析：** 年末未分配利润 = 年初未分配利润 + 本年净利润 - 提取盈余公积 - 分配股利。

### 题目6（选择题）

**题目描述：** 下列各项中，会导致所有者权益增加的是（ ）。

A. 向银行借款  
B. 收到投资者投入  
C. 用银行存款偿还应付账款  
D. 计提折旧

**答案：B**

**解析：** 收到投资者投入：资产增加，实收资本增加，所有者权益增加。A增加负债，C是资产和负债同减，D是费用增加、资产减少。

### 题目7（分录题）

**题目描述：** 企业将资本公积20万元转增资本。写出分录。

**解答：**
```
借：资本公积    200,000
贷：实收资本    200,000
```

**解析：** 资本公积转增资本，是所有者权益内部的变动——资本公积减少，实收资本增加，所有者权益总额不变。

### 题目8（综合题）

**题目描述：** 某企业年初所有者权益构成：实收资本500万，资本公积50万，盈余公积80万，未分配利润120万。本年发生以下业务：（1）收到投资者投入100万（其中80万计入注册资本）；（2）本年净利润150万；（3）提取盈余公积22.5万；（4）分配股利50万。计算年末所有者权益各项目。

**解答：**
```
实收资本：500 + 80 = 580万
资本公积：50 + 20 = 70万（投资者多投的20万）
盈余公积：80 + 22.5 = 102.5万
未分配利润：120 + 150 - 22.5 - 50 = 197.5万

年末所有者权益合计 = 580 + 70 + 102.5 + 197.5 = 950万
```

**解析：** 逐项计算各项目的增减变动。投资者投入100万，80万计入实收资本，20万计入资本公积。净利润增加未分配利润，提取盈余公积和分配股利减少未分配利润。
