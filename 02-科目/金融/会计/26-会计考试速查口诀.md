# 25-会计考试速查口诀

## 概念说明

本笔记汇总了会计考试中所有核心口诀和速记内容，考前5分钟速查专用。

## 核心要点

### 一、六大要素速记

```
资产、负债、所有者权益 → 反映财务状况（资产负债表）
收入、费用、利润       → 反映经营成果（利润表）
```

**记忆：** 三静三动——静态要素（财务状况）、动态要素（经营成果）

**关系：**
- 资产 = 负债 + 所有者权益
- 利润 = 收入 - 费用
- 利润最终归入所有者权益（未分配利润）

### 二、八大原则速记

```
可比性、可靠性、明晰性、谨慎性
重要性、实质大于形式、相关性、及时性
```

**口诀：** "可可明谨，重实相及"

| 原则 | 关键词 | 典型应用 |
|------|--------|---------|
| 可比性 | 同一尺子 | 会计政策一致 |
| 可靠性 | 真实完整 | 不造假 |
| 明晰性 | 清晰明了 | 看得懂 |
| 谨慎性 | 宁可保守 | 计提减值准备 |
| 重要性 | 抓大放小 | 重要的单独反映 |
| 实质大于形式 | 看本质 | 融资租赁按自有资产 |
| 相关性 | 对决策有用 | 提供有用信息 |
| 及时性 | 别拖延 | 及时记账 |

### 三、五种计量属性速记

```
历史成本、重置成本、现值、可变现净值、公允价值
```

**口诀：** "历重现可公"

| 属性 | 含义 | 适用场景 |
|------|------|---------|
| 历史成本 | 过去花了多少 | 最常用，固定资产初始计量 |
| 重置成本 | 现在要花多少 | 盘盈固定资产 |
| 现值 | 未来的钱现在值多少 | 长期应收款/应付款 |
| 可变现净值 | 卖了能拿回多少 | 存货期末计量 |
| 公允价值 | 市场认为值多少 | 交易性金融资产 |

### 四、四大假设速记

```
会计主体、持续经营、会计分期、货币计量
```

**口诀：** "主持会货"（主持会议要花钱）

| 假设 | 核心含义 | 易错点 |
|------|---------|--------|
| 会计主体 | 给谁记账 | ≠ 法人！法人一定是会计主体，反之不然 |
| 持续经营 | 不会马上倒闭 | 清算时要改用清算基础 |
| 会计分期 | 一年算一次账 | 依赖持续经营假设 |
| 货币计量 | 用钱衡量一切 | 确定记账本位币 |

### 五、借贷记账口诀 ⭐⭐⭐

```
资成费，借增贷减
负所收，借减贷增
```

**切记：借和贷与字面意思无关！**

展开：

| 类型 | 科目 | 增加记 | 减少记 |
|------|------|--------|--------|
| **资** | 资产类 | 借方 | 贷方 |
| **成** | 成本类 | 借方 | 贷方 |
| **费** | 费用类 | 借方 | 贷方 |
| **负** | 负债类 | 贷方 | 借方 |
| **所** | 所有者权益类 | 贷方 | 借方 |
| **收** | 收入类 | 贷方 | 借方 |

**核心规则：** 有借必有贷，借贷必相等。

### 六、可变现净值公式

$$可变现净值 = 售价 - 继续生产到完工需要的成本 - 销售费用 - 税费$$

**通俗理解：** 这批存货假设卖掉，扣掉还要花多少钱才能完工、卖的时候要花的销售费用和要交的税，剩下的就是可变现净值。

**用于：** 存货期末计量。可变现净值 < 成本时，按可变现净值计量，差额计提存货跌价准备。

### 七、ROE公式

$$ROE = \frac{净利润}{净资产} \times 100\% = \frac{净利润}{所有者权益} \times 100\%$$

**含义：** 股东每投入100元能赚多少钱。ROE越高，盈利能力越强。

### 八、市盈率（PE）公式

$$PE = \frac{股价}{每股收益} = \frac{市值}{净利润}$$

**含义：** 投资者愿意为每1元利润支付多少价格。PE越高，市场预期越高（或估值过高）。

### 九、资产负债率公式

$$资产负债率 = \frac{负债总额}{资产总额} \times 100\%$$

**含义：** 企业有多少钱是借来的。一般40%-60%较合理。

### 十、毛利率公式

$$毛利率 = \frac{收入 - 成本}{收入} \times 100\%$$

**注意：** 毛利率只考虑收入和成本，**不含期间费用和税**！

### 十一、权责发生制 vs 收付实现制

| 对比项 | 权责发生制 | 收付实现制 |
|--------|-----------|-----------|
| 确认标准 | 交易发生时间 | 现金收付时间 |
| 赊销 | ✅ 确认收入 | ❌ 不确认 |
| 预收款 | ❌ 不确认（负债） | ✅ 确认收入 |
| 预付费用 | ❌ 不确认（资产） | ✅ 确认费用 |
| 计提折旧 | ✅ 确认费用 | ❌ 不确认 |
| 编制基础 | 资产负债表、利润表 | 现金流量表 |

**串讲经典计算：**
- 权责发生制：收入1,055,800 - 费用513,780 = 利润542,020
- 收付实现制：收入800,600 - 费用612,780 = 利润187,820
- 差异354,200，原因：赊销未收款、预收确认、预付/折旧/工资确认差异

### 十二、凭证选择口诀

```
收款看增加，付款看减少，转账啥都不涉及
涉及现金/银行存款增加 → 收款凭证
涉及现金/银行存款减少 → 付款凭证
不涉及现金/银行存款   → 转账凭证
```

### 十三、账户余额计算

```
资产类余额 = 期初借方 + 本期借方 - 本期贷方
负债类余额 = 期初贷方 + 本期贷方 - 本期借方
```

### 十四、利润表结构

```
主营业务收入
- 主营业务成本
= 主营业务利润（毛利）
- 管理费用 - 销售费用 - 财务费用
= 利润总额
- 所得税费用
= 净利润
```

### 十五、资产负债表等式

```
资产 = 负债 + 所有者权益
```

**资产总额变动计算（串讲经典）：**
```
期末资产 = 期初资产 + 接受投资 - 偿还货款 + 销售收入 - 销售成本
         = 1000 + 100 - 20 + 90 - 80 = 1090万
```

### 十六、现金流量表三大分类

| 分类 | 典型流入 | 典型流出 |
|------|---------|---------|
| 经营活动 | 销售收现 | 采购付现、支付职工 |
| 投资活动 | 出售资产、收到股利/利息 | 购买资产 |
| 筹资活动 | 取得借款 | 还款、付息、发放股利 |

**易混点：**
- 债券利息 → 投资活动
- 收到股利 → 投资活动
- 发放股利 → 筹资活动

### 十七、常见误区速记

| 误区 | 正确理解 |
|------|---------|
| 出售固定资产 = 营业收入 | ❌ 是资产处置损益/营业外收入 |
| 收到投资款 = 收入 | ❌ 是实收资本增加（所有者权益） |
| 预收货款 = 收入 | ❌ 是负债（预收账款），发出商品时才确认 |
| 提取现金 = 费用 | ❌ 只是资产内部转换 |
| 会计主体 = 法人 | ❌ 法人一定是会计主体，反之不然 |
| 借 = 借钱 | ❌ 借只是记账符号，与字面意思无关 |
