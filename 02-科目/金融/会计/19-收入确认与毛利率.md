# 19-收入确认与毛利率

## 概念说明

收入是利润表的起点，毛利率是衡量企业盈利能力的基础指标。正确理解收入的构成和毛利率的计算，是分析财务报表的第一步。

## 核心要点

### 营业收入构成

```
营业收入
├── 主营业务收入（核心业务产生的收入）
└── 其他业务收入（非核心但日常活动产生的收入）
```

**注意区分：**
- **主营业务收入**：企业常规经营活动产生的收入（如制造企业卖产品、贸易企业卖商品）
- **其他业务收入**：非主要经营活动但属于日常活动的收入（如出租固定资产、销售材料）
- **营业外收入**：与日常经营活动无关的收入（如捐赠利得、罚款收入、转让股权收益）

### 收入分类对比

| 收入类型 | 来源 | 举例 | 是否属于营业收入 |
|----------|------|------|------------------|
| 主营业务收入 | 核心经营活动 | 卖产品、提供服务 | ✓ |
| 其他业务收入 | 非核心日常活动 | 出租设备、卖材料 | ✓ |
| 营业外收入 | 非日常活动 | 捐赠、罚款、资产处置 | ✗ |

### 重要区分

**出售固定资产 ≠ 营业收入**

- 出售固定资产属于"资产处置收益"，不是营业收入
- 营业收入必须来自"日常活动"
- 固定资产处置不是企业的日常活动

### 毛利率计算

$$毛利率 = \frac{收入 - 成本}{收入} \times 100\%$$

**关键理解：**
- "成本"仅指**主营业务成本**（直接成本）
- **不含**期间费用（管理费用、销售费用、财务费用）
- **不含**税金

**记忆口诀："毛利计算两不要：不要费用，不要税"**

### 毛利率的意义

| 毛利率水平 | 含义 |
|-----------|------|
| 高毛利率（>50%） | 产品附加值高，定价能力强 |
| 中毛利率（20%-50%） | 正常盈利水平 |
| 低毛利率（<20%） | 竞争激烈，利润空间小 |

### 毛利率计算

$$毛利率 = \frac{主营业务收入 - 主营业务成本}{主营业务收入} \times 100\%$$

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，属于企业营业收入的是（ ）。

A. 出售固定资产取得的收入  
B. 接受捐赠取得的收入  
C. 出租包装物取得的收入  
D. 收到的违约罚款

**答案：C**

**解析：** 出租包装物取得的收入属于其他业务收入，是营业收入的组成部分。A属于资产处置收益，B和D属于营业外收入，均不属于营业收入。

### 题目2（选择题）

**题目描述：** 某企业本月主营业务收入为80万元，主营业务成本为48万元，则毛利率为（ ）。

A. 60%  
B. 40%  
C. 66.7%  
D. 33.3%

**答案：B**

**解析：** 毛利率 = (收入 - 成本) / 收入 × 100% = (80 - 48) / 80 × 100% = 40%。注意毛利率计算中的成本仅指主营业务成本，不含期间费用和税金。

### 题目3（判断题）

**题目描述：** 出售固定资产取得的收入应计入主营业务收入。（ ）

**答案：✗（错误）**

**解析：** 出售固定资产不是企业的日常经营活动，取得的收入不应计入主营业务收入，而应计入"资产处置收益"。营业收入必须来自企业的日常活动。

### 题目4（选择题）

**题目描述：** 某企业销售产品一批，售价10万元，成本6万元，发生销售费用1万元，管理费用0.5万元。毛利率为（ ）。

A. 40%  
B. 25%  
C. 30%  
D. 35%

**答案：A**

**解析：** 毛利率 = (收入 - 成本) / 收入 × 100% = (10 - 6) / 10 × 100% = 40%。毛利率计算不考虑期间费用（销售费用、管理费用），只考虑直接成本。

### 题目5（综合题）

**题目描述：** 某制造企业本月发生以下业务：

（1）销售A产品一批，售价50万元，成本30万元，货款已收  
（2）销售B产品一批，售价30万元，成本18万元，货款未收  
（3）出租闲置设备，收取租金2万元  
（4）出售旧设备一台，取得收入5万元（原值10万，已提折旧7万）  
（5）收到客户违约罚款1万元

请计算：（1）主营业务收入（2）其他业务收入（3）营业外收入（4）毛利率

**解答：**

```
（1）主营业务收入 = 50万（A产品）+ 30万（B产品）= 80万
（2）其他业务收入 = 2万（租金收入）
（3）营业外收入 = 1万（违约罚款）
    注：出售旧设备收入5万属于资产处置收益，不属于营业外收入
（4）主营业务成本 = 30万 + 18万 = 48万
    毛利率 = (80 - 48) / 80 × 100% = 40%
```

**解析：**
- 主营业务收入只包括核心经营活动的收入（A、B产品销售）
- 其他业务收入包括非核心但日常的活动（出租设备）
- 出售固定资产属于资产处置，不是营业外收入
- 违约罚款属于营业外收入
- 毛利率只考虑主营业务收入和主营业务成本的比例
