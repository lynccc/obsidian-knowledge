# 36-固定资产核算

> 固定资产是企业长期使用的有形资产，包括房屋、设备、车辆等。掌握其取得、折旧和处置的核算是会计实务的核心内容。

## 概念说明

**固定资产**是指企业为生产商品、提供劳务、出租或经营管理而持有的，使用寿命超过一个会计年度的有形资产。

简单说：买了能用很久（超过一年）的东西，比如机器设备、办公电脑、厂房、汽车等。跟库存商品不同，固定资产不是为了卖的，而是为了"用"的。

## 核心要点

### 一、固定资产的取得

| 取得方式 | 入账价值 | 分录 |
|----------|----------|------|
| **外购** | 买价 + 运输费 + 安装费 + 相关税金（不含可抵扣增值税） | 借：固定资产，贷：银行存款 |
| **自建** | 建造过程中发生的一切合理支出 | 借：在建工程→固定资产，贷：银行存款等 |
| **投资者投入** | 合同或协议约定的价值（公允） | 借：固定资产，贷：实收资本 |

#### 外购固定资产分录

```
购入不需要安装的设备：
借：固定资产                    （买价+运费+保险等）
    应交税费——应交增值税（进项税额）
贷：银行存款

购入需要安装的设备：
借：在建工程                    （买价+运费+安装费等）
    应交税费——应交增值税（进项税额）
贷：银行存款

安装完毕：
借：固定资产
贷：在建工程
```

### 二、固定资产的折旧 ⭐⭐⭐

**折旧**是指固定资产在使用过程中，由于磨损和老化而逐渐转移到成本费用中的那部分价值。

#### 影响折旧的因素

| 因素 | 说明 |
|------|------|
| **原值** | 固定资产的入账成本 |
| **预计净残值** | 报废时预计能卖多少钱 |
| **预计使用寿命** | 预计能用多少年 |
| **折旧方法** | 用什么方法计算折旧 |

#### 四种折旧方法

##### 1. 年限平均法（直线法）

最简单、最常用的方法。每年折旧额相同。

```
年折旧额 = (原值 - 预计净残值) ÷ 预计使用寿命
月折旧额 = 年折旧额 ÷ 12
```

**特点：** 每年折旧额相同，简单易算。

##### 2. 工作量法

按实际工作量计提折旧。

```
单位工作量折旧额 = (原值 - 预计净残值) ÷ 预计总工作量
某期折旧额 = 单位工作量折旧额 × 该期实际工作量
```

**特点：** 使用多折旧多，使用少折旧少。适用于使用不均衡的资产（如运输车辆）。

##### 3. 双倍余额递减法

加速折旧法。前期折旧多，后期折旧少。

```
年折旧率 = 2 ÷ 预计使用寿命 × 100%
年折旧额 = 期初固定资产账面净值 × 年折旧率

最后两年改为直线法：
年折旧额 = (账面净值 - 预计净残值) ÷ 2
```

**特点：** 前期多后期少，体现[[15-会计基础概念与原则|谨慎性原则]]。最后两年要改为直线法。

##### 4. 年数总和法

也是加速折旧法。

```
年折旧率 = 尚可使用年限 ÷ 预计使用年限总和 × 100%
年折旧额 = (原值 - 预计净残值) × 年折旧率
```

**特点：** 也是前期多后期少，但折旧率逐年递减。

#### 折旧分录

```
借：管理费用          （管理部门使用的固定资产）
    制造费用          （生产车间使用的固定资产）
    销售费用          （销售部门使用的固定资产）
贷：累计折旧
```

> **注意：** "累计折旧"是固定资产的备抵科目，贷方表示增加。固定资产账面价值 = 原值 - 累计折旧。

#### 折旧注意事项

- **当月增加，当月不提；当月减少，当月照提**
- 已提足折旧的固定资产不再计提
- 提前报废的固定资产不再补提折旧
- 未使用的固定资产也要计提折旧（除房屋建筑物外）

### 三、固定资产的后续支出

| 类型 | 处理方式 |
|------|----------|
| **资本化支出**（延长使用寿命、提高产品质量等） | 计入固定资产成本 |
| **费用化支出**（日常维修保养） | 计入当期损益（管理费用等） |

### 四、固定资产的清查

| 情况 | 处理 |
|------|------|
| **盘盈** | 按重置成本入账，计入以前年度损益调整 |
| **盘亏** | 计入营业外支出 |

### 五、固定资产的减值

```
借：资产减值损失——固定资产减值损失
贷：固定资产减值准备
```

> **注意：** 固定资产减值准备一经计提，**不得转回**（与存货不同）。

### 六、固定资产的处置

处置固定资产通过"固定资产清理"科目核算：

```
1. 转入清理：
借：固定资产清理
    累计折旧
贷：固定资产

2. 支付清理费用：
借：固定资产清理
贷：银行存款

3. 收到处置价款：
借：银行存款
贷：固定资产清理

4. 结转清理净损益：
净收益：借：固定资产清理，贷：营业外收入
净损失：借：营业外支出，贷：固定资产清理
```

## 公式汇总

```
年限平均法：年折旧额 = (原值 - 净残值) ÷ 使用年限
工作量法：单位折旧额 = (原值 - 净残值) ÷ 总工作量
双倍余额递减法：年折旧率 = 2 ÷ 使用年限
年数总和法：年折旧率 = 尚可使用年限 ÷ 年限总和
固定资产账面价值 = 原值 - 累计折旧 - 减值准备
```

## 练习题

### 题目1（计算题）

**题目描述：** 企业购入设备一台，原值10万元，预计净残值5000元，预计使用5年。按年限平均法计算年折旧额。

**解答：**
```
年折旧额 = (100,000 - 5,000) ÷ 5 = 19,000元
```

**解析：** 年限平均法是最简单的折旧方法，每年折旧额相同。用原值减去净残值，再除以使用年限。

### 题目2（计算题）⭐⭐

**题目描述：** 企业购入设备一台，原值12万元，预计净残值2万元，预计使用5年。按双倍余额递减法计算各年折旧额。

**解答：**
```
年折旧率 = 2 ÷ 5 × 100% = 40%

第1年：12万 × 40% = 4.8万
第2年：(12-4.8)万 × 40% = 2.88万
第3年：(12-4.8-2.88)万 × 40% = 1.728万
第4年：(12-4.8-2.88-1.728-2)万 ÷ 2 = 0.296万
第5年：0.296万

注：最后两年改为直线法，用账面净值减去净残值后除以2。
```

**解析：** 双倍余额递减法前期折旧多，后期少。注意最后两年要改为直线法，且计算基数是账面净值（原值减去已提折旧），不是原值。

### 题目3（计算题）

**题目描述：** 企业购入设备一台，原值20万元，预计净残值2万元，预计使用4年。按年数总和法计算各年折旧额。

**解答：**
```
年限总和 = 1+2+3+4 = 10
应计折旧总额 = 20万 - 2万 = 18万

第1年：18万 × 4/10 = 7.2万
第2年：18万 × 3/10 = 5.4万
第3年：18万 × 2/10 = 3.6万
第4年：18万 × 1/10 = 1.8万
```

**解析：** 年数总和法的折旧率逐年递减。分子是"尚可使用年限"（第1年4年，第2年3年...），分母是"预计使用年限总和"（1+2+3+4=10）。

### 题目4（选择题）

**题目描述：** 下列各项中，应计提折旧的固定资产是（ ）。

A. 已提足折旧继续使用的固定资产  
B. 未使用的房屋  
C. 单独计价入账的土地  
D. 已报废的固定资产

**答案：B**

**解析：** 未使用的房屋建筑物也要计提折旧。已提足折旧的不再计提；单独计价入账的土地不计提折旧；已报废的固定资产不再计提。

### 题目5（判断题）

**题目描述：** 固定资产当月增加，当月开始计提折旧。（ ）

**答案：✗**

**解析：** 固定资产"当月增加，当月不提；当月减少，当月照提"。当月增加的固定资产从下月开始计提折旧。

### 题目6（分录题）

**题目描述：** 企业出售一台设备，原值50万元，已提折旧35万元，出售价款20万元已收存银行。写出相关分录。

**解答：**
```
转入清理：
借：固定资产清理    150,000
借：累计折旧        350,000
贷：固定资产        500,000

收到价款：
借：银行存款        200,000
贷：固定资产清理    200,000

结转净收益（200,000 - 150,000 = 50,000）：
借：固定资产清理     50,000
贷：营业外收入       50,000
```

**解析：** 固定资产清理的账面价值 = 原值50万 - 累计折旧35万 = 15万。售价20万 > 账面价值15万，产生净收益5万，计入营业外收入。

### 题目7（选择题）

**题目描述：** 下列关于固定资产减值准备的表述中，正确的是（ ）。

A. 减值准备可以转回  
B. 减值准备不得转回  
C. 减值准备只能在年末计提  
D. 减值准备不影响折旧

**答案：B**

**解析：** 固定资产减值准备一经计提，不得转回。这与存货跌价准备不同（存货可以转回）。计提减值后，应重新计算折旧。

### 题目8（综合题）

**题目描述：** 企业2023年初购入设备一台，原值30万元，预计净残值3万元，预计使用年限5年，采用年限平均法折旧。2025年末发现该设备发生减值，可收回金额为10万元。计算2025年末的账面价值和应计提的减值准备。

**解答：**
```
年折旧额 = (30万 - 3万) ÷ 5 = 5.4万
2023-2025年已提折旧 = 5.4万 × 3 = 16.2万
2025年末账面价值 = 30万 - 16.2万 = 13.8万

可收回金额 = 10万
应计提减值准备 = 13.8万 - 10万 = 3.8万

分录：
借：资产减值损失    38,000
贷：固定资产减值准备    38,000
```

**解析：** 先计算已提折旧，再算出账面价值。账面价值13.8万 > 可收回金额10万，差额3.8万应计提减值准备。减值后，以后各年折旧应按新的账面价值重新计算。
