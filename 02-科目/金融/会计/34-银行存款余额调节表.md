# 34-银行存款余额调节表

> 银行存款余额调节表用于核对企业银行存款日记账与银行对账单的差异，找出"未达账项"，确保账实相符。

## 概念说明

每个月末，企业银行存款日记账的余额和银行对账单的余额经常不一致。这不是记错了，而是因为有些业务企业记了但银行还没记，或者银行记了但企业还没记。这些差异叫做**未达账项**。

打个比方：你给朋友转了账，你手机上已经显示扣款了（企业已记），但朋友的银行App可能要过一会儿才显示到账（银行未记）。这就是"未达账项"。

## 核心要点

### 未达账项的四种类型

| 类型 | 含义 | 对余额的影响 |
|------|------|-------------|
| **企业已收，银行未收** | 企业已记增加，银行未记 | 企业账面 > 银行账面 |
| **企业已付，银行未付** | 企业已记减少，银行未记 | 企业账面 < 银行账面 |
| **银行已收，企业未收** | 银行已记增加，企业未记 | 银行账面 > 企业账面 |
| **银行已付，企业未付** | 银行已记减少，企业未记 | 银行账面 < 企业账面 |

### 调节表编制公式

```
企业银行存款日记账余额
+ 银行已收企业未收
- 银行已付企业未付
= 调节后的存款余额

银行对账单余额
+ 企业已收银行未收
- 企业已付银行未付
= 调节后的存款余额
```

> **两边调节后的余额必须相等！** 如果不等，说明计算有误。

### 重要提醒

- 调节表**不能**作为记账依据，只是核对工具
- 未达账项**不需要**编制会计分录
- 调节表只是验证双方记录是否正确，不改变账面余额
- 只有当未达账项实际到账后，才需要做账务处理

### 编制步骤

1. **逐笔核对**：将银行存款日记账与银行对账单逐笔勾对
2. **找出未达账项**：标记未勾对的项目
3. **分类整理**：将未达账项分为四种类型
4. **编制调节表**：按公式计算调节后余额
5. **验证平衡**：两边调节后余额应相等

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，属于未达账项的是（ ）。

A. 企业记账错误  
B. 银行记账错误  
C. 企业已收银行未收的款项  
D. 企业与银行都已记录的款项

**答案：C**

**解析：** 未达账项是指企业与银行之间，一方已登记入账而另一方尚未登记入账的款项。A和B是记账错误，不是未达账项。D双方都已记录，不存在差异。

### 题目2（判断题）

**题目描述：** 银行存款余额调节表可以作为调整银行存款账面余额的记账依据。（ ）

**答案：✗**

**解析：** 银行存款余额调节表只是核对工具，不能作为记账依据。调节表中的未达账项不需要编制会计分录，等到实际到账后才需要做账务处理。

### 题目3（计算题）⭐⭐

**题目描述：** 某企业2025年6月30日银行存款日记账余额为25万元，银行对账单余额为32万元。经核对发现以下未达账项：

1. 企业委托银行收款5万元，银行已收妥入账，企业尚未收到通知
2. 银行代扣企业水电费2万元，企业尚未入账
3. 企业送存转账支票3万元，银行尚未入账
4. 企业开出转账支票1万元，持票人尚未到银行办理转账

编制银行存款余额调节表。

**解答：**

```
银行存款余额调节表
2025年6月30日

项目                    金额（万元）

企业银行存款日记账余额：  25
加：银行已收企业未收      5（委托收款）
减：银行已付企业未付      2（代扣水电费）
调节后余额：              28

银行对账单余额：          32
加：企业已收银行未收      3（送存支票）
减：企业已付银行未付      1（开出支票）
调节后余额：              28
```

**验证：** 两边调节后余额均为28万元，调节表编制正确。

**解析：**
- 业务1：银行已收5万，企业未收 → 加到企业账面
- 业务2：银行已付2万，企业未付 → 从企业账面减去
- 业务3：企业已收3万，银行未收 → 加到银行账面
- 业务4：企业已付1万，银行未付 → 从银行账面减去

### 题目4（选择题）

**题目描述：** 企业送存银行的转账支票，银行尚未入账。该未达账项属于（ ）。

A. 企业已收，银行未收  
B. 企业已付，银行未付  
C. 银行已收，企业未收  
D. 银行已付，企业未付

**答案：A**

**解析：** 企业送存支票，企业已记银行存款增加（已收），但银行尚未入账（未收）。属于"企业已收，银行未收"。

### 题目5（判断题）

**题目描述：** 调节后的银行存款余额就是企业可以动用的银行存款实有数。（ ）

**答案：✓**

**解析：** 调节后的余额消除了未达账项的影响，反映了企业实际可以动用的银行存款金额。

### 题目6（计算题）

**题目描述：** 某企业银行存款日记账余额为18万元，银行对账单余额为22万元。经核对发现：银行代收货款4万元企业未入账，企业开出支票2万元银行未兑付。调节后余额是多少？

**解答：**
```
企业账面余额：    18万
加：银行已收      4万
减：银行已付      0万
调节后余额：      22万

银行对账单余额：  22万
加：企业已收      0万
减：企业已付      2万（开出支票未兑付，但企业已记减少？）

注意：题目中"企业开出支票2万元银行未兑付"
如果企业已记减少（已付），则：
调节后余额 = 22 - 2 = 20万 ≠ 22万，不平衡

如果企业未记减少，则不是未达账项而是企业漏记。

假设企业已记减少：
企业调节后 = 18 + 4 = 22万
银行调节后 = 22 - 2 = 20万
不平衡，说明还有其他未达账项或企业/银行有记账错误。
```

**解析：** 这道题故意设置了不平衡的情况，提醒大家：如果调节后余额不等，要检查是否有遗漏的未达账项或记账错误。

### 题目7（选择题）

**题目描述：** 银行代扣企业电话费，企业尚未收到通知。该未达账项的处理是（ ）。

A. 企业账面加该金额  
B. 企业账面减该金额  
C. 银行账面加该金额  
D. 不需要处理

**答案：B**

**解析：** 银行已扣款（已付），企业未入账（未付）。属于"银行已付，企业未付"，应从企业账面余额中减去。但注意：这只是调节表中的处理，不编制会计分录，等企业收到通知后再做账务处理。

### 题目8（综合题）

**题目描述：** 某企业2025年12月31日银行存款日记账余额为50万元，银行对账单余额为58万元。经逐笔核对发现：

（1）企业月末送存的转账支票8万元，银行尚未入账  
（2）企业月末开出的支票3万元，持票人尚未到银行办理  
（3）银行代收货款10万元，企业尚未收到通知  
（4）银行代扣水电费1万元，企业尚未入账  
（5）企业记账错误：将收到的货款6万元误记为0.6万元

编制调节表并指出应如何进行账务处理。

**解答：**

```
银行存款余额调节表
2025年12月31日

项目                        金额（万元）

企业银行存款日记账余额：      50
加：银行已收企业未收          10（代收货款）
减：银行已付企业未付          1（代扣水电费）
加：企业记账错误少记          5.4（6-0.6）
调节后余额：                  64.4

银行对账单余额：              58
加：企业已收银行未收          8（送存支票）
减：企业已付银行未付          3（开出支票）
调节后余额：                  63
```

**分析：** 调节后余额不等（64.4 ≠ 63），差异1.4万元。需要进一步检查是否有其他未达账项或错误。

**账务处理：**
- 业务（3）银行代收货款10万：等收到通知后做账
- 业务（4）银行代扣水电费1万：等收到通知后做账
- 业务（5）记账错误：应立即更正，补记5.4万元
```
借：银行存款    54,000
贷：应收账款    54,000
```
