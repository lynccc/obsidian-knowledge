# 37-无形资产

> 无形资产是没有实物形态但能为企业带来经济利益的长期资产，如专利权、商标权、土地使用权等。

## 概念说明

**无形资产**是指企业拥有或控制的没有实物形态的可辨认非货币性长期资产。

简单说：看不见摸不着，但确实值钱的东西。比如你买了一个专利，这个专利没有实体，但别人用了要付你钱，它就是无形资产。

### 常见无形资产

| 类型 | 说明 |
|------|------|
| **专利权** | 发明创造的专有权利 |
| **商标权** | 品牌标识的专有权利 |
| **著作权（版权）** | 文学、艺术、科学作品的权利 |
| **土地使用权** | 使用土地的权利 |
| **非专利技术（技术秘密）** | 未公开的技术知识 |
| **特许权（经营权）** | 特许经营的权利 |

> **注意：** 商誉不是无形资产（不可辨认）；自创品牌的支出不能确认为无形资产。

## 核心要点

### 一、无形资产的取得

| 取得方式 | 成本确定 | 分录 |
|----------|----------|------|
| **外购** | 购买价款 + 相关税费 + 直接归属于使该资产达到预定用途的其他支出 | 借：无形资产，贷：银行存款 |
| **自行研发** | 研究阶段费用化，开发阶段符合条件的资本化 | 见下文 |
| **投资者投入** | 合同或协议约定的价值 | 借：无形资产，贷：实收资本 |

#### 自行研发的特殊处理

```
研究阶段：全部费用化
借：研发支出——费用化支出
贷：银行存款等
期末：借：管理费用，贷：研发支出——费用化支出

开发阶段（符合资本化条件）：
借：研发支出——资本化支出
贷：银行存款等
研发完成：
借：无形资产
贷：研发支出——资本化支出
```

### 二、无形资产的摊销

无形资产的使用寿命有限的，应当在其使用寿命内系统合理摊销。

#### 摊销方法

一般采用**直线法**（年限平均法）：

```
年摊销额 = (原值 - 预计净残值) ÷ 预计使用寿命
月摊销额 = 年摊销额 ÷ 12
```

#### 摊销分录

```
借：管理费用          （管理用无形资产）
    制造费用          （生产用无形资产）
    其他业务成本      （出租的无形资产）
贷：累计摊销
```

#### 摊销注意事项

- **使用寿命有限**的无形资产：需要摊销
- **使用寿命不确定**的无形资产：不摊销，但每年要进行减值测试
- 当月增加的无形资产，当月开始摊销（与固定资产不同！）
- 当月减少的无形资产，当月不再摊销

### 三、无形资产的减值

```
借：资产减值损失
贷：无形资产减值准备
```

> 无形资产减值准备一经计提，**不得转回**（与固定资产相同）。

### 四、无形资产的处置

#### 出售

```
借：银行存款
    累计摊销
    无形资产减值准备
贷：无形资产
    应交税费——应交增值税（销项税额）
    资产处置损益（差额，或借方）
```

#### 报废

```
借：营业外支出
    累计摊销
    无形资产减值准备
贷：无形资产
```

## 无形资产 vs 固定资产

| 对比项 | 无形资产 | 固定资产 |
|--------|----------|----------|
| 实物形态 | 没有 | 有 |
| 摊销/折旧 | 摊销 | 折旧 |
| 备抵科目 | 累计摊销 | 累计折旧 |
| 增加当月 | 当月开始摊销 | 下月开始计提折旧 |
| 减值转回 | 不得转回 | 不得转回 |

## 练习题

### 题目1（选择题）

**题目描述：** 下列各项中，属于无形资产的是（ ）。

A. 应收账款  
B. 专利权  
C. 存货  
D. 商誉

**答案：B**

**解析：** 专利权没有实物形态、可辨认、属于非货币性长期资产，符合无形资产定义。应收账款是流动资产，存货是有形资产，商誉不可辨认（不确认为无形资产）。

### 题目2（判断题）

**题目描述：** 企业自创的品牌可以确认为无形资产。（ ）

**答案：✗**

**解析：** 自创品牌的支出不能确认为无形资产，因为其成本不能可靠计量。只有外购的品牌才能确认为无形资产。

### 题目3（选择题）

**题目描述：** 无形资产的摊销方法一般采用（ ）。

A. 双倍余额递减法  
B. 年数总和法  
C. 直线法  
D. 工作量法

**答案：C**

**解析：** 无形资产一般采用直线法摊销，方法简单且能合理反映其价值消耗。

### 题目4（判断题）

**题目描述：** 无形资产当月增加，当月开始摊销。（ ）

**答案：✓**

**解析：** 无形资产"当月增加，当月摊销"，与固定资产"当月增加，下月折旧"不同。这是考试易混淆点。

### 题目5（选择题）

**题目描述：** 企业自行研发无形资产，研究阶段的支出应（ ）。

A. 全部资本化  
B. 全部费用化  
C. 符合条件的资本化  
D. 不做处理

**答案：B**

**解析：** 研究阶段的支出全部费用化，计入当期管理费用。开发阶段符合资本化条件的支出才能资本化，确认为无形资产。

### 题目6（分录题）

**题目描述：** 企业购入一项专利权，支付价款20万元，预计使用10年，无净残值。写出购入和每月摊销的分录。

**解答：**
```
购入时：
借：无形资产——专利权    200,000
贷：银行存款            200,000

每月摊销（20万÷10年÷12月 = 1,667元）：
借：管理费用    1,667
贷：累计摊销    1,667
```

**解析：** 专利权是管理用无形资产，摊销计入管理费用。每月摊销额 = 20万 ÷ 10 ÷ 12 ≈ 1,667元。

### 题目7（选择题）

**题目描述：** 使用寿命不确定的无形资产，应当（ ）。

A. 按10年摊销  
B. 不摊销，每年进行减值测试  
C. 一次性计入费用  
D. 不做处理

**答案：B**

**解析：** 使用寿命不确定的无形资产不摊销，但每年至少进行一次减值测试。如果有减值迹象，应计提减值准备。

### 题目8（综合题）

**题目描述：** 企业购入一项商标权，原值60万元，预计使用10年，无净残值。使用3年后，该商标权发生减值，可收回金额为35万元。计算减值前账面价值和应计提的减值准备。

**解答：**
```
年摊销额 = 60万 ÷ 10 = 6万
3年累计摊销 = 6万 × 3 = 18万
减值前账面价值 = 60万 - 18万 = 42万

可收回金额 = 35万
应计提减值准备 = 42万 - 35万 = 7万

分录：
借：资产减值损失    70,000
贷：无形资产减值准备    70,000
```

**解析：** 先计算累计摊销，得出账面价值42万。账面价值42万 > 可收回金额35万，差额7万计提减值准备。减值后，剩余7年应按新的账面价值35万重新计算摊销额。
