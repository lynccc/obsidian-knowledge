# 16-权责发生制与收付实现制

## 概念说明

权责发生制和收付实现制是两种不同的会计确认基础，核心区别在于：**什么时候确认收入和费用？**

- **权责发生制**：看交易发生的时间。发生了就确认，不管钱有没有收到。
- **收付实现制**：看现金收付的时间。收到钱才确认收入，付出钱才确认费用。

## 核心要点

### 两种制度对比

| 对比项目 | 权责发生制 | 收付实现制 |
|----------|-----------|-----------|
| 确认标准 | 交易发生时间 | 现金收付时间 |
| 收入确认 | 商品发出/服务提供时 | 收到现金时 |
| 费用确认 | 费用发生时 | 支付现金时 |
| 适用范围 | 企业会计 | 行政事业单位（部分） |
| 配比原则 | 遵循 | 不遵循 |

### 核心区别举例

| 业务 | 权责发生制 | 收付实现制 |
|------|-----------|-----------|
| 12月销售，次年1月收款 | 12月确认收入 | 次年1月确认收入 |
| 1月预付全年房租 | 每月确认1/12费用 | 1月全额确认费用 |
| 12月发生水电费，次年1月付款 | 12月确认费用 | 次年1月确认费用 |

### 预收/预付款项的处理差异

#### 预收款（先收钱，后交货）

| 时点 | 权责发生制 | 收付实现制 |
|------|-----------|-----------|
| 收到预收款 | 不确认收入（负债增加） | 确认收入 |
| 交货时 | 确认收入 | 不确认收入 |

#### 预付款（先付钱，后享受服务）

| 时点 | 权责发生制 | 收付实现制 |
|------|-----------|-----------|
| 支付预付款 | 不确认费用（资产增加） | 确认费用 |
| 享受服务时 | 确认费用 | 不确认费用 |

### 利润差异分析

两种制度下计算的利润通常不同：

- **权责发生制利润**：更能反映企业真实的经营成果
- **收付实现制利润**：只反映现金收支，不能反映真实的盈利能力

## 公式/分录模板

### 权责发生制下的收入确认

```
销售商品（赊销）：
借：应收账款        （售价）
贷：主营业务收入    （售价）

收到货款：
借：银行存款        （售价）
贷：应收账款        （售价）
```

### 收付实现制下的收入确认

```
收到货款时才确认：
借：银行存款        （售价）
贷：主营业务收入    （售价）
```

## 练习题

### 题目0（串讲经典计算题）⭐⭐⭐

**题目描述：** 某企业本月发生以下经济业务，分别按权责发生制和收付实现制计算收入、费用和利润：

| 序号 | 业务内容 | 金额 | 收付款情况 |
|------|---------|------|----------|
| 1 | 销售商品A | 860,000 | 已收款560,000 |
| 2 | 提供劳务 | 9,800 | 已收款10,600（含预收） |
| 3 | 销售商品B | 186,000 | 已收款230,000（含预收） |
| 4 | 购买原材料 | 473,000 | 已付款473,000 |
| 5 | 支付水电费 | 10,380 | 已付款10,380 |
| 6 | 计提折旧 | 10,000 | 未付款 |
| 7 | 预付下季度租金 | 100,000 | 已付款100,000，本月应负担0 |
| 8 | 计提本月工资 | 15,000 | 未付款 |
| 9 | 支付上月工资 | 24,000 | 已付款24,000 |
| 10 | 支付办公费 | 5,400 | 已付款5,400 |

**解答：**

#### 权责发生制

**收入：**
| 项目 | 金额 | 说明 |
|------|------|------|
| 销售商品A | 860,000 | 商品已发出，确认全部收入（不管收到多少） |
| 提供劳务 | 9,800 | 服务已提供，确认全部收入 |
| 销售商品B | 186,000 | 商品已发出，确认全部收入 |
| **收入合计** | **1,055,800** | |

**费用：**
| 项目 | 金额 | 说明 |
|------|------|------|
| 购买原材料 | 473,000 | 材料已入库，确认成本 |
| 支付水电费 | 10,380 | 本月费用，确认 |
| 计提折旧 | 10,000 | 本月费用，确认（虽未付款但已发生） |
| 预付租金 | 0 | 本月不负担，全部作为待摊费用 |
| 计提本月工资 | 15,000 | 本月费用，确认（虽未付款但已发生） |
| 支付上月工资 | 0 | 上月费用已在上月确认 |
| 支付办公费 | 5,400 | 本月费用，确认 |
| **费用合计** | **513,780** | |

**利润 = 1,055,800 - 513,780 = 542,020**

---

#### 收付实现制

**收入：**
| 项目 | 金额 | 说明 |
|------|------|------|
| 收到商品A货款 | 560,000 | 实际收到的钱 |
| 收到劳务款 | 10,600 | 实际收到的钱（含预收部分也确认） |
| 收到商品B货款 | 230,000 | 实际收到的钱（含预收部分也确认） |
| **收入合计** | **800,600** | |

**费用：**
| 项目 | 金额 | 说明 |
|------|------|------|
| 购买原材料 | 473,000 | 实际支付的钱 |
| 支付水电费 | 10,380 | 实际支付的钱 |
| 计提折旧 | 0 | 未付款，不确认 |
| 预付租金 | 100,000 | 实际支付的钱，全额确认 |
| 计提本月工资 | 0 | 未付款，不确认 |
| 支付上月工资 | 24,000 | 实际支付的钱 |
| 支付办公费 | 5,400 | 实际支付的钱 |
| **费用合计** | **612,780** | |

**利润 = 800,600 - 612,780 = 187,820**

---

#### 差异分析

| 项目 | 权责发生制 | 收付实现制 | 差异原因 |
|------|-----------|-----------|----------|
| 收入 | 1,055,800 | 800,600 | 赊销部分255,200未收款 |
| 费用 | 513,780 | 612,780 | 预付租金100,000和上月工资24,000在收付制下确认 |
| 利润 | 542,020 | 187,820 | **差异354,200** |

**核心差异：**
- 赊销收入860,000只收到560,000，差额300,000权责制确认、收付制不确认
- 预收款项（劳务和商品B多收的部分）收付制确认、权责制不确认
- 预付租金100,000收付制全额确认费用、权责制本月不确认
- 计提折旧10,000和工资15,000权责制确认、收付制不确认
- 支付上月工资24,000收付制确认、权责制不确认

**结论：** 权责发生制更能反映企业真实的经营成果，收付实现制只反映现金收支。本例中权责发生制利润（542,020）远高于收付实现制利润（187,820），说明企业有大量赊销收入尚未收款。

### 题目1（选择题）

**题目描述：** 企业12月20日销售商品一批，售价10万元，商品已发出，货款于次年1月15日收到。按照权责发生制，该笔收入应确认在（ ）。

A. 12月  
B. 次年1月  
C. 12月和次年1月各确认一半  
D. 收到货款时确认

**答案：A**

**解析：** 权责发生制以交易发生时间为准。12月20日商品已发出，销售行为已完成，应在12月确认收入，不管货款是否收到。如果按收付实现制，则在次年1月收到货款时才确认。

### 题目2（选择题）

**题目描述：** 企业1月初用银行存款支付全年房租12万元。按照权责发生制，1月应确认的费用为（ ）。

A. 12万元  
B. 1万元  
C. 0元  
D. 6万元

**答案：B**

**解析：** 权责发生制下，费用应按归属期间确认。12万元是全年房租，每月应负担1万元（12万÷12个月）。1月确认1万元费用，剩余11万元作为待摊费用（资产）。如果按收付实现制，1月确认12万元费用。

### 题目3（判断题）

**题目描述：** 权责发生制和收付实现制下，企业的利润总额一定相同。（ ）

**答案：✗（错误）**

**解析：** 两种制度下的利润通常不同。权责发生制按交易发生时间确认收入费用，收付实现制按现金收付时间确认。当存在赊销、预收、预付、待摊、预提等业务时，两种制度下的利润会产生差异。

### 题目4（选择题）

**题目描述：** 某企业本月发生以下业务，分别按权责发生制和收付实现制计算利润：

（1）销售商品售价5万元，已收款3万元  
（2）发生办公费8000元，已付6000元  
（3）预收货款2万元，商品尚未发出  

权责发生制下的收入为（ ）。

A. 5万元  
B. 7万元  
C. 8万元  
D. 3万元

**答案：A**

**解析：** 权责发生制下：（1）商品已发出，确认收入5万元（不管收到多少）；（2）费用已发生，确认费用8000元（不管付了多少）；（3）商品未发出，预收款不确认收入（作为负债）。收入 = 5万元。收付实现制下：收入 = 3万 + 2万 = 5万元。

### 题目5（综合计算题）

**题目描述：** 某企业本月发生以下业务：

| 业务 | 金额 | 收付款情况 |
|------|------|-----------|
| 销售商品 | 80万 | 已收60万 |
| 购买商品 | 50万 | 已付40万 |
| 发生工资 | 15万 | 已付15万 |
| 预收货款 | 10万 | 已收，未交货 |
| 预付租金 | 6万 | 已付，本月应负担2万 |

分别按权责发生制和收付实现制计算本月收入、费用和利润。

**解答：**
```
权责发生制：
收入 = 80万（预收的10万不确认收入）
费用 = 50万 + 15万 + 2万 = 67万（租金只确认本月的2万）
利润 = 80万 - 67万 = 13万

收付实现制：
收入 = 60万 + 10万 = 70万（预收款确认为收入）
费用 = 40万 + 15万 + 6万 = 61万（租金全额确认费用）
利润 = 70万 - 61万 = 9万
```

**解析：** 权责发生制与收付实现制的核心差异：（1）赊销的20万：权责发生制确认，收付实现制不确认；（2）预收的10万：权责发生制不确认，收付实现制确认；（3）赊购的10万：权责发生制确认，收付实现制不确认；（4）预付租金：权责发生制只确认2万，收付实现制确认6万。两种制度下的利润差异为4万元（13万-9万）。

### 题目6（选择题）

**题目描述：** 下列各项中，按照权责发生制应确认为本月收入的是（ ）。

A. 本月预收客户货款5万元，商品下月发出  
B. 本月销售商品3万元，货款下月收到  
C. 本月收到上月销售货款2万元  
D. 本月收到投资款10万元

**答案：B**

**解析：** A：商品未发出，不确认收入（预收款作为负债）。B：商品已发出，应确认收入（权责发生制看交易时间）。C：上月销售的收入已在上月确认，本月收款不确认收入。D：投资款是所有者投入，不是收入。

### 题目7（判断题）

**题目描述：** 预收客户的货款，在权责发生制下应确认为收入。（ ）

**答案：✗（错误）**

**解析：** 权责发生制下，收入在商品发出或服务提供时确认，不是在收到货款时确认。预收货款时，商品尚未发出，不应确认收入，而应确认为负债（预收账款）。待商品发出时，再从预收账款转入主营业务收入。
