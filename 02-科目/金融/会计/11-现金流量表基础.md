# 11-现金流量表基础

## 概念说明

现金流量表反映企业在一定期间内**现金的流入和流出**情况。它回答一个问题：**企业的钱从哪来、花到哪去了？**

现金流量表把所有现金流分成三大类：
1. **经营活动**：日常买卖商品、支付费用等
2. **投资活动**：买设备、卖资产等
3. **筹资活动**：借款、还款、分红等

## 核心要点

### 三大分类

| 分类 | 现金流入 | 现金流出 |
|------|----------|----------|
| 经营活动 | 销售商品收到现金 | 购买商品支付现金、支付职工、支付其他费用 |
| 投资活动 | 处置资产收到现金 | 购建固定资产支付现金 |
| 筹资活动 | 取得借款收到现金 | 偿还借款、支付利息、分配股利 |

### 关键公式

$$经营活动净额 = 经营活动现金流入 - 经营活动现金流出$$

$$投资活动净额 = 投资活动现金流入 - 投资活动现金流出$$

$$筹资活动净额 = 筹资活动现金流入 - 筹资活动现金流出$$

$$现金净增加 = 经营活动净额 + 投资活动净额 + 筹资活动净额$$

### 应收账款与现金收入的关系

$$期初应收账款 + 本期收入 - 本期收款 = 期末应收账款$$

变形得：

$$本期收款 = 期初应收账款 + 本期收入 - 期末应收账款$$

## 练习题

### 题目1

**题目描述：** 某企业本期经营活动现金流入100万元（销售商品收到），经营活动现金流出70万元（其中购买商品支付50万，支付职工15万，支付其他费用5万）。计算经营活动现金流量净额。

**解答：**
```
经营活动现金流量净额 = 100万 - 70万 = 30万元
```

**解析：** 经营活动现金流量净额 = 流入 - 流出。正值表示经营活动产生了现金净流入，说明企业日常经营能自己"造血"。

### 题目2

**题目描述：** 某企业本期数据：销售商品收到现金80万，购买商品支付现金45万，支付职工工资12万，购买设备支付现金30万，取得银行借款50万，偿还借款本金20万，支付借款利息3万，分配股利5万。编制现金流量表。

**解答：**
```
一、经营活动
  销售商品收到现金：        80万
  购买商品支付现金：        -45万
  支付职工工资：            -12万
  经营活动现金流量净额：    23万

二、投资活动
  购建固定资产支付现金：    -30万
  投资活动现金流量净额：    -30万

三、筹资活动
  取得借款收到现金：        50万
  偿还借款支付现金：        -20万
  支付利息：                -3万
  分配股利支付现金：        -5万
  筹资活动现金流量净额：    22万

现金净增加额 = 23 + (-30) + 22 = 15万
```

**解析：** 按照三大分类分别计算。经营活动是日常买卖，投资活动是购买设备，筹资活动是借款和分红。现金净增加额15万为正，说明企业现金增加了。

### 题目3

**题目描述：** 某企业期初应收账款10万元，本期销售收入50万元（全部赊销），期末应收账款15万元。计算本期实际收到多少现金？

**解答：**
```
本期收款 = 期初应收账款 + 本期收入 - 期末应收账款
        = 10万 + 50万 - 15万 = 45万元
```

**解析：** 应收账款的变动反映了赊销和收款的关系。期初有10万未收，本期又赊销了50万，期末还有15万未收，说明本期实际收到了45万现金。这是经营活动现金流中"销售商品收到现金"的重要计算方法。

### 题目4

**题目描述：** 某企业期初应收账款20万元，本期销售收入80万元，期末应收账款12万元。同时期初应付账款15万元，本期采购额60万元，期末应付账款25万元。计算：（1）销售收现；（2）采购付现。

**解答：**
```
（1）销售收现 = 20万 + 80万 - 12万 = 88万
（2）采购付现 = 15万 + 60万 - 25万 = 50万
```

**解析：** 
- 销售收现：期初应收20万 + 本期销售80万 - 期末应收12万 = 88万，说明比销售收入80万还多收了8万（收回了以前的欠款）
- 采购付现：期初应付15万 + 本期采购60万 - 期末应付25万 = 50万，说明比采购额60万少付了10万（还欠着供应商10万）

### 题目5

**题目描述：** 某企业期初现金余额50万元，本期经营活动现金净额40万元，投资活动现金净额-25万元，筹资活动现金净额-10万元。计算期末现金余额。

**解答：**
```
现金净增加额 = 40万 + (-25万) + (-10万) = 5万
期末现金余额 = 期初现金余额 + 现金净增加额
            = 50万 + 5万 = 55万元
```

**解析：** 现金净增加额是三大活动净额的合计。经营活动产生40万现金，但投资活动花了25万，筹资活动花了10万，最终现金只增加了5万。期末现金 = 期初 + 本期增加。

### 题目6

**题目描述：** 某企业经营活动现金净额为-10万元，投资活动现金净额为-50万元，筹资活动现金净额为80万元。分析该企业的现金流状况。

**解答：**
```
现金净增加额 = -10 + (-50) + 80 = 20万

分析：
- 经营活动为负，说明日常经营不能产生足够的现金，可能处于扩张期或经营困难
- 投资活动为负，说明企业在大量购买资产，可能是扩张期
- 筹资活动为正，说明企业通过借款或融资获得现金
```

**解析：** 这种现金流模式常见于快速扩张的企业：经营还没产生足够现金，大量投资购买资产，靠借款或融资来支撑。如果长期如此，企业可能面临资金链风险。健康的现金流应该是经营活动为正。
