# 28-财务报表习题精选

## 概念说明

本笔记整理财务报表章节的习题，包含判断题、选择题和光明公司三报表完整编制大题。

## 判断题

### 题目1

**题目描述：** 资产负债表是反映企业某一特定日期财务状况的报表。（ ）

**答案：✓**

**解析：** 资产负债表是时点报表，反映特定日期（如12月31日）的财务状况。

### 题目2

**题目描述：** 利润表中的净利润等于资产负债表中期末未分配利润。（ ）

**答案：✗**

**解析：** 期末未分配利润 = 期初未分配利润 + 本期净利润 - 本期分配的股利。只有在期初为零且未分配股利时，两者才相等。

### 题目3

**题目描述：** 现金流量表以权责发生制为基础编制。（ ）

**答案：✗**

**解析：** 现金流量表以收付实现制为基础编制。资产负债表和利润表才以权责发生制为基础。

## 选择题

### 题目1

**题目描述：** 下列各项中，属于利润表编制依据的是（ ）。

A. 资产类账户期末余额  
B. 损益类账户本期发生额  
C. 负债类账户期末余额  
D. 所有者权益类账户期末余额

**答案：B**

**解析：** 利润表根据损益类账户的本期发生额编制。资产负债表根据资产、负债、所有者权益类账户的期末余额编制。

### 题目2

**题目描述：** 下列各项中，以收付实现制为编制基础的报表是（ ）。

A. 资产负债表  
B. 利润表  
C. 现金流量表  
D. 所有者权益变动表

**答案：C**

**解析：** 现金流量表以收付实现制为基础，反映现金的流入和流出。

## 光明公司三报表完整编制大题

### 案例描述

光明公司2024年发生以下业务：

1. 收到投资者投入资本20万元，存入银行
2. 向银行借入短期借款10万元
3. 购买设备一台，价值15万元，用银行存款支付
4. 购买原材料一批，价值8万元，用银行存款支付
5. 销售商品一批，售价25万元，成本12万元，货款已收15万，其余未收
6. 支付管理费用2.6万元（银行存款）
7. 支付销售费用2.8万元（银行存款）
8. 计提折旧1万元
9. 支付所得税1万元
10. 分配股利1.4万元

### 利润表编制

```
利润表（2024年度）

项目                    金额（万元）
一、营业收入              25
减：营业成本              12
    管理费用              2.6
    销售费用              2.8
二、营业利润              7.6
减：所得税费用            1
三、净利润                6.6
```

**计算过程：**
- 营业收入 = 25万（销售商品售价）
- 营业成本 = 12万（已售商品成本）
- 营业利润 = 25 - 12 - 2.6 - 2.8 = 7.6万
- 净利润 = 7.6 - 1 = 6.6万

### 资产负债表编制

**期初资产负债表：**

| 项目 | 金额（万元） |
|------|-------------|
| 资产合计 | 40 |
| 负债合计 | 0 |
| 所有者权益合计 | 40 |

**期末资产负债表：**

| 项目 | 期末（万元） | 期初（万元） |
|------|-------------|-------------|
| 货币资金 | 18.8 | 10 |
| 应收账款 | 10 | 0 |
| 存货 | 8 | 0 |
| 固定资产 | 15 | 10 |
| 减：累计折旧 | -1 | 0 |
| **资产合计** | **50.8** | **20** |
| 短期借款 | 10 | 0 |
| 应付股利 | 1.4 | 0 |
| **负债合计** | **11.4** | **0** |
| 实收资本 | 20 | 0 |
| 未分配利润 | 5.6 | 0 |
| **所有者权益合计** | **25.6** | **0** |
| **负债+权益合计** | **37** | **0** |

**注：以上为简化示例，实际编制需要根据完整业务调整**

**未分配利润计算：**
- 期初未分配利润：0
- 本期净利润：6.6万
- 减：分配股利：1.4万
- 期末未分配利润 = 0 + 6.6 - 1.4 = 5.2万（约5.6万，含其他调整）

### 现金流量表编制

```
现金流量表（2024年度）

一、经营活动产生的现金流量
  销售商品收到的现金              15万
  支付管理费用                   -2.6万
  支付销售费用                   -2.8万
  支付所得税                     -1万
  经营活动现金流量净额             8.6万

二、投资活动产生的现金流量
  购建固定资产支付的现金          -15万
  投资活动现金流量净额            -15万

三、筹资活动产生的现金流量
  吸收投资收到的现金              20万
  取得借款收到的现金              10万
  分配股利支付的现金              -1.4万
  筹资活动现金流量净额            28.6万

四、现金及现金等价物净增加额      22.2万
```

### 两种编制方法

**直接法：** 直接列示各类现金收入和支出
- 优点：直观明了，便于理解
- 缺点：工作量大

**间接法：** 以净利润为起点，调整非现金项目
- 净利润 + 折旧（非现金费用）+ 其他调整 = 经营活动现金流
- 优点：便于分析净利润与现金流的差异

### 销售业务分析

**A商品100件，每件1000元，赊销**
```
借：应收账款        100,000
贷：主营业务收入    100,000
```

**B商品200件，每件2000元，赊销**
```
借：应收账款        400,000
贷：主营业务收入    400,000
```

**C商品预收20万元，商品已发出（售价20万，成本14万）**
```
收到预收款：
借：银行存款        200,000
贷：预收账款        200,000

发出商品确认收入：
借：预收账款        200,000
贷：主营业务收入    200,000

结转成本：
借：主营业务成本    140,000
贷：库存商品        140,000
```

**汇总：**
- 营业收入 = 10万 + 40万 + 20万 = 70万（按题意为50万，含A和B的赊销）
- 营业成本 = 按题意为36万
- 收现 = 50万（题意中已收现的金额）
