# 操作风险与韧性

> ⚠️ **来源说明：** 以下内容基于通用操作风险管理理论整理，非特指某版 FRM 教材。待主人提供教材后补充具体例题。

## 操作风险定义

操作风险是指由**不完善或失效的内部流程、人员、系统或外部事件**导致损失的风险。

**排除：** 信用风险、市场风险、战略风险、声誉风险

## 操作风险分类

### Basel 事件类型

| 类型 | 示例 |
|------|------|
| 内部欺诈 | 交易员违规操作、贪污 |
| 外部欺诈 | 网络攻击、抢劫 |
| 就业实践和工作场所安全 | 歧视诉讼、工伤 |
| 客户、产品和业务操作 | 不当销售、洗钱 |
| 实物资产损坏 | 地震、火灾 |
| 业务中断和系统故障 | IT 系统宕机 |
| 执行、交割和流程管理 | 数据录入错误、结算失败 |

## 操作风险度量

### 基本指标法（BIA）
$$资本要求 = 总收入 × 15\%$$

### 标准化方法（TSA）
按业务线分别计算，各业务线资本 = 收入 × 对应系数

### 高级计量法（AMA）
- 内部损失数据 + 外部损失数据 + 情景分析 + 业务环境和控制因素
- 使用损失分布法（LDA）估计操作风险 VaR

## 关键风险管理框架

### 三道防线模型

| 防线 | 职责 |
|------|------|
| 第一道 | 业务部门（日常风险管理） |
| 第二道 | 风险管理/合规部门（制定政策、监督） |
| 第三道 | 内部审计（独立评估） |

### 关键风险指标（KRI）
- 预警指标，监控潜在操作风险
- 示例：IT 系统故障次数、员工离职率、未完成交易数

### 损失数据收集
- 内部损失数据（Internal Loss Data）
- 外部损失数据（External Data）
- 情景分析（Scenario Analysis）

## 模型风险

- 模型本身存在缺陷或被误用的风险
- **模型验证**：独立团队对模型进行检验
- **模型风险管理**：模型清单、定期审查、压力测试

## 网络安全风险

- 网络攻击类型：DDoS、钓鱼、勒索软件、数据泄露
- 风险管理：预防、检测、响应、恢复
- 合规要求：GDPR、网络安全法
