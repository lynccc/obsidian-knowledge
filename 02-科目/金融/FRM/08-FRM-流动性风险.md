# 流动性与资金风险

> ⚠️ **来源说明：** 以下内容基于通用流动性风险理论整理，非特指某版 FRM 教材。待主人提供教材后补充具体例题。

## 流动性风险类型

### 1. 融资流动性风险（Funding Liquidity Risk）
- 机构无法及时获得足够资金满足支付义务
- 来源：存款挤兑、信贷额度冻结、债务到期无法续借

### 2. 市场流动性风险（Market Liquidity Risk）
- 无法在不显著影响价格的情况下快速买卖资产
- 来源：市场深度不足、交易量低、市场恐慌

## 流动性风险度量

### 融资流动性指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 现金比率 | 现金 / 流动负债 | 最保守的流动性指标 |
| 流动比率 | 流动资产 / 流动负债 | 短期偿债能力 |
| 速动比率 | (流动资产-存货) / 流动负债 | 扣除存货的流动性 |

### 市场流动性指标

| 指标 | 含义 |
|------|------|
| 买卖价差（Bid-Ask Spread） | 越窄流动性越好 |
| 市场深度 | 一定价格变动范围内的订单量 |
| 市场弹性 | 价格受冲击后恢复的速度 |
| 换手率 | 交易量 / 流通股本 |

## 流动性覆盖率（LCR）

$$LCR = \frac{高质量流动资产\ (HQLA)}{未来30天净现金流出} \geq 100\%$$

- **HQLA**：一级资产（现金、国债）+ 二级资产（公司债、股票）
- 未来 30 天压力情景下的资金需求

## 净稳定资金比率（NSFR）

$$NSFR = \frac{可用稳定资金\ (ASF)}{所需稳定资金\ (RSF)} \geq 100\%$$

- 衡量中长期（1年）的流动性状况
- 鼓励银行使用更稳定的资金来源

## 流动性风险管理策略

### 日内流动性管理
- 监控日内现金流
- 确保有足够的日内流动性缓冲

### 应急资金计划（Contingency Funding Plan, CFP）
- 识别潜在流动性压力情景
- 预设应急融资渠道
- 定期演练

### 流动性缓冲
- 持有高质量流动资产
- 保持未使用的信贷额度
- 多元化融资来源
