# 信用风险度量与管理

> ⚠️ **来源说明：** 以下内容基于通用信用风险理论整理，非特指某版 FRM 教材。待主人提供教材后补充具体例题。

## 信用风险的核心要素

| 要素 | 说明 |
|------|------|
| PD (Probability of Default) | 违约概率 |
| LGD (Loss Given Default) | 违约损失率 = 1 - 回收率 |
| EAD (Exposure at Default) | 违约时的风险敞口 |

$$预期损失\ (EL) = PD \times LGD \times EAD$$

## 信用评级

### 外部评级

| 评级 | 含义 |
|------|------|
| AAA / Aaa | 最高信用质量 |
| AA / Aa | 高信用质量 |
| A | 中上信用质量 |
| BBB / Baa | 中等信用质量（投资级最低） |
| BB / Ba 及以下 | 投机级（高收益 / 垃圾债） |

### 评级迁移矩阵

- 衡量信用评级在一定时期内的变化概率
- 用于估计信用风险的动态变化

## 信用风险模型

### 1. Merton 模型（结构化模型）

- 将公司股权视为**看涨期权**
- 标的 = 公司资产，行权价 = 债务面值
- 当公司资产价值 < 债务面值时，公司违约
- 违约距离（Distance to Default）：

$$DD = \frac{\ln(V/D) + (\mu - \sigma^2/2)T}{\sigma\sqrt{T}}$$

### 2. CreditMetrics（JP Morgan）

- 基于评级迁移矩阵
- 估计组合的信用风险 VaR
- 考虑违约和评级下降的损失

### 3. CreditRisk+（CSFB）

- 基于保险精算方法
- 假设违约事件服从泊松分布
- 只关注违约，不考虑评级迁移

## 信用衍生品

### 信用违约互换（CDS）

- 买方定期支付保费（CDS spread）
- 卖方在参考实体违约时赔偿损失
- 用于**转移**或**对冲**信用风险

### 担保债务凭证（CDO）

- 将一组资产（通常是债券或贷款）打包
- 分为不同**分层（Tranche）**：优先级、中间级、权益级
- 优先级最先获得偿付，最后承担损失

## 交易对手信用风险（CCR）

- 场外衍生品（OTC）的信用风险
- **CVA（Credit Valuation Adjustment）**：对交易对手违约风险的估值调整
- **DVA（Debit Valuation Adjustment）**：自身违约风险的估值调整
- **净额结算（Netting）**：降低信用风险敞口
