# 数量分析（Quantitative Analysis）

> ⚠️ **来源说明：** 以下内容基于通用统计学和概率论知识整理，非特指某版 FRM 教材。待主人提供教材后补充具体例题。

## 概率论基础

### 条件概率与贝叶斯定理

$$P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}$$

- P(A) = 先验概率
- P(A|B) = 后验概率
- 在风险管理中用于更新违约概率估计

### 常见概率分布

| 分布 | 应用场景 |
|------|---------|
| 正态分布 | 资产收益率建模（基础假设） |
| 对数正态分布 | 资产价格（保证非负） |
| t 分布 | 厚尾数据，小样本 |
| 泊松分布 | 违约事件计数 |
| 二项分布 | 成功/失败型事件 |

## 描述统计

### 中心趋势
- **均值（Mean）**：算术平均
- **中位数（Median）**：排序后中间值
- **众数（Mode）**：出现频率最高值

### 离散程度
- **方差（Variance）**：σ² = E[(X - μ)²]
- **标准差（Standard Deviation）**：σ
- **协方差（Covariance）**：Cov(X,Y) = E[(X-μx)(Y-μy)]
- **相关系数**：ρ = Cov(X,Y) / (σx × σy)

### 偏度与峰度
- **偏度（Skewness）**：衡量分布的不对称性
  - 正偏：右尾更长
  - 负偏：左尾更长
- **峰度（Kurtosis）**：衡量尾部厚度
  - 正态分布峰度 = 3
  - 超额峰度 = Kurtosis - 3
  - **尖峰厚尾**（Leptokurtic）：超额峰度 > 0

## 假设检验

### 步骤
1. 设定原假设 H₀ 和备择假设 H₁
2. 选择显著性水平 α（通常 5%）
3. 计算检验统计量
4. 比较 p 值与 α，或比较统计量与临界值

### 两类错误
| 错误类型 | 含义 | 概率 |
|---------|------|------|
| 第一类（α） | 拒绝真 H₀ | 显著性水平 |
| 第二类（β） | 未拒绝假 H₀ | — |

## 线性回归

### 简单线性回归

$$Y = \alpha + \beta X + \epsilon$$

- β = Cov(X,Y) / Var(X)
- α = Ȳ - βX̄
- R² = 回归平方和 / 总平方和

### 关键假设（OLS）
1. 线性关系
2. 误差项均值为零
3. 同方差性（Homoskedasticity）
4. 无自相关
5. 无多重共线性

### 违反假设的后果
- **异方差**：标准误估计错误 → 用 White 校正
- **自相关**：标准误低估 → 用 Newey-West 校正
- **多重共线性**：系数不稳定 → 去除相关变量

## 蒙特卡洛模拟

- 随机抽样生成大量情景
- 估计组合价值的分布
- 应用：VaR 计算、期权定价、风险度量
- **方差缩减技术**：对偶变量法、控制变量法
