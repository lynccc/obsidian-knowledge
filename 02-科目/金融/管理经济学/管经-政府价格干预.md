# 🏛️ 政府价格干预

> ⭐⭐ **高频考点** — 福利变化分析是考试重点

---

## 一、最高限价（Price Ceiling）

**政府规定价格不能高于某个上限**

### 什么时候有效？

只有当限价 **低于** 均衡价格时才有效！

```
限价 < P*  → 有效 → 产生短缺
限价 ≥ P*  → 无效 → 市场照常运行
```

### 后果

| 后果 | 说明 |
|------|------|
| 短缺 | 需求量 > 供给量 |
| 排队 | 价格低但买不到 |
| 黑市 | 地下高价交易 |
| 质量下降 | 企业没动力提高质量 |
| 社会福利减少 | 产生无谓损失 DWL |

### 例题

**题目：** QD = 32 - 4P，QS = -3 + P，政府规定最高价格 = 5

```
Step 1：原均衡
  QD = QS → 32 - 4P = -3 + P → P* = 7, Q* = 25

Step 2：限价后
  P = 5 < 7 → 限价有效
  QD = 32 - 4×5 = 12（想买 12）
  QS = -3 + 5 = 2（只供给 2）
  短缺 = 12 - 2 = 10

Step 3：福利变化
  CS：变化不确定（买到的人省钱了，但很多人买不到）
  PS：减少（价格低，销量低）
  DWL = 交易减少导致的福利损失

答：社会总福利减少
```

## 二、最低限价（Price Floor）

**政府规定价格不能低于某个下限**

### 什么时候有效？

只有当限价 **高于** 均衡价格时才有效！

```
限价 > P*  → 有效 → 产生过剩
限价 ≤ P*  → 无效 → 市场照常运行
```

### 典型例子：最低工资

- 最低工资 > 均衡工资 → 劳动力供给 > 需求 → 失业

## 三、价格支持（Price Support）

**政府规定最低价格，并收购过剩供给**

### 与最低限价的区别

| | 最低限价 | 价格支持 |
|--|---------|---------|
| 过剩处理 | 市场自行消化 | 政府收购 |
| 政府支出 | 无 | 有（收购费用） |
| 福利损失 | 较小 | 较大 |

### 例题（来自习题串讲）

**题目：** QD = 50 - 20P，QS = 20 + 10P，支持价格 = 1.5，政府收购过剩后销毁

```
Step 1：原均衡
  QD = QS → P* = 1, Q* = 30

Step 2：支持价格下
  P = 1.5 > 1 → 支持有效
  QD = 50 - 20×1.5 = 20
  QS = 20 + 10×1.5 = 35
  过剩 = 35 - 20 = 15

Step 3：各方福利变化
  CS 损失 = B + D
  PS 增加 = B + D + F
  政府损失 = (D + E + F + G) = 15 × 1.5 = 22.5

Step 4：社会总福利变化
  ΔTS = -(B+D) + (B+D+F) - (D+E+F+G) = -(D+E+G)
  D+E+G = 15×1.5 - 15×0.5/2 = 22.5 - 3.75 = 18.75

答：社会总福利损失 18.75
```

## 四、税收与补贴

### 税收

- 对商品征税 → 供给曲线左移（成本增加）
- 税收归宿：消费者和生产者共同承担
- 弹性小的一方承担更多

### 补贴

- 对商品补贴 → 供给曲线右移（成本降低）
- 补贴收益：消费者和生产者共同分享
- 弹性小的一方获得更多收益
