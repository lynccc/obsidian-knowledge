## 题目 1：垄断边际收益推导

**题目：** 垄断企业面临需求函数 Q = 20 - 2P，求边际收益 MR。

```
Step 1：改写为 P = f(Q) 形式
  Q = 20 - 2P
  2P = 20 - Q
  P = 10 - 0.5Q

Step 2：求 TR
  TR = P × Q = (10 - 0.5Q) × Q = 10Q - 0.5Q²

Step 3：求 MR
  MR = dTR/dQ = 10 - Q

答：MR = 10 - Q
```

**规律：** 线性需求 P = a - bQ → MR = a - 2bQ（斜率是需求曲线的 2 倍）

## 题目 2：垄断利润最大化

**题目：** MC = 2Q，P = 60 - 2Q，求利润最大化价格。

```
Step 1：求 MR
  TR = P × Q = (60 - 2Q) × Q = 60Q - 2Q²
  MR = 60 - 4Q

Step 2：令 MR = MC
  60 - 4Q = 2Q
  60 = 6Q
  Q* = 10

Step 3：求价格
  P = 60 - 2 × 10 = 40

答：利润最大化价格 = 40
```

## 题目 3：需求收入弹性

**题目：** 收入上升 25%，需求量上升 5%，求收入弹性。

```
EI = %ΔQ / %ΔI = 5% / 25% = 0.2

答：EI = 0.2（必需品，因为 0 < EI < 1）
```

## 题目 4：弹性与提价

**题目：** 需求价格弹性恒为 -1，现价 500，要减少一半消费，需提价多少？

```
Step 1：|E| = 1 → 单位弹性
  价格变 x%，需求变 -x%

Step 2：要减少一半消费 → ΔQ/Q = -50%
  因为 |E| = 1，所以 ΔP/P = +50%

Step 3：提价金额
  500 × 50% = 250 元

答：需提价 250 元（新价格 750 元）
```

## 题目 5：MR = 0 时的弹性

**题目：** 当边际收益为零时，需求价格弹性 = ？

```
MR = P × (1 + 1/Ed) = 0
→ 1 + 1/Ed = 0
→ Ed = -1

答：|E| = 1（单位弹性）
```

## 题目 6：劳动供给弹性

**题目：** 劳动供给对工资弹性 0.2，对保姆费弹性 -0.5。工资涨 5%，保姆费涨 5%，影响？

```
工资影响：0.2 × 5% = +1%（工作时间增加）
保姆费影响：-0.5 × 5% = -2.5%（工作时间减少）
总影响：+1% + (-2.5%) = -1.5%

答：工作时间减少约 1.5%
```

## 题目 7：垄断定价（停车场）

**题目：** MC ≈ 0，P = 20，Ed = -2，利用率 80%，如何利润最大化？

```
当前 |E| = 2 > 1 → 富有弹性
MR = P(1 + 1/Ed) = 20(1 - 0.5) = 10 > 0
MR > MC = 0 → 还可以降价增加利润

答：应该降价（吸引更多顾客，增加总收入）
```

## 题目 8：竞争市场生产者福利

**题目：** MC₁ = 3+2q₁, MC₂ = 4+q₂, MC₃ = 3+3q₃，P = 9，求总 PS。

```
Step 1：各企业产量（MC = P）
  q₁ = (9-3)/2 = 3
  q₂ = 9-4 = 5
  q₃ = (9-3)/3 = 2

Step 2：各企业 PS = P×q - ∫MC dq
  PS₁ = 9×3 - [3q+q²]₀³ = 27-18 = 9
  PS₂ = 9×5 - [4q+q²/2]₀⁵ = 45-32.5 = 12.5
  PS₃ = 9×2 - [3q+1.5q²]₀² = 18-12 = 6

Step 3：总和
  总 PS = 9 + 12.5 + 6 = 27.5

答：生产者福利总和 = 27.5
```

## 题目 9：最高限价

**题目：** QD = 32-4P，QS = -3+P，最高限价 = 5，社会总福利？

```
Step 1：原均衡
  QD = QS → P* = 7, Q* = 25

Step 2：限价后
  P = 5 < 7 → 有效
  QD = 12, QS = 2 → 短缺 10

Step 3：福利变化
  CS：变化不确定
  PS：减少
  DWL：交易量从 25 降到 2

答：社会总福利减少
```

## 题目 10：价格支持

**题目：** QD = 50-20P，QS = 20+10P，支持价 = 1.5，政府收购销毁，福利变化？

```
Step 1：原均衡 P* = 1, Q* = 30

Step 2：支持价下
  QD = 20, QS = 35, 过剩 = 15

Step 3：福利变化
  CS 损失：B+D
  PS 增加：B+D+F
  政府损失：15 × 1.5 = 22.5 = D+E+F+G

Step 4：总福利变化
  ΔTS = -(D+E+G) = -18.75

答：社会总福利损失 18.75
```
