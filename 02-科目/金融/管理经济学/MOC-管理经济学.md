## 🗺️ 学习建议

**考试重点排序：**
1. 弹性计算（必考！）— 价格弹性、收入弹性
2. 垄断利润最大化（必考！）— MR=MC
3. 福利分析（常考）— 消费者/生产者剩余变化
4. 政府干预（常考）— 限价、价格支持的福利影响
5. 完全竞争市场均衡（基础）

**学习顺序建议：**
```
需求函数 → 弹性 → 边际收益 → 生产成本 → 市场结构 → 政府干预 → 福利分析
```
