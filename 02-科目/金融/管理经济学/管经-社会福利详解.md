# 📊 社会福利详解（含课堂举例）

> 来源：《管理经济学概念整理》PDF — 课堂举例和食糖题

---

## 一、社会福利的组成

$$社会福利 = EVA（消费者剩余 + 生产者剩余）+ 相关利益主体福利$$

**相关利益主体**：中间商、政府等

### 核心原则

- 社会福利以**供需平衡下的总剩余**作为衡量标准
- 消费者和生产者可以但没有获得的好处 = **社会福利损失**
- 政府支出 = **社会福利损失**

## 二、课堂举例：最低限价的福利分析

### 情况 1：企业按市场需求生产（Q3）

```
政府设定最低价格 PMIN（高于均衡价格）

此时：
  企业预计市场需求 = Q3（按需求曲线）
  企业只生产 Q3

福利变化：
  A = 消费者剩余转移到生产者剩余（不算损失，有人赚到）
  B + C = 没有被任何一方赚到（社会福利损失）

社会总福利损失 = B + C
```

### 情况 2：企业按供给曲线应产尽产（Q2）

```
企业不管市场预期，按供给曲线生产 Q2
Q3 只能卖 Q3，剩下 Q2-Q3 = 库存 D

福利变化：
  A = 消费者转生产者（不算损失）
  B + C = 社会福利损失
  D = 生产出来没卖出去（纯浪费，算社会福利损失）

社会总福利损失 = B + C + D
```

### 情况 3：政府收购库存

```
政府说：多生产的产品我买单
库存 D 产生了价值 E
政府买单 = E + B + C + D（全部算社会福利损失）

福利变化：
  消费者损失 = A + B
  生产者多赚 = A + B + E
  政府支出 = E + B + C + D

社会总福利 = (A+B+E) - (A+B) - (E+B+C+D) = -(B+C+D)
```

**⚠️ 政府买单的部分全部属于社会福利损失！**

## 三、社会福利损失的三种类型

```
1. 消费者和生产者在供需不平衡下相对供需平衡没有赚到的损失
   → B + C（没有成交的交易）

2. 被生产出来却没有产生价值的损失
   → D（库存浪费）

3. 政府买单后没有转化为任何一方剩余的净损失
   → 政府支出中超出 E 的部分
```

## 四、食糖题：进口配额分析

### 题目背景

进口食糖，配额限制为 6.9，进口商以国际价格买入，以配额价格卖出。

### 福利分析

```
进口商（新生产者）的剩余 = C 区域
（以低价买，高价卖，赚差价）

消费者剩余损失 = A + B + C + D
生产者剩余增加 = A + C

社会总福利变化 = (A+C) - (A+B+C+D) = -(B+D)

答：社会总福利损失 = B + D
```

### 关键理解

- 进口商视为**新生产者**，其剩余计入社会福利增加
- 消费者损失 - 生产者增加 = 净损失

## 五、EVA 与社会福利的关系

```
总 EVA = V - C（价值 - 成本）

在供需平衡时：
  消费者剩余 + 生产者剩余 = 最大化
  社会福利 = EVA + 相关利益主体福利

当政府干预导致供需不平衡时：
  部分 EVA 损失 → 社会福利减少
```
