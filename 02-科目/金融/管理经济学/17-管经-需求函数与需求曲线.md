# 📉 需求定律、需求函数与需求曲线

---

## 一、需求定律（Law of Demand）⭐

**其他条件不变时，价格上升 → 需求量下降；价格下降 → 需求量上升。**

价格和需求量**反向变动**！

类比：**奶茶涨价了你就会少买，降价了你就会多买**

### 需求表（价格-需求量对应表）

| 价格（元） | 需求量（杯） |
|-----------|-------------|
| 10 | 0 |
| 8 | 4 |
| 6 | 8 |
| 4 | 12 |
| 2 | 16 |

→ 价格越低，需求量越大

---

## 二、需求函数

**需求函数表示需求量 Q 与价格 P 之间的关系**

### 线性需求函数

$$Q = a - bP$$

- a = 价格为 0 时的最大需求量（截距）
- b = 价格每涨 1 元，需求量减少 b 个（斜率）

### 例题

**题目：** Q = 20 - 2P

```
解读：
- 当 P = 0 时，Q = 20（最多卖 20 个）
- 当 P = 10 时，Q = 0（一个都卖不出去）
- 价格每涨 1 元，需求量减少 2 个
```

### 反需求函数（把 P 放在左边）

$$P = \frac{a}{b} - \frac{1}{b}Q$$

**例题：** Q = 20 - 2P → P = 10 - 0.5Q

---

## 三、需求曲线

```
  价格 P
    ↑
 10 |╲
    |  ╲
    |    ╲  需求曲线
    |      ╲
    |        ╲
  0 ┼──────────╲──→ 数量 Q
    0          20
```

- 需求曲线**向右下方倾斜**（价格越高，需求越少）
- 斜率 = -1/b = -1/2 = -0.5

---

## 四、需求变动 vs 需求量变动（重要区分！）

### ⚠️ 只涉及价格变动 → 需求在曲线上移动（不平移）

```
价格 P
  ↑    A
P1|----●
  |     ╲
P2|------●B
  |       ╲
  ┼────────╲──→ Q
      Q1  Q2

价格从 P1 降到 P2 → 需求量从 Q1 增到 Q2
→ 从 A 点移动到 B 点（在同一条曲线上移动）
```

### ⚠️ 涉及其他因素 → 需求曲线左右平移

```
价格 P
  ↑
  |   D1   D2   D3
  |   ╲    ╲    ╲
  |    ╲    ╲    ╲
P*|-----●A---●B---●C
  |      ╲    ╲    ╲
  ┼───────╲────╲────╲──→ Q
          Q1   Q2   Q3

D1→D2：需求增加（右移）
D1→D3：需求减少（左移）
```

### 导致需求曲线平移的因素（来自教材）

| 因素 | 需求增加（右移） | 需求减少（左移） |
|------|----------------|----------------|
| 收入 | 收入增加 | 收入减少 |
| 替代品价格 | 替代品涨价（如牛奶涨价 → 豆浆需求增加） | 替代品降价 |
| 互补品价格 | 互补品降价 | 互补品涨价 |
| 偏好 | 更喜欢这个商品 | 不喜欢了 |
| 预期 | 预期未来涨价 → 现在多买 | 预期未来降价 → 现在少买 |
| 消费者数量 | 消费者增加 | 消费者减少 |

**举例（来自教材）：**
- 收入增加 → 需求增加 → 右移
- 替代品（可替代商品）价格下降 → 需求下降 → 左移
- 嗜好此商品 → 需求增加 → 右移
