# 💡 机会成本、沉没成本与利润

> 来源：《管理经济学概念整理》PDF

---

## 一、机会成本（Opportunity Cost）

**做了选择后，放弃的其他选项中利润最大的那个。**

类比：**选了A就失去了B，B的价值就是你的机会成本**

### 举例

```
小明种玉米一年能赚 5 万，种葡萄能赚 3 万。

选择种玉米 → 机会成本 = 3 万（放弃了葡萄）
选择种葡萄 → 机会成本 = 5 万（放弃了玉米）
```

**⚠️ 机会成本不是你花的钱，而是你放弃的最大收益！**

---

## 二、沉没成本（Sunk Cost）

**已经付出且不可收回的成本。决策时应排除沉没成本的影响。**

类比：**电影票买了发现不好看，票钱是沉没成本，不应该影响你"要不要继续看"的决策**

### 举例

```
花 100 元买了一张电影票，看了 30 分钟发现很难看。
❌ 错误想法：都花了 100 块，看完吧（被沉没成本绑架）
✅ 正确想法：100 块已经回不来了，接下来的时间用来做更有价值的事
```

## 三、会计利润 vs 经济利润

### 核心公式

```
会计利润 = 总收益 - 显性成本（实际花出去的钱）
经济利润 = 总收益 - 显性成本 - 隐性成本（机会成本）

或者：
经济利润 = 会计利润 - 机会成本
```

### 关系

| 情况 | 会计利润 | 经济利润 | 含义 |
|------|---------|---------|------|
| 赚得多 | 正 | 正 | 真正赚钱，值得继续 |
| 刚好够 | 正 | 0 | 不亏不赚，资源配置刚好 |
| 其实亏了 | 正 | 负 | 看着赚钱，其实有更好的选择 |
| 亏了 | 负 | 负 | 赶紧止损 |

**⚠️ 会计利润为正时，经济利润可正可负可零！**

### 经济利润的意义

- **经济利润 > 0** → 企业继续经营
- **经济利润 < 0** → 除非条件改变，否则企业终将关闭
- **经济利润 < 0** → 资源配置一定有更优化的方案

### 举例

```
小王开奶茶店，年收入 50 万
显性成本（房租、原料、工资）= 30 万
如果小王去上班能赚 25 万（机会成本）

会计利润 = 50 - 30 = 20 万 ✅ 看着赚钱
经济利润 = 50 - 30 - 25 = -5 万 ❌ 其实亏了！
```

## 四、经济附加值 EVA（Economic Value Added）

**EVA = 买方剩余 + 卖方剩余**

```
买方 EVA = 商品价值 V - 付出的价格 P
卖方 EVA = 卖出价格 P - 成本 C

总 EVA = (V - P) + (P - C) = V - C
```

**⚠️ EVA 是考试重点！**

### 举例

```
一杯奶茶对消费者价值 30 元，售价 20 元，成本 10 元

消费者 EVA = 30 - 20 = 10（赚了 10 元的满足感）
商家 EVA = 20 - 10 = 10（赚了 10 元利润）
总 EVA = 10 + 10 = 20 = 30 - 10 = V - C
```

## 五、帕累托最优（Pareto Optimal）

**从此以后，非损人不能利己。**

### 三个条件

1. **有效产出**：最后一单位的 MC = 消费的边际价值（需求曲线）
2. **生产分配效率**：每个生产者的 MC 相同
3. **消费分配效率**：每个消费者的边际价值相同

类比：**蛋糕已经分到不能再分了 — 想让任何一个人多吃一口，就必须让另一个人少吃**
