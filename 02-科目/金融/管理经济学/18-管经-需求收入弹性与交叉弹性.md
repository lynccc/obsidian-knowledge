# 📈 需求收入弹性与交叉弹性

---

## 一、需求收入弹性（Income Elasticity）

### 公式

$$E_I = \frac{\%\Delta Q}{\%\Delta I} = \frac{dQ}{dI} \times \frac{I}{Q}$$

- I = 收入（Income）
- Q = 需求量

### 分类

| 弹性值 | 商品类型 | 含义 | 举例 |
|--------|---------|------|------|
| EI > 1 | 奢侈品 | 收入涨 1%，需求涨 >1% | 旅游、名牌包 |
| 0 < EI < 1 | 必需品 | 收入涨 1%，需求涨 <1% | 粮食、食盐 |
| EI < 0 | 劣等品 | 收入涨，需求反而减少 | 方便面、地摊货 |

### 例题（来自习题串讲）

**题目：** 收入上升 25%，需求量上升 5%，求收入弹性。

```
EI = %ΔQ / %ΔI = 5% / 25% = 0.2

答：EI = 0.2，属于必需品（0 < EI < 1）
```

## 二、需求交叉价格弹性（Cross-Price Elasticity）

### 公式

$$E_{XY} = \frac{\%\Delta Q_X}{\%\Delta P_Y}$$

- X = 我们关心的商品
- Y = 另一个商品

### 分类

| 弹性值 | 关系 | 含义 | 举例 |
|--------|------|------|------|
| EXY > 0 | 替代品 | Y 涨价 → X 需求增加 | 可乐和百事 |
| EXY < 0 | 互补品 | Y 涨价 → X 需求减少 | 汽车和汽油 |
| EXY = 0 | 无关 | Y 价格不影响 X | 面包和手机 |

**记忆口诀：** "正替代，负互补"

## 三、劳动供给弹性（拓展应用）

**题目（来自习题串讲）：** 妇女劳动供给对工资弹性 = 0.2，对保姆费弹性 = -0.5。工资涨 5%，保姆费涨 5%，对工作时间影响？

```
Step 1：分别计算两个因素的影响
  工资涨 5% → 工作时间增加 = 0.2 × 5% = 1%
  保姆费涨 5% → 工作时间减少 = -0.5 × 5% = -2.5%

Step 2：总影响
  总变化 = 1% + (-2.5%) = -1.5%

答：工作时间减少约 1.5%
```

**理解：**
- 工资涨 → 工作更有吸引力 → 工作时间增加（替代效应）
- 保姆费涨 → 养孩子成本高 → 工作时间减少（收入效应）
- 两者叠加，净效果是减少
