# 📊 成本分析（短期与长期）

> 来源：《管理经济学概念整理》PDF

---

## 一、成本基本概念

### 各种成本缩写

| 缩写 | 全称 | 中文 | 公式 |
|------|------|------|------|
| TC | Total Cost | 总成本 | TC = FC + VC |
| FC | Fixed Cost | 固定成本 | 不随产量变动 |
| VC | Variable Cost | 可变成本 | 随产量变动 |
| ATC | Average Total Cost | 平均总成本 | ATC = TC/Q |
| AFC | Average Fixed Cost | 平均固定成本 | AFC = FC/Q |
| AVC | Average Variable Cost | 平均可变成本 | AVC = VC/Q |
| MC | Marginal Cost | 边际成本 | MC = ΔTC/ΔQ |

### 举例：咖啡店

```
固定成本（每天）：
  租金 3000 元 → 不管营不营业都要付

可变成本（随营业时间增加）：
  营业 1 小时 → 咖啡豆+纸杯+工资 = 200 元
  营业 2 小时 → 350 元
  营业 3 小时 → 550 元
  → 产出越多，可变成本越高
```

## 二、短期成本分析

### 关键关系

```
MC 与 AC 的交点 = AC 的最低点！

为什么？
  - 当 MC < AC 时，AC 在下降（边际成本拉低平均成本）
  - 当 MC > AC 时，AC 在上升（边际成本拉高平均成本）
  - 所以 MC 穿过 AC 时，正好是 AC 的最低点
```

类比：**考试成绩** — 新考的分数（MC）比平均分（AC）低，平均分就下降；比平均分高，平均分就上升

### 短期成本曲线图

```
成本
  ↑     MC
  |    /  ╲
  |   / ATC ╲
  |  /  ╱    ╲
  | / AVC     ╲
  |/ ╱         ╲
  ┼──────────────→ 产量
```

## 三、长期成本分析

### 资本密集型 vs 劳动密集型

| 特征 | 劳动密集型 | 资本密集型 |
|------|----------|----------|
| 初期投入 | 小 | 大 |
| 总成本增速 | 快（随产量） | 慢（随产量） |
| AC 下降速度 | 慢 | 快 |
| 举例 | 手工作坊 | 汽车工厂 |

### 长期平均成本（LAC）

**LAC = 所有短期平均成本曲线的包络线**

```
成本
  ↑
  |    SAC₁  SAC₂  SAC₃
  |   ╱╲   ╱╲   ╱╲
  |  ╱  ╲ ╱  ╲ ╱  ╲
  | ╱    ╳    ╳    ╲    ← LAC（包络线）
  |╱    ╱ ╲  ╱ ╲    ╲
  ┼──────────────────→ 产量
```

**举例：** 汽车生产商短期靠加工人增产（SAC 上翘），长期靠建新厂扩大规模（回到 LAC 最低点）

## 四、MES（最低有效生产规模）

**MES = Minimum Efficient Scale = LAC 最低点对应的产量**

类比：**开店的最低客流** — 客流低于这个数，成本太高不赚钱

### MES 与市场竞争

| 市场类型 | MES | 企业数量 | 进入难度 | 举例 |
|---------|-----|---------|---------|------|
| 竞争型 | 低 | 多 | 容易 | 手工作坊、地摊 |
| 集中型 | 中 | 中 | 中等 | 车企 |
| 垄断型 | 高 | 少 | 难 | 电信、航空、电商平台 |

## 五、规模经济 vs 范围经济

### 规模经济（Economies of Scale）

**产量增加 → 单位成本下降**

原因：
- 固定成本不随产量等比增加 → 单位固定成本下降
- 技能和配合磨合后更娴熟 → 变动成本率下降

类比：**批发比零售便宜** — 买 100 个杯子的单价比买 1 个便宜

### 范围经济（Economies of Scope）

**同时生产两种产品的费用 < 分别生产的费用之和**

```
分开生产：产品 A 成本 100 + 产品 B 成本 80 = 180
一起生产：总成本 150

范围经济 = 180 - 150 = 30（省了 30）
```

类比：**餐厅同时卖饭和卖饮料** — 厨房、服务员可以共用，成本更低

**⚠️ 相关多元化容易产生范围经济，非相关多元化很难！**

## 六、市场进入与退出

| 条件 | 含义 |
|------|------|
| P ≥ AC | 进入市场（有利润空间） |
| P < AAC | 退出市场（止损） |

- AAC = Avoidable Average Cost（可以回收的成本）
