# 🔗 边际收益与弹性关系

> ⭐ **必背公式** — 考试直接考推导

---

## 一、核心公式

$$MR = P \left(1 + \frac{1}{E_d}\right)$$

或者写成：

$$MR = P \left(1 - \frac{1}{|E_d|}\right)$$

其中 Ed 是需求价格弹性（负数）

---

## 二、公式推导

```
TR = P × Q

MR = dTR/dQ = P + Q × dP/dQ

因为 Ed = (dQ/dP) × (P/Q)
所以 dP/dQ = P / (Q × Ed)

代入：
MR = P + Q × P / (Q × Ed)
MR = P + P / Ed
MR = P × (1 + 1/Ed)
```

---

## 三、三种情况

| 弹性 | MR | 含义 |
|------|-----|------|
| \|E\| > 1（富有弹性） | MR > 0 | 多卖一个，总收入增加 |
| \|E\| = 1（单位弹性） | MR = 0 | 多卖一个，总收入不变（最大） |
| \|E\| < 1（缺乏弹性） | MR < 0 | 多卖一个，总收入减少 |

---

## 四、经典例题

### 例题 1：MR = 0 时的弹性

**题目：** 当边际收益为零时，需求的价格弹性等于？

```
MR = P × (1 + 1/Ed) = 0

因为 P ≠ 0
所以 1 + 1/Ed = 0
1/Ed = -1
Ed = -1

答：|E| = 1（单位弹性）
```

### 例题 2：用弹性定价

**题目：** 停车场 MC ≈ 0，P = 20，Ed = -2，车位利用率 80%，如何利润最大化？

```
Step 1：利润最大化条件 MR = MC
  因为 MC ≈ 0，所以 MR = 0

Step 2：MR = 0 时 |E| = 1
  但当前 |E| = 2 > 1（富有弹性）

Step 3：富有弹性时，降价能增加 TR
  所以应该降价，吸引更多顾客

答：应该降价
```

---

## 五、记忆技巧

```
弹性大（|E|>1）→ MR>0 → 降价多赚 → "弹性大降价赚"
弹性小（|E|<1）→ MR<0 → 涨价多赚 → "弹性小涨价赚"
弹性=1（|E|=1）→ MR=0 → TR最大 → "弹性为1利润最大"
```
