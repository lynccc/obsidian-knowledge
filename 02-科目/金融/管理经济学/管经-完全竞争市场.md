# 🏪 完全竞争市场

---

## 一、特征

| 特征 | 说明 |
|------|------|
| 企业数量很多 | 没有任何一家能影响价格 |
| 产品同质 | 所有企业的产品完全一样 |
| 自由进入退出 | 没有进入壁垒 |
| 信息完全 | 所有人都知道价格 |

类比：**菜市场卖白菜** — 你的白菜和隔壁的一样，顾客只看价格

---

## 二、企业是价格接受者（Price Taker）

- 企业**不能**自己定价格 → 市场价格由供需决定
- 企业面对的需求曲线是**水平线**（完全弹性）
- 企业可以卖任意数量，但价格固定

---

## 三、利润最大化：P = MC

在完全竞争市场中：
- **P = MR = AR**（价格 = 边际收益 = 平均收益）
- 利润最大化条件：**P = MC**

### 例题：求生产者福利

**题目（来自习题串讲）：** 三家企业 MC₁ = 3+2q₁, MC₂ = 4+q₂, MC₃ = 3+3q₃，市场价格 P = 9，求生产者福利总和。

```
Step 1：求每家企业的产量（令 MC = P）
  企业1：3 + 2q₁ = 9 → q₁ = 3
  企业2：4 + q₂ = 9 → q₂ = 5
  企业3：3 + 3q₃ = 9 → q₃ = 2

Step 2：求每家企业的生产者剩余
  PS = TR - 可变成本 = P×q - ∫MC dq

  企业1：PS₁ = 9×3 - ∫₀³(3+2q)dq = 27 - [3q+q²]₀³ = 27 - (9+9) = 9
  企业2：PS₂ = 9×5 - ∫₀⁵(4+q)dq = 45 - [4q+q²/2]₀⁵ = 45 - (20+12.5) = 12.5
  企业3：PS₃ = 9×2 - ∫₀²(3+3q)dq = 18 - [3q+1.5q²]₀² = 18 - (6+6) = 6

Step 3：求总和
  总 PS = 9 + 12.5 + 6 = 27.5

答：生产者福利总和为 27.5
```

**另一种理解方式：**
```
PS = P×q - 总可变成本
   = 价格线以下、MC 曲线以上的面积（三角形/梯形）
```

## 四、短期与长期

| 对比 | 短期 | 长期 |
|------|------|------|
| 固定成本 | 有 | 没有（全部可变） |
| 企业数量 | 固定 | 可以进出 |
| 经济利润 | 可以 > 0 或 < 0 | 必须 = 0 |
| 均衡条件 | P = MC | P = MC = AC（最低点） |

**长期均衡：** P = MC = AC（价格等于边际成本等于平均成本的最低点）
