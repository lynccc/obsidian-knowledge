# 🏢 垄断市场与边际收益

> ⭐ **高频考点** — 垄断利润最大化是必考计算题

---

## 一、垄断市场的特征

- **只有一个卖家** — 整个行业就一家企业
- **没有替代品** — 消费者没有别的选择
- **进入壁垒高** — 新企业进不来
- **企业就是价格制定者** — 可以自己定价格

类比：**某个小镇唯一的自来水公司** — 你只能从它那买水

---

## 二、边际收益（MR）的推导（必考！）

### 从需求函数推导 MR

**例题：** 需求函数 Q = 20 - 2P，求边际收益 MR

```
Step 1：把需求函数改写为 P = f(Q) 的形式
  Q = 20 - 2P
  2P = 20 - Q
  P = 10 - 0.5Q

Step 2：求总收益 TR
  TR = P × Q = (10 - 0.5Q) × Q = 10Q - 0.5Q²

Step 3：求边际收益 MR（对 TR 求导）
  MR = dTR/dQ = 10 - Q

答：边际收益 MR = 10 - Q
```

### ⚠️ 重要规律

**当需求函数是线性的（P = a - bQ）时：**
- 需求曲线：P = a - bQ
- 边际收益：MR = a - 2bQ

**MR 的斜率是需求曲线斜率的 2 倍！**

```
需求曲线：P = 10 - 0.5Q  （斜率 = -0.5）
MR 曲线：MR = 10 - Q      （斜率 = -1 = 2 × -0.5）
```

## 三、垄断利润最大化（MR = MC）

### 例题（来自习题串讲）

**题目：** 垄断企业 MC = 2Q，市场需求函数 P = 60 - 2Q，求利润最大化价格。

```
Step 1：求 MR
  需求函数 P = 60 - 2Q
  TR = P × Q = (60 - 2Q) × Q = 60Q - 2Q²
  MR = dTR/dQ = 60 - 4Q

Step 2：令 MR = MC
  60 - 4Q = 2Q
  60 = 6Q
  Q = 10

Step 3：代入需求函数求价格
  P = 60 - 2 × 10 = 40

答：利润最大化价格为 40 元
```

### 利润计算（如果需要）

```
利润 = TR - TC

TR = P × Q = 40 × 10 = 400
TC = ∫MC dQ = ∫2Q dQ = Q² = 10² = 100（假设固定成本为0）

利润 = 400 - 100 = 300
```

## 四、MR = 0 的含义

当 MR = 0 时：
- 多卖一个单位，收入增加为 0
- 此时 |弹性| = 1（单位弹性）
- 总收益 TR 达到最大值

```
MR > 0 → |E| > 1（富有弹性）→ 降价能增加 TR
MR = 0 → |E| = 1（单位弹性）→ TR 最大
MR < 0 → |E| < 1（缺乏弹性）→ 涨价能增加 TR
```

## 五、垄断 vs 完全竞争

| 对比项 | 完全竞争 | 垄断 |
|--------|---------|------|
| 企业数量 | 很多 | 一个 |
| 价格 | P = MC | P > MC |
| 产量 | 较高 | 较低 |
| 利润（长期） | 经济利润 = 0 | 经济利润 > 0 |
| 社会福利 | 最大化 | 存在无谓损失 |
