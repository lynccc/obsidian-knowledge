# 📢 供给弹性与广告弹性

> 来源：《管理经济学概念整理》PDF

---

## 一、供给的价格弹性

### 公式

$$E_s = \frac{\%\Delta Q_s}{\%\Delta P}$$

- 供给和价格变动方向**相同**（正数）
- 价格涨 → 供给增加

### 分类

| 弹性值 | 含义 |
|--------|------|
| ES > 1 | 富有弹性（价格小变，供给大变） |
| ES = 1 | 单位弹性 |
| ES < 1 | 缺乏弹性（价格大变，供给小变） |
| ES = 0 | 完全无弹性（供给固定） |
| ES = ∞ | 完全弹性 |

### 影响因素

- **时间**：长期弹性 > 短期弹性（长期可以调整产能）
- **生产灵活性**：容易调整生产 → 弹性大
- **库存**：有库存 → 弹性大

---

## 二、广告弹性

### 公式

$$E_A = \frac{\%\Delta Q}{\%\Delta 广告投入}$$

### 广告投入强度公式（重要！）

$$广告投入强度 = 毛利百分比 \times 广告弹性$$

### 理解

```
毛利百分比高 + 竞争激烈（广告弹性大）
→ 广告投入强度高

举例：
  奢侈品：毛利高 + 竞争激烈 → 大量打广告
  日用品：毛利低 + 竞争一般 → 广告投入少
```

**⚠️ 越是竞争激烈的行业，广告弹性越大！**

---

## 三、弹性总结表

| 弹性类型 | 公式 | 方向 | 用途 |
|---------|------|------|------|
| 需求价格弹性 | %ΔQ / %ΔP | 负 | 定价决策 |
| 需求收入弹性 | %ΔQ / %ΔI | 正（正常品） | 判断商品类型 |
| 供给价格弹性 | %ΔQs / %ΔP | 正 | 供给决策 |
| 交叉价格弹性 | %ΔQx / %ΔPy | 正=替代，负=互补 | 判断商品关系 |
| 广告弹性 | %ΔQ / %Δ广告 | 正 | 广告投入决策 |

---

## 四、弹性与企业决策

| 弹性 | 企业策略 |
|------|---------|
| 需求缺乏弹性（刚需） | 提价提高收益 |
| 需求富有弹性 | 降价提高收益 |
| 供给缺乏弹性 | 短期难以调整，靠库存应对 |
| 供给富有弹性 | 可以快速调整产量 |
