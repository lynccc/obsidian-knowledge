# 📊 社会福利分析

> ⭐⭐ **高频考点** — 政府干预的福利变化分析几乎必考

---

## 一、基本概念

### 消费者剩余（Consumer Surplus, CS）

**消费者愿意付的最高价格 - 实际支付的价格**

类比：**你愿意花 100 块买一杯奶茶，实际只花了 30 块，消费者剩余 = 70 块**

$$CS = \int_0^Q D(Q)dQ - P \times Q$$

图形上 = 需求曲线以下、价格线以上的**三角形面积**

### 生产者剩余（Producer Surplus, PS）

**实际收到的价格 - 生产者愿意接受的最低价格**

类比：**你做一杯奶茶成本 10 块，卖了 30 块，生产者剩余 = 20 块**

$$PS = P \times Q - \int_0^Q S(Q)dQ$$

图形上 = 价格线以下、供给曲线以上的**三角形面积**

### 社会总福利（Total Surplus, TS）

$$TS = CS + PS$$

---

## 二、完全竞争市场的福利

在完全竞争均衡时：
- P = MC（价格 = 边际成本）
- 社会总福利**最大化**
- 没有无谓损失

```
        价格
         ↑
         | 供给曲线（S）
    P* ──┼─────────
         |    ↗
         |  ↗  均衡点
         |↗
    ─────┼────────→ 数量
              Q*
```

## 三、政府干预的福利变化（重点！）

### 情况 1：最高限价（Price Ceiling）

**政府规定：价格不能超过某个上限**

```
例题：需求 QD = 32 - 4P，供给 QS = -3 + P
政府规定最高价格 = 5，分析福利变化
```

**解题步骤：**
```
Step 1：求原均衡
  QD = QS → 32 - 4P = -3 + P → 35 = 5P → P* = 7, Q* = 25

Step 2：分析限价后
  最高价格 = 5 < 7（低于均衡价格，限价有效）
  供给量：QS = -3 + 5 = 2
  需求量：QD = 32 - 4×5 = 12
  实际交易量 = min(2, 12) = 2（供给不足）

Step 3：福利变化
  消费者剩余：变化不确定（买到的人付更少，但买到的人更少了）
  生产者剩余：减少（价格降低，销量也降低）
  社会总福利：减少（产生无谓损失 DWL）
```

**⚠️ 最高限价的后果：**
- 供给不足（短缺）
- 可能出现排队、黑市
- 社会总福利减少

---

### 情况 2：价格支持（Price Support）— 政府收购

**政府规定：价格不能低于某个下限，政府按支持价收购过剩供给**

```
例题（来自习题串讲）：QD = 50 - 20P，QS = 20 + 10P
政府支持价格 = 1.5，收购过剩供给后销毁
```

**解题步骤：**
```
Step 1：求原均衡
  QD = QS → 50 - 20P = 20 + 10P → 30 = 30P → P* = 1, Q* = 30

Step 2：分析支持价格下
  支持价格 = 1.5 > 1（高于均衡价格，支持有效）
  需求量：QD = 50 - 20×1.5 = 20
  供给量：QS = 20 + 10×1.5 = 35
  过剩 = 35 - 20 = 15（政府收购 15 单位后销毁）

Step 3：分析各方剩余变化（与原均衡比较）

  消费者剩余变化：
    原来在 P=1 时买 30 单位
    现在在 P=1.5 时只买 20 单位
    消费者损失 = 区域 B + D（多付的钱 + 少买的损失）

  生产者剩余变化：
    原来在 P=1 时卖 30 单位
    现在在 P=1.5 时卖 35 单位
    生产者增加 = 区域 B + D + F

  政府支出（纯损失）：
    政府按 1.5 收购 15 单位，然后销毁
    政府损失 = 15 × 1.5 = 22.5（对应区域 D + E + F + G）

Step 4：计算社会总福利变化
  ΔTS = ΔCS + ΔPS + Δ政府
  = -(B+D) + (B+D+F) - (D+E+F+G)
  = -(D+E+G)

  D+E+G = 矩形面积 - F
  = (35-20) × 1.5 - (35-20) × 0.5 / 2
  = 22.5 - 3.75 = 18.75

答：社会总福利损失 18.75
```

**⚠️ 价格支持的后果：**
- 供给过剩
- 政府需要花钱收购
- 社会总福利减少（无谓损失）

---

## 四、无谓损失（Deadweight Loss, DWL）

**无谓损失 = 社会总福利的净减少 = 三角形面积**

$$DWL = \frac{1}{2} \times \Delta P \times \Delta Q$$

类比：**本来能成交的买卖被政策搞没了，双方都亏了**
