# 📐 需求价格弹性

> ⭐ **高频考点** — 几乎必考，必须掌握计算和应用

---

## 一、什么是弹性？

**弹性 = 敏感度** — 价格变 1%，需求量变多少？

类比：**弹簧** — 拉一下（价格变），弹多远（需求量变）

---

## 二、计算公式

### 点弹性（Point Elasticity）

$$E_d = \frac{\%\Delta Q}{\%\Delta P} = \frac{dQ}{dP} \times \frac{P}{Q}$$

**记住口诀：** 分子是需求量变化率，分母是价格变化率

### 弧弹性（Arc Elasticity）— 两点之间

$$E_d = \frac{\Delta Q / \bar{Q}}{\Delta P / \bar{P}} = \frac{(Q_2 - Q_1) / [(Q_1+Q_2)/2]}{(P_2 - P_1) / [(P_1+P_2)/2]}$$

**为什么要用平均值？** 因为从 A→B 和从 B→A 算出来的弹性不一样，用平均值消除差异

---

## 三、弹性的分类

| 弹性值 | 名称 | 含义 | 举例 |
|--------|------|------|------|
| \|E\| > 1 | 富有弹性 | 需求对价格敏感 | 奢侈品、替代品多的商品 |
| \|E\| = 1 | 单位弹性 | 价格变1%，需求也变1% | 特殊情况 |
| \|E\| < 1 | 缺乏弹性 | 需求对价格不敏感 | 必需品、没有替代品的商品 |
| \|E\| = 0 | 完全无弹性 | 价格怎么变需求都不变 | 救命药 |
| \|E\| = ∞ | 完全弹性 | 价格一变需求就为零 | 完全替代品 |

---

## 四、弹性的应用（超重要！）

### 弹性与总收入（TR）的关系

$$TR = P \times Q$$

| 弹性 | 价格上涨时 TR | 价格下降时 TR | 策略 |
|------|-------------|-------------|------|
| 富有弹性（\|E\|>1） | TR ↓ 减少 | TR ↑ 增加 | 降价促销 |
| 单位弹性（\|E\|=1） | TR 不变 | TR 不变 | — |
| 缺乏弹性（\|E\|<1）| TR ↑ 增加 | TR ↓ 减少 | 涨价增收 |

**记忆口诀：** "弹性大降价赚，弹性小涨价赚"

## 五、经典例题

### 例题 1：基础计算

**题目：** 需求函数 Q = 20 - 2P，求 P = 4 时的需求价格弹性。

**解题步骤：**
```
Step 1：求 dQ/dP
  Q = 20 - 2P
  dQ/dP = -2

Step 2：求 P = 4 时的 Q
  Q = 20 - 2 × 4 = 12

Step 3：代入公式
  Ed = (dQ/dP) × (P/Q)
  Ed = -2 × (4/12)
  Ed = -2/3 ≈ -0.67

答：弹性为 -0.67，|E| = 0.67 < 1，缺乏弹性
```

### 例题 2：提价计算（来自习题串讲）

**题目：** 需求价格弹性恒为 -1，现价 500 元，要减少一半消费，需提价多少？

**解题步骤：**
```
Step 1：理解弹性 = -1 的含义
  弹性恒为 -1 → 单位弹性 → 价格变 x%，需求变 -x%

Step 2：要减少一半消费 → 需求量变化 = -50%
  因为 |E| = 1，所以价格变化 = +50%

Step 3：计算提价金额
  提价 = 500 × 50% = 250 元

答：需要提价 250 元（新价格 750 元）
```

### 例题 3：边际收益为零时的弹性

**题目：** 当边际收益为零时，需求的价格弹性等于？

**解题步骤：**
```
Step 1：记住公式
  MR = P × (1 + 1/Ed)

Step 2：令 MR = 0
  0 = P × (1 + 1/Ed)
  因为 P ≠ 0，所以：
  1 + 1/Ed = 0
  1/Ed = -1
  Ed = -1

答：当 MR = 0 时，|E| = 1（单位弹性）
```

**理解：** MR = 0 意味着再多卖一个单位的收入为零 → 正好在弹性 = 1 的点上

## 六、影响弹性的因素

| 因素 | 弹性大 | 弹性小 |
|------|--------|--------|
| 替代品数量 | 替代品多 | 替代品少 |
| 必需品 vs 奢侈品 | 奢侈品 | 必需品 |
| 时间长短 | 长期 | 短期 |
| 支出占收入比例 | 占比大 | 占比小 |
