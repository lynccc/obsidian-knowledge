# ⚖️ 市场均衡

> 来源：《管理经济学概念整理》PDF

---

## 一、什么是市场均衡？

**价格和数量使购买者和供应商的愿望达成一致。**

类比：**拔河比赛** — 消费者想低价买，生产者想高价卖，最终在某个价格达成平衡

```
价格太高 → 需求量减少 → 卖不出去 → 降价
价格太低 → 需求量增加 → 抢购 → 涨价
只有均衡价格 → 愿意买的数量 = 愿意卖的数量
```

---

## 二、均衡价格与均衡数量

```
价格 P
  ↑      供给 S
  |      ╱
P*|─────╳─────  ← 均衡点
  |    ╱ ╲
  |   ╱   ╲  需求 D
  |  ╱     ╲
  ┼──────────→ 数量 Q
         Q*
```

- **均衡价格 P***：供需平衡时的价格
- **均衡数量 Q***：供需平衡时的交易量

---

## 三、供需变动对均衡的影响

| 需求 | 供给 | 均衡价格 | 均衡数量 |
|------|------|---------|---------|
| ↑ | ↑ | 不确定 | ↑ |
| ↓ | ↓ | 不确定 | ↓ |
| ↑ | ↓ | ↑ | 不确定 |
| ↓ | ↑ | ↓ | 不确定 |

**记忆口诀：**
- 需求供给同向变动 → 数量确定，价格不确定
- 需求供给反向变动 → 价格确定，数量不确定

---

## 四、市场一价定律

**不同市场，同样商品的价格应该一样。**

如果不一样：
```
A 市场价格 10 元，B 市场价格 15 元
→ 中间商从 A 买，到 B 卖
→ A 需求增加，价格上涨
→ B 供给增加，价格下降
→ 最终两个市场价格趋同
```

类比：**淘宝和京东的同款商品** — 价格差太大就会有人倒买倒价

## 五、需求曲线与供给曲线的移动

### 需求曲线移动（非价格因素）

| 因素 | 需求增加（右移） | 需求减少（左移） |
|------|----------------|----------------|
| 收入 | 收入增加 | 收入减少 |
| 替代品价格 | 替代品涨价 | 替代品降价 |
| 互补品价格 | 互补品降价 | 互补品涨价 |
| 偏好 | 更喜欢 | 不喜欢了 |
| 预期 | 预期未来涨价 | 预期未来降价 |

### 供给曲线移动（非价格因素）

| 因素 | 供给增加（右移） | 供给减少（左移） |
|------|----------------|----------------|
| 投入品价格 | 原料降价 | 原料涨价 |
| 技术 | 技术进步 | 技术退步 |
| 预期 | 预期未来降价 | 预期未来涨价 |
| 卖家数量 | 更多卖家 | 更少卖家 |

## 六、替代品与互补品

### 替代品（Substitutes）

**一种物品的价格上涨 → 另一种物品的需求上涨**

此消彼长！

```
金拱门（麦当劳）涨价 → 需求降低 → 开封菜（肯德基）需求上涨
```

### 互补品（Complements）

**一种物品的价格上涨 → 另一种物品的需求减少**

同生共灭！

```
汉堡涨价 → 需求降低 → 薯条需求也降低（一般一起买）
```

### 交叉价格弹性判断

```
交叉弹性 > 0 → 替代品
交叉弹性 < 0 → 互补品
交叉弹性 = 0 → 无关
```
