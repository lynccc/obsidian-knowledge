# 📝 2018 年管经真题解析（A卷 + B卷）

> **考试必看！** 40 道选择题 + 详细解析 + 核心公式总结

---

## 🔑 核心公式总结（考前必背）

### 1. 边际就是导数
- 边际收益 MR = 总收益 R 对销量 Q 的**导数**
- 边际成本 MC = 总成本 TC 对产量 Q 的**导数**

### 2. 利润最大化 vs 收入最大化
- **MR = MC** → 利润最大化
- **MR = 0** → 收入（收益）最大化

### 3. 弹性公式
$$E_{dp} = \frac{\Delta Q / Q}{\Delta P / P}$$

| 弹性值 | 含义 | 需求曲线形状 |
|--------|------|-------------|
| Ed = 0 | 完全无弹性 | 竖直线 |
| -1 < Ed < 0 | 缺乏弹性 | 较陡 |
| Ed = -1 | 单位弹性 | — |
| Ed < -1 | 富有弹性 | 较平 |

### 4. MR 与弹性关系（必背！）
$$MR = P\left(1 + \frac{1}{E_{dp}}\right)$$

### 5. 总收益变化率公式
$$\frac{\Delta R}{R} = \frac{\Delta P}{P}(1 + E_{dp})$$

### 6. 重要推论
- Ed = -1 → MR = 0 → 收益最大化 → ΔR/R = 0（价格微小变化不影响收益）

## A 卷真题解析（20 题）

### A1. 边际成本计算
**题目：** 产量增加到 21 单位时，总成本为 21×11=231。第 21 单位的边际成本？

```
MC = TC(21) - TC(20) = 231 - 215 = 16

答案：D
```

### A2. 机会成本比较
**题目：** 种玉米 vs 打工的会计收益和机会成本

```
种玉米：会计收益 = 2.2 - 1.0 = 1.2，机会成本 = 1.1（打工的收益）
打工：会计收益 = 1.1，机会成本 = 1.2（种玉米的收益）

答案：B
```

### A3. 新企业加入的影响
**题目：** 新企业加入市场

```
新企业加入 → 供给增加 → 供给曲线右移（S1→S2）
→ 均衡价格 P1→P2↓，均衡量 Q1→Q2↑

答案：D
```

### A4. 需求曲线移动
**题目：** 哪个选项导致豆浆需求曲线右移？

```
A. 某投入涨价 → 供给减少（左移）❌
B. 牛奶（替代品）涨价 → 豆浆需求增加（右移）✅
C. 消费者减少 → 需求减少（左移）❌
D. 价格下降 → 需求量增加（沿曲线移动，不平移）❌

答案：B
```

### A5. 需求+供给同时变动
**题目：** 预期价格上涨 + 技术进步

```
预期价格上涨 → 需求增加（D1→D2）→ 均衡点 A→B
技术进步 → 供给增加（S1→S2）→ 均衡点 B→C

结果：A→C，均衡量增加，均衡价格不确定

答案：B
```

### A6. 供需判断
**题目：** 需求量 < 供给量

```
需求量 < 供给量 → 供过于求

答案：A
```

### A7. 完全缺乏弹性
**题目：** 需求完全缺乏价格弹性时，供给曲线左移

```
完全缺乏弹性 → 需求曲线为竖直线
供给曲线左移 → 价格上升，均衡量不变

答案：C
```

### A8. 弹性计算（提价使供需平衡）
**题目：** P=500, Q=120, Ed=-0.5, 供应量=100，求提价多少使供需平衡

```
目标：需求量从 120 降到 100 → ΔQ = -20

Ed = (P × ΔQ) / (Q × ΔP)
-0.5 = (500 × -20) / (120 × ΔP)
ΔP = (500 × 20) / (120 × 0.5) = 166.7

答案：A
```

### A9. 交叉弹性
**题目：** 以下哪个正确？

```
P_levi 上升 → Q_lee 上升 → A 正确（替代品）
P_Guess 上升 → Q_lee 下降 → B 正确（互补品）
INC 上升 → Q_lee 下降 → C 正确（劣等品）
答案：D（以上都正确）
```

### A10. 缺乏弹性的含义
**题目：** 价格缺乏弹性

```
-1 < Ed < 0 → 需求对价格不敏感，但不是完全无弹性
A. 价格变化不影响需求量 → ❌（完全无弹性才对）
B. 价格变化只影响需求量 → ❌
C. 价格变化对需求量影响较小 → ✅
D. 提价会减少总收入 → ❌（缺乏弹性时提价增加收入）

答案：C
```

### A11. MR 与弹性综合
**题目：** R = 25Q - 0.5Q²，求各选项

```
MR = R' = 25 - Q

A. P=15 → Q=20 → MR=5 → Ed = P/(MR-P) = 15/(5-15) = -1.5
B. P=12.5 → Q=25 → MR=0 → 收益最大化 ✅
C. Ed = P/(MR-P) = 1 - 50/Q，P和Q变化会导致Ed变化 ✅

答案：B
```

### A12. Ed = -1 的含义
**题目：** Ed = -1 时

```
A. ΔR/R = (ΔP/P)(1+Ed) = 0 → 总收益不变 ✅
B. MR=0 → 收益最大化，不是利润最大化 ❌

答案：A
```

### A13. 规模经济 vs 范围经济
```
规模经济：产出增加 → 平均成本下降
范围经济：多产品共享资源 → 总成本降低

答案：C
```

### A14. AC 曲线与规模经济
**题目：** AC 曲线最低点左侧，产量增加 10%

```
AC 最低点左侧 = 规模经济区
产量增加 10% → 总成本增加 < 10%（因为 AC 在下降）

答案：B
```

### A15. 规模报酬
```
规模报酬递增 → 规模经济 → 长期 AC 下降
规模报酬递减 → 规模不经济 → 长期 AC 上升

答案：A
```

### A16. 规模经济区
```
AC 最低点左侧 → 规模经济 → 产量增加，AC 下降

答案：B
```

### A17. 完全竞争利润最大化
**题目：** AC = 3 + 4q，P = 7，求利润最大化产量

```
TC = AC × q = 3q + 4q²
MC = TC' = 3 + 8q
MR = P = 7（完全竞争）

MR = MC → 7 = 3 + 8q → q = 0.5

答案：B
```

### A18. 市场均衡
**题目：** 供给 P = 1+Q，需求 P = 11-Q

```
1 + Q = 11 - Q → 2Q = 10 → Q = 5, P = 6

答案：B
```

### A19. 政府收购农产品
```
收购过剩农产品 → 维持农业生产规模
不收购 → 供过于求 → 农产品卖不出去 → 规模无法维持

答案：C
```

### A20. 最高限价福利分析
**题目：** 均衡 P=20, Q=10，政府限价 P=18

```
限价 18 < 均衡 20 → 有效
社会福利损失 = 阴影三角形面积 = 3

答案：D
```

## B 卷真题解析（20 题）

### B1. 收入最大化
**题目：** R = 20Q - 0.5Q²，求收入最大化

```
MR = R' = 20 - Q
MR = 0 → Q = 20, P = 10

答案：A
```

### B2. 利润最大化（垄断）
**题目：** R = 1000Q - 5Q²，C = 5Q² + 200Q + 1000

```
MR = 1000 - 10Q
MC = 10Q + 200
MR = MC → 1000 - 10Q = 10Q + 200 → Q = 40

答案：C
```

### B3. 短期继续营业 vs 长期退出
**题目：** P=50, 总成本=110000, 变动成本=90000, Q=2000

```
短期：AVC = 90000/2000 = 45 < P=50 → MR > AVC → 继续营业
长期：AC = 110000/2000 = 55 > P=50 → MR < AC → 退出市场

答案：B
```

**⚠️ 重要规律：**
- 短期：P > AVC → 继续营业（能覆盖可变成本）
- 长期：P < AC → 退出市场（不能覆盖总成本）

### B7. 预期价格下降 + 供给增加
```
预期价格下降 → 需求减少（D1→D2）→ A→B
预期价格下降 → 供给增加（S1→S2）→ B→C

结果：A→C，均衡价格降低，均衡量不确定

答案：B
```

### B9. 价格下降导致总费用上升
**题目：** 价格下降 20%，总费用上升，求弹性

```
ΔR/R = (ΔP/P)(1 + Ed)
ΔP/P = -0.2, ΔR/R > 0
所以 1 + Ed < 0 → Ed < -1（富有弹性）

答案：A
```

### B11. 弹性与定价决策
**题目：** P=15, Ed=-2.5, MC=5，如何利润最大化？

```
MR = P(1 + 1/Ed) = 15(1 - 0.4) = 9 > MC = 5
MR > MC → 应该降价提销量

答案：C
```

### B13. 范围经济判断
**题目：** TC = ax² + by² + cxy

```
单独生产 H（y=0）：TC_H = ax², AC_H = ax
单独生产 S（x=0）：TC_S = by², AC_S = by
→ AC 随产量上升，无规模经济

联合生产：TC < TC_H + TC_S（因为 cxy < 0）
→ 存在范围经济

答案：D
```

### B14. 总成本计算
**题目：** 前 15 单位 MC=2，16~20 单位 MC=3

```
前 15 单位：TC = 2×15 + 5 = 35（含固定成本 5）
16~20 单位：TC = 3×5 = 15
总 TC = 35 + 15 = 50
AC = 50/20 = 2.5

答案：C
```

### B17. MES 与市场竞争
```
农产品行业 MES 低 → 准入门槛低 → 接近完全竞争
电信、航空 MES 高 → 准入门槛高 → 寡头垄断

答案：B
```

### B18. 消费者剩余计算
```
消费者剩余 = 需求曲线以下、价格线以上的三角形面积 = 61.25

答案：B
```

### B19. 最高限价的福利分析
**题目：** 均衡时 PS=C+D+E, CS=A+B，限价 Pmax 后

```
限价后：PS = E（减少），CS = A + C
CS 变化 = C - B，无法判断正负

答案：D
```

### B20. 完全无弹性 + 征税
**题目：** Ed=0，征税 5 元

```
Ed=0 → 需求曲线竖直
征税 → 供给曲线上移 5 元
均衡点 A→B，价差 = 5 元（全部由消费者承担）

答案：B
```
