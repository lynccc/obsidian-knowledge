# 💰 利润最大化原则

> ⭐⭐ **核心公式** — 所有市场结构通用

---

## 一、核心原则：MR = MC

**边际收益（MR）= 边际成本（MC）时，利润最大**

### 为什么？

| 情况 | 说明 | 应该 |
|------|------|------|
| MR > MC | 多卖一个赚的 > 成本 | 继续生产（增加产量） |
| MR < MC | 多卖一个赚的 < 成本 | 减少生产 |
| MR = MC | 恰好平衡 | 利润最大化 |

类比：**吃饭** — 还想吃（MR>MC）就继续吃，吃饱了（MR=MC）就停，撑了（MR<MC）就别吃了

---

## 二、不同市场结构下的应用

### 完全竞争

- P = MR（企业是价格接受者）
- 利润最大化：**P = MC**
- 企业需求曲线是水平线

### 垄断

- P > MR（企业是价格制定者）
- 利润最大化：**MR = MC**，然后查需求曲线定价格
- 需求曲线是向下的斜线

---

## 三、解题万能步骤

```
Step 1：写出需求函数，求 TR
  TR = P × Q

Step 2：求 MR（对 TR 求导）
  MR = dTR/dQ

Step 3：令 MR = MC，解出 Q*
  这就是利润最大化产量

Step 4：代入需求函数，求 P*
  这就是利润最大化价格

Step 5（如果需要）：求利润
  利润 = TR - TC = P×Q - TC
```

---

## 四、利润的三种情况

```
P > AC → 经济利润 > 0 → 赚钱
P = AC → 经济利润 = 0 → 盈亏平衡
P < AC → 经济利润 < 0 → 亏损
```

**短期内，即使亏损也可能继续生产（只要 P > AVC）**
