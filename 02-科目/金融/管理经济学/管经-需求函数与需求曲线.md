# 📉 需求函数与需求曲线

---

## 一、需求函数

**需求函数表示需求量 Q 与价格 P 之间的关系**

### 线性需求函数

$$Q = a - bP$$

- a = 价格为 0 时的最大需求量（截距）
- b = 价格每涨 1 元，需求量减少 b 个（斜率）

### 例题

**题目：** Q = 20 - 2P

```
解读：
- 当 P = 0 时，Q = 20（最多卖 20 个）
- 当 P = 10 时，Q = 0（一个都卖不出去）
- 价格每涨 1 元，需求量减少 2 个
```

### 反需求函数（把 P 放在左边）

$$P = \frac{a}{b} - \frac{1}{b}Q$$

**例题：** Q = 20 - 2P → P = 10 - 0.5Q

---

## 二、需求曲线

```
  价格 P
    ↑
 10 |╲
    |  ╲
    |    ╲  需求曲线
    |      ╲
    |        ╲
  0 ┼──────────╲──→ 数量 Q
    0          20
```

- 需求曲线**向右下方倾斜**（价格越高，需求越少）
- 斜率 = -1/b = -1/2 = -0.5

---

## 三、需求变动 vs 需求量变动

| | 需求量变动 | 需求变动 |
|--|----------|---------|
| 原因 | 商品自身价格变化 | 其他因素变化 |
| 图形 | 沿需求曲线移动 | 整条曲线平移 |
| 举例 | 奶茶从 30 涨到 40，买的人少了 | 收入增加，买奶茶的人多了 |

### 导致需求曲线平移的因素
- 收入变化
- 相关商品价格变化
- 消费者偏好变化
- 预期变化
- 消费者数量变化
