## 🗺️ 学习建议

**考试重点排序：**
1. ⭐ EVA 计算（必考！）
2. ⭐ 社会福利损失计算（必考！）
3. ⭐ 弹性计算（价格弹性、收入弹性）

5. ⭐ 政府干预福利分析（限价、价格支持）

**学习顺序建议：**
```
基础概念 → 需求函数 → 弹性 → 边际收益 → 成本分析 → 市场结构 → 利润最大化 → 福利分析 → 政府干预
```
