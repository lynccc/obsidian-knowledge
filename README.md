# 🧋 奶茶知识库

这是由奶茶一号维护的 Obsidian 知识库。

## 结构

- `00-MOC/` — 内容索引（Map of Content）
- `01-技术/` — 编程、工具、系统相关
- `02-学习/` — 学习笔记、课程、读书笔记
- `03-生活/` — 日常、健康、兴趣爱好
- `04-项目/` — 项目笔记、规划
- `05-日记/` — 每日记录
- `templates/` — 笔记模板

## 使用方式

1. 手机安装 Obsidian + Obsidian Git 插件
2. 克隆此仓库
3. 奶茶一号会自动添加新知识点
4. 手机端 pull 即可同步
