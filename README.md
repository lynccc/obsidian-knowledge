# 🧋 奶茶知识库

这是由奶茶一号维护的 Obsidian 知识库。

## 📱 同步方式

使用 **GitSync.md** App 进行 Git 同步（iOS）。

### 拉取新内容
1. 打开 GitSync.md
2. 点仓库旁边的 **Pull**
3. 回到 Obsidian 就能看到新笔记

### 同步修改
1. 在 Obsidian 里编辑笔记
2. 回到 GitSync.md 点 **Push**
3. 奶茶一号就能看到你的修改

## 📂 目录结构

```
obsidian-vault/
├── 00-MOC/          ← 内容索引（Map of Content）
├── 01-技术/         ← 编程、工具、系统
├── 02-学习/         ← 学习笔记
├── 03-生活/         ← 日常、兴趣
├── 04-项目/         ← 项目笔记
├── 05-日记/         ← 每日记录
├── templates/       ← 笔记模板
└── attachments/     ← 附件
```

## 🔄 工作流程

```
你告诉奶茶一号知识点
      ↓
奶茶一号拆解成原子笔记
      ↓
添加双向链接和标签
      ↓
推送到 GitHub
      ↓
你在 GitSync.md 点 Pull
      ↓
Obsidian 自动显示新笔记 ✨
```
